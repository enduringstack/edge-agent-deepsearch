Governing MCP tool calls in .NET with the Agent Governance Toolkit

7 官方动态 开源 2026-04-29 · Microsoft / Microsoft
Microsoft方向:工具调用方向:安全隐私应用:安全
这是什么微软演示如何用开源的 Agent Governance Toolkit 给 .NET 里的 MCP 工具调用加一道治理层：执行前审查调用、扫描可疑工具定义、清洗工具返回内容。
有什么结果未报告
怎么做到McpGateway 在执行前评估每次工具调用，McpSecurityScanner 检查可疑工具定义，McpResponseSanitizer 去除工具输出中的提示注入、凭据和外传链接，GovernanceKernel 用 YAML 策略、审计事件和 OpenTelemetry 串起来；无需外部服务，可在本地运行。
评分依据：工具调用安全治理可直接用于本地运行的 Agent，但文章本身不涉及设备端部署（相关度 3）；把工具调用前后的防护做成可组合组件，工程价值较好（贡献 4）。
