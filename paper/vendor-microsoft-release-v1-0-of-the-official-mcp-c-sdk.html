Release v1.0 of the official MCP C# SDK

6 官方动态 开源 2026-03-05 · Microsoft / Microsoft
Microsoft方向:工具调用
这是什么官方 MCP（模型上下文协议）C# SDK 发布 1.0，完整支持 2025-11-25 版 MCP 规范，.NET 应用可以用它把工具、资源和提示词提供给智能体，或作为客户端调用这些工具。
有什么结果未报告
怎么做到新版补齐授权服务器发现（可在 well-known 地址提供受保护资源元数据）、工具和资源的图标等元数据、新的工具调用模式、向用户追问信息（elicitation）以及长时间请求处理。
评分依据：属于 Agent 工具调用协议的基础设施，桌面 .NET 应用可直接接入；但它是协议 SDK 的工程版本发布，与端侧推理本身关系不大。
