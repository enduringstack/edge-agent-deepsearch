Anonymous-by-Construction: An LLM-Driven Framework for Privacy-Preserving Text

7 学校预印本 2026-03-17 · Federico Albanese; Pablo Ronco; Nicolás D'Ippolito / arXiv
方向:安全隐私
这是什么用本地部署的大模型把文本中的个人隐私信息替换成同类型的逼真替身，让数据既能匿名又不丢语义，可安全喂给第三方 Agent 或用于后续微调。
有什么结果在 Action-Based Conversation Dataset 上，隐私保护、语义保持和可训练性综合表现超过 Microsoft Presidio、Google DLP、命名实体识别基线和 ZSTS（摘要未给出具体数字）。
怎么做到在组织内部用本地大模型识别隐私字段并生成类型一致的替身文本，作为问答 Agent 调用外部大模型之前的匿名化中间层。
评分依据：强调本地私有部署大模型做隐私保护，但“本地”指企业内网服务器而非终端设备，端侧相关度偏低；评测维度较完整。
