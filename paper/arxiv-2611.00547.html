BitLLM: Efficient Low-Bit, Conversion-Hiding LLM Decoding on Mobile GPUs

16 学校预印本 2026-10-31 · Hangyu Zheng; Zhihao Shu; Kunxiong Zhu; Minghai Qin; Xiaolong Ma; Gagan Agrawal; Wei Niu / arXiv
方向:推理框架方向:量化方向:KV cache方向:能耗功耗硬件:手机硬件:GPU硬件:Snapdragon模型:Llama
这是什么手机 GPU 上跑低比特量化的大模型，往往并不比 FP16 快，原因是量化数和浮点数之间频繁转换、KV cache 增长导致访存零散。BitLLM 是专门解决这两个问题的手机端推理引擎。
有什么结果在 OnePlus 12（Snapdragon 8 Gen 3，Adreno 750）上，相比 llama.cpp、MNN-LLM、LiteRT-LM 和 MLC-LLM 平均分别快 1.78、1.73、1.58 和 1.47 倍；长上下文生成时每 token 能耗最多降低 88.9%；在 OnePlus 11 和 Pixel 8（Mali GPU）上也验证了可移植性。
怎么做到给 KV cache 设计自适应的布局与打包方式，保证解码全程访存连续；同时让关键矩阵乘留在整数域执行，把类型转换推迟并与计算重叠，移出热路径。
评分依据：直接在三款真机手机 GPU 上实测，并与四个主流端侧推理引擎正面对比；指出手机 GPU 缺少原生低比特指令导致类型转换成为瓶颈，这一诊断和整数原生流水线都有新意。
