How to Build In-Vehicle AI Agents with NVIDIA: From Cloud to Car

15 官方动态 2026-05-05 · NVIDIA / NVIDIA
NVIDIA方向:端侧agent方向:端云协同方向:工具调用方向:多模态应用:语音硬件:GPU
这是什么NVIDIA 讲解如何在汽车上做本地运行的多模态座舱 Agent：模型跑在车端 DRIVE AGX 计算盒上，复杂任务再与云端 Agent 协作。
有什么结果正文未给出实测基准；列出的车端要求是本地运行 7B 以上模型、响应时间低于 500ms、解码速度超过每秒 30 token，并称基于 DRIVE AGX 的 AI Box 可运行约 130 亿参数的大模型。
怎么做到车端流水线由语音识别、NeMo Agent Toolkit 编排、TensorRT Edge-LLM 推理和语音合成组成；编排器按意图把导航、车辆控制等实时任务交给本地 Agent，把网页搜索、行程规划等交给云端 Agent，并同步上下文、处理断网回退。
评分依据：规划和工具调用闭环（导航、车辆 API 调用、摄像头问答）实际运行在车端 Orin/Thor 计算盒上，云端只承担非实时任务，是典型的端云协同端侧 Agent；内容偏参考架构，缺少实测数字。
