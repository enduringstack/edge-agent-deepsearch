Learning When to Remember: Risk-Sensitive Contextual Bandits for Abstention-Aware Memory Retrieval in LLM-Based Coding Agents

9 学校预印本 开源 2026-04-30 · Mehmet Iscan / arXiv
方向:记忆方向:安全隐私应用:代码
这是什么编码 Agent 会复用过去的调试经验，但相似的报错不一定能用同一个修法，盲目注入记忆反而会帮倒忙。RSCB-MC 把“要不要用记忆、用哪种方式”变成一个风险敏感的决策问题。
有什么结果小规模离线回放中成功率 62.5%，为非理想方法最高，误注入率 0%；200 例热路径验证中代理成功率 60.5%、误注入 0%，决策 p95 时延约 331 微秒。
怎么做到把检索证据压成 16 维上下文特征（相关性、不确定性、结构兼容性、反馈历史、时延和 token 成本等），用风险敏感的上下文老虎机在不用记忆、注入、摘要、放弃、请求反馈等动作里选择，并对误注入施加更重惩罚。
评分依据：Agent 记忆运行时的安全控制，决策开销在微秒级，思路可迁移到端侧 Agent，但实验规模小且非设备侧。代码与数据已在论文所列仓库公开。
