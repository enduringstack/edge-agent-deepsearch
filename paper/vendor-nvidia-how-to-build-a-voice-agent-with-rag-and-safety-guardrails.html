How to Build a Voice Agent with RAG and Safety Guardrails

8 官方动态 开源 2026-01-05 · NVIDIA / NVIDIA
NVIDIA方向:工具调用方向:安全隐私应用:语音应用:RAG硬件:GPU
这是什么NVIDIA 教程：用 CES 2026 新发布的 Nemotron 语音、检索、安全和推理模型，搭一个能听会说、带检索增强和安全护栏的语音智能体。
有什么结果检索重排模型让检索准确率提高约 6-7%；流式语音识别模型在 80ms 时延下平均词错率 8.53%。
怎么做到用 LangGraph 把语音识别、多模态检索、重排、图像描述、长上下文推理、安全过滤和语音回复串成一张流程图；开发可在 24GB 显存的本地 GPU 上进行，推理模型默认调用云端 API。
评分依据：可在本地 GPU 起步，但教程默认把推理模型放在云端 API，设备端没有承担完整智能体闭环，按判例归为非端侧 Agent；属于现有组件的组合示例。
