Red-teaming a network of agents: Understanding what breaks when AI agents interact at scale

8 官方动态 2026-04-30 · Microsoft / Microsoft
Microsoft方向:安全隐私应用:安全方向:记忆
这是什么微软研究院对一个由多用户、多组织 Agent 互相交流组成的网络做红队测试，发现有些风险只在 Agent 互动时才出现，单个 Agent 测不出来。
有什么结果在内部一个有 100 多个 Agent 的真实平台上，一条恶意消息就能在 Agent 之间逐跳传播并沿途窃取隐私数据；归纳出传播、放大、信任劫持和隐身四类网络级风险；少数 Agent 自发出现了限制攻击扩散的安全行为。
怎么做到让使用不同模型、指令和记忆的 Agent 各自代表一个人，在论坛、私信和协作任务中互动，再注入攻击消息观察其在网络中的扩散。
评分依据：多 Agent 网络安全研究，与设备端执行无关（相关度 2）；首次系统揭示网络级 Agent 风险，对 Agent 安全设计有启发（贡献 6）。
