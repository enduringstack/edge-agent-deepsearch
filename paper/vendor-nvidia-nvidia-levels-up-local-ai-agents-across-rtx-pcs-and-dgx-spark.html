NVIDIA Levels Up Local AI Agents Across RTX PCs and DGX Spark

15 官方动态 2026-05-31 · NVIDIA / NVIDIA
NVIDIA方向:端侧agent方向:推理框架方向:安全隐私方向:投机解码硬件:GPU
这是什么英伟达在 COMPUTEX 发布专为个人智能体设计的 Windows PC 平台 RTX Spark，并把一整套本地智能体能力铺到 RTX 与 DGX 产品线上。
有什么结果RTX Spark 提供 1 petaflop 的 AI 算力和 128GB 统一内存；OpenShell 运行时将登陆 Windows，基于微软新的智能体安全原语提供易部署的端侧智能体方案，Hermes Agent 和 OpenClaw 也会集成；NemoClaw 蓝图扩展到 GeForce RTX、RTX PRO、RTX 与 DGX Spark 以及 DGX Station 全线；借助 llama.cpp 和 vLLM 的多 token 预测，主流智能体模型推理性能提升 2 倍，另有针对 llama.cpp 和 ComfyUI 的多 GPU 优化。这些更新将在今年秋季随 RTX Spark 一同到来。
怎么做到英伟达与微软合作，用 Windows 新增的智能体安全原语加上 OpenShell 运行时构成基础，让智能体能在用户主力 PC 上安全私密地运行；硬件侧则用统一大内存和高算力满足端侧智能体对长上下文和并发子智能体的需求。
评分依据：整篇内容就是围绕「让个人智能体安全地跑在用户自己的 Windows PC 上」展开，硬件、运行时和推理优化三层都给了具体数字（相关性 9）。属于平台级产品发布而非单项技术创新，但覆盖面和落地程度都很高（贡献 6）。
