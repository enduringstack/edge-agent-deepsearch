This Is Taking Too Long -- Investigating Time as a Proxy for Energy Consumption of LLMs

6 学校预印本 开源 2026-03-16 · Lars Krupp; Daniel Geißler; Francisco M. Calatrava-Nicolas; Vishal Banwari; Paul Lukowicz; Jakob Karolus / PerCom 2026
方向:能耗功耗方向:云端serving硬件:GPU
这是什么调用云端大模型 API 时用户看不到能耗，本文研究能否只靠测量响应时间来估算这些 API 背后的能耗。
有什么结果通过与本地部署同款模型的实测能耗对比，发现时间测量可以推断出 API 背后使用的 GPU 型号，从而支撑能耗估算；摘要未给出误差数字。
怎么做到在本地部署对应的开源模型，测出推理时间和实际能耗的关系，再用 API 的响应时间反推 GPU 类型和能耗。
评分依据：研究对象是云端 API 的能耗透明度，与端侧部署关系较远；用时延当能耗代理的思路简单实用。
