MemToolAgent: Leveraging Memory for Tool Using Agents Based on Environment and User Feedback

7 学校预印本 2026-06-06 · Suleyman Armagan Er; Danilo Ribeiro; Yogesh Virkar; Surafel Lakew; Adi Kalyanpur; James Gung; Thomas Delteil; Arshit Gupta / arXiv
方向:记忆方向:工具调用
这是什么研究怎么用记忆机制提升智能体的工具调用能力，让它从过往的用户对话和环境反馈里学到经验。
有什么结果相对强基线，在 WorkBench、NESTFUL 和 PEToolBench 三个基准上分别取得 29%、80% 和 17% 的相对提升，而且不需要微调模型。
怎么做到三部分：一个统一的记忆条目格式，同时改善通用和个性化的工具使用；一个基于反思的记忆抽取模块，用环境和用户反馈把错误执行提炼成批评意见存下来；一个检索模块，按记忆相似度分布动态决定取用多少条过往经验。
评分依据：不需微调即可提升工具调用，这条路线对无法在设备上训练的端侧助手有借鉴意义，但原文不涉及部署位置。把错误执行提炼成批评意见存入记忆，是实用的设计。
