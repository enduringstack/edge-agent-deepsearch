HearthNet: Edge Multi-Agent Orchestration for Smart Homes

14 学校预印本 2026-03-16 · Zhonghao Zhan; Krinos Li; Yefan Zhang; Hamed Haddadi / CAIS 2026 Demo Track
方向:端侧agent方向:端云协同方向:记忆方向:工具调用应用:IoT命令硬件:Apple-Silicon硬件:手机
这是什么一个跑在家庭网关上的多智能体智能家居系统：用户用自然语言下指令，多个常驻 Agent 在本地协作规划、校验、授权并直接控制灯、音箱、摄像头、电视等真实设备。
有什么结果三个现场演示场景中，过期指令 5/5 被拒、过期或无效授权 5/5 被拒、误拒 0 次，153/153 个事件写入 Git 留痕；授权校验开销 p95 小于 0.01 毫秒，端到端时延主要来自云端大模型每跳 1-5 秒。
怎么做到根 Agent、管理 Agent、记录 Agent 常驻在本地硬件上，通过 MQTT 通信、用 Git 仓库保存共享状态和执行历史；执行前核对状态版本防止旧指令，由根 Agent 发放短时可校验的执行租约，再经轻量适配器驱动设备。
评分依据：Agent 的编排、状态记忆、校验授权和设备执行闭环都在家里的 Mac mini、NUC 和 Android 手机上运行，只有大模型推理调用云端 API，符合端侧 Agent 定义；用 Git 做共享状态和执行租约来保证安全执行，思路新颖。论文为 CAIS 2026 演示赛道。
