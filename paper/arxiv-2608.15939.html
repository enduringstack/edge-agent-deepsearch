Aborted but Not Forgotten: KV-Cache Retention Breaks Rollback Consistency in Language Agents

12 学校预印本 2026-08-16 · Guijia Zhang; Harry Yang / arXiv
方向:KV cache方向:安全隐私方向:记忆模型:Phi模型:Qwen
这是什么有状态的语言 Agent 默认：把一个被否决的分支从对话记录里删掉，就等于撤回了它。本文发现，如果推理服务在逻辑回滚后仍保留 KV cache，模型其实还在“看”应用以为已经删掉的内容，可能被攻击者利用。
有什么结果在 7 个 3.8B–36B 开源模型家族上审计 63 个单元，仅靠残留的 KV cache 就在 25 个单元里翻转了受保护的行为，而攻击者的 token 在全部 63 个单元的实际请求中都不存在；重建缓存后所有单元恢复正常。该问题在端到端会话应用、Hugging Face Transformers 默认缓存复用路径和 LangGraph 时间回溯中都能复现。
怎么做到提出“回滚一致性”：完整的撤销必须恢复模型实际关注的状态，而不只是对话文本；设计“相同 token、不同缓存”的审计方法，决策步输入完全一致，只改变缓存前缀是陈旧的还是从已提交状态重建的；修复只需在事务内局部恢复缓存，无需全局清空。
评分依据：问题出在 Agent 运行时的 KV cache 复用上，本地小模型（如 Phi-3.5-mini、GLM-4-9B）同样受影响，对端侧 Agent 运行时设计有直接借鉴（相关度 5）。指出逻辑回滚与推理状态之间的跨层漏洞并给出低成本修复，是新颖的安全发现（贡献 7）。
