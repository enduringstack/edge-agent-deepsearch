Windows platform security for AI agents

14 官方动态 2026-06-02 · Dana Huang; Logan Iyer (Microsoft) / Microsoft
Microsoft方向:安全隐私方向:工具调用应用:安全
这是什么微软为在 Windows 上运行的智能体推出执行容器 MXC 的早期预览：开发者用策略声明智能体能碰哪些文件和网络，系统在运行时强制隔离，防止本地智能体越权。
有什么结果未报告
怎么做到MXC 是一层跨平台、按策略执行的隔离层，同一套策略可映射到不同强度的隔离机制：进程隔离限制智能体进程访问策略之外的文件和网络域名；会话隔离让智能体在独立的 Windows 会话和账户中运行，与用户桌面、剪贴板和输入设备分开，并可用本地或 Entra 身份审计。GitHub Copilot CLI 已采用进程隔离，OpenClaw 已经通过 MXC 在 Windows 上隔离运行，后续计划加入基于虚拟化的微型虚拟机。
评分依据：本地运行、能改文件和执行代码的电脑智能体第一次拿到操作系统级的策略化沙箱，直接关系到 PC 端侧智能体能否安全落地（相关度 8）。方案是把已有隔离原语统一成策略层，工程整合为主，文中没有性能数字（贡献 6）。
