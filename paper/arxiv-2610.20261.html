Harness Policy Distillation: Aligning Agent Policies with Runtime Semantics

8 学校预印本 开源 2026-10-14 · Junze Zhu; Weihao Chen; Zhiyang Zhou; Zhen Wu; Xinyu Dai / arXiv
方向:蒸馏方向:工具调用模型:Qwen
这是什么把通用模型放进具体产品的 Agent 运行框架里时，框架规定了哪些动作可执行、状态怎么推进、何时结束，但普通轨迹数据没把这些规则教给模型。这篇工作提出一种蒸馏训练方法，让模型学会遵守运行框架的语义。
有什么结果在 TRAJECT-Bench 的 Pi 框架上，用该方法训练的 Qwen3-8B 自主任务成功率达 22.98%、运行时合规率 49.23%，未适配模型分别只有 3.09% 和 19.90%。
怎么做到把参考轨迹在运行框架中重放，恢复每次调用模型时隐含的控制状态，写成控制文档作为教师的特权信息生成可执行动作，再联合训练学生模型，部署时无需额外文档。
评分依据：研究 Agent 运行时框架与模型策略的对齐，属于 Agent 运行时相邻技术，但实验在云端模型上进行，无端侧部署；把运行时语义变成训练监督的思路有一定新意。作者来自南京大学。
