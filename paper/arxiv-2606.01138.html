memorywire: A Vendor-Neutral Wire Format for Agent Memory Operations

7 学校预印本 2026-05-31 · Thamilvendhan Munirathinam / arXiv
方向:记忆方向:工具调用方向:安全隐私
这是什么给各家智能体记忆框架定一套通用的数据交换格式，让记忆能迁移、也能被人审核。
有什么结果参考实现带五个后端适配器；在 100 条事实、50 条查询的标注语料上，42 条有标准答案的查询取得 recall@5 为 1.000，写入中位时延 37.8 毫秒、召回中位时延 40.6 毫秒；对抗融合实验显示倒数排名融合在注入干扰下仍保持 recall@5 为 1.000，而取最大值的融合会跌到 0.500 并有 80% 泄漏；16 个场景的跨适配器一致性测试 80 格中通过 68 格、零失败。
怎么做到用 JSON Schema 定义五种记忆操作（记住、召回、遗忘、合并、过期）和四类记忆（语义、情景、程序、情绪），配一个记忆存储接口、一个扇出路由器和可选的人工审核通道；作者明确说贡献不是新算法，而是把已有成熟组件打包成中立协议。
评分依据：记忆层的互操作协议，对端侧智能体的可移植性有间接价值，但工作本身不涉及设备约束（相关性 3）。作者自述是工程打包而非算法创新，不过实测和一致性套件做得比较实在（贡献 4）。
