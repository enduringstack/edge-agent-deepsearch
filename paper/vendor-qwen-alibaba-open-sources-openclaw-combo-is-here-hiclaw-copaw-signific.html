Alibaba Open Sources "OpenClaw" Combo Is Here: HiClaw & CoPaw, Significantly Reduces Memory Footprint

11 官方动态 开源 2026-03-17 · Qwen / Qwen
Qwen方向:工具调用方向:记忆方向:推理框架
这是什么阿里云原生团队开源的 HiClaw 1.0.4 把轻量 Python 智能体 CoPaw 接成多智能体系统里的工作节点，解决每个 OpenClaw 工作节点吃内存太多、又碰不到用户本机环境的问题。
有什么结果官方给出的对比：OpenClaw 工作节点约占 500MB 内存，CoPaw 容器模式约 150MB；同样 8GB 内存原先只能跑 8-10 个工作节点，现在可跑 40 个以上。
怎么做到管理节点和各工作节点统一走 Matrix 协议通信，CoPaw 只需实现约 450 行的 Matrix 通道和约 230 行的配置桥接即可接入；本地模式下用 pip 把工作节点装到用户电脑上，直接操作浏览器、本地文件和桌面应用，并用 ReMe 自动压缩和召回对话记忆。
评分依据：工作节点可直接在个人电脑上执行浏览器、文件和桌面操作，并把运行时内存压到约 150MB，对本地 Agent 运行时有参考价值；但推理仍调用云端模型接口，属云端模型驱动的智能体。贡献主要是工程整合与轻量化。
