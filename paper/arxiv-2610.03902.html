When Evidence Changes: Evaluating Memory Repair and Re-reading in Language-Model Agents

7 学校预印本 2026-10-02 · Wenhui Chu / arXiv
方向:记忆方向:评测基准模型:Qwen模型:Mistral
这是什么Agent 从文档里提炼出的事实存进记忆后，如果原文档被撤回或替换，是该修补记忆，还是直接重读最新文档？论文用公开 ICU 病历中的用药和问题清单任务，把两种做法的全流程成本放在一起比较。
有什么结果在 Qwen2.5-7B 和 Mistral-7B 上，短病历时局部修补所需的修订 token 比整体重建少 5–10 倍，但在留出条件下所有记忆方案的总成本都至少是全文重读的 2 倍；病历加长到约 10,000 token 后，记忆方案要被使用 2–14 次累计成本才低于全文重读，而“只重读相关来源”始终最便宜。替换实验中四项预注册检验均未达到统计显著。
怎么做到设计撤回、替换和对照三类证据变更事件，比较全文重读、按来源过滤重读、缓存、整体重建和基于依赖图的局部修补五种做法，把写入、修订和每次使用的 token 成本全部计入。
评分依据：讨论 Agent 记忆维护的成本取舍，结论对算力受限的 Agent 记忆设计有参考意义，但实验在服务器端 7B 模型上进行，相关度 3。以全流程成本比较记忆修补与重读并采用预注册检验，评估严谨但属于实证分析，贡献 4。
