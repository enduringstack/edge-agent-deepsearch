Locomo-Plus: Beyond-Factual Cognitive Memory Evaluation Framework for LLM Agents

8 公司项目 开源 2026-02-11 · Yifei Li; Weidong Guo; Lingling Zhang; Rongman Xu; Muye Huang; Hui Liu; Lijiao Xu; Yu Xu / arXiv
Tencent方向:记忆方向:评测基准模型:Qwen
这是什么LoCoMo-Plus 是一个考察对话智能体“认知记忆”的基准：看模型能否记住用户之前透露的状态、目标、价值观等隐含约束，并在很久之后语义不直接相关的提问中正确用上。
有什么结果所有被测方法从原 LoCoMo 到 LoCoMo-Plus 都大幅下滑：gemini-2.5-pro 平均分从 71.78 跌到 26.06，GPT-4o 从 62.99 跌到 21.05；Mem0、SeCom、A-Mem 三个记忆系统在 LoCoMo-Plus 上只有 15.8、14.9、17.2 分，检索增强方法为 12.3~15.6 分；所用 LLM 评审与两名人工标注的一致度为 0.80 和 0.82。
怎么做到构造“线索”和“触发提问”之间语义脱节的长对话样本，评测时不告诉模型任务类型，并用“回答是否满足先前隐含约束”的一致性判断取代字符串匹配，统一评估开源/闭源模型、检索方法和记忆系统。
评分依据：关注智能体长期记忆评测，对个人助理类端侧智能体的记忆设计有参考，但实验与设备无关，端侧相关度低；揭示了现有记忆评测的提示泄题和长度偏差，基准设计有一定新意。作者机构依据：arXiv PDF 首页作者 Weidong Guo、Hui Liu、Lijiao Xu、Yu Xu 署名 Tencent。 作者机构依据：arXiv PDF 首页署名 Tencent（PDF 首页作者 2、6、7、8（Weidong Guo、Hui Liu、Lijiao Xu、Yu Xu）署名 Tencent，其余作者署名西安交通大学）。
