openvinotoolkit/openvino: [NPU] Properties refactoring (#34315)

7 开源大项目 开源 2026-02-26 · openvinotoolkit / GitHub
方向:编译部署方向:推理框架硬件:NPU
这是什么OpenVINO 英特尔 NPU 插件的一次配置属性重构，理清哪些设置交给编译器、哪些留在插件内部处理。
有什么结果未报告
怎么做到新增在不需要编译器配置时关闭编译器属性的路径，重命名按编译器取配置的接口，编译器返回空属性列表时不再退回旧模式，并且不再把编译器不支持的属性下发给它，同时补充导入路径的测试。
评分依据：改动集中在英特尔 PC 端 NPU 插件，与端侧 NPU 部署链路直接相关；但只是内部配置重构，对使用者几乎没有可见新能力。
