SplitZip: Ultra Fast Lossless KV Compression for Disaggregated LLM Serving

9 学校预印本 开源 2026-05-03 · Yipin Guo; Siddharth Joshi / arXiv
方向:云端serving方向:KV cache硬件:GPU
这是什么SplitZip 是一个跑在 GPU 上的无损 KV cache 压缩器，用来加速预填充与解码分离部署时 KV cache 在机器之间的传输。
有什么结果在真实 BF16 激活上压缩吞吐 613.3 GB/s、解压 2181.8 GB/s；端到端 KV 传输加速最高 1.32 倍、首 token 时延加速 1.30 倍、请求吞吐提升 1.23 倍；FP8 KV cache 相对原生 E5M2 还能再压 1.14 倍。
怎么做到利用 KV 激活浮点指数高度集中的特点，用预先校准的前 16 个常见指数码表做定长编码，罕见指数走稀疏的位置加数值旁路，编解码都适合 GPU 并行。
评分依据：面向数据中心的预填充/解码分离 serving，与端侧关系较远。指数分流的无损编码思路简洁有效，代码开源。
