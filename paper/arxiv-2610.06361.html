Capability-Driven Self-Evolution of Agent Memory

这是什么智能体的记忆模块可以写成可执行程序，再根据任务反馈让 LLM 反复改进。PrisMem 改为按“能力维度”分别诊断和优化，避免整体分数掩盖某项能力的进步或退步。
有什么结果在百万 token 级历史的 BEAM-1M 和 LongMemEval-M 上，分别比最强基线高 10.54 和 7.83 个百分点。
怎么做到把记忆程序拆成抽取、索引、规划、检索、回答五个部分；按依赖关系优先挑选可能带来跨能力收益的目标，用历史引导的诊断培养各项能力的专项改进者，再在成对差异样例上比较不同版本的行为，把互补的改进合并成一个统一的记忆程序。
