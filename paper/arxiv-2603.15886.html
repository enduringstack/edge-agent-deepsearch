PhasorFlow: A Python Library for Unit Circle Based Computing

5 学校预印本 开源 2026-03-16 · Dibakar Sigdel; Namuna Panday / arXiv
方向:模型架构
这是什么PhasorFlow 是一个开源 Python 库，用单位圆上的复数相量来做计算，提供一套类似量子线路的“相量电路”编程方式。
有什么结果在金融波动检测、神经形态联想记忆、周期发现等示例任务上做了功能验证，未报告与主流方法的量化对比。
怎么做到把输入编码成单位圆上的相位，通过保持范数的干涉门运算；提供 22 种门、可训练的变分相量电路，以及用无参数 DFT 混合代替注意力的相量 Transformer。
评分依据：属于新计算范式的软件库，与端侧推理部署关联很弱；概念新颖但验证有限。
