Small Agents with Semantic Search: Efficient Multilingual Code Localization

12 学校预印本 2026-10-04 · Maxence Lasbordes; Aarush Sinha; Raphael Sourty; Amélie Chatelain; Djamé Seddah / arXiv
方向:工具调用应用:代码应用:RAG硬件:CPU模型:Qwen模型:MiniCPM
这是什么编程智能体改代码前要先找到该改哪些文件，这一步往往要反复 grep 和读文件，费 token 又慢。这篇工作训练 20 亿参数以下的小模型专门做文件定位，配上本地语义搜索工具 ColGREP，让这一步可以交给能在本地运行的小智能体。
有什么结果Qwen3-1.7B 经过监督微调和强化学习后，用 ColGREP 在 SWE-bench Lite 上文件定位 F1 为 67.29（用 grep 为 63.75），在 Multi-SWE-bench Flash 上为 54.00（grep 为 50.16），在 SWE-bench Lite 上与 DeepSeek-V4-Flash（63.96）和 Qwen3-32B（63.50）相当；纯 CPU 推理时每条轨迹端到端时延从 36.08 秒降到 20.18 秒（减少 44.1%），token 用量减少 29.1%；对训练中没见过的编程语言泛化也更好。
怎么做到ColGREP 是基于多向量后期交互检索的本地语义搜索工具（单个 Rust 程序，无需服务器）；先用教师模型轨迹做加权监督微调，按每轮检索结果分配功劳，再以文件定位质量为奖励做强化学习，训练 Qwen3、LFM2.5、MiniCPM 三个系列的小模型学会写查询、看结果、选文件。
评分依据：小模型加本地检索工具的智能体可以在本机运行、减少调用大模型，方向贴近 PC 端编程智能体，但时延是在双路 Xeon 服务器 CPU 上用 llama.cpp 测的，没有在个人电脑上实测，判为非端侧智能体，相关度 6。系统比较了语义搜索与词法搜索对小模型智能体的影响并给出训练配方，贡献 6。
