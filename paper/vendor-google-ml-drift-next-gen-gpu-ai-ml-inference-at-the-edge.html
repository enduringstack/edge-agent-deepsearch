ML Drift: Next-Gen GPU AI/ML Inference at the Edge

16 官方动态 开源 2026-10-08 · Google / Google
Google方向:推理框架方向:编译部署方向:KV cache方向:量化硬件:GPU硬件:手机模型:Gemma
这是什么Google AI Edge 开源 ML Drift：一个跨 OpenGL ES、OpenCL、Metal 和 WebGPU 的端侧 GPU 推理引擎，作为 LiteRT 的核心 GPU 加速器，取代旧的 TFLite GPU delegate。
有什么结果在 Gemma 测试中内存开销比其他框架最多低 12%；YouTube Shorts 迁移后安卓和 iOS 平均帧延迟最多降 40%；Google Photos 比旧 GPU delegate 最多快 2 秒；Adobe Lightroom/Photoshop 移动端相关 AI 功能最多快 30%；Snapchat 滤镜模型延迟改善 30%；已在每天数百万台设备上运行。
怎么做到用张量虚拟化把逻辑张量和物理 GPU 对象解耦，一套着色器模板覆盖多个图形 API；支持 5D 张量和可扩展的自定义算子；针对端侧 LLM 在 prefill 和 decode 阶段切换不同内核与布局，decode 时采用与卷积对齐的 KV cache 布局并在内核中做激活量化，减少多余的显存往返；借助 Dawn 还能原生运行在 Windows 和 Linux 桌面上。
评分依据：这是覆盖手机、浏览器和桌面的端侧 GPU 推理运行时，并有大规模线上产品数据，端侧相关度很高。张量虚拟化统一着色器和面向 LLM 分阶段切换内核是实打实的系统创新，且以 Apache 2.0 开源。
