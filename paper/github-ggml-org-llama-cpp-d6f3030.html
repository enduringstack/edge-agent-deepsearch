ggml-org/llama.cpp: ggml: backend-agnostic tensor parallelism (experimental) (#19378)

9 开源大项目 开源 2026-04-09 · ggml-org / GitHub
方向:推理框架方向:高效推理硬件:GPU
这是什么llama.cpp 合入实验性的张量并行功能，让一个模型的权重和 KV cache 可以按张量切分到多块 GPU 上同时计算，而不只是按层串行切分。
有什么结果未报告
怎么做到在 ggml 里新增一个与具体后端无关的“元后端”，把张量按维度切到多设备并做 AllReduce，可选 NCCL/RCCL 通信；命令行新增 tensor 切分模式，已支持 GPT-OSS、Qwen3 MoE、Qwen3.5 和 Gemma 4 等模型。
评分依据：llama.cpp 是端侧推理的主力引擎，但这次改动面向多 GPU 工作站和服务器的并行推理，与手机等单设备场景关系有限。后端无关的张量并行设计在工程上有一定新意，仍为实验功能。
