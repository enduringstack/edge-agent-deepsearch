VaLiDRec: Variable-Length LLM-Aligned Semantic IDs for Generative Recommendation

7 学校预印本 2026-07-28 · Shutong Qiao; Wei Yuan; Tong Chen; Hao Wang; Quoc Viet Hung Nguyen; Hongzhi Yin / arXiv
方向:高效推理方向:云端serving
这是什么一种生成式推荐框架，直接用大模型词表里的原生 token 给商品编变长“语义 ID”，免去自回归逐字生成和束搜索。
有什么结果在 4 个真实数据集上全面超过序列推荐和生成式推荐基线，冷启动零样本表现更好，推理速度比 LC-Rec 快 87.49 倍。
怎么做到通过 token 重要性估计、语义质量感知剪枝和防冲突修正，从大模型词表中挑出能代表商品的 token 组成变长 ID；再把推荐改写为 token 集合预测并逐 token 打分。
评分依据：属于推荐系统模型设计，推理加速主要来自去掉自回归解码，对端侧仅有间接参考，相关度低。作者来自昆士兰大学等高校。
