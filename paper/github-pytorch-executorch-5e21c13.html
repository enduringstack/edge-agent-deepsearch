pytorch/executorch: Samsung Exynos AI LiteCore - Support yolo26 (#22960)

14 开源大项目 开源 2026-10-05 · pytorch / GitHub
方向:编译部署方向:量化硬件:NPU方向:推理框架
这是什么ExecuTorch 给三星 Exynos 的 AI 加速后端补上了 YOLO26 模型支持，让这个检测模型能在三星芯片上做量化推理。
有什么结果这次提交涉及 24 个文件、新增 1085 行，包含针对 E9955 芯片上 YOLO26 做 A8W8 量化的测试文件与验证脚本；提交本身没有给出精度或时延数字。
怎么做到新增一个把取余运算拆成整除、乘法和减法的分解通道；补上 amax、floor、floor_divide、gather、max_dim 等算子构建器并重构了除法、索引、切分、topk 和上采样等已有实现；同时改进量化参数标注算法，使其能处理 YOLO26 里更复杂的图拓扑和扇出结构。
评分依据：ExecuTorch 是 PyTorch 官方的端侧部署路径，这次是直接给三星手机芯片的 AI 加速后端扩算子和量化支持，端侧契合度很高。工作内容是算子覆盖与量化标注的工程扩展，不是新方法。
