SkillMemo: Expert-guided Skill Memory Framework for Compositional Embodied Manipulation

8 学校预印本 2026-08-06 · Changyuan Wang; Chubin Zhang; Zhenyu Wu; Runhao Li; Angyuan Ma; Ke Chao; Yinan Liang; Xiuwei Xu / arXiv
方向:记忆方向:MoE应用:机器人
这是什么SkillMemo 给机器人操作策略加了一个“技能记忆库”：把长示范拆成可复用的原子技能存起来，执行新的组合任务时检索相关技能辅助动作预测。
有什么结果在仿真基准和真实机器人操作任务上，持续提升扩散策略和 VLA 两类底座，取得最好成绩并超过 π0.5，对没见过的任务组合泛化更好；摘要未给出具体数字。
怎么做到用混合专家结构把轨迹隐式切分成技能原语，把紧凑的技能表示以键值对存进情景记忆库，推理时检索并与当前门控分布融合。
评分依据：机器人操作策略的记忆增强，属于具身动作模型，没有端侧部署与算力约束讨论（相关度 3）。技能级记忆设计有一定新意（贡献 5）。
