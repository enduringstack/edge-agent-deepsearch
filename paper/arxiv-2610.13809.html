GPU-resident Execution for Timing-predictable Sensor Processing Systems

14 公司项目 2026-10-09 · Soham Sinha; Rahul Choudhury; Shekhar Dwivedi; Gregory Lee; Gigon Bae; Anisha Goel; Elena Agostini; Patrick O'Grady / arXiv
NVIDIA方向:推理框架方向:调度服务方向:编译部署硬件:GPU
这是什么机器人、医疗设备等实时嵌入式系统用 GPU 处理高带宽传感器数据，但每一轮仍由 CPU 主机读传感器、提交 CUDA 任务、等结果再输出，主机的中断和调度会带来时延抖动。GPU-resident Execution 让输入输出和 GPU 计算留在一个常驻 GPU 的循环里，全程不唤醒主机。
有什么结果在工业级 1080p、60 Hz 相机到显示的实时应用上，相比 CPU 驱动的 GPU 内存 RDMA 基线，光子到显示的抖动从 4.83 毫秒降到 0.66 毫秒（7.3 倍），软件处理抖动从 1.70 毫秒降到 0.01 毫秒（170 倍）；在单级 TensorRT 推理中，MobileNetV2、EfficientNet-B0 和 ResNet-50 的时延标准差和抖动比 CPU 启动 CUDA Graph 的方式降低 1.4–2.4 倍。
怎么做到传感器数据直接到达 GPU 内存并触发 GPU 侧处理，结果写到 GPU 可见的输出端点；在 NVIDIA Holoscan C++ 框架中实现常驻 GPU 的循环和数据就绪处理器，提供 TensorRT 推理等参考组件，并在 IGX Orin、IGX Thor 嵌入式平台和 RTX A6000 上评测。
