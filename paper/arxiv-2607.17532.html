CommitLLM: A Fine-Tuned Pipeline for Git Commit Message Generation

5 学校预印本 2026-07-20 · Md Rafid Haque; Poojan Narendrabhai Patel; Meetkumar Vijaybhai Raychura / arXiv
应用:代码模型:Mistral硬件:GPU
这是什么用一个微调过的小语言模型自动从代码改动生成规范的 git 提交信息，整个系统可在一块消费级 GPU 上运行。
有什么结果在 50 个样本上格式合规率 98%（原版 Mistral 为 22%），平均输出长度从 154.8 字符降到 37.9 字符，LLM 评审分从 1.97 提升到 3.68（满分 5）；后处理带来的提升大于微调本身。
怎么做到用 QLoRA 在 CommitPackFT 数据集上微调 Mistral-7B，再加约束解码限制长度和确定性后处理规整格式。
评分依据：本地单卡运行的小模型应用，与端侧部署有一定联系，但重点是任务效果而非推理优化，评测规模也很小。方法是常规微调加后处理，贡献较低。
