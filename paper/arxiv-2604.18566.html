Benchmarking System Dynamics AI Assistants: Cloud Versus Local LLMs on CLD Extraction and Discussion

8 学校预印本 开源 2026-04-20 · Terry Leitch / arXiv
方向:评测基准方向:量化硬件:Apple-Silicon
这是什么拿系统动力学建模助手做场景，系统比较云端大模型和在本地 Mac 上跑的开源大模型，看本地模型能不能顶上，以及推理后端、量化精度各有多大影响。
有什么结果因果回路图抽取任务上云端模型通过率 77%-89%，本地最好的 Kimi K2.5 GGUF Q3 达到 77%，与中档云模型持平；但在长上下文的纠错类讨论任务上本地模型只有 0%-50%。推理后端选择（llama.cpp 与 mlx_lm）的影响大于量化等级。
怎么做到在一台 512GB 统一内存的 Mac Studio（M3 Ultra）上，用 LM Studio 和 mlx_lm 跑多个模型族的 GGUF 与 MLX 量化版本，在两套自建基准上与云端 API 对照，并扫完采样参数。
评分依据：实测的是在 Apple Silicon 个人工作站上本地跑超大模型的效果与坑，对本地部署有参考价值，但属于应用评测而非新方法。给出了后端差异（JSON 约束、长上下文卡死）的实用经验。
