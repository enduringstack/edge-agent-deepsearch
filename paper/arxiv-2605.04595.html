A Queueing-Theoretic Framework for Stability Analysis of LLM Inference with KV Cache Memory Constraints

8 学校顶会 2026-05-06 · Chengyi Nie; Nian Si; Zijie Zhou / ICML 2026
方向:云端serving方向:KV cache硬件:GPU
这是什么大模型推理服务既受算力限制、又受 KV 缓存占用显存的限制，这篇论文用排队论回答“多大集群才能扛住某个请求速率而不排爆”。
有什么结果在真实 GPU 生产环境中验证，推导出的稳定性条件与实测偏差通常在 10% 以内。
怎么做到建立首个同时把计算量和显存（KV 缓存）约束纳入的排队模型，推导服务稳定与不稳定的充分条件，再结合到达率估算所需集群规模。
评分依据：面向云端 GPU 集群容量规划，与端侧关联较弱；把 KV 缓存显存约束纳入排队论分析有理论贡献，已被 ICML 2026 接收。
