Developer's Guide to Building ADK Agents with Skills

9 官方动态 开源 2026-04-01 · Google / Google
Google方向:工具调用方向:记忆
这是什么谷歌讲解如何在 ADK 里用 Agent Skills 规范给智能体按需加载技能，代替把所有知识塞进一个巨大的系统提示。
有什么结果以 10 个技能为例，启动时只加载约 1000 token 的技能元数据，而单体提示约需 1 万 token，基线上下文减少约 90%。
怎么做到渐进披露分三层：启动时只加载每个技能约 100 token 的名称和描述，用到时再加载不超过 5000 token 的完整说明，参考资料按需读取；ADK 自动生成 list_skills、load_skill、load_skill_resource 三个工具。
评分依据：按需加载技能能显著压缩上下文，对上下文和内存都受限的端侧 Agent 有直接借鉴价值，Gemma 4 端侧 Agent Skills 采用同类思路；本文本身是云端框架教程。
