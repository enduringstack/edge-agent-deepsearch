Webwright: A Terminal Is All You Need For Web Agents

11 官方动态 开源 2026-05-04 · Microsoft / Microsoft
Microsoft方向:工具调用应用:代码模型:Qwen
这是什么微软研究院和港大提出 Webwright：不让网页 Agent 一步步点按钮，而是只给它一个终端，让它写 Playwright 代码来操控浏览器。
有什么结果在 100 步预算下于 Odysseys 和 Online-Mind2Web 上达到最佳结果；GPT-5.4 平均每任务成本 2.37 美元；配合他们的工具，9B 的 Qwen3.5 在 Online-Mind2Web 难题集上也表现强劲。
怎么做到极简框架只有三个模块、约 1000 行代码和一个 Agent 循环：Agent 输出 bash 命令、写脚本开浏览器、看日志迭代，最终产出可复用的命令行脚本。
评分依据：走的是 CLI/代码范式而非 GUI 点击，属于有非 GUI 创新的 Agent 工作；小模型也能用、产物可复用，对资源受限场景有迁移潜力，但没有端侧部署实验。
