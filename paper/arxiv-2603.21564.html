Toward a Theory of Hierarchical Memory for Language Agents

9 学校预印本 2026-03-23 · Yashar Talebirad; Ali Parsaee; Csongor Y. Szepesvari; Amirhossein Nadiri; Osmar Zaiane / arXiv
方向:记忆方向:规划推理应用:长上下文推理
这是什么各种长上下文系统和 Agent 都在用“分层记忆”，但设计五花八门、没法比较。这篇给分层记忆提出一套统一的理论框架。
有什么结果未报告
怎么做到把分层记忆拆成三个算子：从原始数据抽取原子信息、分组压缩成多级代表、按查询和 token 预算遍历选取内容；并用它解析了 11 个现有系统。
评分依据：Agent 记忆是端侧 Agent 运行时的关键组件，这套形式化有助于设计受预算约束的记忆检索；但纯理论梳理，不涉及设备与效率实测。
