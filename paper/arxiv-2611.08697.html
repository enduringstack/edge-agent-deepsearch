CPU Micro-Architectural Characteristic Sensitivity Study on CPU-Side Agentic Task Latency

12 学校预印本 开源 2026-11-05 · Jack Adiletta; Shixin Ji; Zhuoping Yang; Peipei Zhou / arXiv
方向:评测基准方向:工具调用硬件:CPU模型:Qwen
这是什么个人和小企业想把 AI Agent 放在本地跑以省钱、保隐私。这项研究测量 CPU 的核心频率、非核心频率、核心数和超线程如何影响 Agent 任务中 CPU 一侧的时延，为本地 Agent 机器选 CPU 提供依据。
有什么结果在 Intel Core i9-14900KS 上做了 8 组实验：性能核频率影响最大，从 2.5 GHz 提到 5.5 GHz，单 Agent 提速 1.154 倍、8 个并发 Agent 提速 1.341 倍；多 Agent 对非核心频率更敏感，四核四 Agent 起开始出现共享资源争用。
怎么做到先用本地 vLLM 跑 Qwen3-Coder-30B-A3B 采集 Terminal-Bench 等任务的 Agent 轨迹，再确定性回放：分词与工具执行真实在 CPU 上跑，GPU 预填充用固定延迟近似，从而隔离出 CPU 侧时延，并开源框架和轨迹数据集。
评分依据：直接面向本地运行的 Agent，在桌面级 CPU 上量化工具执行等 CPU 侧开销，对 PC 端 Agent 的硬件选型有参考价值；但实验中模型推理是回放并以固定延迟近似，不构成完整的端侧 Agent 系统，提速幅度也较温和。
