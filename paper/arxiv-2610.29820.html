UlaCache: Unified Logical Addressing for Sparse LLM Serving

8 学校预印本 2026-10-21 · Isaac Zhu; Alan Cao; Hugh Yin; Rocky Wang; Orion Wang; Hscos Zhang; Jack Li; Jason Zhao / arXiv
方向:KV cache方向:稀疏注意力方向:云端serving方向:投机解码硬件:GPU
这是什么长上下文推理中稀疏注意力只选部分历史 token，但保留的 KV 缓存仍要随时可用。UlaCache 用统一的逻辑地址空间管理 GPU 和 CPU 上的 KV 缓存。
有什么结果开启投机解码、在相同 CPU 和 GPU 内存预算下，峰值解码吞吐在 8 卡 H200 上比最先进基线提升 1.16 倍（数据并行）和 1.70 倍（张量并行），在 8 卡 B300 上提升 1.73 倍和 2.51 倍。
怎么做到用稳定的逻辑引用让推理引擎独立于物理位置分配和选择 KV；本地 GPU 缓冲在解码步之间保留已选 KV，只传缺失部分；启用 CPU 存储时用并行分桶 LRU 管理跨请求共享的 GPU 池。
评分依据：数据中心多卡 GPU 上的 KV 缓存管理，属于云端服务优化，端侧相关度低。工程设计完整，方法属常规组合。作者来自初创公司 Scitix.AI（不在公司名单内）。
