Self-State Attacks on Self-Hosted AI Agents: How Far Can OS Defenses Go?

11 学校预印本 2026-07-21 · Yimeng Chen, Nathanaël Denis, Roberto Di Pietro, Jürgen Schmidhuber / arXiv
方向:安全隐私方向:记忆应用:安全硬件:CPU
这是什么像 OpenClaw、Claude Code 这类自托管智能体会在本机保存持久记忆、指令和配置。一旦被攻破，攻击者能借智能体自身的合法写权限篡改这些“自身状态”。论文系统评估了操作系统现有防护能挡住多少。
有什么结果在四类智能体负载和 Linux 遥测管线上测试发现：文件级访问控制要么留下其他篡改路径，要么连正常更新一起拦掉；检测器会把相当一部分正常活动误报；受保护备份能恢复被篡改状态，但需要可信恢复点并付出回滚代价。
怎么做到先形式化“自身状态攻击”的攻击空间，再用 inotify、fanotify、auditd 等五类 Linux 遥测采集数据，逐一评估访问控制、异常检测和备份恢复等代表性防御。
评分依据：研究本地运行的智能体运行时安全，与端侧 Agent 的记忆和配置保护直接相关；但实验不涉及模型在本地推理，属于主机安全分析。结论指出通用操作系统防御缺乏判断上下文，对设计端侧 Agent 的状态保护有参考价值。作者来自 KAUST 与 IDSIA，未见公司署名。
