How to write fast AArch64 SVE/SME Kernels with Ripple and LLVM

12 官方动态 开源 2026-10-29 · Qualcomm / Qualcomm
Qualcomm方向:编译部署方向:高效推理方向:量化硬件:CPU
这是什么高通开发者博客介绍开源的 Ripple 编译扩展：用普通 C/C++ 加少量标注，就能为 Arm 的 SVE 和 SME 矩阵扩展生成接近手写汇编性能的 GEMV、GEMM 内核，这两类正是大模型解码和预填充的核心算子。
有什么结果FP32 GEMV 内核约 17 行代码（手写汇编约 1200 行，代码量减少 98.5%），在 1K 到 40K 方阵上性能与手工优化的 SME 内核相差不到 5%；FP32 与 INT8 GEMM 分别为 57 行和 71 行（汇编参考实现为 318 和 464 行），大矩阵下与手写 SME 汇编相差约 1–2%，极小矩阵差距为 5–10%。
怎么做到Ripple 基于 Clang/LLVM，开发者声明向量块形状和要并行的循环维度，编译器自动完成向量化、掩码尾部处理和寄存器分配；SME 的外积和 ZA 矩阵寄存器通过一组头文件函数暴露，在 C 代码里直接调用。
评分依据：直接针对 Arm CPU 上大模型推理的矩阵算子，可迁移到手机和 PC 的 CPU 端推理，属于端侧技术栈；用高层写法逼近手写汇编性能有工程价值，但文中实测未给出具体设备型号。
