NVIDIA Open Agent Safety Platform: A Reference for Continuous In-Silicon Agent Monitoring

9 官方动态 2026-09-28 · NVIDIA / NVIDIA
NVIDIA方向:安全隐私方向:工具调用应用:安全
这是什么NVIDIA 放出一套开源的智能体安全平台，把软件侧的 OpenShell 运行时和硬件侧的 Sentry 监控合在一起，对自主智能体做持续监控。
有什么结果未报告
怎么做到分应用、运行时和基础设施三层：OpenShell 创建沙箱环境，用可验证的策略管控文件、网络、工具和凭据访问；NVIDIA Sentry 借助 DOCA 把管控延伸到 BlueField-4 DPU 上，在节点通往模型的唯一路径上以线速关联智能体活动并执行策略。
评分依据：把智能体策略执行下沉到数据处理单元硬件这一思路有价值，对未来端侧智能体的硬件级隔离有参考意义；但部署形态是 Vera Rubin 这类数据中心机柜，与设备端无关。
