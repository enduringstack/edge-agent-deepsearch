MCPHallu: Benchmarking Reasoning, Execution, and Memory Hallucinations in MCP Agents

8 公司项目 开源 2026-11-05 · Yizhen Jiang; Haowei Guo; Tianyi Bai; Zengjie Hu; Lu Ma; Zhengyang Zhao; Haoze Sun; Peng Pei / arXiv
Meituan方向:工具调用方向:评测基准方向:记忆
这是什么通过 MCP 协议调用工具的大模型智能体，容易在推理、执行和记忆上“幻觉”。MCPHallu 专门设计会诱发这类失败的任务，按失败类型细分诊断。
有什么结果358 个任务、36 个真实 MCP 服务器，评测 8 家厂商的 14 个前沿模型、5012 条轨迹：平均分 0.642（满分 1）；“目标不可达”类任务平均分只有 0.458，仅 23.2% 通过；同一模型在不同失败子类上的排名平均变动 6.9 位。
怎么做到每个任务都内置一个结构性触发点，让分支坍缩、目标不可达、工具误用或上下文遗忘之一成为主要风险，在隔离容器里运行真实 MCP 服务器并按子类打分。
评分依据：面向云端前沿模型的工具调用智能体评测，没有端侧部署内容（相关度 3）；按失败类型构造任务的评测设计有一定新意（贡献 5）。 作者机构依据：arXiv PDF 首页署名 Meituan（论文首页多名作者（含通讯作者 Peng Pei）机构署名包含 Meituan，并注明部分工作在美团实习期间完成）。
