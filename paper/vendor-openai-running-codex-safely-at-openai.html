7 官方动态 2026-05-08 · OpenAI / OpenAI

这是什么OpenAI 介绍公司内部如何安全地使用 Codex 编程智能体：靠沙箱隔离、操作审批、网络策略和面向智能体的遥测日志，让编程 Agent 在合规前提下推广使用。
有什么结果未报告
怎么做到把智能体能执行的命令关进沙箱，高风险操作要人工批准，联网受策略限制，并记录智能体行为日志用于审计。
评分依据：讲的是编程智能体的安全运行与治理实践，和端侧推理部署关系较远，只对本地运行 Agent 的权限隔离有参考价值；属于工程经验分享，没有新算法。
