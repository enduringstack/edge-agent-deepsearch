FlowState: Execution State as Memory for Long-Horizon LLM Agents

10 公司项目 2026-09-28 · Minghao Li; Bangyan Li; Zifan Wang; Yulong Li; Hu Xu; Gan Zhang; Jingtong Wu; Wenqiang Xu / arXiv
Ant Group方向:记忆方向:工具调用应用:长上下文推理模型:DeepSeek
这是什么长周期任务里，智能体要不断用到早先交互中的信息：全量保留历史太费上下文，压缩又可能丢掉后面用得上的细节。FlowState 把“执行状态”当作可保留、可回看的记忆来管理。
有什么结果同样使用 DeepSeek-V4-Flash，与全量上下文基线相比，在 MemoryArena 上平均成功率提高 4.55 个百分点，在 τ³-Bench 上平均通过率提高 13.95 个百分点，总 token 消耗分别减少 43.2% 和 40.6%。
怎么做到把历史保存为带语义类型的状态节点、节点之间的关系以及指向原始工具输出的引用，将“长期保留”与“按需取用”分开；在单次执行循环内，增量状态更新（ISU）根据新输入和反馈维护当前状态，渐进状态访问（PSA）在推理需要时逐步展开历史状态和证据，让智能体能根据新信息重新审视之前的决策。
