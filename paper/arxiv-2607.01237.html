KARA: Efficient Reasoning LLM Serving via Sliding-Window KV Cache Compression

10 学校预印本 2026-05-01 · Shen Han; Yuyang Wu; Junpu Yu; Olexandr Isayev / arXiv
方向:KV cache方向:云端serving应用:长上下文推理
这是什么推理模型的长思维链会让 KV cache 越积越大，拖慢解码。这篇提出只在最近生成的一段窗口里做压缩的 KV cache 方法 Kara，并基于 vLLM 做了推理框架 KvLLM。
有什么结果只保留 20% 的 KV cache 时准确率接近完整 KV 的 100%；在显存受限的并发 serving 下，KvLLM 吞吐平均比原生 vLLM 高 12.75%。
怎么做到在滑动窗口内用双向注意力给 KV 对打分并挑选重要的，再用 Token2Chunk 模块把部分选中的 KV 扩成可变长度的块以保留完整语义，并适配 PagedAttention。
评分依据：针对显存受限下的推理模型 KV cache 压缩，可迁移到内存紧张的端侧，但实验在 GPU serving 上；滑动窗口加可变块保留是对现有方法的改进。
