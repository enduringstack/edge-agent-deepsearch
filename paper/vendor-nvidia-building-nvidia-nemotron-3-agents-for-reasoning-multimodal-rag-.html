Building NVIDIA Nemotron 3 Agents for Reasoning, Multimodal RAG, Voice, and Safety

8 官方动态 开源 2026-03-24 · NVIDIA / NVIDIA
NVIDIA方向:多模态方向:MoE应用:RAG应用:语音应用:长上下文推理
这是什么NVIDIA 梳理 GTC 2026 发布的 Nemotron 3 开放模型家族如何组合成智能体：长上下文推理、多模态检索、全双工语音对话和内容安全审核各有专门模型。
有什么结果官方给出：Nemotron 3 Super 在 Blackwell 上用 NVFP4 运行时吞吐最高达上一代 5 倍，Artificial Analysis 智能指数 42 分；4B 安全审核模型在多语言多模态安全基准上准确率约 84%；VoiceChat 目标端到端时延低于 300 毫秒。
怎么做到Super 是激活 12B 参数、支持 100 万 token 上下文的混合专家模型；配套 1.7B 的图文向量和重排模型做多模态 RAG，基于 Gemma-3-4B 的安全模型做审核，开放训练数据和配方。
评分依据：文章侧重数据中心部署，测试平台是 Blackwell、H100，没有提到端侧设备；其中 1.7B、4B 级小模型对端侧 RAG 和安全审核有间接参考价值。
