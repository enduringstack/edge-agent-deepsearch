Evaluating Container Orchestration for Neuromorphic Workloads in Virtual Edge Environments

8 学校预印本 2026-05-15 · Huyen Pham; Bilhanan Silverajan / arXiv
方向:SNN方向:调度服务方向:能耗功耗
这是什么测试把脉冲神经网络的推理负载塞进 Kubernetes 容器编排、放在虚拟化的边缘环境里跑，会出什么问题。
有什么结果把 CPU 限制到 0.5 核时中位时延涨 47.6 倍、吞吐降 49 倍，最紧的配置因内存不足直接失败；各个还能跑的配置下分类准确率保持稳定；K3d 默认的轮询路由在副本扩容时带来明显的长尾时延。
怎么做到在 Windows 11 加 WSL2 和 Docker Desktop 上搭一个单节点 K3d 集群，逐步收紧 CPU 和内存配额，测端到端时延、吞吐、准确率、基础设施开销和并发下的运行行为。
评分依据：面向边缘环境的脉冲神经网络部署，资源受限下的时延数据对端侧调度有参考价值，但实验跑在虚拟化的单节点集群上而不是真实边缘硬件，端侧证据偏弱。工作性质是测量基线，没有提出新方法。
