H2LooP Spark Preview: Continual Pretraining of Large Language Models for Low-Level Embedded Systems Code

7 学校预印本 开源 2026-03-11 · Amit Singh; Vedant Nipane; Pulkit Agrawal; Jatin Kishnani; Sairanjan Mishra / arXiv
方向:模型架构应用:代码硬件:H100
这是什么通用大模型不熟悉寄存器操作、厂商 SDK 和实时操作系统接口，这家公司用大规模嵌入式代码对 7B 开源模型做继续预训练，让它更会写底层嵌入式代码。
有什么结果领域内困惑度下降 70.4%，留出仓库困惑度下降 66.1%；在 13 个嵌入式领域的代码补全测试中，7B 模型有 8 个类别的 token 准确率超过 Claude Opus 4.6 和 Qwen3-Coder-30B。
怎么做到以 OLMo-3-7B 为底座，在 8 张 H100 上用高秩 LoRA（r=512）继续预训练；语料来自 117 家芯片厂商的代码仓与数据手册配对，整理成 235 亿 token 的数据集。
评分依据：服务对象是嵌入式开发者，模型本身在云端 GPU 上训练和使用，与端侧推理部署无直接关系；领域继续预训练属常规做法，但开放了模型权重。论文首页署名为 H2LooP.ai 公司。
