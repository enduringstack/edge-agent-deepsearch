Human-Robot Interaction in GenAI Architectures via the Agent-Client Protocol

13 学校预印本 开源 2026-07-16 · Jesus Moncada-Ramirez; Jose-Raul Ruiz-Sarmiento; Javier Gonzalez-Jimenez / arXiv
方向:端侧agent方向:工具调用方向:规划推理应用:机器人
这是什么提出用原本为编程智能体设计的 Agent-Client 协议，统一机器人智能体与各种人机交互界面的通信，配合 MCP 连接机器人执行层，构成三层解耦架构。
有什么结果在实体移动机器人 Sancho 上让命令行、平板和网页三种界面无改动接入；一次交互平均 36.9 秒，其中 ACP 只增加 1.0 毫秒、MCP 增加 170.6 毫秒，合计不到 0.5%。
怎么做到机器人上的 ReAct 编排器作为 ACP 服务端面向用户界面，同时作为 MCP 客户端调用封装了 ROS 导航、相机和语音的工具；支持实时查看推理过程、敏感动作需人工授权和随时打断。
评分依据：在真实移动机器人上运行带工具调用、人工授权和中断的智能体编排闭环，属于端侧 Agent 运行时架构；大模型推理调用云端 Gemini，创新主要在协议选型与架构解耦。作者来自马拉加大学，代码开源。
