Leanstral: Open-Source foundation for trustworthy vibe-coding

8 官方动态 开源 2026-03-16 · Mistral / Mistral
Mistral方向:MoE方向:工具调用应用:代码模型:Mistral
这是什么Mistral 开源 Leanstral，首个面向 Lean 4 定理证明语言的代码 Agent 模型，目标是让 Agent 写代码的同时给出形式化证明，减少人工审查。
有什么结果在新基准 FLTEval 上，pass@2 得分 26.3，比 Claude Sonnet 高 2.6 分，成本为 36 美元对 549 美元；pass@16 达到 31.9。
怎么做到采用高度稀疏的混合专家结构（总参数 120B、激活 6B），针对真实形式化仓库中的证明工程训练，用 Lean 作为验证器并行采样；通过 Mistral Vibe 支持任意 MCP，并专门针对 lean-lsp-mcp 优化。
评分依据：低激活参数降低推理成本，权重开放可自托管，但面向的是云端或服务器上的编码 Agent，与端侧部署关系弱；把形式化验证引入编码 Agent 有新意。
