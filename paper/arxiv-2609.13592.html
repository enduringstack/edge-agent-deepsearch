BOOST: Concurrent Access to Host Memory and HBM to Accelerate LLM Inference

10 学校预印本 2026-09-11 · Anish Saxena; Jae Hyung Ju; Hritvik Taneja; Po-An Tsai; Aamer Jaleel; Christos Kozyrakis; Moinuddin Qureshi / arXiv
方向:推理框架方向:高效推理硬件:GPU
这是什么显存不够时现有系统要么只用高带宽显存、要么先把数据搬进去，这套运行时让 GPU 线程同时按带宽比例读两层内存。
有什么结果论文报告在不改核函数的前提下能把主机内存和高带宽显存的带宽合起来用；摘要截断未给出具体加速倍数。
怎么做到关键洞察是每一波 GPU 线程块都要按带宽比例同时访问两层内存；系统据此让页分配和运行时数据管理感知 GPU 的波次结构和 2MB 大页，对静态权重用取模方式放页消除访问比失衡。
评分依据：是数据中心 GPU 的内存层级优化，但「并发使用两层内存而非分级预取」的思路对端侧统一内存也有启发（相关性 4）。波次感知的页放置是有新意的系统设计（贡献 6）。
