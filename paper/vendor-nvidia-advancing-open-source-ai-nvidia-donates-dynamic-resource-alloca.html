Advancing Open Source AI, NVIDIA Donates Dynamic Resource Allocation Driver for GPUs to Kubernetes Community

4 官方动态 开源 2026-03-24 · NVIDIA / NVIDIA
NVIDIA方向:云端serving方向:调度服务硬件:GPU
这是什么NVIDIA 在 KubeCon 欧洲站宣布把 Kubernetes 上的 GPU 动态资源分配（DRA）驱动捐给 CNCF 社区维护，方便数据中心更灵活地切分和调度 GPU。
有什么结果未报告
怎么做到驱动支持多进程服务和 MIG 切卡共享 GPU、对接多节点 NVLink；同时与机密容器社区合作给 Kata Containers 加上 GPU 支持，KAI 调度器进入 CNCF 沙箱。
评分依据：内容是数据中心 GPU 集群调度基础设施的开源治理变化，与端侧设备基本无关；属于生态层面的工程动作，技术新意有限。
