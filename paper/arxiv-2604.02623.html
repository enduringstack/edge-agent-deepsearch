Poison Once, Exploit Forever: Environment-Injected Memory Poisoning Attacks on Web Agents

9 公司项目 2026-04-03 · Wei Zou; Mingwen Dong; Miguel Romero Calvo; Shuaichen Chang; Jiang Guo; Dongkyu Lee; Xing Niu; Xiaofei Ma / arXiv
Amazon方向:记忆方向:安全隐私模型:GPT
这是什么带记忆的网页智能体会把过去的交互存下来，这也成了攻击面。论文提出一种只需让智能体“看到”一个被篡改页面就能污染其记忆、并在之后其他网站任务中触发的攻击。
有什么结果在 (Visual)WebArena 上，攻击成功率在 GPT-5-mini 上最高 32.5%、GPT-5.2 上 23.4%、GPT-OSS-120B 上 19.5%；智能体遇到点击失效或文字乱码等压力时，成功率最高放大 8 倍，能力更强的模型并不更安全。
怎么做到攻击者不直接写入记忆库，而是在网页内容里埋入恶意信息，让智能体在正常浏览时把它当作经验存入记忆，之后在不同网站、不同会话中被检索出来并生效，从而绕过基于权限的防护。
评分依据：揭示智能体记忆的跨会话安全风险，对任何带长期记忆的智能体（包括本地运行的）都有警示意义，但实验基于云端模型和网页环境；首次实现不需直接访问记忆的跨站攻击，有新意。 作者机构依据：arXiv PDF 首页署名 Amazon（PDF 首页多数作者署名 Amazon Web Services，第一作者注明工作完成于 AWS 实习期间）。
