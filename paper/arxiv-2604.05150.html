Compiled AI: Deterministic Code Generation for LLM-Based Workflow Automation

7 学校预印本 2026-04-06 · Geert Trooskens; Aaron Karlsberg; Anmol Sharma; Lamara De Brouwer; Max Van Puyvelde; Matthew Young; John Thickstun; Gil Alterovitz / arXiv
方向:工具调用方向:编译部署应用:代码
这是什么提出“编译式 AI”：让大模型在编译阶段一次性生成可执行代码，之后业务流程确定性地跑这段代码，不再每次都调用模型，主打医疗等高可靠场景。
有什么结果在函数调用测试（BFCL，400 条）上任务完成率 96%，运行时零 token 消耗，约 17 次事务即可回本，1000 次事务时 token 消耗减少 57 倍；发票信息抽取上关键字段准确率 80.0%，与直接调用大模型持平；提示注入检测准确率 96.7%。
怎么做到把生成范围限制在经过验证的模板中的窄业务函数，并用四阶段生成加校验流程把模型输出变成可上线的代码。
评分依据：把模型调用从运行时搬到编译期，能大幅降低工作流 Agent 的推理成本，思路对资源受限场景有启发；但场景是云端企业流程，没有端侧部署。
