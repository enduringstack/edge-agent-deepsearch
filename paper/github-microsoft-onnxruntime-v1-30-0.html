ONNX Runtime v1.30.0

12 开源大项目 开源 2026-09-10 · microsoft / GitHub
方向:推理框架方向:KV cache方向:量化方向:投机解码硬件:CPU硬件:GPU
这是什么ONNX Runtime 发布 1.30.0，重点加强生成式推理，同时改进 CPU、GPU 和 WebGPU 三条执行路径，并新增 Go 语言绑定。
有什么结果版本说明称本版有 57 位贡献者参与；所列优化均未给出性能数字。
怎么做到CUDA 侧新增按通道 scale 的 INT4 分页 KV 缓存和分页 XQA 投机解码；WebGPU 改进 PagedAttention 并加入 INT8 KV 缓存分块量化；CPU 侧加了 AVX-512、Arm64 NEON 和 SVE 的融合线性注意力核，并加固模型加载和输入校验。
评分依据：ONNX Runtime 是端侧部署常用运行时，本次 Arm64 线性注意力核、WebGPU KV 缓存量化可直接用于端侧，但不少改动面向 CUDA 服务端（相关性 7）。属版本迭代式工程整合（贡献 5）。
