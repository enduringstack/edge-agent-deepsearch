SkillFS: Governing Dozens of Agent Skills with a File System

9 官方动态 开源 2026-10-10 · Qwen / Qwen
Qwen方向:工具调用方向:安全隐私模型:Qwen
这是什么阿里主导的 OpenAnolis 社区推出 SkillFS：用一个虚拟文件系统管理 AI Agent 的几十个技能（Skill），只把当前任务需要的技能暴露给 Agent，同时管住技能的版本和可信度。
有什么结果在 5 类 38 个技能、27 个场景、每个场景跑 4 轮的测试中，开启 SkillFS 后平均 token 成本：kimi-2.5 降低 21.37%（174167 降到 136942），minimax-m2.5 降低 7.51%，qwen3.6-plus 降低 7.20%，qwen3.5-plus 仅降低 0.94%；正文没有报告任务成功率。
怎么做到基于 FUSE 把技能目录映射成稳定的 /skills/<技能名> 路径，按视图决定 Agent 能看到哪些技能；外部安全扫描给出“使用当前版本、回退到可信快照、隐藏”三种决策并热更新生效；打开文件时锁定版本保证读取一致，并记录 JSONL 审计日志。代码用 Rust 实现并开源，目前只支持 Linux。
评分依据：属于 Agent 工具与技能运行时，按需暴露技能能节省上下文，对上下文窗口有限的端侧小模型 Agent 有迁移价值，但正文测试全部基于云端模型，相关度 4。用文件系统做技能治理的思路较新，但收益因模型差异很大（0.94% 到 21.37%），贡献 5。
