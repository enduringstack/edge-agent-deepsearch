Invalidation Contracts for Cross-Episode Agent Memory

10 公司项目 开源 2026-08-31 · Michael Wu; Arquimedes Canedo / arXiv
Siemens方向:记忆方向:工具调用
这是什么智能体会把 API 报错后的修复方案缓存起来下次直接用，但服务端数据一变，旧修复就会悄悄失效。这篇工作提出“失效契约”，让客户端能精确淘汰过期的缓存修复。
有什么结果在七个模型、三种服务路径、两个领域、约 9400 个回合上评测：行级失效让首轮采纳率提升 0 到 66.7 个百分点，并在七个模型中的四个上收回 29% 到 33% 的基线 token 成本；契约只让响应载荷增加约 15%；表级失效则让五个模型在数据漂移后的首轮成功率降到 0%。
怎么做到服务端在每条修复建议上附加版本戳和可缓存提示，客户端据此淘汰过期条目、保留其余；节省量被拆成“缓存仍然正确的比例”和“规划模型首轮就采纳的比例”两个独立因素分析。
评分依据：关注智能体跨回合记忆在客户端的正确性和 token 开销，属于可迁移的智能体运行时机制，但未涉及设备端运行。把缓存失效做成协议层并量化不同模型的采纳差异，很实用。作者机构依据 arXiv PDF 首页署名：第二作者来自 Siemens Digital Industries Software。 作者机构依据：arXiv PDF 首页署名 Siemens（PDF 首页第二作者 Arquimedes Canedo 署名 Siemens Digital Industries Software（siemens.com 邮箱），第一作者来自南达科他州立大学）。
