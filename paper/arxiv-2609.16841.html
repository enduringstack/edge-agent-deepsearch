StackTok: Accelerating VLMs Inference with Budget-Adaptive Visual Token Selection

14 学校预印本 2026-09-15 · Zhenbin Wang; Lei Zhang; Lituan Wang; Wei Huang; Yan Wang; Zhenwei Zhang / arXiv
方向:剪枝稀疏方向:多模态方向:高效推理
这是什么给视觉语言模型挑视觉 token，按问题类型和 token 预算自动在「相关性优先」和「覆盖优先」之间调节，不用重新训练。
有什么结果在五个视觉语言模型、十个图像理解基准上，所有模型与预算组合中都排免训练选择器第一；在高分辨率 LLaVA-NeXT-7B 上只留 2880 个视觉 token 中的 160 个（5.6%）仍保留 95.26% 的全 token 性能。
怎么做到先用只看覆盖的贪心序列建一个按规模索引的覆盖参考，再用问题与视觉的亲和度熵调整覆盖目标，靠一个参考门控的交替策略在相关性和覆盖之间切换；高分辨率输入下按各切片的边际收益共享一个 token 预算。
评分依据：视觉 token 剪枝是端侧多模态部署最直接的省算力手段，5.6% token 保住 95% 性能的量级很实用（相关性 7）。预算自适应的覆盖参考设计有新意（贡献 7）。
