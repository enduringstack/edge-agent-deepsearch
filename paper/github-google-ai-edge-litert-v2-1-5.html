这是什么端侧推理框架 LiteRT 发布 2.1.5 版本，主要是接口精简和新硬件支持。
有什么结果未报告性能数值。发布说明列的是能力变化：新增 Python 3.14 的预编译包、新增树莓派 5 的 GPU 加速支持。
怎么做到把 C++ 接口改成仅头文件形式；让环境和选项接口可以直接从 Python 调用；选项类改成纯数据对象，创建和更新不再需要走 C 接口调用；GPU 加速器和分派接口的共享库不再依赖 libLiteRt.so；另外修了 iOS 的 GPU 预编译包和主机内存张量缓冲对齐两个问题。
评分依据：LiteRT 是谷歌官方的端侧推理运行时，这一版新增树莓派 5 的 GPU 加速并修了 iOS 预编译包，端侧契合度高。改动以接口整理和依赖解耦为主，属于维护性版本。
