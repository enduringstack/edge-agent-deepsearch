Agent Retrieval Bench: Evaluating Repository Context Retrieval for Coding Agents

8 学校预印本 2026-07-29 · Bowen Qin, Yi Xie / arXiv
方向:评测基准方向:工具调用应用:代码应用:RAG
这是什么一个专门评测编程智能体“先找对文件”能力的基准：在动手改代码之前，智能体能否从仓库里检索到下一步真正需要的文件。
有什么结果基准含 25 个仓库共 427 个样本、约 39.2 万个文件；没有一种检索方法全面领先，Qwen3-Embedding-4B 平均排名指标最好、RepoMap 在 8K token 预算下上下文产出最高；智能体实际轨迹在 27%–35% 的样本中漏掉全部正确文件。
怎么做到从真实编码流程信号构建样本并冻结在基础提交上，按“智能体下一步需要什么”定义相关性，设四类正向检索任务和一类“应当拒答”的子集，对比词法检索、向量检索、RepoMap 等方法。
评分依据：研究对象是云端编程智能体的上下文获取环节，属于智能体运行时的评测，与端侧部署关系较弱。基准设计贴近真实工作流且揭示了校准缺口，贡献中等。作者来自新加坡国立大学和北京大学。
