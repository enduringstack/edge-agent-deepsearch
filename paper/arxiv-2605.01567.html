Feedback-Normalized Developer Memory for Reinforcement-Learning Coding Agents: A Safety-Gated MCP Architecture

8 学校预印本 2026-05-02 · Mehmet Iscan / arXiv
方向:记忆方向:工具调用应用:代码
这是什么为强化学习代码开发场景下的编程智能体设计一套本地优先、基于 MCP 协议的开发者记忆系统，强调记忆选择可审计、可回溯。
有什么结果在 200 例确定性基准上，确定性排序与完整影子学习配置的期望决策准确率都是 80.0%、困难负例抑制率都是 100.0%；静态校验 11/11 通过、动态集成 10/10 通过；完整配置的在线时延有所退化。
怎么做到把记忆选择当成有日志的上下文决策过程：确定性排序器在线服务，上下文赌博机策略只在影子模式运行，必须通过离线策略评估门控才能影响行为。
评分依据：智能体记忆与工具协议属于 Agent 运行时技术栈，系统设计为本地优先，但没有设备端执行与资源开销评测。作者坦承完整配置没有带来准确率提升，贡献主要在可审计的架构设计。
