rknn-llm release-v1.3.0

15 开源大项目 开源 2026-06-17 · airockchip / GitHub
方向:推理框架方向:量化方向:多模态方向:KV cache硬件:NPU模型:Qwen模型:Gemma模型:SmolLM
这是什么瑞芯微面向自家 NPU 的端侧大模型工具链 RKLLM 发布 1.3.0，补齐新模型支持并修掉几个会直接影响推理结果的问题。
有什么结果发布说明列出的要点包括：新增 Qwen3.5、Gemma4、SmolLM3 模型支持；优化多模态输入接口与缓存复用策略；支持多个结束符 token 并新增忽略结束符的参数；优化 32 位系统性能；新增分词器与词嵌入回调；改善 RK3576 平台上部分模型的长上下文解码性能；优化词嵌入输入数据的量化方法；修复 RV1126B 的内存统计问题和 RK3588 上部分模型推理时的数值溢出；并增强示例服务的 OpenAI 接口兼容性。
怎么做到在工具链层面扩展模型转换与运行时支持：多模态侧重做输入接口并复用缓存，解码侧放开结束符判定并针对长上下文优化，量化侧改进词嵌入输入的量化方式，同时修复特定芯片上的数值与统计缺陷。
评分依据：RKLLM 是瑞芯微 NPU 上跑大模型的官方工具链，RK3576、RK3588、RV1126B 都是典型的端侧边缘芯片，端侧语境确凿。一个版本同时补齐新模型、改善长上下文解码并修掉会算错结果的数值溢出，对实际部署影响直接，贡献中等偏上。
