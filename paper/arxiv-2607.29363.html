Stable Autoregressive Speech Generation with Low-Frame-Rate High-Dimensional Continuous Tokens

7 公司项目 2026-07-31 · Yi Luo; Rongzhi Gu; Jixun Yao / arXiv
ByteDance应用:语音方向:模型架构
这是什么语音生成模型面临两难：token 越密细节越多，但流式生成越容易漂移。这篇工作设计了 8Hz、768 维的低帧率高维连续语音 token，配套一个抗误差累积的自回归生成框架。
有什么结果用 8Hz、768 维 token 时，重建质量保持住，单 token 可预测性提升，WER 有竞争力，长文本合成保持稳定，且不依赖外部自监督/ASR 模型、预训练文本模型或后训练；摘要未给出具体数值。
怎么做到编解码器 Locodec 对表示空间做约束，让高维 token 既好插值又好辨识；生成端 MP-ELD 用单 token 流匹配加多路信息路由和残差无分类器引导，抑制误差累积。
评分依据：低帧率 token 缩短了序列长度，对语音生成推理开销有间接帮助，但工作重心是生成质量与稳定性，与端侧部署关系较远（相关度 2）；编解码与生成器协同设计有一定新意（贡献 5）。机构依据：arXiv 论文首页署名 ByteDance Seed，第一作者注明为在 ByteDance Seed 实习期间完成。 作者机构依据：arXiv PDF 首页署名 ByteDance（arXiv 论文首页作者单位为 ByteDance Seed，第一作者 Yi Luo 注明工作完成于 ByteDance Seed 实习期间）。
