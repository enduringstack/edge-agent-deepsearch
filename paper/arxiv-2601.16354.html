NOIR: Privacy-Preserving Generation of Code with Open-Source LLMs

12 学校顶会 2026-01-22 · Khoa Nguyen; Khiem Ton; NhatHai Phan; Issa Khalil; Khang Tran; Cristian Borcea; Ruoming Jin; Abdallah Khreishah / USENIX Security 2026
方向:端云协同方向:安全隐私应用:代码
这是什么用云端大模型写代码会暴露公司的提示词和生成代码。NOIR 把编码和解码放在用户本地，只把加噪后的中间向量交给云端。
有什么结果在 MBPP 和 HumanEval 上 Pass@1 分别为 76.7 和 77.4，BigCodeBench 上为 38.7，仅比原模型低 1.77%，同时能抵御重建攻击和频率分析攻击。
怎么做到客户端本地运行编码器和解码器，在 token 嵌入层加局部差分隐私，并使用随机化的本地分词器，云端只处理嵌入、看不到明文。
评分依据：端云切分推理、让敏感部分留在本地，是端云协同的隐私方案，可迁移到终端设备；被 USENIX Security 2026 接收，方法有新意。
