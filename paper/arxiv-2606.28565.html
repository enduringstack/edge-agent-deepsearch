KernelSight-LM: A Kernel-Level LLM Inference Simulator

9 公司项目 2026-06-26 · Xiteng Yao, Taeho Kim, Hengzhi Pei et al. / arXiv
Amazon方向:云端serving方向:评测基准硬件:GPU
这是什么KernelSight-LM 是一个细到 GPU 内核级别的大模型推理模拟器，帮助工程师在不实际部署的情况下，预测不同显卡、模型和服务参数下的推理速度并找出瓶颈。
有什么结果不用目标显卡任何测量数据时，对新一代显卡的单内核时延预测误差 12.1%，比屋顶线模型好 1.8 倍；在目标卡上补跑一次通用微基准后误差降到 3.8%；端到端首 token 时延、每 token 时延和吞吐的中位误差最低分别为 14.3%、6.2% 和 2.7%。
怎么做到把每个推理步骤拆成带学习效率项的屋顶线内核模型、通信模型和主机开销模型，再用离散事件调度器组合起来，并模拟前缀缓存和连续批处理等服务机制。
评分依据：主要服务数据中心显卡上的容量规划，与端侧设备关系弱；内核级建模加少量数据迁移到新硬件的思路有一定价值。公司归属依据 arXiv PDF 首页：除第一作者（AWS 实习生，同时署名波士顿大学）和末位作者外，作者均署名 Amazon Web Services。 作者机构依据：arXiv PDF 首页署名 Amazon（PDF 首页 Taeho Kim、Hengzhi Pei、Leonard Lausen 等多位作者署名 Amazon Web Services，邮箱为 amazon.com，第一作者注明工作完成于 AWS 实习期间）。
