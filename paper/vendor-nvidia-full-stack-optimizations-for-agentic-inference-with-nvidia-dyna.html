Full-Stack Optimizations for Agentic Inference with NVIDIA Dynamo

10 官方动态 2026-04-17 · NVIDIA / NVIDIA
NVIDIA方向:云端serving方向:KV cache方向:调度服务
这是什么英伟达介绍如何让 Dynamo 推理框架更适合编程智能体这类负载：智能体反复带着完整对话历史调用模型，KV cache 复用率极高。
有什么结果以 Claude Code 为例，首次调用后同一 worker 上的后续调用 KV cache 命中率达 85–97%；4 个 Opus 协作智能体的总体命中率为 97.2%，读写比 11.7 倍。
怎么做到在前端支持 v1/responses 和 v1/messages 协议，路由层按 KV 重叠度把请求派到缓存最多的 worker，并允许智能体框架传递优先级、预计输出长度等提示，按块的生命周期决定保留或提前淘汰 KV。
评分依据：面向数据中心 GPU 的智能体推理服务优化，不涉及端侧设备；但「一次写入多次读取」的 KV 复用规律和按生命周期淘汰缓存的思路，对端侧多轮智能体推理有参考价值。
