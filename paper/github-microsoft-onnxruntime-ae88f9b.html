microsoft/onnxruntime: QMoE CUDA: Rename build options, refactor PrePack, add GPU kernels (#28583)

7 开源大项目 开源 2026-05-21 · microsoft / GitHub
方向:量化方向:MoE方向:推理框架硬件:GPU
这是什么ONNX Runtime 的量化专家混合算子在 CUDA 后端做了一轮重构，把原来在 CPU 上做的数据变换搬到 GPU 内核里。
有什么结果未报告性能数值。提交说明描述的是代码质量改动：原先 373 行、嵌套五个匿名函数的预打包函数被拆成具名辅助方法，涉及 300 个文件、新增 1178 行、删除 1022 行。
怎么做到把构建选项按命名规范重命名，修掉静态扫描的空异常处理告警，将模型加载时做权重和缩放因子预打包的逻辑从嵌套匿名函数重构成具名方法，并用 GPU 内核替换原来的 CPU 数据变换循环。
评分依据：ONNX Runtime 是跨端部署的主力运行时，量化专家混合算子对低比特部署有价值，但这次改动落在 CUDA 后端即服务器 GPU 侧，端侧相关性有限。内容以重构和代码质量为主。
