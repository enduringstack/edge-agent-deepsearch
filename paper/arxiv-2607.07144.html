Fractal KV-Cache Archives: Lossless Symbolic Storage with In-Place Retrieval for Long-Context LLM Inference

10 学校预印本 开源 2026-07-08 · Vladimir Gusev / arXiv
方向:KV cache方向:量化应用:长上下文推理模型:GPT
这是什么研究量化后的 KV 缓存该怎么存：把码本索引序列编码成一串低维实数向量，既能无损存储、随机访问和追加，又能直接在存储上做文本片段检索。
有什么结果在 GPT-2、1024 token 上下文上，保留 4 个注意力汇聚 token 和最近 32 个 token 精确存储、其余归档时，按头残差向量量化把归档缓存压到 fp16 的 1/36 到 1/54，困惑度代价 11% 到 15%；量化 key 的损伤约为量化 value 的 4 倍。全部结果可在笔记本 CPU 上复现。
怎么做到借用收缩迭代映射编码，把符号序列线性时间地序列化为低维向量，支持 O(1) 随机访问和摊还 O(1) 追加；配合按头残差向量量化和 key/value 不对称比特分配。
评分依据：KV 缓存压缩与存储格式和端侧长上下文推理的内存瓶颈相关，但实验只在 GPT-2 小规模设置上做，困惑度代价也不小；把存储层同时做成检索索引的视角新颖。作者为独立研究者。
