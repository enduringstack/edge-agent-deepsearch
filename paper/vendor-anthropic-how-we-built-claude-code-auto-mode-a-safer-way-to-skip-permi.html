How we built Claude Code auto mode: a safer way to skip permissions

10 官方动态 2026-03-25 · Anthropic / Anthropic
Anthropic方向:安全隐私方向:工具调用应用:代码
这是什么Claude Code 新增“自动模式”：在开发者电脑上执行命令前，由分类器代替人工审批，拦下越权、误删、泄露凭据等危险操作，缓解用户 93% 的提示都直接点通过的审批疲劳。
有什么结果在 1 万条真实流量上，完整两阶段流水线的误拦率从第一阶段的 8.5% 降到 0.4%；在 52 条真实越权操作上漏拦率为 17%，在 1000 条合成数据外泄样本上漏拦率为 5.7%。
怎么做到两层防护：输入侧用服务端提示注入探针扫描工具返回内容并给智能体加警示；输出侧用基于 Sonnet 4.6 的对话记录分类器，先做单 token 快速判断，只有被标记的动作才进入带思维链的二次判断，且分类器只看用户消息和工具调用、看不到模型自己的解释。
评分依据：智能体的工具调用和命令执行发生在用户本机，但规划和分类器都跑在云端模型上，因此不算端侧智能体；不过它给出了本机执行型智能体权限安全的完整设计和真实误拦/漏拦数据，对做 PC 侧智能体运行时的人直接有用。
