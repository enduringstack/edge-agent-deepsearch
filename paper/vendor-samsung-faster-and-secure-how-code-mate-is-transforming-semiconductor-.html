Faster and Secure: How Code Mate is Transforming Semiconductor Software Development

7 官方动态 2026-10-29 · Samsung / Samsung
Samsung方向:工具调用方向:云端serving应用:代码
这是什么三星半导体介绍内部编码智能体 Code Mate：模型和服务全部私有化部署在内部基础设施上，结合语义代码检索和 MCP 协议，帮工程师完成代码探索、定位问题、修改和验证。
有什么结果内部超过 1 万名开发者使用；9 月月度词元用量约 1.45 万亿，比 5 月增长约 3.5 倍；有用户反馈原本 3 到 4 天的任务一天能完成。
怎么做到用语义代码搜索和基于大模型的相似实现检索获取开发上下文，再通过 MCP 把代码、文档和工具接给智能体，按执行结果调整工具使用；同时扩充 GPU 并优化模型服务以降低高峰时延。
评分依据：是企业私有化部署的编码智能体，跑在公司内部服务器上而非终端设备，属于非端侧智能体；对本地化部署、数据不出域的智能体工程实践有参考价值。
