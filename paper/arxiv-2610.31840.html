SPECMEM: Accelerating Agentic Tool Calling via Live Memory Management

13 公司项目 2026-10-22 · Zihe Song; Wenting Zhao; Ye Liu; Yuanjie Zhu; Ke Xu; Shanghao Li; Philip S. Yu / arXiv
Salesforce方向:投机解码方向:工具调用方向:记忆方向:调度服务
这是什么工具调用型智能体每次调用都要逐 token 生成，时延越来越高。SpecMem 为每个用户维护一个持续更新的历史调用记忆，用它做投机解码的草稿，加速工具调用且不改变输出。
有什么结果在多会话、多用户的请求流上，用三种开源模型测试：冻结草稿库的接受率逐渐下降，SpecMem 能保持住，平均接受 token 数高 27%（各基准 +11% 至 +34%），端到端最高加速 1.74 倍。
怎么做到验证通过的工具调用在线写回每个用户独立、按 LRU 淘汰的有界记忆库，检索到的历史调用作为投机解码草稿；对有副作用、不可撤销的调用加门控，验证确认后才执行。
评分依据：实验在 H200 上服务 gpt-oss-120b 等模型，属于云端服务，但“按用户记忆加速工具调用”的思路可以直接迁移到端侧智能体运行时；把草稿库做成在线更新、并处理副作用安全，创新较实。 作者机构依据：arXiv PDF 首页署名 Salesforce（arXiv HTML 首页作者 Wenting Zhao、Ye Liu 署名 Salesforce Research）。
