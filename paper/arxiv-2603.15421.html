CLAG: Adaptive Memory Organization via Agent-Driven Clustering for Small Language Model Agents

11 学校预印本 开源 2026-03-16 · Taeyun Roh; Wonjune Jang; Junha Jung; Jaewoo Kang / ACL 2026 Findings
方向:记忆应用:RAG模型:Qwen模型:Llama
这是什么CLAG 针对小语言模型智能体的记忆问题：所有经验堆在一个检索池里，无关内容会干扰小模型。它让智能体自己把记忆分门别类整理，检索时先找对类别。
有什么结果在 LoCoMo、HotpotQA、BioASQ 等问答数据集和 Qwen3-0.6B、Llama3.2-1B、DeepSeek-R1-Distill-Qwen-1.5B 三个小模型上，答案质量普遍优于 A-mem、MemoryOS 等记忆系统；例如 Qwen3-0.6B 在 BioASQ 上 F1 从普通 RAG 的 2.4 提到 22.01。
怎么做到由小模型充当路由器，把新记忆分配到语义一致的簇，并为每个簇自动生成主题摘要和标签；更新只在簇内局部进行，检索分两步：先按簇画像筛簇，再在簇内找具体记忆。
评分依据：专门面向 1B 级小模型智能体的记忆组织，对端侧 Agent 记忆有直接迁移价值；但实验在 A100 上完成，未做设备实测。
