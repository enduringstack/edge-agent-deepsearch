Inference Economics of Enterprise Coding Agents: A Case Study of Cloud vs. On-Premise LLMs

8 学校预印本 2026-07-13 · Sheng-Wei Peng; Yi-Hsun Lin; Yi-Pei Lee / arXiv
方向:云端serving方向:量化应用:代码硬件:GPU
这是什么一份企业内部的长期案例研究：对比用云端 API 前沿模型和公司内网自建量化开源模型来跑编程智能体，哪种更划算、代码质量差多少。
有什么结果提示缓存命中率 99.3%，让 API 实际成本降低 88.6%，折合每百万 token 0.57 美元，低于内网共享 GPU 的 2.83 美元；本地配置的修复类提交占比 74.9%，远高于云端的 45.9%；按台湾市场参数，共享 GPU 方案总拥有成本节省 40.1%，独占预留则比带缓存的 API 贵 43.8%。
怎么做到两个连续 28 天周期分别使用 Claude Code 搭配 Claude Opus 和 Opencode 搭配 NVFP4 量化的 GLM-5.1/5.2（NVIDIA Blackwell 内网部署），结合大模型调用遥测与 Git 历史统计成本与返工率。
评分依据：讨论的是企业机房的私有化部署，不是端侧设备，只与本地部署选型宽泛相关；真实生产数据的成本与质量分析有参考价值，但属案例研究。PDF 首页三位作者均署名和硕联合科技（Pegatron Corporation）PEGAVERSE。
