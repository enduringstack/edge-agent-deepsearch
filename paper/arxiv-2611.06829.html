Enabling AWS Cloud FPGA Development Using High-Level Vitis HLS

6 学校预印本 2026-11-04 · David Rostcheck / arXiv
方向:编译部署方向:量化硬件:FPGA
这是什么一套在 AWS EC2 F2 云端 FPGA 上开发机器学习模型的工具链，补齐了从 Vitis HLS 高层代码到 FPGA 镜像（AFI）的完整流程，还能让编码智能体按用户要求自己写、测、调 FPGA 设计。
有什么结果用微调后的 TinyBERT 做地址命名实体识别验证，在 FPGA 上实现了嵌入层和 4 个编码层中的第 1 层；由于权重从主机内存流式读入，性能明显不如 CPU/GPU 实现。
怎么做到把开发分成 FP32 PyTorch、位精确的量化 Python、HLS C 仿真、真实 FPGA 四级逐层比对，便于定位包括电路级在内的错误，并整理了时序收敛和 HLS 工程经验。
评分依据：面向云端 FPGA 的模型部署工具链，量化与硬件映射流程对边缘 FPGA 有一定参考价值，但验证在云上且性能结果偏弱。贡献主要是工程流程整理，作者以个人邮箱署名。
