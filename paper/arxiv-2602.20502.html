ActionEngine: From Reactive to Programmatic Web Agents via State Machine Memory

11 公司项目 2026-02-24 · Hongbin Zhong; Fazle Faisal; Luis França; Tanakorn Leesatapornwongsa; Adriana Szekeres; Kexin Rong; Suman Nath / arXiv
Microsoft方向:记忆方向:规划推理方向:工具调用
这是什么网页 Agent 通常每一步都要看界面、想下一步、再执行，步数一多就又慢又贵。ActionEngine 先离线把应用摸清楚存成状态机记忆，执行时一次性生成完整程序直接跑。
有什么结果在 WebArena 四个领域 655 个任务上成功率 91.2%，比最强的反应式基线 Claude Code 高 8.5 个百分点，平均任务时延降低 3.2 倍、成本降低 8 倍。
怎么做到爬取 Agent 离线探索应用，构建记录界面状态、可用操作和状态转移的可更新状态机记忆；执行 Agent 据此单次规划合成可执行程序，界面变化时再用反应式兜底修复并回写记忆。
评分依据：工作对象是网页 Agent，运行在云端模型上，与端侧没有直接关系；但用结构化记忆把多次规划压成一次，对算力受限的端侧 Agent 降低调用次数有直接借鉴价值。PDF 首页作者 5 人署名 Microsoft，另 2 人来自 Georgia Tech。 作者机构依据：arXiv PDF 首页署名 Microsoft（PDF 首页作者 Fazle Faisal、Luis França、Tanakorn Leesatapornwongsa、Adriana Szekeres、Suman Nath 署名 Microsoft，邮箱为 microsoft.com）。
