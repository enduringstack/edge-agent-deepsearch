All-Mem: Agentic Lifelong Memory via Dynamic Topology Evolution

10 学校预印本 开源 2026-03-20 · Can Lv; Heng Chang; Shengyu Tao; Mingju Chen; Zhaoxin Fan; Ziwei Zhang; Yuchen Guo; Shiji Zhou / arXiv
方向:记忆应用:长上下文推理
这是什么长期陪伴型 Agent 的记忆越积越多，检索出的内容会冗余、过时或带噪声。All-Mem 用一张可演化的拓扑图来管理终身记忆，既不丢原始证据，又把检索成本控制住。
有什么结果在 LoCoMo 和 LongMemEval-s 上，检索和问答效果都优于代表性记忆系统基线（摘要未给出具体数值）。
怎么做到在线时只在有限的“可见层”上找锚点，控制检索开销；离线时让 LLM 诊断记忆图，用拆分、合并、更新三种操作做非破坏式整理；查询时沿带类型的链接在预算内多跳扩展到归档证据。
评分依据：属于 Agent 记忆运行时，对资源受限设备上的长期记忆管理有迁移价值，但实验未涉及端侧设备；拓扑化、非破坏式整理记忆的思路有一定新意。
