Parallelizing Tool Execution and LLM Generation for Low-Latency Agent Serving

11 公司项目 2026-03-19 · Yifan Sui; Han Zhao; Rui Ma; Zhiyuan He; Hao Wang; Jianxun Li; Kaiqiang Xu; Kai Chen / arXiv
Microsoft; Google方向:调度服务方向:工具调用方向:云端serving模型:Qwen
这是什么面向低时延智能体服务的系统：智能体一轮轮“模型生成—工具执行”串行跑时工具时延会卡在关键路径上，它让工具调用在模型还在生成时就提前投机执行。
有什么结果在深度研究、编码、科学智能体负载上平均任务完成时间降低 43.5%、观测到的工具时延降低 1.8 倍。
怎么做到从智能体反复出现的模式预测未来会调用哪些工具并投机执行，把投机结果隔离直到 LLM 确认，再联合调度工具执行与返回的 LLM 会话，避免瓶颈转移到 GPU。
评分依据：面向智能体服务的运行时优化，属 Agent 工具调用可迁移技术，但在 A100 集群云端 serving 场景、未涉及端侧（相关度 5）；工具调用投机执行加联合调度的思路较新颖（贡献 6）。 作者机构依据：arXiv PDF 首页署名 Microsoft, Google（PDF 首页作者 Rui Ma、Zhiyuan He、Yuqing Yang 署名 Microsoft Research，Kaiqiang Xu 署名 Google（第一作者为上海交通大学））。
