MemMachine: A Ground-Truth-Preserving Memory System for Personalized AI Agents

9 学校预印本 开源 2026-04-06 · Shu Wang; Edwin Yu; Oscar Love; Tom Zhang; Tom Wong; Steve Scargall; Charles Fan / arXiv
方向:记忆应用:RAG应用:长上下文推理模型:GPT
这是什么个性化 Agent 需要跨多次对话记住用户和事实，但常规的上下文窗口和检索增强流程在多轮会话中会逐渐失真。MemMachine 是一个开源的 Agent 记忆系统，尽量原样保存对话而不是让大模型提炼摘要。
有什么结果LoCoMo 上使用 gpt4.1-mini 得分 0.9169；LongMemEvalS 上消融后准确率 93.0%，其中检索阶段优化带来的提升大于写入阶段；与 Mem0 相比输入 token 少约 80%；配套检索 Agent 在 HotpotQA-hard 和 WikiMultiHop 上分别达到 93.2% 和 92.6%。
怎么做到同时维护短期记忆、长期情景记忆和用户画像记忆，完整保存对话片段；检索时以命中片段为中心扩展前后文；检索 Agent 根据问题在直接检索、并行拆解和迭代链式查询之间自动选择。
评分依据：Agent 记忆运行时可迁移到端侧 Agent，并显著减少输入 token，但系统依赖云端模型、未涉及设备部署；工程整合扎实，创新中等。PDF 首页全部作者署名 MemVerge。
