Inside Fast's Model Layer: Matching Every Task with the Right Model

6 官方动态 2026-10-19 · Qwen / Qwen
Qwen方向:调度服务方向:云端serving应用:代码
这是什么介绍 Qoder Fast 档位的模型路由：先用一个轻量分类模型判断这次编程请求属于哪类任务，再挑最合适的模型去执行，以缩短响应时间。
有什么结果Qoder Fast 把首次响应时间从 8 秒降到 3 秒，积分消耗从 1.1 倍降到 0.8 倍；在 1000 多条历史任务上，任务分类平均耗时为数百毫秒级，超过 99% 在 0.5 秒内返回。
怎么做到分类模型只读当前请求和最近对话的结构化摘要（约千 token 量级）并直接输出类别，路由器结合离线评测得到的各任务类型模型优先级、能力需求和可用性来选模型。
评分依据：属于云端多模型路由与时延优化，思路可借鉴到端云协同的模型选择，但本身不涉及端侧设备；方法是常见的任务分类加路由组合。
