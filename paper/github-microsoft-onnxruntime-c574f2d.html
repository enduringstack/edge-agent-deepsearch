方向:量化方向:MoE方向:推理框架硬件:CPU
这是什么ONNX Runtime 为 CPU 新增量化混合专家模型（QMoE）的 INT4、INT3、FP4 计算内核，让 MoE 模型可以直接在 x86 CPU 上跑低比特专家。
有什么结果未报告
怎么做到为 AVX-512 与 AVX2 分别实现共享布局的 INT4、INT3 内核，以及 AVX-512 的 NVFP4/MXFP4 内核，直接读取打包好的低比特专家权重，省掉解包和预打包步骤；新增按原字节读取冷门专家权重的文件专家存储，并补齐 CPU 与 CUDA 结果一致性测试。
评分依据：低比特 MoE 在普通 CPU 上运行属于可迁移到 PC 端的推理技术栈，但目标是 x86 的 AVX 指令集，提交也没有给出速度数据，相关度中等。
