Android Studio supports Gemma 4: our most capable local model for agentic coding

13 官方动态 2026-04-02 · Google / Google
Google方向:端侧agent方向:工具调用应用:代码硬件:GPU模型:Gemma
这是什么Android Studio 的编程智能体 Agent Mode 现在可以改用开发者电脑本地运行的 Gemma 4，不联网、不要 API Key 也能完成多步编码任务，代码不出本机。
有什么结果官方给出的整机内存与存储需求（含 Android Studio 本身）：E2B 需 8GB 内存、2GB 存储；E4B 需 12GB 内存、4GB 存储；26B MoE 需 24GB 内存、17GB 存储，并推荐 Android 开发者使用 26B MoE。未报告速度或准确率数字。
怎么做到在电脑上装 Ollama 或 LM Studio 并下载 Gemma 4，再在 Android Studio 的模型提供方里接入该本地实例；Gemma 4 针对 Android 开发训练、具备工具调用能力，Agent Mode 的规划和工具调用请求全部交给本机 GPU 和内存处理。
评分依据：编程智能体的推理、规划与工具调用闭环完全在开发者电脑本地完成，是本地模型驱动的 PC 端侧 Agent 产品化案例；方法上是现有 IDE Agent 接入本地模型的工程整合。
