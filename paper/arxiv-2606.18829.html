GateMem: Benchmarking Memory Governance in Multi-Principal Shared-Memory Agents

7 学校预印本 2026-06-22 · Zhe Ren, Yibo Yang, Yimeng Chen, Zijun Zhao, Benshuo Fu, Zhihao Shu, Bingjie Zhang, Yangyang Xu, Dandan Guo, Shuicheng Yan / HuggingFace Daily
方向:记忆方向:安全隐私方向:评测基准
这是什么一个评测基准，考察多人共用同一块记忆的智能体能不能管好权限和遗忘。
有什么结果在多种基线和骨干模型上，没有任何方法能同时做到高可用性、稳健的访问控制和可靠的遗忘；长上下文提示常常拿到最好的治理分数，但 token 开销很高。
怎么做到针对以往记忆基准大多假设单用户、忽略了医院、职场、校园和家庭里多人共用助理的现实，该基准同时评估三件事：长程请求伴随状态更新时的可用性、跨情境授权边界的访问控制，以及收到明确删除请求后面向智能体的主动遗忘；覆盖医疗、办公、教育和家庭四个领域，设计了长篇多方对话、增量记忆注入、隐藏检查点、结构化评判和泄漏目标标注。
评分依据：家庭共用助理等场景与端侧设备相关，但基准本身不涉及设备端算力或部署，相关度按宽泛关联计；把可用性、访问控制和遗忘三者放在一起评测并给出「无一方法三者兼顾」的负面结论，诊断价值不错。
