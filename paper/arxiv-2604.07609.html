Blink: CPU-Free LLM Inference by Delegating the Serving Stack to GPU and SmartNIC

8 学校预印本 2026-04-08 · Mohammad Siavashi; Mariano Scazzariello; Gerald Q. Maguire; Dejan Kostić; Marco Chiesa / arXiv
方向:云端serving方向:调度服务方向:KV cache硬件:GPU
这是什么数据中心大模型服务的调度和控制一直压在主机 CPU 上，CPU 一被抢就掉性能。Blink 把这条链路整个交给智能网卡和 GPU，让 CPU 退出稳态推理路径。
有什么结果对比 TensorRT-LLM、vLLM、SGLang：饱和前 P99 首 token 时延最多降 8.47 倍，P99 每 token 时延最多降 3.4 倍，解码吞吐最多提升 2.1 倍，每 token 能耗最多降 48.6%；有 CPU 干扰时其他系统最多劣化两个数量级，Blink 保持稳定。
怎么做到智能网卡接收请求并通过 RDMA 直接写入 GPU 显存；GPU 上常驻一个内核，自己完成批处理、调度和 KV cache 管理，不再需要主机 CPU 参与。
评分依据：纯数据中心 serving 架构，和端侧设备关系很远。把 serving 控制面整体下沉到 GPU+SmartNIC 的思路较新，数据扎实。
