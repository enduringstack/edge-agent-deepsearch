Model Routing Explained: Send Each Request to the Cheapest Model That Passes

5 官方动态 2026-10-07 · Qwen / Qwen
Qwen方向:调度服务方向:云端serving模型:Qwen
这是什么阿里云博客讲解大模型路由：不再默认把所有请求发给旗舰模型，而是在 Qwen Flash、Plus、Max 之间把每个请求发给“能通过质量门的最便宜模型”，不达标再逐级升级。
有什么结果文中示例按每月 100 万请求、以 60%/30%/10% 分流到 Flash/Plus/Max 计算：全部用 qwen3.8-max 每月 7000 美元，路由后 1548 美元加 96 美元升级成本共 1644 美元，降低 76.5%；先试 Flash 再升级到 Plus 的做法在升级率低于 66.6% 时更省钱。
怎么做到规则处理明显的请求，小模型分类器判断难度或意图，级联加质量门兜底；质量门包括离线黄金集评测，以及在线的格式校验、引用检查、拒答检测等低成本检查，每次决策都记录路由、token、时延和成本。
评分依据：讲的是云端模型之间的成本路由，本身不涉及端侧，但“先用小模型、质量不过再升级”的级联思路可迁移到端云协同路由，相关度 3。属于常见工程实践的讲解，贡献 2。
