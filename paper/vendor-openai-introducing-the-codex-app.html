Introducing the Codex app

10 官方动态 2026-02-02 · OpenAI / OpenAI
OpenAI方向:工具调用方向:安全隐私应用:代码硬件:Apple-Silicon模型:GPT
这是什么OpenAI 推出 macOS 版 Codex 桌面应用，作为在本机同时指挥多个编程智能体的“指挥中心”，支持并行任务、长时间任务、技能扩展和定时自动化。
有什么结果原文给出：借助图像生成和网页游戏开发两个技能，Codex 仅凭一条初始提示、消耗 700 多万 token 独立做出一款赛车游戏；自 GPT-5.2-Codex 发布以来 Codex 使用量翻倍，过去一个月超过 100 万开发者使用。
怎么做到每个智能体在按项目组织的独立线程里工作，借助 git worktree 各自在隔离的代码副本上改动；技能把说明、资源和脚本打包供智能体调用；应用沿用 Codex CLI 的开源系统级沙箱，默认只能改当前目录，需要联网等提升权限时向用户申请。
评分依据：智能体的任务编排、代码修改和命令执行发生在用户的 Mac 上，是 PC 端智能体的重要产品形态；但模型推理走云端订阅服务，本地只负责执行和隔离，因此判为非端侧智能体。
