HybridKV: Hybrid KV Cache Compression for Efficient Multimodal Large Language Model Inference

11 学校预印本 2026-04-07 · Bowen Zeng; Feiyang Ren; Jun Zhang; Xiaoling Gu; Ke Chen; Lidan Shou; Huan Li / arXiv
方向:KV cache方向:多模态模型:Qwen
这是什么多模态大模型处理图像和视频时 KV cache 会迅速膨胀。HybridKV 针对不同注意力头的不同行为，分别采用不同的压缩策略。
有什么结果在 11 个多模态基准上用 Qwen2.5-VL-7B 测试，KV cache 内存最多减少 7.9 倍，解码速度提升 1.52 倍，效果几乎不降甚至略有提升。
怎么做到先用以文本为中心的注意力把注意力头分为静态和动态两类，再自上而下分配缓存预算；静态头按文本先验剪掉 token，动态头按块检索需要的缓存。
评分依据：多模态 KV cache 压缩直接缓解端侧显存压力，7B 规模也接近端侧可用范围；但实验在 GPU 上进行，没有端侧设备结果。
