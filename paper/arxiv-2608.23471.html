InjecMEM: Memory Injection Attack on LLM Agent Memory Systems

11 公司项目 开源 2026-08-24 · Hanling Tian; Gengyu Zhang; Zeyang Sha; Jingying Wang; Yuhang Liu; Zhehao Huang; Kun Yang; Xiaolin Huang / COLM 2026
Ant Group方向:记忆方向:安全隐私应用:RAG
这是什么智能体越来越多地带上长期记忆，InjecMEM 证明攻击者只需一次正常对话，就能往记忆里埋入内容，让之后相关话题的回答被操控。
有什么结果在 MemoryOS 上检索命中率最高 35.4%、攻击成功率最高 76.6%；其中 Multi-GCG 达到 76.6% 的 ASR-c 和 35.6% 的 ASR-j，而 DPI、BadChain 和原版 GCG 在该设置下成功率全部为 0；对无关查询没有影响，记忆漂移下仍有效。
怎么做到注入内容由两部分组成：带高召回主题线索、对检索器通用的锚点，保证以后能被检索到；以及用梯度坐标搜索优化的短指令，在不同提示模板和插入位置下都能稳定操控输出。
评分依据：保存个人数据的端侧助理同样依赖记忆检索，这类攻击对其威胁直接，迁移价值明确；单次交互即可生效的设定有警示意义，已被 COLM 2026 接收。公司归属依据 arXiv PDF 首页：作者 Zeyang Sha、Kun Yang 署名蚂蚁集团。 作者机构依据：arXiv PDF 首页署名 Ant Group（PDF 首页作者 Zeyang Sha、Kun Yang 署名 Ant Group，其余作者为上海交通大学）。
