Qoder NEXT Performance Optimization: Achieving Millisecond-Level Code Completion

8 官方动态 2026-01-09 · Qwen / Qwen
Qwen方向:投机解码方向:KV cache方向:量化方向:云端serving应用:代码
这是什么Qoder 团队分享如何把代码补全做到 300 毫秒以内：从上下文收集、模型推理、结果排序到界面渲染全链路压时延，并把“首个可采纳片段”的时延作为核心指标。
有什么结果首个可采纳片段时延 P50 从 800 毫秒降到 300 毫秒；网络往返从 200 毫秒降到 50 毫秒；流式输出把感知等待从 1200 毫秒降到 300 毫秒；约 23% 请求命中缓存，命中时 10 毫秒内返回。
怎么做到推理侧重排提示词把 KV cache 命中率提高约 10%、选用本地 KV cache 调度，解码用 FP8 量化和融合算子，并用自训草稿模型做投机解码；外加就近接入和结果缓存。
评分依据：本身是云端补全服务，但 KV cache、FP8 量化、投机解码与端到端时延拆解的思路可直接迁移到本地补全模型；属成熟技术的工程组合。
