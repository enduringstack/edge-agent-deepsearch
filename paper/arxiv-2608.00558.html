AiFlow: Token-Native Reactive Orchestration with Bounded Backpressure for Streaming LLM Applications

9 学校预印本 开源 2026-08-01 · Qunhui Zhang / arXiv
方向:调度服务方向:工具调用方向:推理框架
这是什么AiFlow 是一个面向流式大模型应用的编排运行时：把模型逐 token 输出当作事件流，在检索、工具调用、安全过滤和多智能体协作组成的图里传递，并给每个节点设定队列上限和背压规则。
有什么结果相比先汇总再处理的方式，应用首段输出时间降低 70.9-94.7%，不改变模型侧首 token 时间；运行时队列深度始终在设定上限内，最大队列比无界策略减少 93.7-96.5%；另做了 Ollama 本地后端的验证。
怎么做到把各家模型的增量输出统一成带类型的事件，每个节点由一个“守护者”管理队列上限、并发、顺序、溢出、取消和重试；工作流可由 DSL 或 JSON 编译，并做类型和并发的静态检查。
评分依据：属于智能体与大模型应用的运行时层，内存有界的设计对资源受限设备有参考价值，也验证了本地 Ollama 后端，但主体不是端侧部署；单作者工程系统，规范化程度高、创新中等。
