Jetson-ORB-SLAM3: Accuracy-Preserving GPU Implementation for Edge Computing Devices

12 学校预印本 开源 2026-08-18 · Rajat Roy; Aditya Arun Kumar Yadav; Hardik Jain / arXiv
硬件:Jetson硬件:GPU方向:编译部署应用:机器人
这是什么在 Jetson 这类低功耗板子上跑视觉惯性 SLAM，特征提取和回环检测太慢；以往的 GPU 移植靠近似 ORB 检测器提速，却改变了轨迹结果。这项工作在 Jetson Orin Nano 上实现了与原版 CPU 结果数值等价的 ORB-SLAM3，并让基于 CNN 的回环检测能实时运行。
有什么结果GPU 版 ORB 前端与 CPU 参考实现的关键点完全一致率 94.7%、描述子比特一致率 99.9%；GPU/CPU 与 Jetson/台式机四种组合在 EuRoC 上的平均轨迹误差相差不超过 0.10 cm。回环检测网络 CosPlace ResNet-50 用原生 TensorRT FP16 引擎单次查询 2.2 ms，比板载 CPU 的 396 ms 快约 180 倍；单目惯性模式在这台 7 W 设备上 11 条 EuRoC 序列平均 32 FPS。
怎么做到在 GPU 上逐步复现参考 ORB 检测器（图像金字塔、FAST、网格非极大抑制、方向与描述子）而不做近似，建图和优化后端仍留在 CPU；学习式地点识别网络绕开 ONNX Runtime 执行器、直接构建 TensorRT 引擎，并放在回环线程里异步运行，不阻塞跟踪。
评分依据：在 Jetson Orin Nano 真机上完整测量了精度与速度，属于明确的边缘部署；其中 AI 部分是 TensorRT 加速的回环识别网络，主体仍是经典几何 SLAM，端侧相关度 7。“精度无损”的移植思路和 ONNX Runtime 执行器在 Orin Nano 上不可用的实测结论很实用，但整体属于工程整合，贡献 5。
