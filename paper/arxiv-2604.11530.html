Beyond Attention Scores: SVD-Based Vision Token Pruning for Efficient Vision-Language Models

10 学校预印本 2026-04-13 · Yvon Apedo; Martyna Poreba; Michal Szczepanski; Samia Bouchafa / arXiv
方向:剪枝稀疏方向:多模态方向:高效推理
这是什么视觉语言模型要处理大量图像 token，推理又慢又占内存。SVD-Prune 是一种无需训练、即插即用的图像 token 剪枝方法。
有什么结果在只保留 32 个甚至 16 个图像 token 的极端预算下，效果持续优于此前的剪枝方法；原文摘要未给出具体分数。
怎么做到对图像 token 特征矩阵做奇异值分解，用统计杠杆分数挑出对全局主要方差贡献最大的 top-k 个 token 保留，避免注意力分数带来的位置偏置。
评分依据：视觉 token 剪枝能直接降低多模态模型推理开销，可迁移到端侧 VLM，但论文未在端侧设备上评测；方法简洁，属于剪枝方向的常规改进。
