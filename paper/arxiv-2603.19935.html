Memori: A Persistent Memory Layer for Efficient, Context-Aware LLM Agents

8 学校预印本 2026-03-20 · Luiz C. Borro; Luiz A. B. Macarini; Gordon Tindall; Michael Montero; Adam B. Struck / arXiv
方向:记忆应用:RAG
这是什么LLM Agent 跨会话记忆通常靠把大段原始对话塞进提示词，费 token 还效果差。Memori 是一个与模型无关的持久记忆层，把对话整理成结构化信息再检索。
有什么结果在 LoCoMo 上准确率 81.95%，优于现有记忆系统，每次查询只用 1,294 个 token（约为完整上下文的 5%）；比竞品少用 67% token，比全上下文方案省 20 倍以上。
怎么做到用增强流水线把非结构化对话转成紧凑的语义三元组和对话摘要，查询时精确检索这些结构化记忆，而不是扩大上下文窗口。
评分依据：Agent 记忆层面向 API 调用场景，主要省云端 token 成本，对端侧小上下文 Agent 有一定迁移价值；本质是结构化抽取加检索的工程整合，且为白皮书性质。
