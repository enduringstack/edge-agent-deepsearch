MOLT: A Fine-Grained GPU Memory Sharing System for LLM Serving with Opportunistic Fine-Tuning

8 学校预印本 2026-10-05 · Jaehoon Yang; Yongbeom Kim; Hojoon Kim; Seung Yul Lee; Jae W. Lee / arXiv
方向:云端serving方向:调度服务硬件:H100
这是什么大模型在线服务的副本里常有显存闲着，而增减副本要几分钟。MOLT 让参数高效微调（如 LoRA）利用这些闲置显存，同时保证推理需要显存时能在几秒内细粒度地拿回来，而且不打断正在进行的微调步。
有什么结果在 H100 SXM 和 B200 上的四个 24B–70B 模型部署、按真实轨迹施加负载时，推理 SLO 达成率保持在 99.7% 以上，完成的微调工作量是“直接丢弃式”显存共享方案的 1.9–3.3 倍。
怎么做到推理可以逐个回收微调步为反向传播保存的激活所占的显存，微调步继续运行，反向时再重算这些激活；回收前确认没有在途 GPU 任务还会访问这块内存，即使存在 CPU–GPU 异步和张量并行也安全；实现为 vLLM 补丁加 PyTorch 扩展。
评分依据：讨论数据中心 GPU 上推理与微调共置的显存调度，与端侧部署基本无关，相关度 2；把显存回收粒度从整个训练样本细化到单个激活、且不丢弃进行中的训练步，系统设计扎实，贡献 6。
