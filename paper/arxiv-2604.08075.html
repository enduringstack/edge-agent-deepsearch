Dual-Pool Token-Budget Routing for Cost-Efficient and Reliable LLM Serving

5 公司项目 2026-04-09 · Xunzhuo Liu; Bowei He; Xue Liu; Andy Luo; Haichen Zhang; Huamin Chen / arXiv
AMD方向:云端serving方向:调度服务方向:KV cache硬件:GPU模型:Llama
这是什么线上 vLLM 集群通常按最长上下文配置每个实例，但绝大多数请求很短，造成 KV cache 过度分配和吞吐浪费。论文把集群拆成短上下文池和长上下文池按预算路由。
有什么结果在 Azure 与 LMSYS 真实流量、A100 上跑 Llama-3-70B，GPU 时长减少 31-42%（集群规模约每年省 286 万美元），抢占率降 5.4 倍，P99 首 token 时延改善 6%。
怎么做到按请求估算的总 token 预算分流，字节到 token 的换算比按类别在线用指数滑动平均学习，无需分词器，调度开销为常数级。
评分依据：纯云端集群调度优化，与端侧设备基本无关。方法简单实用，属工程优化。 作者机构依据：arXiv PDF 首页署名 AMD（PDF 首页作者 Andy Luo、Haichen Zhang 署名 AMD）。
