SuperLocalMemory V3: Information-Geometric Foundations for Zero-LLM Enterprise Agent Memory

11 学校预印本 开源 2026-03-15 · Varun Pratap Bhardwaj / arXiv
方向:记忆方向:安全隐私硬件:CPU
这是什么给 AI Agent 用的本地长期记忆系统第三版，用信息几何等数学工具替代余弦相似度和人工衰减规则，可以完全不依赖大模型和云端。
有什么结果在 LoCoMo 基准上数学层比工程基线高 12.7 个百分点，最难对话上高 19.9 个百分点；完全本地的四通道检索达到 75% 准确率，接入云端后为 87.7%。
怎么做到检索用对角高斯族的 Fisher 信息度量，记忆生命周期用黎曼朗之万动力学建模，用层上同调检测不同上下文间的矛盾；全部数据在本地 CPU 上处理并存于一个 SQLite 库。
评分依据：Agent 记忆可在本地 CPU 离线运行，对端侧个人 Agent 有直接参考；但论文只评测记忆检索准确率，没有给出设备端完整 Agent 闭环的实测，数学框架的实际增益仍需更多验证。
