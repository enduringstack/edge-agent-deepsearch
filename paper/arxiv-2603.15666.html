Compiled Memory: Not More Information, but More Precise Instructions for Language Agents

10 学校预印本 2026-03-12 · James Rhodes; George Kang / arXiv
方向:记忆方向:规划推理模型:GPT
这是什么Agent 记忆通常是把更多信息塞回上下文。Atlas 换个思路：把积累的经验“编译”成系统提示里的更精确指令，不微调、不用检索。
有什么结果CUAD 合同分析上，演化后的提示让 GPT-4o 的 token 级 F1 提升 8.7 个百分点、精确率提升 12.5 个百分点；HotpotQA 联合 F1 提升 3.16 个百分点；同一提示直接用于 Claude Sonnet 4.5 也提升 2.31 个百分点。
怎么做到从成功和失败任务中提取事实，经过三步晋升检查后，以子条目的形式改写 Agent 的系统提示，让记忆以指令而非上下文的方式起作用。
评分依据：把记忆压缩成指令能减少上下文占用，对端侧 Agent 记忆设计有一定启发，但实验全在云端大模型上。作者来自 AlphaBitCore 公司。
