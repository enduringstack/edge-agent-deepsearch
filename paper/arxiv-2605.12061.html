SAGE: A Self-Evolving Agentic Graph-Memory Engine for Structure-Aware Associative Memory

10 学校预印本 2026-05-12 · Juntong Wang; Haoyue Zhao; guanghui Pan; Xiyuan Wang; Yanbo Wang; Qiyan Deng; Muhan Zhang / arXiv
方向:记忆应用:RAG
这是什么语言 Agent 的长期记忆常被当成静态检索库。SAGE 让图结构记忆在使用中自我进化：一个模块负责写入记忆，另一个模块检索并反馈，让记忆越用越好。
有什么结果两轮自我进化后在多跳问答上平均排名最好；零样本开放域迁移在 NQ 上 Recall@2/5 达到 82.5/91.6；在 LongMemEval 和 HaluMem 上多项长期记忆与幻觉诊断指标提升。
怎么做到记忆写入器从交互历史中增量构建结构化图记忆，基于图基础模型的读取器负责检索并把效果反馈给写入器，形成闭环优化。
评分依据：Agent 长期记忆属于端侧 Agent 运行时可迁移的组件，但本文未讨论设备侧部署和资源开销。
