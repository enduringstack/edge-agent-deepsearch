Portable Agent Memory: A Protocol for Cryptographically-Verified Memory Transfer Across Heterogeneous AI Agents

9 公司项目 开源 2026-05-10 · Santhosh Kumar Ravindran / arXiv
Microsoft方向:记忆方向:安全隐私
这是什么智能体积累的记忆被锁在各家运行时里，换模型就丢。Portable Agent Memory 提出一套开放协议，让记忆能在不同智能体之间安全搬迁。
有什么结果提供带 54 个通过测试的 Python SDK，演示了在 GPT-4、Claude、Gemini 和 Llama 之间迁移记忆；未给出性能数字。
怎么做到把记忆分成情景、语义、程序、工作状态和身份偏好五类，用 Merkle-DAG 记录来源防篡改，用能力令牌控制按需披露，并在回灌记忆时防范间接提示注入。
评分依据：Agent 记忆运行时的互操作协议，与端侧 Agent 记忆管理相关但未涉及设备部署；主要是协议工程设计。作者署名 Microsoft，邮箱为 microsoft.com。 作者机构依据：arXiv PDF 首页署名 Microsoft（PDF 首页作者署名 Microsoft Corporation, Redmond，邮箱为 microsoft.com）。
