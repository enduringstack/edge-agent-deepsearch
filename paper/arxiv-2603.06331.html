WorldCache: Accelerating World Models for Free via Heterogeneous Token Caching

11 学校顶会 开源 2026-03-09 · Weilun Feng, Guoxin Fan, Haotong Qin, Chuanguang Yang, Mingqiang Wu, Yuqi Li, Xiangqi Li, Zhulin An, Libo Huang, Dingrui Wang, Longlong Liao, Michele Magno, Yongjun Xu / ICML 2026
方向:高效推理方向:多模态应用:视频
这是什么扩散式世界模型每一步都要反复去噪，交互和长时推演都太慢。WorldCache 是一种免训练的特征缓存加速方法，专门针对世界模型里不同 token 变化快慢不一的特点。
有什么结果在扩散世界模型上端到端最高加速 3.7 倍，同时保持 98% 的推演质量。
怎么做到用基于曲率的分数判断每个 token 好不好预测，对方向突变的“混沌” token 用带阻尼的 Hermite 预测器；累计曲率归一化的漂移信号，只有关键 token 开始漂移时才重新计算。
评分依据：免训练缓存加速可迁移到资源受限的生成推理，作者也强调受限场景的实用性，但没有端侧设备实测；针对世界模型 token 异质性的缓存策略有新意，论文已被 ICML 2026 接收。
