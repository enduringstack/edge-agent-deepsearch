Rethinking the Evaluation of Harness Evolution for Agents

8 学校预印本 开源 2026-07-17 · Yike Wang, Huaisheng Zhu, Zhengyu Hu, Yige Yuan, Zhengyu Chen, Shakti Senthil, Hannaneh Hajishirzi, Yulia Tsvetkov, Pradeep Dasigi, Teng Xiao / arXiv
方向:评测基准方向:工具调用
这是什么重新审视「自动进化 Agent 运行框架（harness）」这类方法的评测方式，指出以往评测既没有对照同等预算的简单基线，又在同一批测试题上搜索和报告成绩。
有什么结果在 Terminal-Bench 2.1 上，自动 harness 进化无论有无测试用例都没能超过简单的测试时扩展方法，泛化也有限；但在长程游戏中，针对任务的 harness 进化在同等预算下比搜索基线在 ARC-AGI-3 上高 80%、在 EdgeBench 游戏上高 11%。
怎么做到在匹配反馈次数和推理预算的条件下，把 harness 进化与测试时扩展、发现式搜索等基线对比，并在留出任务上检验进化出的 harness 能否迁移。
评分依据：讨论的是云端 LLM Agent 运行框架的评测方法，与端侧部署关系较弱；对判断 Agent 运行时改进是否真实有效有借鉴意义。
