Finding bugs across the Python ecosystem with Claude and property-based testing

5 官方动态 2026-01-14 · Anthropic / Anthropic
Anthropic方向:工具调用应用:代码
这是什么Anthropic 用 Claude 做了一个自动找代码缺陷的智能体：先推断函数应满足的性质，再写基于性质的随机测试，在常用 Python 库里找真实 bug。
有什么结果第一阶段在 100 多个热门 Python 包上生成 984 份缺陷报告；人工抽查 50 份，56% 是真实缺陷、32% 值得报给维护者；已有 NumPy 等项目合入修复。
怎么做到智能体读取目标代码和文档，提出应满足的性质，用 Hypothesis 生成测试并运行，再自我判断失败是真缺陷还是测试写错，只在有把握时出报告，最后经专家筛选提交。
评分依据：属于云端代码智能体应用，与端侧推理和部署无关，仅作为智能体工具使用案例低分保留。
