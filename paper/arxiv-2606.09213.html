SNN-MLIR: An MLIR Dialect for Compiling Neuromorphic SNNs from NIR to Bare-Metal C

15 学校预印本 开源 2026-06-08 · Alejandro García Gener; Alvaro Rollón de Pinedo / arXiv
方向:SNN方向:编译部署方向:推理框架硬件:MCU方向:量化
这是什么补上脉冲神经网络从统一交换格式到真正能在嵌入式芯片上跑起来之间缺的那一段编译器。
有什么结果当前支持前馈全连接网络和 CPU 后端，作者评估了数值保真度、跨 CPU 目标的可移植性和量化的代价；项目以 Apache 2.0 许可开源。
怎么做到提供一个面向脉冲网络的 MLIR 方言，加一条从神经形态中间表示经 MLIR 到 C 的编译桥；方言里一小组类型多态算子在浮点和量化数据上行为一致，同一套中间表示既服务仿真也服务硬件部署；Python 前端读入交换格式文件并自动插入重缩放操作以保持各层量化尺度一致，再降级到标准算子，最终产出自包含、无依赖的 C11 代码，可以在任何支持 C 的 CPU 或嵌入式目标上编译运行。
评分依据：产出的是无依赖的 C11 代码、可直接编译到嵌入式目标，正好补上脉冲网络端侧部署里缺失的编译环节，端侧契合度高。工作性质是补齐工具链并开源，目前只覆盖前馈全连接网络和 CPU 后端。
