Revati: Transparent GPU-Free Time-Warp Emulation for LLM Serving

8 学校预印本 2026-01-01 · Amey Agrawal; Mayank Yadav; Sukrit Kumar; Anirudha Agrawal; Garv Ghai; Souradeep Bera; Elton Pinto; Sirish Gambhira / arXiv
方向:云端serving方向:调度服务硬件:GPU
这是什么Revati：不用真 GPU 也能直接运行 vLLM、SGLang 等 LLM 服务框架代码，快速估算不同部署配置的性能。
有什么结果在 vLLM 和 SGLang 上，多模型、多并行配置下预测误差低于 5%，运行速度比真实 GPU 快 5–17 倍。
怎么做到拦截 CUDA API 虚拟化设备，不执行算子而是按预测耗时让虚拟时钟“跳跃”，并设计协议让分布式进程的时钟跳跃保持因果一致。
评分依据：面向云端 LLM 服务配置调优，与端侧关系弱；用真实代码加时间跳跃替代模拟器的思路有工程新意。
