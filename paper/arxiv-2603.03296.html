PlugMem: A Task-Agnostic Plugin Memory Module for LLM Agents

12 公司项目 开源 2026-02-06 · Ke Yang; Zixi Chen; Xuan He; Jize Jiang; Michel Galley; Chenglong Wang; Jianfeng Gao; Jiawei Han / arXiv
Microsoft方向:记忆应用:长上下文推理应用:RAG模型:Qwen模型:GPT
这是什么给任意 LLM 智能体外挂的通用长期记忆模块：把过往经历提炼成紧凑的知识图，而不是原样塞回上下文，解决记忆检索噪声大、上下文爆炸的问题。
有什么结果LongMemEval 上准确率 75.1%，高于任务专用的 LiCoMemory（73.0%），而注入的记忆只有约 363 个 token（后者约 5915 个）；WebArena 购物站成功率 52.6%/58.4%，高于 AgentOccam 的 42.1%/43.6%。
怎么做到借鉴认知科学，把情节记忆抽取成“事实型”和“操作型”两类知识节点组成图，以知识为单位检索，再由推理模块压缩成少量对当前决策有用的提示交给智能体。
评分依据：Agent 记忆运行时在端侧同样关键，它把注入上下文的记忆 token 压到几百个，对上下文和算力紧张的设备有直接迁移价值，但实验用的是 32B/72B 和 gpt-4o，未做端侧部署。即插即用、跨任务不改设计且超过任务专用方案，贡献较新。PDF 首页作者 5-7 署名 Microsoft Research。 作者机构依据：arXiv PDF 首页署名 Microsoft（PDF 首页作者 5、6、7（Michel Galley、Chenglong Wang、Jianfeng Gao）署名 Microsoft Research，其余作者来自 UIUC、清华）。
