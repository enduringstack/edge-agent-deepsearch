MiniMax Open-Sources New Benchmark: Defining Production-Grade Standards for Coding Agent

7 官方动态 开源 2026-01-14 · MiniMax / MiniMax
MiniMax方向:评测基准方向:工具调用应用:代码模型:DeepSeek
这是什么MiniMax 开源 OctoCodingBench，专门检查编程 Agent 在干活过程中是否守规矩：系统提示、多轮指令、系统提醒、仓库里的 CLAUDE.md/AGENTS.md 规范、Skills 和记忆偏好都要遵守，而不只看代码能不能跑。
有什么结果所有被测模型的单条规则遵守率（CSR）都在 80% 以上，但整题全部合规率（ISR）只有 10%~30%；最好的 Claude 4.5 Opus 为 36.2%，开源的 MiniMax M2.1（26.1%）和 DeepSeek V3.2（26%）高于 Claude 4.5 Sonnet（22.8%）和 Gemini 3 Pro（22.9%）。
怎么做到从多种指令来源抽取可逐条检查的规则，按单条规则和整道题两个粒度打分，用整题合规率暴露“大部分照做但总有一条漏掉”的问题。
评分依据：评测对象是云端编程 Agent 的指令遵循，与端侧部署无直接关系，只属于 Agent 技术栈的相邻工作；贡献在于把过程合规单独做成可量化基准，数据集已在 Hugging Face 开源。
