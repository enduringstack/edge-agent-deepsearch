Building a Production-Grade Cloud-Native Large Model Inference Platform with SGlang RBG + Mooncake

6 官方动态 开源 2026-03-10 · Qwen / Qwen
Qwen方向:云端serving方向:KV cache方向:调度服务
这是什么SGLang RBG 和 Mooncake 团队介绍如何在 Kubernetes 上搭建预填充与解码分离、KV cache 外置的生产级云端大模型推理平台。
有什么结果多轮对话测试中，接入 Mooncake 三级缓存后平均首字时延降到 2.58 秒（降低 56.3%），P90 降低 42.7%，输入吞吐提升到每秒 15022 token（提升 49.41%）。
怎么做到用 RoleBasedGroup 把预填充节点、解码节点和 Mooncake 缓存节点作为不同角色统一编排、协同升级与扩缩容；Mooncake 通过分布式内存池和 RDMA 提供跨请求共享的 KV cache。
评分依据：这是典型的云端 serving 与 KV cache 外置方案，与端侧无直接关系；工程整合扎实，但方法并不新。
