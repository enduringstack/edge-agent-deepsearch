方向:推理框架方向:编译部署方向:量化硬件:NPU硬件:MCU硬件:Apple-Silicon模型:Qwen模型:Gemma
这是什么端侧推理框架 ExecuTorch 发布 v1.3.1，这是 1.3 系列第一个广泛发布的补丁版本，大幅扩展了嵌入式、移动和 GPU 后端的覆盖面。
有什么结果Arm 后端在 TOSA 方言下降、量化支持、VGF 基础设施、Cortex-M 测试覆盖和 Ethos-U 兼容性上均有大幅扩展；新增或扩展支持 Qwen3.5 MoE、Gemma 4 31B、LFM2.5、Voxtral 实时与语音合成、Llama4 导出，并补充了安卓端大模型运行器文档；CUDA 后端加入融合 MoE 与 INT4 内核、CUDA 图捕获回放和 GPU 侧采样；Metal 与 MLX 后端加入 Qwen3.5 MoE 路径、Gemma 4 31B 支持和运行时代码签名加固；Vulkan 后端加入线性层与矩阵乘的协作矩阵派发并修复了内存与整数溢出问题；高通 AI 引擎后端扩展了算子支持、低功耗与直通模式以及自定义算子与量化标注接口。
怎么做到围绕各硬件后端分别补齐算子下降、量化标注和运行时能力，并把新模型的导出路径接进框架。
评分依据：ExecuTorch 是 PyTorch 官方的端侧部署路径，本次版本同时推进 Cortex-M、Ethos-U、高通、Metal、MLX 和 Vulkan 等典型端侧后端（相关性 9）。覆盖面相当广，并把多个新模型的端侧导出打通（贡献 7）。
