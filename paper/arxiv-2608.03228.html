SAKI: Score-Aware Low-Rank Key Indexing with Random-Matrix Noise Correction for KV Retrieval

12 学校预印本 2026-08-04 · Lin Zhang / arXiv
方向:KV cache方向:稀疏注意力应用:长上下文推理模型:Llama模型:Qwen模型:Mistral
这是什么长上下文推理时要从 KV cache 里快速找出最相关的 key，现有低秩索引只保留权重或 key 方差，没有直接保住注意力分数。SAKI 是一种无需训练、直接面向注意力分数的低秩 key 索引。
有什么结果在 LLaMA 3.1 8B、Qwen 2.5 7B、Mistral 7B、Llama 3.2 3B 上每个秩都优于 key PCA；秩 32 时把 PCA 剩余的 top-64 召回误差再减少 13%–30%，LLaMA 3.1 8B 从 0.748 提到 0.799，Qwen 2.5 7B 从 0.786 提到 0.850；只需 512 个校准 token。
怎么做到先推导出秩 r 压缩带来的注意力分数失真，得到协方差加权的低秩目标，并用 query-key 算子的 SVD 求出闭式非对称分解；再用随机矩阵理论把真实协方差信号和采样噪声分开。
评分依据：KV cache 检索与压缩属于端侧长上下文推理可以直接借鉴的技术栈，但论文只做离线召回评测、没有设备实测；理论推导和闭式解较扎实。PDF 首页唯一作者署名 Cotality 公司的数据科学部门。
