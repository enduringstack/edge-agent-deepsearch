Add a Specialized Deep Research Skill to Agent Harnesses

6 官方动态 2026-05-20 · NVIDIA / NVIDIA
NVIDIA方向:工具调用应用:RAG方向:规划推理
这是什么NVIDIA 介绍怎么把自家的 AI-Q 深度研究能力作为一个技能挂进 Claude Code、Codex 这类智能体框架。
有什么结果未报告量化指标。文中只给了工程参数，例如需要 Python 3.10 以上、默认服务地址是本机 8000 端口、文档覆盖三种 MCP 接入场景。
怎么做到研究流程分四段：意图分类器先判断该做多深的研究，再向用户澄清，然后浅研究，最后深研究，每一段都用 FreshQA、Deep Research Bench 和 DeepSearchQA 单独调优评估；数据接入支持免认证的 MCP 服务、服务账号 OAuth2 以及转发用户令牌三种方式，部署可以用 Docker Compose 或 Helm 放到开发机、本地集群甚至离网机房。
评分依据：可以部署到开发机和离网机房这一点与本地化部署沾边，但运行载体仍是服务器级环境，端侧相关性低。把研究流程切成可分别评估的四段并做好数据接入认证，是扎实的工程设计。
