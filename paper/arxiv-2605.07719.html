An Efficient Hybrid Sparse Attention with CPU-GPU Parallelism for Long-Context Inference

11 公司项目 2026-05-08 · Feiyu Yao; Zhixiong Niu; Xiaqing Li; Yongqiang Xiong; Juan Fang; Qian Wang / arXiv
Microsoft方向:稀疏注意力方向:KV cache应用:长上下文推理硬件:CPU硬件:GPU模型:Llama模型:Qwen
这是什么长上下文推理时 KV cache 放不进显存，只能放在 CPU 内存里，单靠稀疏注意力仍会卡在 PCIe 带宽和 GPU 空转上。Fluxion 让 CPU 和 GPU 分工协同完成稀疏注意力。
有什么结果在 Llama-3.1-8B 和 Qwen2.5-7B、3 个基准 40 个任务上，平均质量最差只比全注意力低 0.26；相对最强的固定稀疏混合基线提速 1.5-3.7 倍。
怎么做到按每个注意力头预测其特性，分配不同的 KV 预算和稀疏粒度，再用优先级调度器让 CPU 端的 top-k 选择和稀疏计算与 GPU 计算重叠。
