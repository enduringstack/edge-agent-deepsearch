Build Applications on NVIDIA BlueField Faster with NVIDIA DOCA Agent Skills

7 官方动态 2026-10-01 · NVIDIA / NVIDIA
NVIDIA方向:工具调用应用:代码
这是什么英伟达把 BlueField 数据处理器的开发知识打包成一组「技能」放到 GitHub 上，让通用编码智能体写 DOCA 代码时不用靠猜。
有什么结果在 65 条真实开发者提示的测试中，没有这组技能的智能体只满足 19% 的必查项，带技能的达到 100%；在一次并排演示里，带技能的智能体构建 RDMA 应用时少写 73% 的代码、少用 46% 的硬件命令。
怎么做到技能里提供经过验证的接口签名、硬件能力要求和构建约束，覆盖 Flow、GPUNetIO、PCC、RDMA 等整个 DOCA 库，并做成机器可读的规范让智能体直接据此推理。
评分依据：面向数据中心网络加速卡的开发辅助，与端侧部署没有直接关系。把领域知识做成机器可读规范而不是提示词堆砌，并用 65 条真实提示做了对照，方法上比较实在。
