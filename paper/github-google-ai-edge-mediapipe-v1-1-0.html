MediaPipe v1.1.0

11 开源大项目 开源 2026-10-07 · google-ai-edge / GitHub
方向:推理框架应用:RAG方向:多模态硬件:手机硬件:NPU模型:Gemma
这是什么Google 端侧 AI 框架 MediaPipe 发布 1.1.0，主要新增通用嵌入（Universal Embedder）、语义检索（Semantic Retriever）和 LiteRT-LM 集成，让手机、浏览器和桌面应用能在本地做多模态嵌入与检索。
有什么结果新能力覆盖 C++、C、Python、Android、iOS 和 Web；Android 与 iOS 支持多段多模态嵌入和向量库序列化，Python 与 Android 附带基于 SQLite 的向量库；新增 EmbeddingGemma 1/2 决策后端；release 没有报告性能数字。
怎么做到在 Tasks API 中统一 TextPart、AudioPart、ImagePart 和 EmbeddingProvider 接口，底层改用 LiteRT 推理并向应用开放 LiteRT 与 NPU 委托选项；Android 端加入 GPU 输出零拷贝 AHardwareBuffer 的支持，Web 端为通用嵌入器启用 GPU。
评分依据：直接面向手机和浏览器的端侧 AI 框架，本地嵌入加语义检索是端侧 RAG 和 Agent 记忆的基础组件，相关度 7。以接口整合和多平台补齐为主，没有性能数据，贡献 4。
