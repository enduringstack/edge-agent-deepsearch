PREPING: Building Agent Memory without Tasks

8 学校预印本 2026-05-15 · Yumin Choi, Sangwoo Park, Minki Kang, Jinheon Baek, Sung Ju Hwang / HuggingFace Daily
方向:记忆方向:工具调用方向:规划推理
这是什么让智能体在还没见到目标任务之前，就靠自己造的练习题先把流程记忆建起来。
有什么结果在 AppWorld、BFCL v3 和 MCP-Universe 上大幅优于无记忆基线，表现接近用离线或在线经验构建的强方法，而部署成本在 AppWorld 上比在线记忆构建低 2.99 倍、在 BFCL v3 上低 2.23 倍。分析显示主要收益不来自合成数量，而来自提议方对可行性、冗余度和覆盖面的控制，加上有选择的记忆更新。
怎么做到框架核心是一个结构化的「提议方记忆」控制状态：提议方据此生成合成任务，求解方执行，校验方决定哪些轨迹够格写进记忆，并把反馈回传指导后续提议。这样避免了无控制的合成任务变得冗余、不可行甚至无信息，也避免未过滤轨迹污染记忆。
评分依据：冷启动与部署成本的问题在端侧同样存在，但论文不涉及设备端执行，端侧相关性很低。把「任务前记忆构建」单独立为问题，并指出关键在提议侧的控制而非合成量，视角有新意。
