ONNX Runtime v1.24.3

9 开源大项目 开源 2026-03-05 · microsoft / GitHub
方向:推理框架方向:量化方向:MoE方向:安全隐私硬件:CPU
这是什么ONNX Runtime 1.24 的补丁版本，集中修复安全漏洞和若干算子错误，并带来 MoE 量化算子的 CPU 性能提升。
有什么结果4 比特量化 MoE 算子在 CPU 上最高提速 4 倍；其余为漏洞和缺陷修复，未报告其他数字。
怎么做到修复多处堆越界读写（含恶意 LoRA 适配器）和算子融合错误；更新 QMoE CPU 实现，新增反量化加 MatMulNBits 融合，并开始打包 Windows ARM64X 二进制。
评分依据：ONNX Runtime 是 PC 和移动端常用推理运行时，4 比特 MoE 在 CPU 上提速对本地跑 MoE 模型直接有用；但本版以补丁修复为主，创新有限。
