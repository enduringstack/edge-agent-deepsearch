Memory Makes the Difference: Evaluating How Different Memory Roles Shape Conversational Agents

6 学校预印本 2026-06-24 · Yuxin Wang; Paul Thomas; Zhiwei Yu; Yuan Gao; Saeed Hassanpour; Soroush Vosoughi; Robert Sim; Nick Craswell / arXiv
方向:记忆方向:评测基准
这是什么研究对话智能体检索到的记忆承担不同功能角色时，分别会怎样改变回复质量。
有什么结果分析发现不同类型记忆的影响有明显差异，例如澄清类记忆能提升回复的事实准确性和约束意识；摘要未给出统一的量化指标。
怎么做到先给对话记忆做一套细粒度分类，把检索到的记忆按功能角色归类，再设计一个模拟用户视角的以用户为中心的评测框架，在长期对话数据集和前沿大模型上做对照实验。
评分依据：智能体记忆是端侧 Agent 的相邻能力，但本文完全基于云端前沿模型做分析，与设备端部署只有宽泛关联；属分类学加评测框架的实证研究，创新度一般。
