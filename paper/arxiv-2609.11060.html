Grounding Agent Memory: Environment-Probing Curation for Enterprise Agents

9 学校预印本 2026-09-10 · Susheel Suresh; Hazel Mak; Sahil Bhatnagar; Chhaya Methani; Alejandro Gutierrez Munoz / arXiv
方向:记忆方向:工具调用方向:安全隐私
这是什么给智能体的长期记忆做质检：让策展智能体拿只读工具去真实环境里核对候选记忆是否还成立，再决定要不要留。
有什么结果在类生产的 GitHub Copilot 环境里，环境探查把 CLBench 通过率从 39% 提到 73%、折算奖励从 8.60 提到 22.60，同时每题查询从 8.8 降到 4.7、任务智能体成本从 3.38 美元降到 1.68 美元；六个 APEX 世界里 18 组记忆对基线的平均奖励比较全部为正，工具调用下降 16% 到 75%。
怎么做到给已有的异步策展智能体加最小权限的只读世界工具，让它在写入记忆前先检查、限定范围并刷新候选记忆；不需要重训模型，也不改任务智能体、检索器、记忆表示和生产写权限。
评分依据：记忆质检对端侧长期助手同样必要，但论文完全面向企业云端环境（相关性 3）。可直接嵌入现有系统的改造方式很实用（贡献 6）。
