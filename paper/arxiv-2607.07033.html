AnchorPrune: Relevance-Anchored Contextual Expansion for Visual Token Pruning

12 学校顶会 开源 2026-07-08 · Kyuan Oh; Bumsoo Kim / ECCV 2026
方向:剪枝稀疏方向:多模态方向:高效推理应用:视频
这是什么AnchorPrune 是免训练的视觉 token 剪枝方法：高分辨率图片会产生上千个视觉 token，它先保住与问题最相关的一小批“锚点”，再用剩余预算补充互不重复的上下文，从而大幅削减多模态大模型的推理开销。
有什么结果在 LLaVA-NeXT-7B 上，只保留 2880 个视觉 token 中的 160 个，仍能保持完整 token 时 97.6% 的性能；在图像和视频多模态模型上，高压缩比下均优于其他免训练剪枝方法。
怎么做到按与问题的相关度给 token 排序，根据新颖度曲线自适应决定锚点大小并加以保护；剩余名额按“重要性加权的新颖度”挑选与锚点互补的区域，避免补充上下文挤掉关键证据。
评分依据：视觉 token 剪枝能直接降低端侧多模态模型的计算和显存，免训练、即插即用，迁移性好，但论文未做端侧实测；先锚后扩的顺序设计有新意。作者来自韩国中央大学，已被 ECCV 2026 接收。
