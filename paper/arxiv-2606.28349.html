HMARS: A Hierarchical Multi-Agent Memory System for Long-Context Reasoning

7 学校预印本 2026-06-03 · Zeju Li; Ziyang Zheng; Yizhou Zhou; Qiang Xu / arXiv
方向:记忆应用:长上下文推理应用:RAG
这是什么用分层的多智能体把超长上下文当成「有人管的内存」，而不是一堆待检索的片段。
有什么结果在长文档和多轮记忆任务上，总体表现优于检索、重排、全上下文、图结构和智能体式长上下文等各类基线；证据覆盖率分析显示提升来自更完整地取到支撑证据。
怎么做到子 agent 负责各自有界的记忆区域并保持原文可追溯，中层 agent 管理区域上下文并按查询做协调，最后由前沿模型在取回的证据页上做推理；作者另构建了两个诊断基准来考察证据广度和上下文相关的相关性。
评分依据：长上下文记忆管理方法，与端侧部署只有宽泛关联（相关性 2）。分层管理加证据覆盖率分析是合理的设计与论证（贡献 5）。
