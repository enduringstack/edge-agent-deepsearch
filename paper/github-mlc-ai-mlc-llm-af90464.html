mlc-ai/mlc-llm: [Model] Add Gemma 4 E2B text and audio support (#3559)

14 开源大项目 开源 2026-09-29 · mlc-ai / GitHub
方向:推理框架方向:编译部署方向:多模态应用:语音方向:KV cache模型:Gemma
这是什么MLC-LLM 加上了 Gemma 4 E2B 的文本和音频支持，可以把语音直接转成模型能吃的嵌入，不必先走语音识别。
有什么结果这次提交涉及 23 个文件、新增 2628 行；音频塔支持 16000 赫兹单声道、161 到 480000 个采样点的输入；本次里程碑明确只覆盖文本和音频输入，视觉、视频、语音识别、压缩音频和原生服务端路径都不在范围内。
怎么做到实现完整的 Gemma 4 配置，包括文本解码器、共享 KV 的注意力布局，以及把脉冲编码调制音频转成嵌入的音频塔；同时引入带版本的产物清单契约，把任务输入、参数模式和设备要求与旧配置分开声明；编译侧则让 KV cache 支持逐层不同的滑动窗口大小，并允许架构在需要通用缓存操作时退出 FlashInfer 优化。
评分依据：MLC-LLM 走的是 TVM 编译路线，是跨平台端侧部署的主力之一，这次把多模态音频输入落到编译栈里，对设备端语音交互是实质进展。新增的产物清单契约和逐层滑动窗口支持也是编译部署层的实用改动，但功能本身标注为实验性。
