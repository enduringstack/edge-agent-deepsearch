Efficient On-Device Diffusion LLM Inference with Mobile NPU

18 学校预印本 2026-06-11 · Tuowei Wang; Yanfan Sun; Ju Ren / arXiv
方向:推理框架硬件:NPU方向:投机解码方向:KV cache硬件:手机方向:编译部署
这是什么第一个针对手机 NPU 的扩散大模型推理框架，解决扩散式并行解码在手机上反复去噪、算力吃不满的问题。
有什么结果在 LLaDA-8B 上，相对带前缀 KV 缓存复用的 CPU 基线，生成时延降低 17 到 42 倍，同时保持生成质量。
怎么做到三招对齐手机 NPU 的执行特性：用多块投机解码把后期块解码时缩水的算力用未来块的投机 token 填满；用双路渐进修订让已提交 token 在稳定前仍可改、不稳定 token 走 CPU 侧通路刷新而不打断 NPU 的稠密计算；再用交换优化的内存运行时压紧 NPU 可见地址布局并让数据搬运与计算重叠。
评分依据：明确面向智能手机 NPU 的端侧大模型推理框架，并在多种真实硬件平台上实测，端侧契合度最高。三项优化都是针对扩散解码特性重新设计的系统机制，不是常规量化或缓存的整合。
