A Jagged Frontier: Evaluating Robustness of Code Agents to Semantics-Preserving Transformations

7 公司项目 开源 2026-08-18 · Hasan Najib Mahmud; Shreya Gupta; Isha Chaudhary; Nathaniel Enis; Ravi Mangal; Gagandeep Singh; Corina Pasareanu / arXiv
Microsoft方向:评测基准应用:代码模型:Qwen
这是什么AI 编程智能体修复仓库级 bug 时，如果把代码改写成语义等价但长相不同的版本（改控制流、插入死代码、换变量名），它还能不能修好？这篇论文专门测量这种鲁棒性。
有什么结果在 SWE-bench Verified 和 SWE-bench Pro 上，用 mini-SWE agent 和 OpenCode 两种框架搭配 Claude Opus 4.5、Kimi K2.5、MiniMax M2.5、Qwen 3.6-27B 测试：受影响最大的配置平均解题率下降 6.7 个百分点，16 种配置中有 6 种下降具有统计显著性；Qwen 在 mini-SWE agent 下最稳，换到 OpenCode 却最脆弱，更简单的 mini-SWE agent 整体更抗扰动。
怎么做到用随机变体采样器对代码库施加常见的语义保持变换生成扰动版本；同一道题在原版和扰动版上各跑多次，做配对统计，把扰动带来的影响和模型自身的随机性区分开。
