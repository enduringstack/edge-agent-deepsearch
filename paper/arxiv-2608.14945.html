Trust Is Not Enough: Influence Calibration for On-Policy Self-Distillation in Agentic RL

7 公司项目 开源 2026-08-14 · Qizhen Lan; Xi Xiao; Xiangchen Guan; Mengchen Fan; Moule Lin; Jung Im Choi; Lijing Zhu / arXiv
Amazon方向:蒸馏
这是什么用强化学习训练语言智能体时，常让一个能看到特权信息的“自我老师”逐 token 指导学生。这篇指出只按老师可信度分配指导权重不够，还要看这个 token 是否真正有利于当前强化学习目标。
有什么结果在 ALFWorld、WebShop 和 Search-QA 上，GRPO 与 GiGPO 两种优化器、1.5B 到 7B 两个模型家族下所有汇总指标都优于只按可信度分配；7B 模型 ALFWorld 成功率 96.1%、WebShop 得分 93.1；分给与目标相反 token 的老师支持占比从 60.1% 降到 37.8%，与强化学习梯度的余弦相似度提高 0.192。
怎么做到对每个被监督 token 估计它对强化学习代理目标的一阶影响，经批内自适应校准转成有界权重，只作用于蒸馏损失，并保持每轮动作内的总监督量不变，不需要额外的前向计算。
