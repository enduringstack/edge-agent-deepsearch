GitOfThoughts: Version-Controlled Reasoning and Agent Memory You Can Replay, Diff, and Merge

7 学校预印本 2026-06-12 · Pavan C Shekar; Abhishek H S; Aswanth Krishnan / arXiv
方向:记忆方向:评测基准
这是什么代码和实验都有版本管理，模型的推理过程却跑完就没了；这篇把智能体的推理树存成一个 git 仓库，可以回放、比对和合并。
有什么结果作者在两个基准、两种模型规模上比较无记忆、Markdown 文件、向量库、图和 git 五种记忆存储，并做了预注册的重复实验，结论是在新问题上记忆并没有提升准确率，一个早期的积极结果在重复后没有站住。
怎么做到每个被打分的思考步骤存成一次提交，分数记在注解里，结果打成标签，检索就是对智能体自己历史记录的 git log 查询。
评分依据：智能体记忆形式与端侧智能体相关，但论文完全不涉及设备端约束，相关度低，按相邻工作保留。用版本控制系统承载推理树的思路有趣，而且难得地报告了「记忆没有帮助」这个否定结论，贡献中等。
