Autonomous Action Runtime Management(AARM):A System Specification for Securing AI-Driven Actions at Runtime

9 学校预印本 2026-02-10 · Herman Errico / arXiv
方向:安全隐私方向:工具调用
这是什么AARM 是一份给 AI 智能体“动作执行”做运行时安全把关的开放规范：在工具调用真正执行前拦截、评估并留痕。
有什么结果未报告
怎么做到在动作执行前拦截请求，累积会话上下文，对照策略和用户意图判断放行或拒绝，并记录防篡改凭据；给出协议网关、SDK 插桩、内核 eBPF、厂商集成四种落地架构。
评分依据：属于 Agent 工具调用运行时的安全层，端侧 Agent 同样需要动作授权和审计，可迁移；但只是规范与威胁模型，没有实现和实验，作者为独立研究者。
