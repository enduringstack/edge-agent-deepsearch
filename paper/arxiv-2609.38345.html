OpenCollab: A Multi-Agent Coding Framework with Programmable Collaboration and Controllable Runtime

7 学校预印本 2026-09-29 · Chun-Wah Hsu; Kai Gong; Yu Wu; Xianhe Chen; Mengyang Liu; Jie Li; Hanyu Li; Zhixuan Liu / arXiv
方向:规划推理应用:代码方向:评测基准
这是什么多智能体写代码的系统都假设配好的分工会被老实执行，现实并非如此。这份工作做了统一基础设施，并量化「声明的组织形式到底实现了多少」。
有什么结果实验显示智能体在不同配置下的协作方式差别极大，只改任何一个维度，组织遵从度就会从 47.2% 变到 97.2%；在多个智能体编码基准上，基于该框架搭的双编码者工作流相比 Mini-SWE-agent、Codex CLI 和 Claude Code 等主流框架取得了新的最好成绩。
怎么做到统一组织设计、在共享运行时上施加实验控制，并通过细粒度事件流追踪执行过程；在此基础上定义「遵从度」指标来量化声明的组织形式是否真的被实现。
评分依据：与端侧部署没有直接关系。指出「评测多智能体时组织形式根本没被执行」这个长期被忽视的混淆因素，并把它变成可测量的指标，是方法论上的实质贡献。
