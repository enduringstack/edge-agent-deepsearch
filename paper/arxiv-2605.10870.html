Remember the Decision, Not the Description: A Rate-Distortion Framework for Agent Memory

12 公司项目 2026-05-11 · Mingxi Zou; Zhihan Guo; Langzhang Liang; Zhuo Wang; Qifan Wang; Qingsong Wen; Irwin King; Lizhen Qu / arXiv
Meta方向:记忆方向:规划推理
这是什么长任务智能体的运行时记忆有限，该记什么、能忘什么？这项工作主张记忆要保留「影响决策的区别」，而不是忠实描述过去。
有什么结果在合成诊断任务和长对话基准上，相同运行时记忆预算下 DeMem 都有稳定提升，摘要未给出具体数字。
怎么做到把记忆压缩看成以决策质量损失为失真度量的率失真问题，推导出可安全遗忘的边界；据此提出在线记忆学习器 DeMem，只有数据证明合并会造成决策冲突时才细分记忆，并给出近似最优的遗憾界。
评分依据：智能体记忆在有限预算下的取舍对端侧 Agent 有直接参考价值，但论文未涉及设备部署；理论框架新颖。作者署名含 Meta AI 与松鼠 AI（Squirrel Ai Learning）。 作者机构依据：arXiv PDF 首页署名 Meta（PDF 首页作者 Qifan Wang 署名 Meta AI，Qingsong Wen 署名 Squirrel Ai Learning 研究院）。
