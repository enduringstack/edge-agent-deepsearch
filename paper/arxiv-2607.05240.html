Optimizing ML Workload Partitioning between CPUs and CIM Accelerators for Heterogeneous Computing

11 学校预印本 2026-07-06 · Joel Klein, Rebecca Pelke, Roberto Laudani, Jan Moritz Joseph, Rainer Leupers / VLSI-SoC 2026
方向:编译部署方向:调度服务硬件:CIM硬件:CPU
这是什么存内计算（CIM）加速器擅长做矩阵向量乘，但阻变存储容量小、写入慢、寿命有限；论文给出在 CPU 与 CIM 之间切分机器学习负载的优化框架。
有什么结果异构 CPU-CIM 执行相比纯 CPU 执行，在边缘 CPU 上最高加速 30.9 倍，在高性能 CPU 上最高加速 7.3 倍。
怎么做到用整数线性规划在阻变存储约束下最小化端到端推理延迟，考虑并行性，并结合实测画像与解析模型；再做设计空间探索，给出未来 CIM 设计建议。
评分依据：面向边缘 CPU 加 CIM 加速器的异构推理切分，与端侧硬件部署直接相关；方法是 ILP 建模的工程整合，已被 VLSI-SoC 2026 接收。
