Autonomous Topology Mutation: Safe Runtime Restructuring for Multi-Agent LLM Systems with Capability, State, and Shadow Invariants

8 学校预印本 2026-06-04 · Bronislav Sidik; Chaya Levi; Nizzan Kimhi / arXiv
方向:调度服务方向:安全隐私方向:规划推理
这是什么让多智能体系统在运行中自己重组团队结构：发现某个 agent 过载就把它拆成几个专职子 agent。
有什么结果在 720 次 DeepSeek-V3 驱动的任务运行中，拆分机制把代码任务成功率从 3.3% 提升到 61.7%；高隐私记忆泄露事件从每任务 2.0 次降到 0；运行时护栏只增加不到 500 微秒的 p99 时延。
怎么做到用队列深度、上下文抖动、工具错误率等六个信号算「瓶颈指数」，超阈值就把过载 agent 分解成子 agent 并让父 agent 转为协调者；状态迁移按隐私级别路由，新拓扑先在影子模式验证通过才接真实流量。
评分依据：多智能体运行时自适应重构，与端侧部署只有间接关系（相关性 3）。安全不变式加影子验证的工程设计扎实，但仍在云端框架层面（贡献 5）。
