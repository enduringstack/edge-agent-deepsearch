PALUTE: Processing-In-Memory Acceleration via Lookup Table for Edge LLM Inference

16 学校预印本 2026-06-08 · Runyang Tian; Yanru Chen; Weihong Xu; Tajana Šimunić Rosing / arXiv
方向:量化硬件:CIM方向:能耗功耗方向:高效推理模型:Qwen
这是什么一个基于单片三维 DRAM 的查表式存内计算加速器，面向功耗和面积都很紧的端侧设备上的大模型推理。
有什么结果周期精确仿真和寄存器传输级综合显示，在 W4A4 配置的 Qwen3-4B 上端到端吞吐达每秒 1264 token、功耗 0.16 瓦，能效相对 CHIME 提升 12.8 倍、相对 FIGLUT 提升 1.6 倍，面积效率相对 PIMPAL 提升 2.0 倍。
怎么做到利用单片三维 DRAM 存储阵列块的垂直组织方式在内存内部直接完成查表，以较小的面积代价换取高并行度；再配一个近内存的查表生成器，为矩阵乘和逐元素非线性算子低延迟地生成表；系统层面用分层与调度策略减少跨存储层级的数据搬运。
评分依据：明确面向功耗面积受限的端侧大模型推理，并给出 0.16 瓦下每秒上千 token 的量化结果，端侧契合度高。用三维 DRAM 的垂直结构解决查表法固有的容量与查找时延开销，针对性强。
