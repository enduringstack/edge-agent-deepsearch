Accelerating LLAMA inference on mobile CPUs using Qualcomm Matrix Extensions

15 官方动态 开源 2026-04-07 · Qualcomm / Qualcomm
Qualcomm方向:高效推理方向:量化方向:推理框架硬件:Snapdragon硬件:CPU硬件:手机模型:Llama模型:Gemma
这是什么高通实测其手机 CPU 内置的矩阵扩展 QMX（兼容 Arm SME）对大模型推理的加速效果，并给出在骁龙平台上 30 分钟内复现的步骤。
有什么结果在骁龙 8 Elite Gen 5 手机平台上用 llama.cpp 对比仅用 NEON：8 比特量化模型首 token 时延最高快 2.9 倍（单线程），4 线程约 2.0 倍，解码最高约 1.5 倍；4 比特模型首 token 最高快 2.07 倍，解码提升有限（约 1.2 倍），已被内存带宽卡住。
怎么做到QMX 在 CPU 里提供分块矩阵乘指令并支持 INT8/BF16，直接加速预填充阶段计算密集的矩阵乘；测试覆盖 Gemma 270M/1B/4B 和 Llama 1B/3B/8B 的 GGUF 量化模型，固定 CPU 频率、输入输出各 128 token。
评分依据：手机真机上的大模型推理实测，数据扎实且可复现，端侧相关度高；结论（预填充受益大、解码受内存带宽限制）属于工程测量，方法创新一般。
