Xcode 26.3 unlocks the power of agentic coding

10 官方动态 2026-02-03 · Apple / Apple
Apple方向:工具调用应用:代码
这是什么苹果发布 Xcode 26.3 候选版，在 Mac 上的开发工具里直接接入 Anthropic 的 Claude Agent 和 OpenAI 的 Codex 等编程智能体，让它们自主拆解任务、改代码、调用 Xcode 内置工具，并通过 MCP 协议向任何兼容的智能体开放 Xcode 能力。
有什么结果未报告
怎么做到智能体可以搜索苹果开发文档、浏览项目文件结构、修改项目设置，并通过截取 Xcode Previews 界面预览、反复构建修复来自查结果；Xcode 同时把这些能力以 Model Context Protocol 暴露出来，其他智能体或工具也能接入。
评分依据：智能体的工具调用发生在开发者的 Mac 上，但规划和推理由云端模型完成，原文未说明模型在本地运行，按非端侧 Agent 处理。贡献在于主流 IDE 把智能体闭环和 MCP 接口原生化，属于产品层面的重要整合。
