Environment-free Synthetic Data Generation for API-Calling Agents

9 公司项目 2026-07-21 · Seanie Lee, Sanjoy Chowdhury, Chao Jiang, Cheng-Yu Hsieh, Ting-Yao Hu, Alexander T Toshev, Oncel Tuzel, Raviteja Vemulapalli / arXiv
Apple方向:工具调用方向:规划推理
这是什么训练会调用 API 的智能体需要大量能改变状态的真实环境，搭建成本极高。这篇工作用大模型充当“世界模拟器”来扮演 API 后端，只给领域名就能自动合成 API、任务和训练轨迹。
有什么结果在训练中完全未见过的 AppWorld 和 OfficeBench 两个有状态基准上，用合成数据微调后性能显著提升；摘要未给出具体数字。
怎么做到先从领域名自动生成 API 与任务，再让教师智能体解题，同时由大模型模拟器实时跟踪状态并返回 API 结果，最后由自动评审筛选高质量轨迹用于微调。
评分依据：属于工具调用智能体的训练数据合成，不涉及设备端执行，相关度低；对构建能离线训练的小型 API 智能体有参考价值。PDF 首页全部作者署名 Apple。 作者机构依据：arXiv PDF 首页署名 Apple（PDF 首页全部 8 位作者署名 Apple）。
