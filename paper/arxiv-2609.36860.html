IronLLM: Forging Compact Edge-Native Language Models for Real-Time Embodied Intelligence

16 学校预印本 2026-09-29 · Changdi Yang; Fengquan Jiao; Haochih Lin; Haoran Yang; Jing Xiao; Liangyu Huo; Suxin Lu; Tiance Chen / arXiv
方向:模型架构方向:高效推理方向:KV cache方向:蒸馏方向:量化
这是什么一个 6.54 亿参数、专为设备端推理设计的语言模型，从注意力结构到多 token 预测再到归一化层，都是按端侧时延和量化效率来挑的。
有什么结果共享 KV 的多 token 预测设计免去了逐深度的 KV cache 重放，并用轻量验证头实现无回滚草稿，带来 1.48 倍解码加速；模型用约 6.2 万亿 token 预训练，评测显示其表现可与 Qwen3.5-0.8B、MiniCPM5-1B 等更大模型竞争，且在许多任务上回答更简洁；另有一个把 RMSNorm 换成 Dynamic Tanh 并简化若干昂贵组件的轻量版本，推理和量化效率更好。
怎么做到混合注意力架构配上共享 KV 的轻量多 token 预测；预训练走质量导向的数据流水线，后训练用多领域在线策略蒸馏把各领域专长教师的能力整合进来；为满足端侧低时延需求还采用了只做指令版、不带长思考的设计。
评分依据：从架构选型到后训练再到归一化层替换，每一步都明确以设备端时延和量化友好为准绳，端侧契合度很高。共享 KV 的多 token 预测免去逐深度重放、并做到无回滚草稿，是针对端侧内存与时延的实质设计。
