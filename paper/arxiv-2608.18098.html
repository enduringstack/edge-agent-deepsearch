Fractional Decay KV-Cache: Ownership-Aware Memory Management for Improved Inference Relevancy in Dialog Systems

11 学校预印本 2026-06-09 · Sukanta Ganguly / arXiv
方向:KV cache方向:高效推理应用:长上下文推理
这是什么一种 KV 缓存管理算法，针对多轮对话里话题会变的特点，决定哪些缓存条目该留、哪些该淘汰。
有什么结果五类多轮对话场景各 600 段对话的实验中，综合的后期轮次对齐指标比当前最好的重要 token 基线 H2O 高 6.7%，话题切换场景高 127%、渐进演化高 87%、混合话题高 30%；适应新话题的速度是 H2O 的 3.6 倍，话题多样性 80.6% 为所有方法最高。
怎么做到给每个缓存的键值对维护双通道打分：一个累计注意力通道跟踪整体重要性，另一个按时间衰减并带强化式更新的新近相关性通道；再用一个由归属损失驱动的自适应学习率保证收敛不震荡。整个算法完全在 CPU 上运行，开销可忽略。
评分依据：KV 缓存淘汰直接决定端侧长对话能撑多久，算法完全跑在 CPU 上、开销很小，对设备端有迁移价值，但没有端侧实测。双通道打分是在已有重要 token 方法上的合理扩展。
