Optimize Supply Chain Decision Systems Using NVIDIA cuOpt Agent Skills

7 官方动态 开源 2026-05-04 · NVIDIA / NVIDIA
NVIDIA方向:工具调用硬件:GPU
这是什么NVIDIA 把自家 GPU 加速的运筹优化求解器 cuOpt 打包成大模型 Agent 可调用的“技能”，让 Agent 能把自然语言描述的供应链问题交给 GPU 去求解。
有什么结果正文称 cuOpt 求解线性规划、混合整数规划和路径问题比 CPU 求解器快几个数量级，但没有给出这个供应链参考工作流本身的量化对比。
怎么做到Agent 用 LangChain Deep Agents 把业务目标拆解成数学模型，再通过 agent skills 调用 cuOpt 在 GPU 上求解，输出多周期生产与库存计划；可用云端 GPU 实例或本地 Docker 部署。
评分依据：这是云端/数据中心 GPU 上的 Agent 工具调用工作流，与端侧部署关系很弱；贡献主要是把现成求解器封装成 Agent 技能的工程整合。
