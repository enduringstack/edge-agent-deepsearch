ElasticMem: Latent Memory as a Learnable Resource for LLM Agents

9 学校预印本 2026-05-29 · Tao Feng; Chongrui Ye; Fangxu Yu; Tianyang Luo; Jingjun Xu; Xueqiang Xu; Haozhen Zhang; Weizhi Zhang / arXiv
方向:记忆方向:高效推理模型:Qwen
这是什么把记忆当成可伸缩的隐空间资源：按当前问题给每条记忆分配不同的「占位预算」。
有什么结果在 Qwen2.5-3B-Instruct 和 Qwen2.5-7B-Instruct 两个底座上，问答加权平均准确率相比最强基线分别提升 26.2% 和 24.6%，ALFWorld 成功率提升 66.3% 和 27.2%，且在 ALFWorld 上平均 token 消耗最少。
怎么做到离线建一个带检索键和内容缓存的隐空间记忆库，运行时从推理器的隐状态自适应检索，再由一个学出来的策略给每条取回的记忆分配可变的隐空间预算，最后把选中的隐状态作为软记忆 token 注入生成；整个记忆使用过程用下游任务奖励通过组相对策略优化来训练。
评分依据：在 30 亿参数这类端侧可部署规模上验证，且 token 消耗更少，对本地长程助手有参考价值，但没有设备实验（相关性 3）。把记忆预算做成可学习的弹性资源，比固定容量接口前进了一步（贡献 6）。
