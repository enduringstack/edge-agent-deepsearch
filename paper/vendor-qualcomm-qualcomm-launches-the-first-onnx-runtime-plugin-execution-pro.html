Qualcomm launches the first ONNX Runtime Plugin Execution Provider

16 官方动态 2026-05-20 · Qualcomm / Qualcomm
Qualcomm方向:推理框架方向:编译部署硬件:Snapdragon硬件:NPU硬件:手机
这是什么高通发布业界第一个公开的 ONNX Runtime 插件式执行提供者，让自家 AI 栈的加速能力不再跟着 ONNX Runtime 的发版节奏走。
有什么结果未报告性能数值。官方给出的是节奏上的变化：优化、修复和算子覆盖按月随插件发布，不必再等 ONNX Runtime 的季度版本，并称这是唯一一个开源了执行提供者代码的硅片厂商方案。
怎么做到执行提供者原本要编进 ONNX Runtime 主仓，现在改成实现一套稳定接口的动态加载共享库，可以独立开发、独立版本、独立发布；模型的算子和子图照常由它分派到骁龙平台的 CPU、GPU 或 NPU 上执行，覆盖手机、PC、物联网和机器人。
评分依据：直接关系到骁龙平台上手机、PC 和物联网设备的模型加速怎么落地，推理分派到端侧 NPU，端侧契合度极高。把执行提供者从主仓解耦成插件，解决的是端侧推理栈长期的版本耦合痛点，属于生态级的架构改动。
