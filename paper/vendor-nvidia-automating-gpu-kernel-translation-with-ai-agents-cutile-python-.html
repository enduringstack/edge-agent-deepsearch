Automating GPU Kernel Translation with AI Agents: cuTile Python to cuTile.jl

6 官方动态 开源 2026-04-30 · NVIDIA / NVIDIA
NVIDIA方向:工具调用方向:编译部署应用:代码硬件:GPU
这是什么NVIDIA 演示让编码 Agent 把 cuTile Python 写的 GPU 内核自动翻译成 Julia 版 cuTile.jl，解决手工移植容易出现静默错误的问题。
有什么结果一个典型 GEMM 内核的转换在前沿大模型上约 4 分钟、消耗约 7.8 万 token，全程无需人工干预；后续内核因复用规则和示例转换更快。
怎么做到把两种语言的差异（0/1 起始下标、显式广播、行列主序、API 命名）整理成 17 条关键规则、API 对照表、静态校验器和示例，打包成 TileGym 里的一个 Agent 技能，让模型一次生成可通过校验的内核。
评分依据：面向数据中心 GPU 的内核开发工具链，本身不涉及端侧推理；用技能包约束 Agent 做跨语言代码迁移的做法可借鉴，但属于工程实践分享。
