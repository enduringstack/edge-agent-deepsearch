这是什么阿里开源端侧推理引擎 MNN 发布 3.5.0 版本，重点扩展了大模型在更多硬件后端上的推理能力，并加强了手机端语音对话体验。
有什么结果发布说明称新的二进制 tokenizer 格式让加载速度提升 20 倍以上；Vulkan 推理、TurboQuant KV cache 量化、多轮 Prompt Cache 等未给出具体数字。
怎么做到Vulkan 后端新增大模型推理，新接入摩尔线程 MUSA 后端，高通 QNN 后端支持 Attention 算子，CPU 支持 RISC-V 向量扩展；新增 TQ3/TQ4 两种 KV cache 量化和多轮对话文本级 Prompt Cache；MNNChat 安卓应用加入回声消除打断、实时视觉语音和 TTS 模型。
评分依据：MNN 是面向手机和嵌入式设备的推理引擎，本版直接扩充了手机 GPU（Vulkan）、高通 NPU（QNN）和 RISC-V 上的大模型推理，端侧相关度高。改动以工程整合为主，低比特 KV cache 量化和多轮缓存对端侧长对话有实用价值。
