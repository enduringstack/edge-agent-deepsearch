Building a C compiler with a team of parallel Claudes

9 官方动态 2026-02-05 · Anthropic / Anthropic
Anthropic方向:规划推理方向:工具调用应用:代码
这是什么Anthropic 研究员让 16 个 Claude Opus 4.6 智能体在几乎无人干预的情况下并行协作，从零用 Rust 写出一个能编译 Linux 内核的 C 编译器，文章总结了让长时间自主运行的智能体团队保持正轨的经验。
有什么结果前后近 2000 次 Claude Code 会话、约 2 万美元 API 费用，产出约 10 万行代码的编译器，能在 x86、ARM 和 RISC-V 上编译 Linux 6.9。
怎么做到用一个无限循环的脚本让每个 Claude 做完一个任务就自动接下一个；每个智能体跑在独立 Docker 容器里，各自克隆共享 git 仓库，通过在任务目录写锁文件来认领任务、靠 git 合并同步成果；主要靠高质量测试让智能体在无人监督下保持方向，没有专门的编排智能体。
评分依据：全部在云端容器中运行，与端侧设备无关，只对 Agent 运行时设计有间接参考。长程多智能体自主开发的规模与工程经验少见，贡献较高。
