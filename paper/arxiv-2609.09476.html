From Fixed Keys to Readable Schemas: Small Language Models for Vehicle Agent Function Calls

14 学校预印本 2026-09-08 · Hamed Jafarzadeh Asl; Yuanhao Yu; Vahid Partovi Nia / arXiv
方向:工具调用方向:评测基准方向:高效推理应用:IoT命令
这是什么车载助手要在严格的内存和时延限制下把自然语言变成准确的车辆函数调用，这篇比较两种把可用函数告诉小模型的方式：专用功能 token 与直接在提示里给函数 schema。
有什么结果论文报告：在训练见过的函数上，规模帮助有限，270M 模型能追平 1.7B，最好的是 0.6B；在没见过的函数上功能 token 方式按构造就是 0 分，schema 方式能泛化且随规模提升明显；对超出范围的请求，功能 token 方式会调用一个本不存在的函数，schema 方式更可靠地拒答。
怎么做到作者从 Android Automotive 里整理出覆盖 79 个车辆函数、9822 条单轮样例的基准（含留出函数和应当拒答的请求），在 270M 到 1.7B 的四个小模型上做同等条件的微调对比。
评分依据：面向车机端侧部署的小模型函数调用，设备语境和内存时延约束都写得很清楚；「小模型不是越大越好、0.6B 是甜点」和「schema 方式才能拒答」这两个结论对端侧 agent 的接口设计有直接指导。
