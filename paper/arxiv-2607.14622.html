ExaGEMM: Exploration Framework for CPU-Driven ML Inference via Associative In-Register Computing for Low-Bit GEMM

12 学校顶会 2026-07-16 · Hyunwoo Oh; Suyeon Jang; Hanning Chen; Sanggeon Yun; Ryozo Masukawa; Mohsen Imani / ICCAD 2026
方向:量化方向:编译部署硬件:CPU
这是什么ExaGEMM 是一个软硬件协同探索框架，研究如何只给 CPU 增加很少的指令支持，就能高效执行 1/2/4 比特等超低比特矩阵乘。
有什么结果在代表性模型和 CPU 目标上，相比纯软件基线延迟改善 13.29 倍；解析模型在仿真前剪掉 99.2% 的候选设计。
怎么做到利用 CPU 现有 SIMD 通路完成查表生成和累加，只新增寄存器内选择与送数机制；用解析模型联合搜索内核参数和轻量指令扩展，再自动生成指令规格、gem5 补丁和 GEMM 内核做验证。
评分依据：低比特 GEMM 是端侧 CPU 推理的核心算子，工作直接服务于 CPU 推理加速；但结果来自 gem5 仿真和新增指令设计，尚未落到现成芯片。PDF 首页作者均署名加州大学尔湾分校，未出现 OPPO。
