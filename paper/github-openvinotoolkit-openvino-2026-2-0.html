方向:推理框架方向:KV cache方向:量化方向:编译部署硬件:CPU硬件:GPU
这是什么英特尔端侧推理框架 OpenVINO 发布 2026.2.0，扩了一批新模型支持，并在压缩和部署能力上做了推进。
有什么结果发布说明列出的具体能力包括：CPU 与 GPU 新增支持 Gemma 4 E2B/E4B、Qwen3.5、Qwen3.6、LFM2 系列等模型，GPU 侧启用 INT4 的 KV 缓存压缩，官方称在 3.2 万 token 以上长提示词场景能显著降低显存占用；并兼容 Hugging Face Transformers 5.0。
怎么做到GenAI 侧新增扩展加载机制，允许用户注册框架未内置的自定义算子；KV 缓存按 INT4 存储以压低长上下文的显存占用；并为 LFM2 系列模型补上缩放点积注意力的执行通路。
评分依据：OpenVINO 是面向 CPU、集成显卡和边缘设备的端侧推理框架，本次更新直接作用于端侧模型覆盖与显存占用，端侧契合度很高。贡献上是框架的常规大版本迭代，INT4 KV 缓存压缩属于业界已有做法的落地。
