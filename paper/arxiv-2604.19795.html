Prism: An Evolutionary Memory Substrate for Multi-Agent Open-Ended Discovery

9 学校预印本 2026-04-08 · Suyash Mishra / arXiv
方向:记忆方向:规划推理
这是什么给多智能体开放式探索系统设计的统一记忆层 Prism，把文件持久化、向量记忆、图记忆和进化搜索放进一个框架。
有什么结果在 LOCOMO 记忆基准上 LLM 评审分 88.1，比 Mem0 高 31.2%；在 CORAL 风格的进化优化任务上，4 个 Agent 的 Prism 改进速度是单 Agent 基线的 2.8 倍。
怎么做到按信息熵把记忆分到技能/笔记/尝试三层，用带因果边的记忆图记录来源，按信息价值决定检索什么，并用心跳式整理和“复制-衰减”动力学淘汰低价值记忆。
评分依据：Agent 记忆运行时可迁移到端侧 Agent，但论文面向云端多智能体系统，未讨论资源受限部署；框架整合多种已有范式，原创度中等。作者邮箱为 roche.com 域名。
