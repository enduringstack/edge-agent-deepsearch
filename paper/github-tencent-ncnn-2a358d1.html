Tencent/ncnn: x86 avx-ne-convert optimization for bf16 gemm and conversion (#6947)

10 开源大项目 开源 2026-09-07 · Tencent / GitHub
方向:推理框架方向:高效推理方向:编译部署硬件:CPU
这是什么腾讯 ncnn 新增了一批基于 x86 AVX-NE-CONVERT 指令集的 bf16 优化，覆盖卷积、GEMM、BatchNorm 等多类算子。
有什么结果提交页未报告速度数字，只能看到改动规模：152 个文件、新增 6792 行、删除 1802 行。
怎么做到为多种层类型新增 *_x86_avxneconvert.cpp 实现走快路径，加上运行时的 CPU 能力检测，并用 _mm_comp_bcstnebf16_ps 之类的新宏改写原有的 bf16 转换函数。
评分依据：ncnn 是移动端推理引擎的老牌代表，这次优化的是 x86 桌面路径而非手机 ARM 路径，所以端侧契合度中等；内容是指令集特化的算子实现，属于常规工程优化。
