Lever: Speculative LLM Inference on Smartphones

16 学校预印本 2026-05-16 · Tuowei Wang; Fengzu Li; Yanfan Sun; Wei Gao; Ju Ren / arXiv
方向:投机解码方向:高效推理方向:推理框架硬件:手机硬件:NPU硬件:CPU
这是什么手机内存装不下的大模型放在闪存里跑，这套系统用投机解码把反复读闪存的代价摊薄。
有什么结果相比基线的闪存卸载推理平均降低 2.93 倍时延，相比常规投机解码降低 1.50 倍，把闪存驻留和内存驻留两种推理方式的时延差距收窄。
怎么做到草稿阶段按「收益减去 I/O 与算力成本」的目标构建候选词树；验证阶段用提前退出预测剪掉价值低的分支，减少大模型实际要算的量；执行阶段再把投机过程映射到手机的 CPU 与 NPU 上提高利用率。
评分依据：整套系统围绕手机 DRAM 装不下大模型这一真实约束设计，并在手机 CPU 与 NPU 上实际执行，端侧契合度很高。把投机解码的三个阶段全部按闪存 I/O 和移动硬件特性重做，不是简单移植。
