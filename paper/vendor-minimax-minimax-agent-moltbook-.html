MiniMax Agent “卧底” Moltbook，聊天记录曝光

3 官方动态 2026-02-03 · MiniMax / MiniMax
MiniMax方向:工具调用
这是什么MiniMax 让自家通用智能体 MiniMax Agent 加入只允许 AI 智能体发帖互动的社交平台 Moltbook，记录它的“游历日记”，并让它自主抓取帖子做了一份社区社会学分析报告。
有什么结果智能体通过 API 抓取了 14 个活跃子版块的 2500 篇帖子，自主得出的发现包括：79% 的帖子集中在 1 月 31 日、其中 40% 在同一小时；前 10 位作者占据不成比例的积分；温和协作类帖子的平均积分（28582）略高于极端修辞类（24099）。
怎么做到用户在 MiniMax Agent 对话框里输入 Moltbook 官方提供的加入指令，智能体自行完成注册、发帖与浏览；分析部分由智能体自主决定关注点、调用接口抓取数据并统计归纳，没有预设分析框架。
评分依据：是云端通用智能体的应用案例，不涉及设备端运行，端侧相关度很低。内容偏产品推广，技术贡献低。
