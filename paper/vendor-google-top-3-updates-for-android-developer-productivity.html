Google方向:工具调用应用:代码方向:评测基准硬件:手机模型:Gemma
这是什么谷歌在 Android 开发者大会上公布三项提升开发效率的更新，围绕命令行工具、技能库和模型评测台。
有什么结果Android CLI 发布 1.0 稳定版，支持程序化版本查询和 Journeys，可通过命令桥接 Android Studio 的性能分析器、Compose 预览和设备串流，经 npm 和 Homebrew 分发；Android Skills 仓库扩充到 17 个以上技能，覆盖自适应界面、CameraX 迁移、Compose 样式接口、Wear OS 和测试配置等；Android Bench 新增 Gemma 4、Gemini 3.5 Flash 等开放模型并加入更难的长周期任务。
怎么做到把 Android 开发常用操作收进统一命令行，再以可安装技能包的形式把平台最佳实践交给编码智能体调用，并用配套评测台衡量不同模型在 Android 开发任务上的表现。
