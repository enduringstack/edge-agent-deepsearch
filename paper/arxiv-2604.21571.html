Separable Expert Architecture: Toward Privacy-Preserving LLM Personalization via Composable Adapters and Deletable User Proxies

9 公司项目 2026-04-23 · Chris Schneider; Philipp Schoenegger; Ben Bariach / arXiv
Microsoft方向:安全隐私方向:记忆模型:Phi模型:Llama
这是什么微软提出一种让大模型个性化又能干净删除用户数据的架构：用户信息不进共享权重，删掉对应的小文件就等于“遗忘”。
有什么结果在 Phi-3.5-mini 和 Llama-3.1-8B 上，删除用户代理后输出回到基线（KL 约 0.21 nats，验证通过率 82-89%），跨用户污染接近零。
怎么做到三层结构：冻结的基础模型 + 可组合的领域 LoRA 适配器 + 每个用户独立的代理文件，个性化只经过用户代理。
评分依据：与端侧隐私个性化思路相关，模型也偏小，但没有端侧部署实验。贡献是把机器遗忘变成确定性的删除操作；PDF 首页三位作者均署名 Microsoft AI。 作者机构依据：arXiv PDF 首页署名 Microsoft（PDF 首页三位作者均署名 Microsoft AI）。
