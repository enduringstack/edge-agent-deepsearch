Stop When Memory Suffices: Evidence-Conditioned Progressive Execution for LLM Agents

10 学校预印本 2026-08-02 · Yidan Lin; Kaixiang Wang; Jiong Lou; Jie Li / arXiv
方向:记忆方向:高效推理应用:长上下文推理
这是什么Router-Mem 让 Agent 的长期记忆系统“够用就停”：先做一次廉价检索，再由轻量路由器判断证据是否足够，不够才展开深度分析。
有什么结果在 AMA-Bench 和 BEAM 上分别得到 55.17% 和 38.77% 的分数，与完整记忆执行相比平均推理时间减少 27.3% 和 25.5%。
怎么做到共享一个低成本检索前缀，用单 token 判断的充分性路由器决定是否提前结束；路由器用证据级监督和理由条件的表征蒸馏训练，证据不足时复用检索结果扩展记忆块。
评分依据：降低 Agent 记忆检索的在线延迟，对资源受限的端侧 Agent 有直接迁移价值，但未在设备上验证；渐进式执行设计有一定新意。论文署名未标注机构，未填写公司。
