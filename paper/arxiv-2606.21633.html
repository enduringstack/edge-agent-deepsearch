HERALD: High-Throughput Block Diffusion LLM Serving via CPU-GPU Cooperative KV Cache Retrieval

9 学校预印本 2026-06-19 · Omin Kwon; Doyeon Kim; Jongseok Park; Seung Yul Lee; Ion Stoica; Jae W. Lee / arXiv
方向:KV cache方向:云端serving方向:稀疏注意力硬件:CPU
这是什么长上下文服务中 KV 缓存挤占 GPU 显存，卸载到 CPU 内存又受 PCIe 带宽限制。HERALD 是首个面向块扩散大模型的 KV 卸载系统，利用这类模型“每块选一次、去噪复用多次”的访问特点，让 KV 只需每块过一次 PCIe。
有什么结果在两个生产级块扩散大模型上，只保留 5% KV 预算时精度几乎无损，解码吞吐最高达到纯 GPU 服务的 2.28 倍，且上下文越长优势越大。
怎么做到在 CPU 上做关键 KV 的选择、在 GPU 上做多步去噪；用草稿块让两阶段重叠，用单个 [MASK] 查询降低 CPU 端选择成本，并以双缓冲稀疏 KV 池组成双流流水线。
评分依据：CPU-GPU 协同管理 KV 缓存对显存受限的本地设备有一定借鉴意义，但原文面向数据中心长上下文服务，相关度按宽泛关联计；针对块扩散模型访问模式重新设计卸载是新的切入点。
