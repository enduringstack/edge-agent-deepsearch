怎么做到自回归解码每出一个 token 关键 KV 子集就会变，于是选择和搬运每步都要重来，吞吐被 PCIe 带宽卡住。块扩散大模型则是对一个 B 个 token 的块做 T 步去噪，稀疏推理因此天然分成两段：选择阶段每块只扫一遍完整 KV 缓存，去噪阶段则把选出的小子集复用 T 次。这种不对称正好对上 CPU 与 GPU 在算力和内存上的不对称，从而让卸载变得划算。
评分依据：KV 缓存卸载到 CPU 内存是显存受限设备的通用手段，CPU-GPU 协作取缓存的思路对本地部署有迁移价值，但原文面向的是长上下文服务场景，相关度按可迁移工作计；抓住块扩散模型访问模式与 CPU-GPU 硬件不对称之间的匹配关系，洞察有分量。
