7 官方动态 开源 2026-05-14 · Microsoft / Microsoft
Microsoft方向:安全隐私方向:工具调用
这是什么微软介绍开源的智能体治理工具包如何与 Agent Framework 1.0 配合，在智能体运行时对每次工具调用、资源访问和智能体间消息做策略检查和审计。
有什么结果原文称每次策略检查开销低于 0.1 毫秒，无需旁路代理。
怎么做到治理工具包以中间件形式插入 Agent Framework 的执行管线，在动作执行前做确定性策略判定，并提供零信任身份、执行沙箱和审计日志。
评分依据：内容是企业级智能体运行时治理，主要部署在云端，对端侧 Agent 的安全设计有一定借鉴，但相关度较低。
