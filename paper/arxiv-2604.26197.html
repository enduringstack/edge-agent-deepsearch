Hierarchical Long-Term Semantic Memory for LinkedIn's Hiring Agent

8 学校预印本 2026-04-29 · Zhentao Xu; Shangjin Zhang; Emir Poyraz; Yvonne Li; Ye Jin; Xie Lu; Xiaoyang Gu; Karthik Ramgopal / KDD 2026
方向:记忆应用:RAG
这是什么LinkedIn 招聘助手 Agent 的分层长期语义记忆系统，把用户长期行为数据整理成多层级记忆树，供 Agent 低延迟检索和个性化。
有什么结果在 LinkedIn 招聘助手上回答正确率提升超过 5%、检索 F1 提升超过 10%，查询延迟与索引延迟的权衡明显改善，已全量上线。
怎么做到按预定义 schema 把文本数据组织成多粒度记忆树，支持可扩展写入、隐私感知存储、低延迟检索和来源追溯，并有适配机制迁移到不同用例。
评分依据：Agent 长期记忆的工业实践，记忆层设计对端侧 Agent 有参考价值，但系统运行在云端；被 KDD 2026 应用数据科学方向接收。PDF 首页全部作者署名 LinkedIn Corporation，邮箱为 linkedin.com。
