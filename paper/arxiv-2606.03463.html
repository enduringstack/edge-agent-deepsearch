DMF: A Deterministic Memory Framework for Conversational AI Agents

11 学校预印本 2026-06-02 · Matteo Stabile; Enrico Zimuel / arXiv
方向:记忆方向:高效推理硬件:CPU
这是什么把对话助手的记忆管理改成纯确定性的计算流程，不再让大模型来写摘要。
有什么结果在基于 LoCoMo 和 LongMemEval 构建的基准上，准确率与常用记忆层 Mem0 相当，但准备记忆上下文用 0 个 token，整段对话下来 token 消耗少 5 倍到 242 倍。
怎么做到以 CPU 优先的方式，用经典自然语言处理分析、向量几何和数学打分替代生成式压缩：给每轮交互算一个「存活分」，再用按交互条数（而非时钟时间）衰减的规律决定相关性如何随新对话到来而下降，从而保证完全确定性。
评分依据：把记忆管理环节的大模型调用完全去掉、改成 CPU 上的确定性计算，对本地运行的助手非常对路（相关性 5）。用确定性打分替代生成式摘要并给出数量级的 token 节省，思路干净（贡献 6）。
