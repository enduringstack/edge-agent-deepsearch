这是什么CPU 上逐 token 解码卡的是内存带宽不是算力，这篇把模型结构和推理运行时放在一起重新设计。
有什么结果五个在 TinyStories 上训练的架构中，其中一个把关键路径上的权重带宽从每 token 9.00MB 降到 4.50MB（2.00 倍），困惑度只差 0.24。
怎么做到配套的 cflow 是 CPU 优先的流式引擎，把权重按消费顺序存成 L2 大小的分块，MoE 层只读 top-k 专家，融合投影，并按各模型的依赖参数执行延迟感知调度；模型侧则设计层间依赖图允许纵向、按阶段为主的执行顺序。
评分依据：明确围绕 CPU 解码带宽瓶颈做模型与运行时协同设计，端侧相关性高；把带宽写进架构设计目标的做法有实质创新。
