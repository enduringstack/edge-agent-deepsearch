MediaPipe v1.1.1

9 开源大项目 开源 2026-10-14 · google-ai-edge / GitHub
方向:推理框架方向:编译部署硬件:手机硬件:NPU硬件:GPU
这是什么MediaPipe 发布 v1.1.1 小版本：主要是给 Flutter 和 Flutter Web 补上 Tasks C 接口，并把底层 LiteRT 依赖升到 2.3.0。
有什么结果未报告
怎么做到迁移到 LiteRT 新的 GetOptions 接口、统一 NPU 选项调用方式，安卓上的交互式分割改用 LiteRT 委托运行，同时修复 macOS 上 GPU 交互分割的问题。
评分依据：MediaPipe 是谷歌移动端和网页端的端侧视觉/多模态推理框架，相关度高；本版以平台适配和依赖升级为主，没有新能力，贡献较低。
