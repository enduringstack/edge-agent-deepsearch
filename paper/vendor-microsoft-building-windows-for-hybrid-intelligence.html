Building Windows for hybrid intelligence

15 官方动态 2026-10-07 · Microsoft / Microsoft
Microsoft方向:端侧agent方向:端云协同方向:量化方向:推理框架硬件:NPU硬件:GPU方向:安全隐私
这是什么微软提出 Windows 的“混合智能”路线：智能体能在本机跑就用本地模型，需要时再上云；新版 Copilot 将在 Copilot+ PC 上获得本地上下文、本地动作和本地模型三项能力。
有什么结果本地模型方面，MAI Code 1.1 Flash（总参数 1370 亿、激活 68 亿）用 3 比特精度把模型体积缩小近 80%，并在本机保留 256K 上下文；700 亿参数以上的 Nemotron 量化到 2 比特后约占 20GB 出头；所有 Copilot+ PC 每月本地推理超过 2 万亿次。微软实测 RTX Spark 机器相比 MacBook Pro M5 Pro（64GB）首 token 时间快 2.1 倍（llama.cpp 运行 Qwen3.5 27B）。
怎么做到Windows ML 接入 llama.cpp，统一调度 GPU、NPU 和 CPU；GitHub HydraFusion 路由扩展到本机模型，按任务在本地和云端之间分配；Copilot 读取本机文件和近期活动作为上下文，在本机执行整理文件、设备诊断、排障、编码和工作流等动作，常驻的 Autopilot 可在后台持续工作，这些动作都运行在 MXC 容器里。
评分依据：微软官方把 Agent 的上下文、动作和部分模型推理都放到 PC 本机，并给出本地模型的量化规格，属于明确的 PC 端 Agent，相关度 9。混合路由与本地量化模型是平台级整合，部分能力仍在陆续推出，贡献 6。
