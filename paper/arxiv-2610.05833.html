Request Order Matters: Cache-History Sensitivity in Selective KV-Cache Reuse for Rolling Agents

10 学校预印本 2026-10-05 · Tiffany Gu; Annie Guan; Manshu Huang; Nitin Rao; Siddhant Shah; Margaret Capetz / arXiv
方向:KV cache方向:高效推理模型:Qwen硬件:GPU
这是什么长时间运行的智能体每次调用大模型都会换掉一部分旧文档、追加新文档，精确前缀缓存因此失效，只能做“非前缀 KV 复用加少量重算”。这篇发现这种复用会让同一个提示词因为之前处理过哪些请求而给出不同答案，并比较了不同重算策略的稳定性。
有什么结果在 Qwen3-8B 加 LMCache、vLLM 的滚动文档负载中，同样 5% 的重算预算下，按文档整段重算把不同请求顺序下的答案变化率从 CacheBlend 逐 token 挑选的 69.0% 降到 26.1%，对完整预填充结果的保真度高出 34.5–52.5 个百分点；两种策略在 NVIDIA L4 上的首 token 时延中位数都提速约 5.7 倍（2408 毫秒降到 415–426 毫秒）。
怎么做到把 CacheBlend 按键值偏差逐个挑 token 重算的做法，改成按文档边界挑连续片段重算；消融实验显示，重算片段是否连续是结果稳不稳的主要因素。
评分依据：智能体反复调用模型时的 KV 复用在端侧同样存在，结论可以迁移，但实验是在 NVIDIA L4 数据中心 GPU 上的 vLLM 里完成，相关度 5；指出 KV 复用带来的“请求历史依赖”这一被忽视的正确性问题，方法本身是重算选择策略的调整，贡献 5。PDF 首页作者 2 署名 Capital One。
