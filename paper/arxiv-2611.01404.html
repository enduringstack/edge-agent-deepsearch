Serving Agentic Robot Fleets: Workload Characterization, KV-Cache Thrashing, and Admission Control

8 公司项目 2026-11-01 · Sida He / arXiv
Huawei方向:云端serving方向:KV cache方向:调度服务应用:机器人硬件:GPU
这是什么具身 Agent 机器人由“视觉语言大脑+工具调用框架+动作模型”组成，一个集群同时服务很多台机器人时会出现什么资源问题？这篇在数据中心 GPU 上做了负载刻画并给出准入控制办法。
有什么结果大脑上下文最长到 21.5 万 token，中位请求 7.78 秒而环境步间隔仅 1 秒；并发从 20 台增到 32 台时吞吐从约 2.4 掉到 0.6 请求/秒；加静态活跃回合上限后恢复到 2.24-2.25 请求/秒，完成回合数从 1.30 升到 5.00-5.55 个/分钟。
怎么做到采集 80 个 LIBERO-PRO 回合的大脑与动作推理轨迹，在 H800 上分别剖析两层负载，再在 vLLM 上回放 Agent 程序，发现反复预填充挤占生成导致 KV 缓存颠簸，用活跃回合上限做准入控制。
评分依据：研究的是云端 GPU 集中服务机器人 Agent 集群，机器人端只是客户端（相关度 3）；对具身 Agent 负载的刻画和 KV 颠簸发现有参考价值（贡献 5）。PDF 首页作者署名 Huawei Inc.。 作者机构依据：arXiv PDF 首页署名 Huawei（论文首页唯一作者 Sida He 署名 Huawei Inc., China）。
