LAST: The Last Query Token Guides Visual Token Pruning for Edge-Cloud Collaborative MLLM Inference

11 学校预印本 2026-07-30 · Feng Yang; Xinrui Ju; Keyang Zhang; Xiandong Meng; Rongqun Lin; Howard Leung; Shiqi Wang; Haoliang Li / arXiv
方向:端云协同方向:多模态方向:剪枝稀疏
这是什么端云协同的多模态大模型里，终端把图像编码成视觉 token 发给云端大模型，但 token 太多会让云端计算变贵。LAST 让终端上的小模型先按用户问题挑出真正有用的视觉 token，只把它们发上云。
有什么结果在 InternVL2-1B（端）加 InternVL2-8B（云）的组合、11 个多模态基准上，只保留 12.5% 视觉 token 仍能保住全量精度的 95.4%；ChartQA 上同样预算下准确率 64.8，高于 SGP 的 56.2 和 FastV 的 45.4，打分聚合只要 2.51ms（SparseVLM 约 50.9ms）。实验在单张 A800 GPU 上模拟端云两侧。
怎么做到终端小 VLM 只做一次不生成文字的预填充，取“问题最后一个 token”对各视觉 token 的注意力作为相关度；因果注意力下这个 token 已经看过整张图和整个问题，所以不用聚合多位置注意力，也不用访问云端模型，最后再在固定预算内挑一组既相关又多样的 token。
评分依据：面向端云协同推理，裁剪决策完全在终端侧完成并减少上传和云端计算，属于可直接迁移的端侧技术，但未在真实终端设备上测时延，相关度 6。用最后一个查询 token 做免训练引导的思路简洁有效，贡献 5。
