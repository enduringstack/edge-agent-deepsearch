Foundry Local 1.1: Live Transcription, Embeddings, and Responses API

13 官方动态 开源 2026-05-12 · Microsoft / Microsoft
Microsoft方向:推理框架方向:量化方向:工具调用应用:语音应用:RAG硬件:CPU模型:Qwen
这是什么微软发布本地 AI 运行时 Foundry Local 1.1，让开发者在 Windows、Mac 和 Linux 上不依赖云端运行模型，这一版新增实时语音转写、文本向量和支持工具调用的 Responses 接口。
有什么结果配套的流式语音识别模型经量化后从 2.47GB 缩到最小 0.67GB，词错误率与全精度相差不到 1 个百分点；推荐的 int4 版本在 8 个基准上平均流式词错误率 8.20%，在 CPU 上快于实时、算法延迟 0.56 秒；JavaScript 包体积减少约 27MB。
怎么做到把流式语音模型在 ONNX Runtime 中重写并做混合精度和 k-quant 量化与算子融合；Responses 接口支持多轮、工具调用往返和图像输入，模型目录新增可在本地运行的 Qwen3.5 视觉语言模型 3B/7B；WebGPU 执行器改为按需下载的插件。
评分依据：这是面向 PC 的本地推理运行时，语音、向量检索和工具调用都在本机完成，并给出了端侧语音模型的量化与延迟数据；它提供的是运行时能力，本身不是一个跑在设备上的智能体，因此判为非端侧 Agent。
