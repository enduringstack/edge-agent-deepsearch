Your Agent Has a Genome: Sequence-Level Behavioral Analysis and Runtime Governance of LLM-Powered Autonomous Agents

9 学校预印本 开源 2026-04-05 · Sidi Deng / arXiv
方向:规划推理方向:工具调用方向:评测基准应用:代码
这是什么把 LLM Agent 的运行过程编码成由“探索、执行、规划、验证”四个字母组成的序列，像分析基因序列一样找出导致失败的行为模式，并据此在运行时干预。
有什么结果在 347 条生产 ReAct Agent 轨迹中，“规划-探索-规划”是唯一显著的高风险模式，使成功率降低 10.4%；执行后转入验证的概率只有 2.1%。上线干预系统 Governor 后，任务成功率绝对提升 6.2%，平均 token 消耗降低 44%；在 2000 条 SWE-agent 轨迹上复现了同样的问题。
怎么做到用 n-gram 模式挖掘、马尔可夫转移矩阵和相关性分析找出风险模式，再设计由规则引擎、统计累加器和卡方阈值自适应组成的三层运行时干预器。
评分依据：属于 Agent 运行时治理，能降低 token 消耗，对端侧 Agent 有一定借鉴意义，但实验在云端 Agent 系统上完成；行为序列化分析的视角较新颖。
