Task-Adaptive Retrieval over Agentic Multi-Modal Web Histories via Learned Graph Memory

8 学校预印本 开源 2026-04-09 · Saman Forouzandeh; Kamal Berahmand; Mahdi Jalili / SIGIR 2026
方向:记忆方向:多模态应用:RAG
这是什么网页 Agent 的交互历史又长又杂（截图、HTML、结构化信号），用固定阈值或固定缓冲区检索效果差。ACGM 学一张随任务变化的图结构记忆来检索相关历史。
有什么结果在 WebShop、VisualWebArena、Mind2Web 上检索质量达到 nDCG@10 82.7（比 GPT-4o 高 9.3）、Precision@10 89.2%（高 7.7），优于 19 个基线；学到的图平均每节点 3.2 条边，检索复杂度 O(log T)。
怎么做到用下游任务成功率作为奖励、以策略梯度学习历史观察之间的稀疏关联图，并为视觉和文本设置不同的时间衰减（视觉衰减快 4.3 倍）。
评分依据：属于 Agent 记忆检索，稀疏图检索对资源受限场景有一定借鉴，但场景是网页 Agent 且未涉及设备部署。被 SIGIR 2026 接收，方法有新意。
