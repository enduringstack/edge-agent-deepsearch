这是什么llama.cpp 发布 v0.7.0 正式版：新增 LiliCorr 投机解码和 GLM5-Next 的多 token 预测，并为放在主机内存里的 MoE 专家加了一层 GPU 缓存，同时一次性接入了一大批新模型。
有什么结果官方说明：MoE 专家 GPU 缓存在专家被卸载到主机内存时解码最高快约 2.2 倍；嵌入模型启用池化后跳过输出头，显存最多省 10 倍。
怎么做到把常用的 MoE 专家按 LRU 方式缓存在显卡上按需调入，投机解码则用一个小型草稿 Transformer 在 DFlash 之上挑选候选；后端还补了 Hexagon、Metal、Vulkan、KleidiAI SME2 等端侧算子。
评分依据：llama.cpp 是端侧本地推理最常用的引擎，本版的 MoE 专家缓存、投机解码和 Hexagon/Metal 后端改进都直接影响个人电脑和手机上跑大模型的速度与显存；属于工程整合型更新，创新度中等。
