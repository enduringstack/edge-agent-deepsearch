TierKV: Long-Context On-Device LLMs via Predictive Multi-Tier KV Caching

17 学校预印本 2026-09-18 · Zhihao Shu; Md Musfiqur Rahman Sanim; Jie Hu; Kun Yuan; Minghai Qin; Gagan Agrawal; Wei Niu / arXiv
方向:KV cache方向:高效推理方向:多模态硬件:手机应用:长上下文推理
这是什么TierKV 是一套手机上的长上下文推理框架，核心是在解码开始前就预测未来的 KV cache 需求，并把 token 分到不同存储层级。
有什么结果在三款手机 SoC 上跑八个文本、视觉和音频模型，预填吞吐相比现有移动端框架最高提升 17.6 倍，常驻内存里的 KV cache 减少 12.5%–34%，精度只有轻微下降。
怎么做到用预填阶段的隐状态预测后续缓存需求，在设备内存和精度预算下把 token 联合分配到精确层、低秩层和闪存卸载层，并用闭式解在运行时选出层边界和逐层秩。
评分依据：明确面向手机，覆盖文本、视觉、音频三类负载并在三款真实 SoC 上给出吞吐与内存数字，是本周端侧推理最硬的一篇。
