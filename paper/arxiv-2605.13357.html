AI Harness Engineering: A Runtime Substrate for Foundation-Model Software Agents

7 学校预印本 2026-05-13 · Hailin Zhong; Shengxin Zhu / arXiv
方向:工具调用方向:记忆方向:评测基准应用:代码
这是什么提出“AI 驾驭工程”的说法：编程 Agent 在真实项目里靠不靠谱，不只取决于模型本身，还取决于包在模型外面的运行时支撑层（harness）怎么给它提供上下文、工具和验证手段。
有什么结果未报告
怎么做到把 harness 拆成任务说明、上下文选择、工具访问、项目记忆、任务状态、权限、验证等 11 项职责，按 H0 到 H3 四个等级逐步开放给 Agent，再把每次运行的轨迹打包成可审计的证据包来评估。
评分依据：讨论的是编程 Agent 运行时的系统设计框架，对 Agent 运行时设计有概念参考，但与设备端部署无关，相关度 3。论文只在一个小型登录修复任务上每个等级各跑一次，用来展示四级证据包的结构差异，没有给出任何量化对比，因此效果记为未报告；框架化梳理有一定价值，贡献 4。
