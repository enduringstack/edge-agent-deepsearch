Capture the Flags: Family-Based Evaluation of Agentic LLMs via Semantics-Preserving Transformations

7 学校预印本 2026-02-05 · Shahin Honarvar; Amber Gorzynski; James Lee-Jones; Harry Coppock; Marek Rei; Joseph Ryan; Alastair F. Donaldson / arXiv
方向:评测基准方向:工具调用应用:安全
这是什么用夺旗赛（CTF）题目评测网络安全 Agent 时，单题测试看不出 Agent 是否只是记住了题。这项工作把一道题自动变换出一族语义相同的变体，用来测 Agent 的鲁棒性。
有什么结果评测了 13 种带工具的 Agent 配置：模型对改名和插入代码很稳健，但组合变换和深度混淆会明显降低成功率；开启显式推理对成功率影响不大。
怎么做到开发工具 Evolve-CTF，对 Python 题目做保持语义的程序变换，从 Cybench 和 Intercode 的题目生成题族，再对比 Agent 在原题和变体上的表现。
评分依据：属于云端大模型 Agent 的安全能力评测，与端侧部署无直接关系，只因涉及 Agent 工具使用而低分保留。
