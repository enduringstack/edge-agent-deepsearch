Local LLM Agents as Vulnerable Runtimes:A Source-Code Audit of the Agent Runtime Layer

14 学校预印本 2026-06-19 · Zhengsong Zhang; Zongze Li; Jiawei Guo; Haipeng Cai / arXiv
方向:安全隐私方向:工具调用应用:安全
这是什么审计跑在个人电脑上的本地大模型智能体，看它的运行时代码本身有哪些安全漏洞。
有什么结果原文提出的静态审计框架从 STRIDE 推导出五类漏洞分类法，并针对智能体特有模式开发了定制静态分析规则；摘要未给出最终发现的漏洞数量。
怎么做到以往研究多从提示注入、恶意技能、市场风险或黑盒评测角度看待本地智能体，但真正做中介的实现层——提示构造器、解析器、工具分发器、技能加载器、记忆写入器、网络客户端和权限闸门——一直没被当作安全边界检查过。作者因此直接审计智能体的源码树，用静态分析度量这些组件的漏洞暴露面。
评分依据：审计对象正是跑在最终用户机器上、能操作 shell、文件系统、浏览器和已存凭据的本地智能体运行时，是 PC 端侧 Agent 落地绕不开的安全面，端侧契合度高；首次把实现层当作安全边界来系统审计，补上了此前只看提示注入和黑盒行为的空白。
