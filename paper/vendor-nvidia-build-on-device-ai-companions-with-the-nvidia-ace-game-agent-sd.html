Build On-Device AI Companions with the NVIDIA ACE Game Agent SDK and Unreal Engine 5 Plugins

15 官方动态 2026-06-16 · NVIDIA / NVIDIA
NVIDIA方向:端侧agent方向:工具调用方向:高效推理硬件:GPU应用:语音模型:Qwen
这是什么NVIDIA 把游戏里的 AI 伙伴做成完全在本机显卡上运行的智能体：语音识别、小模型推理和语音合成都在本地完成，不走云服务。
有什么结果官方案例包括 KRAFTON 的 PUBG Ally 和 Total War: PHARAOH；虚幻引擎 5 插件自带可直接使用的本地模型（120M 参数的语音识别模型与 Qwen 3.5 4B 小语言模型），并明确标注与云端服务不同，这些是本地且针对 RTX 优化的工作流。
怎么做到一个轻量的 C/C++ 智能体框架，针对小模型和 NVIDIA RTX 硬件加速做优化，其智能体接口是带状态的多步推理加工具调用循环；配套的虚幻引擎 5 插件把语音识别、小语言模型和语音合成打包成本地流水线。
评分依据：核验官方正文确认整条智能体链路完全在玩家本机的 RTX 显卡上运行，并自带本地语音与小语言模型，是本周最明确的个人电脑端侧智能体发布。把带状态的多步智能体循环塞进游戏运行时并随插件分发，工程价值明确，贡献中等偏上。
