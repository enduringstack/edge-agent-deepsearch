AutoAdapt: Automated domain adaptation for large language models

8 官方动态 2026-04-22 · Microsoft / Microsoft
Microsoft方向:规划推理应用:RAG
这是什么微软研究院提出 AutoAdapt：自动帮大模型做领域适配，在时延、隐私、成本等部署约束下选出该用 RAG 还是微调，以及怎么调参。
有什么结果未报告
怎么做到用“适配配置图”刻画所有合法的适配流程组合，由规划 Agent 按任务和约束选择并排列步骤，再用预算感知的 AutoRefine 循环在限定开销内调优超参数。
评分依据：考虑了硬件、时延和隐私约束，思路可迁移到资源受限部署，但本身针对云端大模型适配；把领域适配当成约束规划问题来自动化有一定新意。
