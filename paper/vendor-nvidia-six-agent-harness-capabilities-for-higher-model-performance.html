Six Agent Harness Capabilities for Higher Model Performance

9 官方动态 开源 2026-07-27 · NVIDIA / NVIDIA
NVIDIA方向:记忆方向:工具调用方向:规划推理应用:代码
这是什么NVIDIA Labs 开源研究预览 NOOA，把智能体写成一个 Python 类，并总结出六种能明显提升模型表现的智能体外壳（harness）设计。
有什么结果用 GPT-5.5 在 SWE-bench Verified 上达到 82.2%，token 和模型调用次数约为对比框架的一半；ARC-AGI-3 上单个智能体用 GPT-5.5 平均 RHAE 为 50.2%、用 GPT-5.6-sol 达 85.1%，每局成本低于 20 美元；CyberGym L1 在无网络条件下解决 86.8% 的任务。
怎么做到方法就是能力、字段就是状态、文档字符串就是提示词、类型注解是强制约束；工具结果按引用传递而不是塞进上下文，因此不需要上下文压缩；另有让模型通过工具自己整理长期记忆的子系统，记忆存成可读的 SQLite 文件跨会话保留。
评分依据：智能体依赖云端大模型，没有端侧部署，相关度 3；按引用传递工具结果、模型自管理长期记忆等设计能明显省 token，对资源受限的智能体运行时有迁移价值，贡献 6。
