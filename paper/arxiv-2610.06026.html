Differentiable Bit-Widths: Co-optimizing Pruning and Quantization via SVD for Ultra-Efficient LLM Compression

13 学校顶会 开源 2026-10-05 · Hankyul Kang; Jongbin Ryu / NeurIPS 2026
方向:量化方向:剪枝稀疏硬件:GPU模型:Llama
这是什么把大模型压到 2 bit 以下时，常见做法是先剪枝再量化，两步各调各的，压得越狠掉点越多。这篇把“剪掉哪些分量”和“每个分量用几 bit”放进一个可微框架里一起学，不重要的分量直接分到 0 bit 剪掉。
有什么结果LLaMA-2-7B 压到平均 1.61 bit 时困惑度 10.54、常识推理平均准确率 49.06%，同码率的 PTQ1.61 为 15.22 和 39.20%；2 bit 时为 9.56 和 51.90%，优于 OmniQuant 的 13.04 和 40.86%。实验覆盖 LLaMA-1/2/3 共 8 个 7B–70B 模型；用自写 CUDA 内核在 RTX 3090 上测 LLaMA-65B 端到端时延，比 cuBLAS FP16 和 OmniQuant INT2 都低，且上下文越长优势越大。
怎么做到先用 SVD 把权重拆成若干奇异分量，再给每个分量学一个可微的位宽，位宽学到 0 就等于剪掉这个分量；剩下的分量按学到的位宽量化，并按组打包成统一格式，配套混合位宽矩阵乘内核。
评分依据：作者以“在只有 2GB 显存的笔记本 GPU 上跑 7B 模型”这类内存约束为动机，压缩结果可直接用于端侧部署，但时延只在 RTX 3090 这类桌面 GPU 上测，相关度 6；把 SVD 剪枝和低比特量化统一成可微的分量级位宽学习、支持 0 bit 剪除，已被 NeurIPS 2026 接收，贡献 7。作者均来自韩国亚洲大学，无公司署名。
