AMA-Bench: Evaluating Long-Horizon Memory for Agentic Applications

10 学校预印本 开源 2026-02-26 · Yujie Zhao; Boqin Yuan; Junbo Huang; Haocheng Yuan; Zhongming Yu; Haozhou Xu; Lanxiang Hu; Abhilash Shankarampeta / arXiv
方向:记忆方向:评测基准方向:工具调用
这是什么现有记忆评测多以对话为主，而真实 Agent 的记忆是由状态、动作、观察和工具输出组成的长轨迹。AMA-Bench 专门评测这种长程 Agent 记忆。
有什么结果现有记忆系统在该基准上表现不佳；提出的 AMA-Agent 准确率 57.22%，比最强基线高 11.16%。
怎么做到基准结合真实 Agent 轨迹加专家问答，以及可扩展到任意长度的合成轨迹加规则问答；AMA-Agent 用因果图组织记忆并配合工具增强检索。
评分依据：Agent 记忆评测与方法可迁移到本地 Agent，但不涉及设备端运行。
