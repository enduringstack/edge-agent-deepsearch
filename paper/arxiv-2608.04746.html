Caching for the Future: Scrub Jay Episodic Memory Principles for Agent Memory Systems

9 学校预印本 2026-08-05 · Kartikey Singh Bhandari; Aarya Wadhwani; Dhruv Kumar; Pratik Narang / arXiv
方向:记忆方向:评测基准
这是什么给跨会话长期运行的大模型智能体做记忆管理：不同类型的记忆过期速度不同，系统按类型给每条记忆设定“保鲜期”，避免检索时把过时事实混进上下文。
有什么结果在新提出的时间泛化测试上是唯一显著为正的检索式方案（泛化差距 +0.108）；在 MemoryAgentBench EventQA-64k 上 F1 比 Mem0 高 2.66、比 Qwen3-Embedding-4B 高 3.09；去掉衰减后泛化差距缩小 5.7 倍。更强骨干模型下收益变小，在事实整合任务上反而变差。
怎么做到借鉴灌丛鸦的情景记忆，把每条记忆存成“什么-在哪-何时”三元组，并自动估计易腐程度和有用期限，检索时按查询自适应打分，更新时只需常数次大模型调用。
评分依据：智能体记忆属于 Agent 运行时技术栈，轻量的记忆衰减策略可迁移到端侧助手，但论文未涉及设备部署；按类型衰减的记忆思路有新意，但适用范围作者自己也限定在易过期事实上。
