Token Latency Fairness: Performance Isolation for Multi-Tenant LLM Serving

8 学校预印本 开源 2026-09-16 · Dev Bali; Soujanya Ponnapalli; Yichuan Wang; Natacha Crooks; Scott Shenker; Matei Zaharia / arXiv
方向:云端serving方向:调度服务方向:KV cache
这是什么FairInference 给多租户大模型服务提出“δ-token 公平”：某个正常客户端的每个 token，在多租户下最多只比独占时晚 δ 时间生成。
有什么结果在 SGLang 上实现；表 1 中一个高负载客户端会让其他客户端首 token 时延变慢 66 倍（SGLang）、28 倍（VTC）、32 倍（DLPM），FairInference 保持在独占水平；宏基准中正常客户端 p99 首 token 时延为 1.07–1.36 秒，而 VTC、DLPM、SGLang 分别为 171、273、512 秒，同时吞吐高于静态分区。
怎么做到调度器为每个 token 设定截止时间，同时为共享 GPU 计算带来的延迟设上界，并按恢复时间决定每个客户端需要在显存里保留多少不可驱逐的 KV cache。
评分依据：这是云端多租户服务的时延隔离问题，对端侧直接价值有限，只有同一设备上多应用共享加速器时才会遇到类似问题。
