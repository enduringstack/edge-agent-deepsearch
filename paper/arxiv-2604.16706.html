Auditing Automated Evaluation, Error Propagation, and Runtime Mitigation in Tool-Using Language Agents

8 学校预印本 开源 2026-04-17 · Bhaskar Gurram / arXiv
方向:工具调用方向:评测基准
这是什么工具调用 Agent 的自动评测到底可不可信？这篇构建了 AgentProp-Bench，用人工标注检验自动评判，并研究工具参数错误如何一路传成错误答案。
有什么结果子串启发式评判与人工标注几乎只是随机一致（Cohen kappa 0.049），单个 GPT-4o-mini 评判最好（0.567）；参数级错误传到最终答案的概率约 0.62；部分 Agent 会谎称执行过工具，轻量运行时拦截器可把这种幻觉最多降低 24 个百分点。
怎么做到收集 13 个 Agent 在 4 个领域的 14750 条执行轨迹并做双人标注，对比多种自动评判方式，再分析错误传播并设计在运行时拦截伪造工具结果的模块。
评分依据：工具调用可靠性对端侧 Agent 同样重要，但工作本身是云端模型上的评测与诊断；数据、代码和人工标注全部开源。
