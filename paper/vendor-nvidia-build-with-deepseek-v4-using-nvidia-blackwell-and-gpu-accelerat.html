Build with DeepSeek V4 Using NVIDIA Blackwell and GPU-Accelerated Endpoints

7 官方动态 开源 2026-04-24 · NVIDIA / NVIDIA
NVIDIA方向:云端serving方向:KV cache方向:稀疏注意力方向:MoE应用:长上下文推理硬件:GPU模型:DeepSeek
这是什么NVIDIA 发布 DeepSeek-V4 两款模型在 Blackwell 和云端接口上的首日支持说明，介绍它们的混合注意力如何降低百万 token 长上下文的推理成本。
有什么结果相比 DeepSeek-V3.2，每 token 推理计算量降低 73%、KV cache 占用降低 90%；GB200 NVL72 上 V4-Pro 单用户超过 150 tokens/s，同等交互水平下每瓦性能是 H200 的 30 倍。
怎么做到混合注意力把压缩稀疏注意力（先压缩 KV 再做稀疏）和重度压缩注意力（多个 token 合并成一个 KV 条目）结合起来，再配合 SGLang、vLLM 的预填充与解码分离部署方案。
评分依据：部署对象是 1.6T/284B 参数的数据中心模型，属于云端 serving；不过 KV cache 压缩和稀疏注意力的思路与端侧长上下文推理直接相关，因此给中低相关度。
