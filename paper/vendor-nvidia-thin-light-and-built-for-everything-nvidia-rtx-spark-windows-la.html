Thin, Light and Built for Everything: NVIDIA RTX Spark Windows Laptops Gain New Models, Agent Tools and Games

NVIDIA方向:端侧agent方向:调度服务方向:编译部署硬件:GPU应用:语音
这是什么英伟达 RTX Spark 轻薄本（Blackwell GPU 与 Grace CPU 同封装、最高 128GB 统一内存）正式由华硕、戴尔、惠普、联想、微软、微星上市，同时为本地 AI 带来新的语音模型、Liquid AI LFM3 模型首日支持，以及在前台应用和后台常驻智能体之间分配 GPU 的资源控制。
有什么结果最高 1 PFLOPS 的 FP4 算力、最高 128GB 统一内存，起售价 2599 美元；Nemotron 3.5 Transcribe 约 43 亿激活参数，比排名第一的开源权重模型少 80%，在 Hugging Face Open ASR 榜排名第一；LFM3 的 17 亿参数基座模型超过其上一代 26 亿参数基座模型。
怎么做到单芯片统一内存让大模型和创作软件共用同一内存池；NVIDIA App 新增资源管理开关（需开启 Windows 硬件加速 GPU 调度），可选择优先前台应用还是后台运行的本地智能体；LFM3 通过 llama.cpp、vLLM 在本机运行并可本地微调。
评分依据：文章明确把长期运行的智能体放在笔记本本地、与前台应用共享 GPU，并配套本地模型与资源调度，是 PC 端侧智能体的产品化落地；技术细节以产品说明为主，创新度中等。
