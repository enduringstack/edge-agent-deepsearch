SPIDER: Multi-Layer Semantic Token Pruning and Adaptive Sub-Layer Skipping in Multimodal Large Language Models

11 公司项目 2026-09-28 · Tianxiang Chen; Zhentao Tan; Zi Ye; Yue Wu; Xiaobing Tu; Jinkui Ren; Xiantao Zhang; Tao Gong / arXiv
Alibaba方向:剪枝稀疏方向:多模态方向:高效推理模型:Qwen
这是什么多模态大模型的开销一方面来自视觉 token 太多，另一方面来自解码器每层都全量计算。SPIDER 同时处理两者：借助视觉编码器中间层的信息挑出真正重要的视觉 token，并在解码器里自适应跳过部分注意力或前馈子层。
有什么结果在 LLaVA-NeXT-7B 上计算量减少 79%，仍保持基线 96% 的性能；在 LLaVA-1.5-7B 上把视觉 token 从 576 个减到 128 个时，预填充时延从 67.4 ms 降到 48.2 ms（-28.5%），解码时延从 23.1 ms 降到 20.6 ms，吞吐从每秒 43.3 提到 45.2 个 token。方法无需训练，另在 Qwen2.5-VL-3B、Qwen3-VL-8B 上做了验证。
怎么做到观察到视觉编码器中间层的 token 保留了更多以物体为中心的细节，于是结合多层语义显著性来剪枝视觉 token；又发现解码器不同层里注意力和前馈网络的贡献差别很大，据此让视觉 token 在部分层只充当键值、或直接绕过前馈层，实现子层级的跳算。
