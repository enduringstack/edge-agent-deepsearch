Building a safe, effective sandbox to enable Codex on Windows

13 官方动态 2026-05-13 · OpenAI / OpenAI
OpenAI方向:安全隐私方向:工具调用应用:代码硬件:CPU
这是什么OpenAI 讲解如何为编程智能体 Codex 在 Windows 电脑上自建沙箱：让它在用户本机执行命令时只能写工作目录、默认不能联网，又不必每条命令都等人批准。
有什么结果未报告
怎么做到先试过 AppContainer、Windows Sandbox 和完整性级别标记都不合适；最终方案在安装时创建两个专用本地账户和合成身份，用写受限令牌加访问控制表限定可写目录，再用 Windows 防火墙封住离线账户的出网流量，由单独的命令执行程序以沙箱账户身份启动每条命令及其子进程。
评分依据：Codex 的命令执行、文件读写等行动环节运行在用户的 Windows 电脑上，沙箱正是这一本机执行环节的安全基础；但规划所用模型在云端，属于单机执行云端智能体下发的命令，因此判为非端侧 Agent。原文是工程设计复盘，没有量化指标。
