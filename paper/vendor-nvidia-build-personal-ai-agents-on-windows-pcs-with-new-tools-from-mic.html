Build Personal AI Agents on Windows PCs with New Tools from Microsoft and NVIDIA

15 官方动态 2026-06-02 · NVIDIA / NVIDIA
NVIDIA方向:端侧agent方向:推理框架方向:投机解码方向:安全隐私模型:Qwen硬件:GPU
这是什么英伟达和微软一起把「在 Windows 本机上安全跑智能体」这件事做成开箱即用的开发工具。
有什么结果微软的执行容器提供把智能体与整机隔离的安全策略层，英伟达 OpenShell 运行时集成该容器并加上策略管理与个人信息脱敏；RTX Spark 台式机与笔记本提供 1 petaflop 算力和最高 128GB 内存以在本地跑大模型，另有预装的 Surface 开发机；NemoClaw 通过 Linux 和 WSL 支持全部英伟达客户端系统；llama.cpp 借助多 token 预测与程序化依赖启动，在 Qwen 3.5 和 3.6 的 270 亿稠密模型上性能提升 2 倍、350 亿 MoE 模型上提升 1.6 倍，vLLM 侧提升 2.6 倍；llama.cpp 新增张量并行，双卡下显存可用量约 2 倍、算力约 1.8 倍。
怎么做到安全侧靠微软新增的执行容器把智能体限制在策略允许的范围内，运行时侧由 OpenShell 负责沙箱与凭据管理，性能侧则在 llama.cpp 和 vLLM 上引入多 token 预测和多卡并行。
评分依据：整篇围绕 Windows 本机上的端侧智能体开发展开，沙箱、运行时和本地推理加速三层都给了具体倍数（相关性 9）。把安全隔离与推理优化一起打包成开发者可用的工具链，落地性强（贡献 6）。
