ATLAS-RTC: Closing the Loop on LLM Agent Output with Token-Level Runtime Control

9 学校预印本 开源 2026-03-29 · Christopher Cruz / arXiv
方向:工具调用方向:高效推理模型:Qwen
这是什么大模型 Agent 输出 JSON、工具调用参数时经常格式出错。ATLAS-RTC 在解码过程中逐 token 盯着输出，发现要跑偏就当场纠正。
有什么结果在结构化生成和工具调用任务上（Qwen2.5-7B-Instruct），首次尝试成功率提高 20–37.8 个百分点，在失败居多的场景下时延最多降低 88%。
怎么做到每生成一步就用轻量信号检测是否偏离输出约定，并通过调整概率、屏蔽 token 或回滚来干预，形成闭环控制，而不是事后校验或静态语法约束。
评分依据：属于 Agent 工具调用的解码期运行时控制，可直接迁移到端侧小模型 Agent 提高工具调用可靠性，但本文没有端侧实验；思路清晰，代码已开源。
