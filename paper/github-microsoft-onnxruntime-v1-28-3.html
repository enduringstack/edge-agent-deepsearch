ONNX Runtime v1.28.3

10 开源大项目 开源 2026-10-02 · microsoft / GitHub
方向:推理框架方向:编译部署方向:安全隐私
这是什么ONNX Runtime 发布 v1.28.3 补丁版，集中修内存安全和模型校验问题，并修了插件执行和打包方面的毛病。
有什么结果官方发布说明列出的修复包括：EmbedLayerNormalization 在 beta 为标量时形状推断的越界读取、复用打包的亚字节缓冲区给整字节张量时的堆缓冲区溢出、Loop 或 Scan 的体输入同时是初始化器时的越界读取、ConvTransposeWithDynamicPads 和推断上下文取输入数据时的越界读取，并加固了 GroupQueryAttention、SparseAttention、CausalConvWithState 等算子的形状推断、拒绝非法图结构；另有 Linux、ARM64、Android 和移动端的构建依赖打包修复。
怎么做到在 v1.28.2 基础上做补丁发布，逐项修复越界读取和缓冲区溢出，并收紧了算子形状推断与图结构校验。
评分依据：ONNX Runtime 是端侧部署最通用的运行时之一，这次修的越界读取和缓冲区溢出直接关系到在设备上加载不可信模型的安全性，移动端打包修复也与端侧相关。属于补丁级维护发布，技术贡献很低。
