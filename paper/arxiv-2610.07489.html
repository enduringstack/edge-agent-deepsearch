Deep Defence on Wheels: A Dual Intrusion Detection System Architecture for Comprehensive In-Vehicle Network Security

13 学校预印本 开源 2026-10-05 · Shashwat Khandelwal; Shanker Shreejith / ACM TECS
方向:量化方向:编译部署方向:能耗功耗方向:安全隐私硬件:FPGA应用:安全
这是什么车内 CAN 总线缺少安全机制，入侵检测要塞进车载电子单元，就得同时做到低时延、低能耗、少占资源。这篇给出双检测器方案：有监督模型识别已知攻击，无监督模型发现未知异常，两者都量化后放在同一块 FPGA 上实时运行。
有什么结果量化 LSTM 检测器在两个常用数据集上对 DoS/泛洪、模糊测试、欺骗/故障三类攻击的检测准确率超过 99.9%；8 bit 卷积自编码器对改变 CAN-ID 序列模式的未知异常检测准确率超过 99%。在 ZCU104（XCZU7EV FPGA）上，前者每条报文 0.25 毫秒、0.8 毫焦，后者每块 0.42 毫秒、1.1 毫焦。
怎么做到LSTM 检测器用 Brevitas 做量化感知训练，经 AMD FINN 工具链转成带自定义模块的数据流加速器并用 Vitis HLS 综合；自编码器用 Vitis-AI 量化到 8 bit；再设计一个集成架构把网络接口 IP 与处理系统直连，让两个模型共用一块 FPGA、减少软件开销。
评分依据：两个量化模型都实际部署在 ZCU104 FPGA 开发板上，并实测单条报文的时延和能耗，是明确的设备端部署，相关度 8；方法是量化感知训练加厂商工具链的工程整合，属期刊扩展工作，贡献 5。
