v0.10.1-alpha.3

10 开源大项目 开源 2026-11-05 · qualcomm / GitHub
方向:推理框架硬件:NPU硬件:Snapdragon方向:投机解码
这是什么高通端侧推理框架 GenieX 的 v0.10.1-alpha.3 预发布版，主要是骁龙 NPU 运行时的修复与小功能，包括 IQ9 NPU 上的大模型分段加载和多 token 预测草稿头的修复。
有什么结果未报告
怎么做到在 IQ9 NPU 上把 2 GiB 以上的模型按层拆分到多个 HTP 会话加载；修复 MTP 预测头加载并让草稿模型 KV 与目标模型同步；SDK 新增报告总提示 token 与缓存命中 token，基准工具可导出原始 logits；Windows on Snapdragon 使用微软签名的 HTP 目录，无需手动导入证书。
评分依据：直接面向骁龙 NPU 的端侧推理运行时，相关度高；但这是 alpha 预发布，内容以修复和小改进为主，没有新的性能数据。本周此前未收录 GenieX 版本。
