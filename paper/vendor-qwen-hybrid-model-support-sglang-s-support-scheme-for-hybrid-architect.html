Hybrid Model Support | SGLang's Support Scheme for Hybrid Architecture Models like Mamba-Transformer

9 官方动态 开源 2026-02-04 · Qwen / Qwen
Qwen方向:KV cache方向:投机解码方向:模型架构方向:推理框架硬件:GPU模型:Qwen
这是什么阿里云 Tair KVCache 团队和 SGLang 社区介绍如何在推理框架里支持 Mamba 与 Transformer 混合架构模型，解决两类层缓存方式冲突导致前缀缓存和投机解码失效的问题。
有什么结果在 H200 上用 SGLang v0.5.5 跑 Qwen3-Next-80B-A3B-Instruct-FP8：开启前缀匹配后首 token 时延降到原来的 57.63%；批大小为 1 时，MTP 投机窗口 2 个 token 吞吐 257.20 token/s，3 个 token 为 306.94 token/s，4 个 token（top-k=4、8 个草稿）达到 324.57 token/s。
怎么做到把显存拆成互相隔离的 Mamba 状态池和注意力 KV 缓存池，并让两个池按负载弹性调整比例；对 Mamba 状态做快照，弥补其原地更新不可回退的缺陷，从而恢复前缀复用和投机解码。
评分依据：混合注意力与状态空间模型正成为端侧长上下文模型的重要选择，这里的双缓存池和状态快照思路可直接迁移到端侧推理引擎；但实验在数据中心 GPU 上完成。
