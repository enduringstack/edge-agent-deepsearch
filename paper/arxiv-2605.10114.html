SkillRAE: Agent Skill-Based Context Compilation for Retrieval-Augmented Execution

9 学校预印本 2026-05-11 · Xiangcheng Meng; Shu Wang; Yixiang Fang / arXiv
方向:工具调用方向:记忆应用:RAG
这是什么智能体技能库越来越大，检索到的技能怎么整理成既紧凑又能直接用的上下文是个被忽视的问题。SkillRAE 专门优化这一步。
有什么结果在两个公开基准上明显优于基线，例如在 SkillsBench 上比当前最好方法提升 11.7%。
怎么做到离线把技能库建成“技能社区-技能-可复用子单元”的多层图；在线先按技能排序检索并导出选中子单元，再做带补救机制的紧凑编排，找回被漏掉的关键证据。
评分依据：属于 Agent 工具与技能调用的运行时优化，压缩上下文对端侧小模型智能体有迁移价值，但实验不涉及设备。多层技能图加紧凑编排是实用的工程改进。
