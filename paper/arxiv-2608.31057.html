Measure Before You Manage: Evaluating Agent Working Memory in Coding Agents

9 学校预印本 2026-08-31 · Le Chen; Zishen Wan; Baixi Sun; Xiaolong Ma; Chih-Hsuan Yang; Feng Yan; Sheng Di; Franck Cappello / arXiv
方向:记忆方向:评测基准应用:代码
这是什么编码智能体的工作记忆里装着指令、产物、工具输出和自己生成的状态，这些东西性质完全不同，这篇主张先量清楚再谈管理。
有什么结果作者分析了 55 条归档的编码智能体轨迹，发现语义上不同的工作记忆对象在体积、保留时长和表示形式上确实差别显著。
怎么做到研究聚焦语义异构性，考察它应当如何影响编码智能体工作记忆的管理方式和评估方式。
评分依据：工作记忆体积直接决定上下文开销，对受限设备有间接价值，但论文不涉及设备端部署，端侧相关性较弱。用真实轨迹先做度量再谈管理，方法论上比较克制。
