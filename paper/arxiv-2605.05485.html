ReaComp: Compiling LLM Reasoning into Symbolic Solvers for Efficient Program Synthesis

9 学校预印本 开源 2026-05-06 · Atharva Naik; Yash Mathur; Prakam; Carolyn Rose; David Mortensen / arXiv
方向:规划推理方向:高效推理应用:代码
这是什么大模型做程序综合时在难题上要大量搜索、很费 token，ReaComp 用编码 Agent 把少量推理轨迹“编译”成可复用的符号求解器，测试时不再调用大模型。
有什么结果符号求解器集成在 PBEBench-Lite 上 91.3%、PBEBench-Hard 上 84.7%，后者比带测试时扩展的大模型高 16.3 个百分点且零推理成本；与大模型搜索配合时把 PBEBench-Hard 从 68.4% 提到 85.8%，token 用量减少 78%；SLR-Bench 困难档从 34.4% 提到 58.0%。
怎么做到给定少量推理轨迹，让编码 Agent 在受限领域语言上写出通用的符号程序合成器，一次构建、多次零 token 执行，难题再交给大模型兜底。
评分依据：通过把推理转为符号程序大幅降低大模型调用成本，与推理效率间接相关，但不涉及端侧；“把推理编译成求解器”的思路有新意。代码开源。
