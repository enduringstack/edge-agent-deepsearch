有什么结果原文称本版有 18 位新贡献者参与；未给性能数字。
怎么做到通过 Model Context Protocol 连接外部工具服务器；多步工具执行时把中间进度流式推送给用户；新增自定义 OpenAI 兼容端点、GitHub Copilot、OpenAI Codex、硅基流动等服务商；会话存储改为按工作区隔离，用 json_repair 兜底解析不规范的模型输出，并提供 Docker Compose 一键部署。
