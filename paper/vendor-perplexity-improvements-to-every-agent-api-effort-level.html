Improvements to every Agent API effort level

8 官方动态 2026-11-05 · Perplexity / Perplexity
Perplexity方向:工具调用方向:规划推理方向:高效推理应用:RAG
这是什么Perplexity 降低了智能体 API 每个推理档位的单次成本，同时保持或提升调研质量，并新增最高档 ultra。
有什么结果medium 档在 BrowseComp+DSQA 上从 55% 升到 77%，成本降近 90%；xhigh 档以 8 月配置约 25% 的成本保持 WANDR 76.5%；内容抽取让 high 档输入 token 减约一半，准确率从 83.5% 升到 88.0%，单次成本从 0.094 降到 0.073 美元；ultra 档 WANDR 85.9%，每任务 21.71 美元。
怎么做到给每档设定步数上限、工具调用上限和预算提醒，上下文超阈值时压缩成摘要，网页先抽取要点再送入模型，技能按需加载；ultra 档并行跑三个智能体再由第四个合并结论。
评分依据：完全运行在云端 API，不是端侧智能体；但步数预算、上下文压缩和技能按需加载都是降低智能体 token 与时延开销的实用手段，对资源受限的智能体有借鉴意义。
