InfiniLoRA: Disaggregated Multi-LoRA Serving for Large Language Models

8 公司项目 2026-04-08 · Hongyu Chen; Letian Ruan; Zilin Xu; Yuchen Li; Xinyu Chen; Jingwen Leng; Bingsheng He; Minyi Guo / arXiv
ByteDance方向:云端serving方向:MoE硬件:GPU
这是什么InfiniLoRA 是一个多 LoRA 大模型服务系统，把 LoRA 计算从基座模型推理中拆出去，交给共享的 LoRA 服务器处理，缓解 MoE 模型下 LoRA 内存暴涨的问题。
有什么结果在严格时延要求下，可服务请求率平均提升 3.05 倍，满足时延要求的 LoRA 适配器比例提高 54.0%。
怎么做到设立独立的 LoRA 服务器，按并行方式执行、按时延目标分配资源，并用 GPU 发起的通信和专门优化的 LoRA 内核缩短关键路径。
评分依据：面向数据中心多租户服务，端侧相关度低；分离式 LoRA 服务的架构有一定新意。作者 3 署名字节跳动。 作者机构依据：arXiv PDF 首页署名 ByteDance（arXiv 论文首页作者 3 Zilin Xu 署名 Bytedance，并使用 bytedance.com 邮箱）。
