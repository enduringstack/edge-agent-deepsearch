SAID: Accelerating Diffusion-Based Language Models via Scaffold-Aware Iterative Decoding

11 学校预印本 开源 2026-06-03 · Na Li; Chengda Wang; Mingju Gao; Hao Tang / arXiv
方向:高效推理方向:模型架构
这是什么扩散式语言模型解码时，把算力先花在搭骨架的关键 token 上，细节 token 少迭代几步。
有什么结果在 LLaDA-8B 和 LLaDA 1.5 上跨数学、编码和知识类基准测试，最高提速 9.1 倍且性能仍有竞争力。代码已开源。
怎么做到先用较多去噪步数把骨架 token 定下来建立粗粒度语义结构，再用较少步数补可预测的细节 token；并适配到分块扩散解码，用置信度分层生成只给低置信 token 额外步数。
评分依据：去噪步数是扩散语言模型推理开销的主因，减少步数对端侧部署意义直接，但实验未涉及真实设备（相关性 5）。按 token 重要性重新分配计算是清晰有效的思路（贡献 6）。
