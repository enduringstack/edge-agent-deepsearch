Low-Latency Real-Time Audio Game Commentary System via LLM-Based Parallel Text Generation

7 学校预印本 2026-06-11 · Ryota Kawamatsu; Anum Afzal; Yuki Saito; Shinnosuke Takamichi; Graham Neubig; Katsuhito Sudoh; Hiroya Takamura; Tatsuya Ishigaki / arXiv
方向:高效推理应用:语音应用:视频
这是什么一个实时游戏解说系统，直接从直播画面生成语音解说，重点解决句子之间长时间沉默的问题。
有什么结果在快节奏游戏视频上，句间平均沉默从 9.6 秒降到 0.3 秒；与专业解说的说话与停顿节奏相似度提升超过 40%；120 名资深玩家的用户研究确认节奏感知明显改善。
怎么做到不再按取帧、生成文本、合成语音严格串行等待，而是让文本生成与语音播放并行，提前缓存多条候选语句，播放到边界时立刻合成下一句。
评分依据：实时多模态流水线的时延优化，对端侧语音交互有一定迁移价值，但原文没有设备端部署内容。并行生成加缓冲属于工程层面的常规优化。
