Rashomon Memory: Towards Argumentation-Driven Retrieval for Multi-Perspective Agent Memory

7 学校预印本 2026-04-04 · Albert Sadowski; Jarosław A. Chudziak / AAMAS 2026 EXTRAAMAS Workshop
方向:记忆方向:规划推理
这是什么长期运行的智能体常要对同一件事保留互相冲突的理解。Rashomon Memory 让多个代表不同目标的视角各自记忆，查询时通过“辩论”决定采用哪种解读。
有什么结果概念验证显示，选择、组合和冲突呈现三种检索模式可以从攻击图结构中自然产生；未给出量化指标。
怎么做到每个视角维护自己的本体和知识图谱，检索时各自提出解释并互相反驳，用 Dung 论证语义判定哪些解释成立，生成的攻击图本身就是可解释的决策记录。
评分依据：属于智能体记忆的概念架构研究，没有部署或效率评估，与端侧关系很弱；以论证推理组织多视角记忆有一定新意。发表于 AAMAS 2026 的 EXTRAAMAS 研讨会。
