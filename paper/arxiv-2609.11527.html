Lightweight LiDAR-Based Cone Detection Framework Using Random Forest for Formula Student Driverless

11 学校预印本 2026-09-10 · Márk Mező-Kerekes; Péter Praksz; Chang Liu / arXiv
方向:高效推理硬件:CPU应用:机器人
这是什么给无人方程式赛车做的只用激光雷达、只跑 CPU 的锥桶检测流程，避免依赖 GPU 加速。
有什么结果在真实比赛采集的 2371 个标注簇上，F1 达到 98.33%，纯 CPU 硬件上端到端耗时 3.13 毫秒；特征重要性分析把输入从 12 个特征减到 7 个且性能不变。
怎么做到把地面剔除、基于惯性单元的运动补偿、DBSCAN 聚类和基于几何特征的随机森林分类串起来，全部在 CPU 上跑。
评分依据：明确为算力受限的车上 CPU 设计并给出毫秒级实测（相关性 8）。是经典方法的工程组合（贡献 3）。
