ScrapMem: A Bio-inspired Framework for On-device Personalized Agent Memory via Optical Forgetting

13 学校预印本 2026-05-05 · Jiale Chang; Yuxiang Ren / arXiv
方向:记忆方向:多模态模型:Qwen
这是什么让多模态 Agent 在存储有限的端侧设备上保留长期个人记忆：把各种记录拼成“剪贴簿页面”图片，越旧的记忆分辨率压得越低，像人一样逐渐遗忘细节。
有什么结果在 ATM-Bench 上 Joint@10 达到 51.0%，为当前最好；通过逐步降分辨率最多节省 93% 存储；Recall@10 提升到 70.3%。
怎么做到把多模态记录渲染成图像页面，按时间逐步降低旧页面分辨率；同时用事件记忆图按因果和时间组织关键事件，用 Qwen3-VL-2B 读取记忆页面回答问题。
评分依据：面向端侧 Agent 记忆的存储压缩方案，直接可迁移到手机个人助理，但没有在真实设备上运行和测量；“光学遗忘”压缩思路较新颖。
