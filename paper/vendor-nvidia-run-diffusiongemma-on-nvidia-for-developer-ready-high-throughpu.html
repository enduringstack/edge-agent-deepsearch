Run DiffusionGemma on NVIDIA for Developer-Ready, High-Throughput Text Generation

8 官方动态 2026-06-12 · NVIDIA / NVIDIA
NVIDIA方向:高效推理方向:云端serving硬件:GPU模型:Gemma
这是什么把 Google 的扩散式语言模型 DiffusionGemma 在 NVIDIA 平台上优化部署，用并行解码换取更高的文本生成吞吐。
有什么结果官方页面给出的规格是基于 Gemma 4 的 26B A4B 模型采用扩散式并行解码，单张 H100 上约每秒 1000 token，并提供 NIM 封装。
怎么做到扩散式语言模型不按 token 逐个生成，而是并行解码多个位置，从而绕开自回归逐字生成带来的速度上限；再配合推理栈优化和容器化封装交付。
评分依据：面向数据中心的高吞吐部署，与端侧没有直接关系，相关度较低；但扩散式并行解码是绕开逐字生成瓶颈的新路线，对端侧时延优化有参考价值。属于厂商部署优化通报，贡献中等。
