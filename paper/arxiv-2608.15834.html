Schema-Agnostic Graph Reasoning Agent for Hybrid Knowledge Graphs

8 学校预印本 2026-08-16 · Marius Dragic; Ruben Ifrah; Alexandre Rio / arXiv
方向:工具调用方向:规划推理应用:RAG
这是什么代码 Agent 靠 ls、cat、grep 这类通用命令就能摸清陌生代码库。GRA 把同样的思路搬到知识图谱上：用 7 个通用工具在“文本概念加关系表”的混合知识图谱里自己探索，领域细节在运行时再去发现。
有什么结果在含 258 道工业分析题的 UFK-M 基准上准确率 88.4%，比把全部上下文塞进提示的 Agent（83.3%）高 5.1 个百分点，读取的输入 token 不到后者的三分之一；去掉图结构的对照实验显示，收益主要来自“按需选择性读取”而非图拓扑本身。
怎么做到把列出邻居、读取节点内容、搜索描述等操作做成类似文件系统命令的通用工具，Agent 一步步导航知识图谱并对关系表执行查询，只读取回答问题所需的部分。
评分依据：这是工具调用 Agent 节省上下文的方法，减少输入 token 对资源受限推理有间接价值，但实验未涉及端侧（相关度 3）。把代码 Agent 的通用工具范式迁移到混合知识图谱，思路清楚（贡献 5）。作者机构依据：PDF 首页三位作者均署名 Oplit 研发部，邮箱域名为 oplit.fr。
