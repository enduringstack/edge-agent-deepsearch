How Automated Prompt Optimization Unlocks Quality Gains for ML Kit’s GenAI Prompt API

13 官方动态 2026-01-28 · Google / Google
Google方向:编译部署方向:高效推理硬件:手机模型:Gemma
这是什么安卓系统里的 Gemini Nano 是多个应用共享的系统模型，没法给每个应用单独挂 LoRA 微调。谷歌为此在 Vertex AI 上推出面向端侧模型的自动提示词优化（APO），帮开发者用调提示词的方式把 ML Kit Prompt API 的效果做到接近微调。
有什么结果在多个已上线的端侧功能上验证，准确率稳定提升 5-8%：主题分类 +5%、意图分类 +8.0%、网页翻译 BLEU +8.57%。
怎么做到借助云端 Gemini Pro/Flash 自动分析初始提示词的错误模式、从大量样本中提炼任务真实意图，并并行生成和测试大量候选提示词，选出最优系统指令后交给手机上的 Gemini Nano v3 使用，模型权重不变。
评分依据：直接面向安卓手机上的 Gemini Nano v3（AICore 共享系统模型），解决端侧模型无法按应用微调的现实约束，端侧相关度高；方法本身是成熟的自动提示词搜索，贡献在落地场景。
