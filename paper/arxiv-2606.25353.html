Cache-Resident LLM Inference in GB-Scale Last-Level Caches

10 学校预印本 2026-06-24 · Wanning Zhang; Tongzhou Gu; Marco Canini; Ceyu Xu; Jian Weng / arXiv
方向:推理框架方向:高效推理方向:KV cache硬件:CPU模型:Llama
这是什么3D 堆叠缓存让服务器 CPU 拥有 GB 级末级缓存，理论上可以把模型权重常驻片上。本文提出缓存常驻的推理执行模型，让普通 CPU 也能高效跑大模型。
有什么结果在多路 CPU 集群上部署 Llama-3.2-3B 和 Llama-2-7B，每输出 token 时间比同等配置的 llama.cpp 快 2.04–11.51 倍；经验证的分析模型显示在不同模型规模、上下文长度和批大小下最高可达 13.9 倍。
怎么做到把以权重为中心的算子与注意力和 KV 缓存管理分到不同资源域，让权重常驻缓存、KV 容量独立扩展；把同步从算子边界放宽到真实的子算子依赖；配合局部性感知的放置和专用静态运行时。
评分依据：CPU 推理和以缓存为中心的执行组织对大缓存的桌面与边缘 CPU 有借鉴意义，但实验在多路服务器 CPU 上，相关度中等偏低；把执行围绕缓存常驻重新组织是有分量的系统设计。
