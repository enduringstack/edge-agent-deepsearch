Metis: Bridging Text and Code Memory for Self-Evolving Agents

8 学校预印本 2026-06-23 · Zijie Dai; Siuhin He; Hui Li; Qihui Zhou; Jiajun Li; Mingcong Song; Guoping Long; Hongjie Si / arXiv
方向:记忆方向:工具调用应用:代码
这是什么研究自进化智能体把经验存成自然语言好，还是存成可调用代码好。
有什么结果受控对比显示文本记忆和代码记忆在构建成本、执行效率和可迁移性上各有长短，单靠任一种都不够；摘要未给出具体数值。
怎么做到先在同一批经验上做第一个把文本记忆和代码记忆隔离开的受控研究，再据此设计分层的双表示记忆：把文本经验组织成执行计划、环境事实和常见坑三类，并有选择地把反复出现的计划固化成经过验证的可调用工具。
评分依据：智能体经验记忆与工具固化属端侧 Agent 的相邻能力，但实验全在云端、无设备端算力约束，相关度按宽泛关联计；把两种记忆表示放在同一批经验上做受控对比，实证设计较扎实。
