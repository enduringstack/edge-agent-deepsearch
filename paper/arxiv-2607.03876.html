AdaptiveSD A Stability-Aware, Runtime-Adaptive Speculative Decoding Framework with Multi-Policy Orchestration for CPU-Constrained LLM Inference

10 学校预印本 开源 2026-07-04 · Sadra Saremi / arXiv
方向:投机解码方向:KV cache方向:推理框架硬件:CPU
这是什么AdaptiveSD 面向纯 CPU 上运行的小型量化 GGUF 模型，做了一个运行时自适应的投机解码框架，目标是避免固定深度投机解码在内存带宽受限时反而变慢甚至把系统拖垮。
有什么结果原文报告投机效率稳定在 68%~82%，即被浪费的草稿 token 不超过约 32%，并能压住 token 间延迟的突增；监控模块每步开销约 0.057 毫秒。
怎么做到由运行时监控、按 11 条规则分层决策的草稿长度控制器、结合启发式与强化学习的动态策略引擎，以及用 INT8 影子缓冲管理 KV cache 的协调层组成闭环，优先保护系统资源而非追求最大草稿数。
评分依据：直接面向 CPU 本地推理的投机解码稳定性问题，与端侧部署相关；但以规则和启发式整合为主，部分实验依赖模拟层，证据较弱。
