Building Reliable Data Analytics Agents: Lessons from the KDD Cup

8 官方动态 2026-10-08 · NVIDIA / NVIDIA
NVIDIA方向:工具调用方向:评测基准模型:Qwen
这是什么NVIDIA KGMON 团队在 KDD Cup 2026 数据分析 Agent 赛道获得第二，复盘在“只能用固定小模型”的限制下，如何把 Agent 执行框架做小、做清楚、可验证，让它可靠地回答跨数据库、表格、文档、PDF 和视频的问题。
有什么结果团队获得该赛道第二名；正文没有公布得分或其他量化指标。
怎么做到先把 CSV/JSON 统一导入 SQLite，并提前做只读的表结构侦察，视频预先抽帧并转写；只给 Agent 四个受限工具（schema、sql、write_answer、prose_helper）并禁止整文件读取，用中间件修复格式错误的工具调用，用持久化的 Python 环境保存中间结果；再用一个读取完整轨迹的检查 Agent 归类失败原因来迭代。比赛限定模型为 Qwen3.5-35B-A3B。
评分依据：Agent 运行在服务器上，不属于端侧；但“受限工具、持久状态、轨迹评测”这套在小模型约束下提升可靠性的做法，可直接迁移到端侧小模型 Agent，相关度 4。属于工程经验总结，贡献 4。
