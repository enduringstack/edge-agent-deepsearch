KVCapsule: Efficient Sequential KV Cache Compression for Vision-Language Models with Asymmetric Redundancy

11 公司项目 2026-05-14 · Yingbing Huang; Tharun Adithya Srikrishnan; Steven K. Reinhardt; Deming Chen / arXiv
AMD方向:KV cache方向:多模态硬件:GPU
这是什么多模态大模型的图像会产生大量 token，解码时 KV cache 占用的显存急剧膨胀。KVCapsule 是专门压缩视觉 token KV cache 的框架，不改动模型主干和注意力模块。
有什么结果在多个 VLM 和基准上，60% 压缩率下每秒生成 token 数最多提升 2 倍、KV cache 内存最多减少 2.4 倍，准确率和回答质量几乎不降；在 AMD MI250X 上 9K-15K 长输入的单 token 延迟最多降低约 25%。
怎么做到分析发现视觉 token 的 Key 和 Value 冗余不对称：对 Key 做选择性保留再重建，对 Value 做序列级低秩压缩，用轻量的压缩和重建组件插入现有 VLM。
评分依据：KV cache 压缩是端侧多模态推理的核心瓶颈之一，方法可迁移，但实验在数据中心 GPU（AMD MI250X）上完成，没有端侧设备测试。针对视觉 token 的不对称冗余设计有一定新意。PDF 首页作者 2、3 署名 AMD。 作者机构依据：arXiv PDF 首页署名 AMD（PDF 首页作者 Tharun Adithya Srikrishnan、Steven K. Reinhardt 署名 AMD）。
