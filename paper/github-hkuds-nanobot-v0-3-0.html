nanobot v0.3.0

8 开源大项目 开源 2026-07-25 · HKUDS / GitHub
方向:工具调用方向:规划推理方向:安全隐私
这是什么港大 HKUDS 的轻量个人 AI 助理框架 nanobot 发布 v0.3.0，重点是一行命令启动本地网页工作台，并让智能体在授权边界内调用子智能体、持续执行长任务。
有什么结果未报告
怎么做到nanobot webui 一条命令完成本地网关启动和引导配置；内联子智能体可在当前任务中被咨询，长任务需用 /goal 显式开启，并带权限、取消、超时和心跳控制；运行时支持配置热重载，网关对外暴露时必须带令牌，并封堵了用命令串联绕过白名单的漏洞；新增 OpenCode、Kimi Coding、Grok 等模型服务商和 WhatsApp、Mattermost 等渠道。
评分依据：智能体运行时和工具执行在用户自己的机器上，但发布说明接入的都是云端模型服务商，没有说明本地模型推理，相关度 4；属于工程整合型版本更新，贡献 4。
