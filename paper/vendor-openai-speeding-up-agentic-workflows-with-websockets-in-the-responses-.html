Speeding up agentic workflows with WebSockets in the Responses API

10 官方动态 2026-04-22 · OpenAI / OpenAI
OpenAI方向:端云协同方向:工具调用方向:KV cache应用:代码
这是什么OpenAI 工程团队拆解 Codex 智能体循环的时延来源：推理变快后，API 服务开销成了瓶颈，于是给 Responses API 加上 WebSocket 长连接模式。
有什么结果智能体循环端到端快 40%；前期缓存等优化让首 token 时间缩短近 45%；GPT-5.3-Codex-Spark 达到 1000 token/s 目标、峰值 4000 token/s。外部集成方 Vercel 时延降最多 40%，Cline 多文件流程快 39%，Cursor 中 OpenAI 模型快最多 30%。
怎么做到在 WebSocket 连接内缓存上一轮响应状态、已渲染 token 和工具定义，后续请求只处理新增输入；安全分类器只检查增量内容，并把计费等后处理与下一轮请求重叠执行。
评分依据：优化发生在云端 API 侧，但它揭示了智能体多轮工具调用中“推理之外的开销”占比，以及工具在用户本机执行、状态在连接内复用的设计，对端云协同智能体有参考价值；方法本身是缓存加长连接的工程组合。
