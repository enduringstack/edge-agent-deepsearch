NVIDIA-Verified Agent Skills Provide Capability Governance for AI Agents

7 官方动态 2026-05-19 · NVIDIA / NVIDIA
NVIDIA方向:工具调用方向:安全隐私应用:安全
这是什么NVIDIA 给智能体技能建了一套验证和签名机制，想解决「技能可以随便装，但不知道安不安全」的问题。
有什么结果未报告。原文描述的是流程规范，没有给出验证速度、技能数量或性能数据。
怎么做到验证流水线分八步：源码仓库、人工评审、SkillSpector 自动扫描、评估、生成技能卡、加密签名、入库、同步。扫描既查常规风险（有漏洞的依赖、危险代码模式），也查智能体特有风险（隐藏指令、提示词注入、触发词滥用、权限过大、工具投毒）；签名遵循 OpenSSF 模型签名标准，可用 NVIDIA 的根证书校验。
评分依据：技能供应链安全是智能体生态的共性问题，但文章没有涉及设备端执行，端侧相关性低。把智能体特有的提示词注入、工具投毒等风险纳入可签名可校验的流水线，是比较前瞻的治理设计。
