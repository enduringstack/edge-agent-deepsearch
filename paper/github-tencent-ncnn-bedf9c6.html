Tencent/ncnn: unaryop: extend sign, hyperbolic, expm1 and log1p support (#6675)

9 开源大项目 开源 2026-05-21 · Tencent / GitHub
方向:推理框架方向:编译部署硬件:CPU硬件:GPU
这是什么端侧推理框架 ncnn 补齐了一批一元算子，让更多模型能原样转过来跑。
有什么结果未报告性能数值。提交本身是算子覆盖面的扩展，涉及 44 个文件、新增 2897 行。
怎么做到在标量、SIMD 和 Vulkan 三条执行路径上补齐 sign、sinh、cosh、asinh、acosh、atanh、expm1 和 log1p 这些一元算子；同时把新算子接进 onnx2ncnn 和 pnnx 的表达式转换、更新生成的 Python 代码，并补上转换路径的回归测试；另外修了 expm1 和 log1p 的数学函数声明可移植性等问题。
评分依据：ncnn 是面向手机和嵌入式设备的推理框架，算子覆盖直接决定模型能不能在端上原样跑通，端侧契合度较高。改动是补齐算子和修可移植性问题，属于常规维护。
