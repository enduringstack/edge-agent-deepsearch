OmniDelta: Skill-Driven Budget Allocation for Token Compression in OmniLLMs

11 公司项目 2026-07-28 · Haoyang Huang; Wenjie Huang; Tianqi Xu; Hongyaoxing Gu; Kang Tan; Yikai Fu; Yuhao Shen; Tianyu Liu / arXiv
Alibaba方向:多模态方向:高效推理方向:剪枝稀疏应用:视频应用:语音模型:Qwen
这是什么阿里千问应用团队与浙江大学提出的 OmniDelta：在全模态大模型里压缩音视频 token 时，先按问题需要决定音频和视频各留多少预算，再决定每段音频、每帧画面留多少。
有什么结果在 Qwen2.5-Omni 两个模型、四个音视频基准上刷新精度与效率的帕累托前沿；在 Qwen2.5-Omni-7B 只保留 25% token 时，显存减少 22.0%，端到端比全量推理快 1.64 倍。
怎么做到构建音频和视频“技能池”判断问题更依赖哪种模态，据此在模态之间重新分配固定的 token 预算；模态内部再按局部复杂度和时间冗余分配到各音频片段与视频帧，可与现有剪枝方法叠加，无需训练。
评分依据：音视频 token 压缩直接降低多模态推理的显存和时延，可迁移到端侧全模态助手，但实验在 GPU 上，相关度中等；把预算分配单独作为问题处理有新意。作者机构依据 arXiv PDF 首页：多位作者署名 Qwen Application, Alibaba，其余来自浙江大学等高校。 作者机构依据：arXiv PDF 首页署名 Alibaba（PDF 首页多位作者（含第 1–4 作者）署名 Qwen Application, Alibaba）。
