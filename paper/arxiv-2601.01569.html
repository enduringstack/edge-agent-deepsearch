CaveAgent: Transforming LLMs into Stateful Runtime Operators

10 学校预印本 开源 2026-01-04 · Maohao Ran; Zhenglin Wan; Cooper Lin; Yanting Zhang; Hongyu Xin; Hongwei Fan; Yibo Xu; Beier Luo / arXiv
方向:工具调用方向:记忆应用:代码模型:DeepSeek模型:Qwen
这是什么现有智能体靠文本上下文串联多轮工具调用，长任务容易丢状态。CaveAgent 把一个持久的 Python 运行时当作智能体的主工作区，让对象在多轮之间常驻。
有什么结果在 Tau2-bench 和 BFCL 上 12 个设置中 11 个有提升，多轮零售任务成功率最多提高 13.5%；三个开源模型在 BFCL 上达到 94.0% 到 94.7%；总 token 消耗降低 28.4%，数据密集任务最多降低 51%。
怎么做到双流架构：持久 Python 运行时保存 DataFrame、数据库连接等复杂对象，轻量语义流负责编排；工具和技能以可执行对象注入运行时，兼容 Agent Skills 标准。
评分依据：属于智能体工具调用与记忆的运行时设计，可迁移到端侧 Agent，但实验全部基于云端大模型。作者均来自高校，未见公司署名。
