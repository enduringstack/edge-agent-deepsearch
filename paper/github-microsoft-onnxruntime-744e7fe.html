microsoft/onnxruntime: Add type definitions, registration, utilities for INT2/UINT2 support (#26824)

10 开源大项目 开源 2026-01-15 · microsoft / GitHub
方向:量化方向:推理框架
这是什么ONNX Runtime 开始支持 2 比特整数（INT2/UINT2）张量类型，这是为极低比特量化模型铺路的第一步。
有什么结果未报告
怎么做到新增把 4 个 2 比特数打包进 1 个字节的数据类型，并在类型系统、C API 枚举和 ONNX 协议映射中注册；具体的 CPU 算子（类型转换、量化反量化等）留到后续提交。
评分依据：2 比特权重是端侧压缩大模型的重要方向，ONNX Runtime 又是端侧常用运行时，所以相关度中等偏上；本次只是类型基础设施，尚无可用算子，提交说明也没有给出性能数字，贡献有限。
