Dreaming: Better memory for a more helpful ChatGPT

7 官方动态 2026-06-04 · OpenAI / OpenAI
OpenAI方向:记忆方向:云端serving应用:长上下文推理
这是什么OpenAI 更新 ChatGPT 的记忆机制，用「做梦」的方式把零散对话合成更有条理的长期记忆。
有什么结果新架构被描述为更强且更省算力；合成出来的记忆可在记忆摘要页查看，用户可以在那里增补或更正信息、也可以指定希望模型在什么时候提起哪些话题。文章按「延续上下文、遵守偏好、随时间保持时效」三个目标，对比了 2024 年的保存式记忆、2025 年的初版合成记忆和 2026 年的新版本。
怎么做到不再只保存用户显式提到的条目，而是在后台对历史对话做记忆合成，并以可读摘要的形式交还给用户审阅和修改。
评分依据：面向云端助手的长期记忆机制，与端侧部署只有宽泛关联（相关性 2）。把记忆合成做成可审阅可修改的产品形态，并给出三目标的评估口径，思路值得借鉴（贡献 5）。
