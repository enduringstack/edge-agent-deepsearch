Springdrift: An Auditable Persistent Runtime for LLM Agents with Case-Based Memory, Normative Safety, and Ambient Self-Perception

8 学校预印本 开源 2026-04-06 · Seamus Brady / arXiv
方向:记忆方向:安全隐私方向:工具调用
这是什么多数 LLM Agent 按会话运行，关掉就忘。Springdrift 是一个长期常驻的 Agent 运行时，带可审计的持久记忆、安全闸门和自我状态感知，作者用它做了 23 天的单实例实际部署。
有什么结果未报告量化结果；作为案例报告，作者描述在 23 天（19 个工作日）部署中，Agent 自行诊断了基础设施缺陷、归类故障模式、发现一处架构漏洞，并在邮件和网页渠道间保持上下文。
怎么做到用 Gleam 语言基于 Erlang/OTP 实现，执行层采用只追加记忆、受监管进程和 git 备份恢复；记忆层用基于案例的推理和混合检索；安全层用确定性的规范演算做闸门；每轮把结构化的自身状态直接注入上下文。
评分依据：属于 Agent 运行时与记忆架构，有一定迁移参考价值，但没有说明运行设备，也没有端侧部署；作为单一实例的系统案例，证据较弱。
