Bole: Efficient Tree Speculation for Hybrid-Attention Language Models

11 公司项目 2026-08-03 · Li Wang; Yi Su; Xiabao Wu; Chiran You; Yongchao Liu; Zhan Qiu; Juelu Zhang; Jiajun Zheng / arXiv
Ant Group方向:投机解码方向:高效注意力方向:云端serving硬件:GPU
这是什么线性注意力与全注意力混合的大模型解码仍受内存带宽限制，而现有树状投机解码系统按全注意力的 KV cache 设计，用在混合模型上验证慢、显存占用大。Bole 做了内核与运行时协同设计。
有什么结果线性注意力树验证加速 3.4–7.7 倍，投机状态的临时内存减少 82–99 倍；在 4 个模型、2 种 GPU 平台上，离线解码吞吐最高达自回归解码的 4.72 倍、最强树投机基线的 2.03 倍；在线智能体负载下首 token 延迟和每 token 延迟分别最多降低 67.6% 和 49.9%。
怎么做到把线性注意力递推改写成树结构闭式解并用高效 GPU 内核并行验证所有候选节点；把投机状态更新无损编码成 token 级因子，只重建采样后选中的状态；并集成进 SGLang。
评分依据：树状投机解码与混合注意力都是端侧推理可迁移的技术，但本工作面向 SGLang 服务端批量推理（相关度 4）。系统解决混合注意力模型的树投机验证问题，内存节省显著（贡献 7）。PDF 首页有多位作者署名蚂蚁集团。 作者机构依据：arXiv PDF 首页署名 Ant Group（PDF 首页作者机构含 Ant Group，Xiabao Wu、Yongchao Liu、Zhan Qiu、Juelu Zhang 使用 antgroup.com 邮箱）。
