Hidden in Memory: Sleeper Memory Poisoning in LLM Agents

9 学校预印本 2026-05-14 · Sidharth Pulipaka; Stanislau Hlebik; Leonidas Raghav; Sahar Abdelnabi; Vyas Raina; Ivaxi Sheth; Mario Fritz / arXiv
方向:记忆方向:安全隐私应用:安全模型:GPT
这是什么带持久记忆的大模型助理可能被网页、文档里的恶意内容写入一条关于用户的虚假记忆，并在之后多次对话中潜伏发作。本文系统研究这种“潜伏式记忆投毒”。
有什么结果虚假记忆写入成功率在 GPT-5.5 上最高达 99.8%，在 Kimi-K2.6 上达 95%；在成功被检索到的情况下，有 60%-89% 的评测会导致攻击者预期的 Agent 行为。
怎么做到攻击者操纵外部上下文诱导助理存下伪造记忆，作者按“写入—检索—影响后续对话”完整链路评测多个有状态大模型助理。
评分依据：揭示 Agent 持久记忆的长期攻击面，对端侧个人助理的记忆设计有警示意义，但实验在云端助理上进行，相关度 3；首次完整评估潜伏式记忆投毒链路，贡献 6。
