这是什么让 Agent 从失败中定向补短板：自动找出 Agent 缺少的能力，为每种能力合成专门的训练环境，用强化学习分别训练再合并。
有什么结果在客服 Agent 基准 τ²-Bench 上比基础 Agent 提高 15.3 分，在 SWE-Bench Verified 上 Pass@1 提高 15.0 分；比 GEPA 和 SWE-RL 分别高 8.6 和 8.4 分；只用不到四分之一的 rollout 就超过 GRPO 和 GEPA。
怎么做到对比成功和失败轨迹找出缺失能力，为每个能力生成奖励环境训练一个 LoRA 适配器，最后用混合专家方式组合这些适配器。
评分依据：属于 Agent 训练方法，提升工具调用类任务表现，思路有新意；但训练和运行都在云端，与端侧部署无直接关系。
