Control How Your GPU Shares Work with Green Contexts

7 官方动态 2026-10-06 · NVIDIA / NVIDIA
NVIDIA硬件:GPU方向:调度服务
这是什么NVIDIA 介绍 CUDA Green Contexts：同一进程里的应用可以把 GPU 的一部分 SM 划给特定任务，让低时延算子、后台内核、数据预处理和模型推理并行运行而不互相拖慢。
有什么结果在 148 个 SM 的 Blackwell GPU 上让关键小内核与大批量内核并行：用 Green Context（关键任务独占 8 个 SM）时关键内核时延 0.007 毫秒，只用高优先级流为 0.140 毫秒，同优先级为 3.727 毫秒；代价是批量任务可用的 SM 变少。
怎么做到通过 cudaGreenCtxCreate 创建只占用指定 SM 子集和工作队列的轻量上下文，再在上面创建流，其余基于流的写法不变；Driver API 自 CUDA 12.4 起可用，Runtime API 自 CUDA 13.1 起可用。
评分依据：GPU 资源隔离属于推理部署的底层能力，但正文场景是数据中心 GPU 和 Holoscan 传感处理，没有涉及 Jetson 等端侧设备，相关度 3。这是 CUDA 已有特性开放到 Runtime API 并给出用法，贡献 4。
