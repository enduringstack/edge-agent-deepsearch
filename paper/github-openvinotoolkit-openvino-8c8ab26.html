openvinotoolkit/openvino: [PyTorch] Convert exported programs without run_decompositions (#38078)

7 开源大项目 开源 2026-09-21 · openvinotoolkit / GitHub
方向:推理框架方向:编译部署
这是什么OpenVINO 改写 PyTorch 前端，直接转换 torch.export 导出的模型而不再先执行 run_decompositions 分解步骤。
有什么结果FX 转换映射表从 343 项缩减到 125 项；提交报告 CPU 上 16,505 项 TorchScript、12,954 项 export、5,170 项 torch.compile 和 729 项前端/API 测试通过，未给出转换速度或推理性能数字。
怎么做到跳过分解可省掉额外的 AOTAutograd 追踪和形状传播；没有专门转换器的算子按 ATen 名回落到 TorchScript 转换器复用，并统一视图、容器、原地修改等别名处理。
评分依据：属于模型转换链路的工程改动，影响 PyTorch 模型落到 OpenVINO 时的算子覆盖与保真度，但不直接改变推理性能。
