Announcing winapp, the Windows App Development CLI

7 官方动态 开源 2026-01-22 · Microsoft / Microsoft
Microsoft方向:编译部署
这是什么微软发布开源命令行工具 winapp 公开预览版，让不用 Visual Studio 的开发者也能一条命令完成 Windows 应用的环境配置、清单、证书和打包。
有什么结果未报告
怎么做到winapp 统一下载 SDK、生成投影代码、创建清单和开发证书，并能给可执行文件直接添加调试用包身份，从而在任意工具链里调用 Windows AI API、MCP Host 等需要包身份的接口。
评分依据：降低了 Electron、C++、Rust 等应用调用 Windows 本地 AI 接口的门槛，属于 PC 端侧开发工具链；本身是工程工具，与模型推理无直接关系。
