有什么结果版本说明列出的要点包括：新增 Gemma4 文本视觉语音、Qwen3.5 等模型支持；推出 dflash 投机解码；Omni 模型采用 Thinker 与 Talker 交错生成把首帧音频时延降低 2.7 倍；CPU 与 GPU 全栈支持 2 比特和 3 比特权重量化；CUDA 支持 Blackwell 架构；QNN 后端支持 Qwen3.5 与离线图多进程并行导出。
怎么做到多模态侧扩展模型覆盖并重构键值缓存复用；GPU 侧分别在 Vulkan、OpenCL、Metal、CUDA 上做算子与调度优化；量化侧补齐 ARM 低比特内核并把 2 比特、3 比特权重量化打通到各 GPU 后端。
