Heavy-Tailed Memory Traces in Long-Horizon Language Agents

9 学校预印本 开源 2026-07-09 · Xinyuan Song; Zekun Cai / arXiv
方向:记忆应用:长上下文推理
这是什么长任务语言智能体靠外部记忆充当“世界模型”，但上下文有限时检索会集中在少数常用状态上，罕见状态被冷落、预测误差越积越多。论文先量化这种“核心加长尾”现象，再据此设计更省 token 的记忆控制器。
有什么结果在合成图世界任务上，CTWM 保持状态和转移全覆盖，提示词 token 减少 5.9%，下半区长尾状态的预测误差比图记忆基线降低 13.6%；在 LongMemEval 上 token 减少 24.48% 且整体准确率持平，在 ALFWorld 上也有一致的 token 节省。
怎么做到按状态被检索的频次排序，用单个幂指数 τ 给“核心”记忆分配提示词预算，同时把长尾状态压缩成摘要保留下来，避免罕见状态被彻底丢掉。
评分依据：智能体记忆的 token 预算分配对上下文受限的端侧智能体有迁移价值，但实验没有涉及任何设备部署。贡献在于把检索分布的重尾形状变成可调的控制信号，思路较新但收益幅度有限。PDF 首页作者 2 同时署名东京大学与 LocationMind（东京），据此标注公司归属。
