OCR-Memory: Optical Context Retrieval for Long-Horizon Agent Memory

10 学校顶会 2026-04-29 · Jinze Li; Yang Zhang; Xin Yang; Jiayi Qu; Jinfeng Xu; Shuo Yang; Junhua Ding; Edith Cheuk-Han Ngai / ACL 2026
方向:记忆方向:多模态模型:GPT模型:Qwen
这是什么长任务 Agent 的历史经验太长，原样塞进上下文太贵、做摘要又丢信息。OCR-Memory 把历史轨迹渲染成图片存起来，需要时再从图里定位并逐字转写出相关片段。
有什么结果在 Mind2Web 上以 GPT-4 为主模型，元素准确率从文本检索的 41.3% 提到 53.8%；换成 Qwen3-32B 也从 35.2% 提到 48.6%。每步注入的文本 token 从 3980 降到 596（减少 6.7 倍），代价是检索时延从 0.3 秒升到 1.7 秒、每回合存储从 18KB 增到 1.47MB。
怎么做到用带唯一视觉编号的图片高密度存储轨迹，检索时先通过视觉锚点定位相关区域，再把对应原文逐字转写回来，而不是让模型自由生成，以减少幻觉。
评分依据：Agent 记忆运行时的新思路，用视觉 token 压缩上下文，对上下文预算紧张的端侧 Agent 有迁移价值，但实验在云端大模型上完成。已被 ACL 2026 主会接收，方法有新意。
