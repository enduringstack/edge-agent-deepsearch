TOPS: First-Principles Visual Token Pruning via Constructing Token Optimal Preservation Sets for Efficient MLLM Inference

11 学校预印本 2026-06-25 · Tinghao Wang; Yichen Guo; Rui Huang; Junchi Yao; Qizhe Zhang; Zheng Lu; Yuan Zhang; Jiajun Cao / arXiv
方向:剪枝稀疏方向:多模态方向:高效推理
这是什么一种免训练的视觉 token 剪枝方法，用来减少多模态大模型处理图像时的冗余计算。
有什么结果原文称在 7 个多模态大模型骨干和 14 个基准上做了大量实验并验证有效，摘要未给出具体的加速比或精度数字。
怎么做到从信息论角度自顶向下地把剪枝重新表述成「构造 token 最优保留集」，归纳出任务相关性、信息覆盖度和语义多样性三条选择原则，据此做成一个免训练、与模型无关的剪枝模块挂到各类多模态模型上。
评分依据：视觉 token 剪枝直接降低多模态推理开销，对资源受限设备有明确迁移价值，但原文未做端侧部署，相关度按可迁移技术栈计；把多条启发式准则统一到一个信息论目标下，比单纯堆准则更有章法。
