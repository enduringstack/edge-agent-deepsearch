Browser automation tool in Microsoft Foundry is now GA

4 官方动态 2026-10-19 · Microsoft / Microsoft
Microsoft方向:工具调用方向:云端serving
这是什么Microsoft Foundry 的浏览器自动化工具正式可用，给云端智能体一个托管浏览器去浏览网页、填写表单和执行多步网页流程。
有什么结果未报告
怎么做到由 Playwright Workspaces 按需开启隔离的云端浏览器会话，智能体按观察、选择操作、执行、校验结果的循环推进，并支持私有网络、实时查看和人工接管。
评分依据：浏览器会话和智能体都托管在云端，与端侧无关；价值在于企业级可观测和人工监督的工程整合。
