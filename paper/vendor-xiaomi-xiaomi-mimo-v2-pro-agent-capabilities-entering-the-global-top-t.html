Xiaomi MiMo-V2-Pro: Agent capabilities entering the global top tier

7 官方动态 2026-03-18 · Xiaomi / Xiaomi
Xiaomi方向:MoE方向:高效注意力方向:工具调用应用:代码
这是什么小米发布旗舰基座模型 MiMo-V2-Pro，定位为智能体系统的大脑，面向编程和多步骤真实任务。
有什么结果官方称在 Artificial Analysis 智能指数全球第 8；PinchBench 平均 81.0、ClawEval 61.5，接近 Claude Opus 4.6 的 66.3；匿名测试版 Hunter Alpha 在 OpenRouter 累计调用超 1T token。
怎么做到总参数超 1T、激活 42B 的 MoE 模型，混合注意力比例从 5:1 提到 7:1，支持 1M token 上下文，并用轻量多 token 预测层加速生成；再在多种智能体框架上做监督微调和强化学习。
评分依据：万亿参数云端模型，与端侧部署无直接关系；混合注意力和多 token 预测属可借鉴的高效推理设计，整体为模型发布。
