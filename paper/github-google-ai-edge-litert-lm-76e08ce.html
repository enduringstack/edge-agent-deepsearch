google-ai-edge/LiteRT-LM: Verify drafts in the static compiled-model executor.

11 开源大项目 开源 2026-10-31 · google-ai-edge / GitHub
方向:投机解码方向:推理框架方向:高效推理
这是什么Google 端侧大模型运行时 LiteRT-LM 给静态编译模型执行器补上了草稿校验，让多 token 预测（MTP）投机解码能在这条执行路径上直接使用。
有什么结果未报告
怎么做到新增通用的草稿校验器：用基础模型的 verify 签名一次校验多个草稿 token，自动规划每轮校验宽度，支持约束解码掩码；校验采样复用会话自身的采样参数和随机数生成器，保证接受的 token 与正常解码分布一致。
评分依据：LiteRT-LM 面向手机与边缘设备跑大模型，投机解码是端侧提速的常用手段，与端侧推理直接相关；本次是运行时内部的工程改造，没有公布提速数字，贡献按常规工程整合计。
