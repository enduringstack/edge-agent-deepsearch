ContextWeaver: Selective and Dependency-Structured Memory Construction for LLM Agents

11 公司项目 2026-04-24 · Yating Wu; Yuhao Zhang; Sayan Ghosh; Sourya Basu; Anoop Deoras; Jun Huan; Gaurav Gupta / arXiv
Amazon方向:记忆方向:工具调用应用:代码应用:长上下文推理
这是什么大模型 Agent 交互历史越来越长时，滑动窗口或压缩会丢掉后续步骤依赖的早期信息。ContextWeaver 把 Agent 的执行轨迹组织成推理步骤依赖图，只挑相关上下文给下一步。
有什么结果在 SWE-Bench Verified 和 Lite 上，pass@1 优于滑动窗口基线，同时推理步数和 token 用量都下降（摘要未给出具体数字）。
怎么做到每一步都记录它依赖哪些早期步骤，按依赖关系遍历取上下文；把从根到当前步的推理路径压缩成可复用的摘要，并加一层结合执行反馈的轻量校验。
评分依据：属于 Agent 记忆与上下文管理，能直接减少 token 开销，对端侧 Agent 有迁移价值，但实验在云端编程 Agent 上，不涉及设备端，相关度中等；依赖图式记忆比检索式记忆多了因果结构，有一定新意。公司归属依据 arXiv 论文首页作者 2 至 7 署名 AWS AI Labs。 作者机构依据：arXiv PDF 首页署名 Amazon（论文首页作者 2 至 7 署名 AWS AI Labs，通讯邮箱为 amazon.com，第一作者在 AWS 实习期间完成）。
