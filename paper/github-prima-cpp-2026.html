prima.cpp：家用异构设备上 30-70B LLM 快速推理

16 开源大项目 开源 2026-06-30 · OpenCPIL / GitHub
方向:推理框架方向:编译部署方向:高效推理硬件:手机硬件:CPU硬件:GPU模型:Llama模型:Qwen
这是什么prima.cpp 是基于 llama.cpp 的分布式推理实现，把家里的笔记本、台式机、手机等异构设备连成一个小集群，合力跑 30B 到 70B 级别的大模型，对应论文发表于 ICLR 2026，本周以官方组织仓库重新发布。
有什么结果在 Mac M1、两台 Linux 电脑和一部 Mate40Pro 手机组成的家用集群上，Llama 3-70B 每个 token 延迟 674 毫秒，单机 llama.cpp 为 10120 毫秒，exo 和 dllama 直接内存不足；QwQ-32B 约每秒 11 个 token，各设备内存压力保持在 10% 以下。
怎么做到用带预取的环形流水线并行，提前加载后续层的权重来掩盖磁盘读取延迟；再按各设备的算力、内存、磁盘速度自动选择参与设备并分配层数。
评分依据：直接面向手机和个人电脑等日常设备的大模型推理，有真机集群实测，端侧相关度高；环形流水线并行加异构设备调度有新意并已被 ICLR 2026 接收。
