Energy-Efficient Reinforcement Learning for Large Language Models

7 公司项目 2026-11-03 · Rahul Sharma; Nitin Vegesna; Yanxin Zhang / arXiv
NVIDIA方向:能耗功耗硬件:H100硬件:GPU
这是什么大模型强化学习训练在“生成回答”和“更新策略”两个阶段对 GPU 的需求不同，存在降频省电的空间。EE-RL 在训练过程中在线为两个阶段分别选择 GPU 频率。
有什么结果在 H100 和 GB200 上做固定频率扫描，每个有效训练 token 的 GPU 能耗最多可省 28.2% 且吞吐基本不变；EE-RL 在线控制下实际节能最多 16.9%，吞吐只有小幅损失。
怎么做到把候选频率组合与默认 GPU 调速器在相同 token 工作量下的预测表现对比，选出满足吞吐门限的最省能设置，并持续监测吞吐和能耗、随负载变化调整。
