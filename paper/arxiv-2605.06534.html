ROSE: Rollout On Serving GPUs via Cooperative Elasticity for Agentic RL

7 公司项目 2026-05-07 · Wei Gao; Yuheng Zhao; Dilxat Muhtar; Dakai An; Xuchun Shang; Tianyuan Wu; Lunxi Cao; Shaopan Xiong / arXiv
Alibaba方向:云端serving方向:调度服务硬件:GPU
这是什么Agent 强化学习训练中，多轮交互采样（rollout）耗时最多且负载波动大，而推理服务集群又常有闲置算力。ROSE 让 rollout 借用已部署的推理服务 GPU，按需弹性扩容。
有什么结果在多种模型规模和集群规模下，端到端吞吐比固定资源方案提高 1.3-3.3 倍，rollout 时间比弹性借卡方案缩短 1.2-1.5 倍，且没有违反推理服务的时延承诺。
怎么做到三部分：在同一 GPU 上安全混跑推理服务和 rollout 模型的执行器、利用分片路由和权重稀疏的跨集群权重同步引擎，以及在专用 GPU 与借用 GPU 之间动态分配 rollout 的调度器。
评分依据：这是云端 Agent 强化学习训练的基础设施，与端侧部署无关；把训练借用推理集群闲置算力做成系统，有工程价值。 作者机构依据：arXiv PDF 首页署名 Alibaba（论文首页标注 ‡ 的多位作者署名 Alibaba Group）。
