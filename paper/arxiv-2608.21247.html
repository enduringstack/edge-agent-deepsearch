Just Noticeable Difference Modeling for Token Compression in Vision-Language-Action Models

11 学校预印本 2026-08-21 · Zhuoyuan Li; Rui Zhao; Jin Wang; Hanwei Zhu; Cong Zhang; Giuseppe Valenzise; Weisi Lin; Kin-Man Lam / arXiv
方向:剪枝稀疏方向:KV cache方向:多模态应用:机器人
这是什么机器人用的视觉-语言-动作模型需要压缩视觉 token 来降时延，但现有方法按“像不像、重不重要”挑 token。本文改为直接估计每个 token 能被改动多少而不影响机器人动作，以此决定压缩哪些。
有什么结果在 LIBERO 上，60% 和 80% 的 KV 复用比例下，OpenVLA 平均成功率比 VLA-Cache 高 23.70 和 41.65 个百分点，OpenVLA-OFT 高 6.20 和 10.10 个百分点；87.5% 剪枝时比 VLA-Cache 剪枝基线高 11.65 个百分点。
怎么做到借用“最小可察觉差异”的思想，训练一个轻量的逐 token 估计器，预测在策略动作不超出容差的前提下 token 最多能被扰动多少，再把这个分数接入陈旧 KV 复用和 token 剪枝。
评分依据：VLA 推理加速对机器人端侧闭环控制有直接价值，但实验只在仿真基准上进行；以动作容差为压缩依据的思路有新意。
