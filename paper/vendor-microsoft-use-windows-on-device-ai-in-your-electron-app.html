Use Windows on-device AI in your Electron app

10 官方动态 开源 2026-02-23 · Microsoft / Microsoft
Microsoft方向:编译部署硬件:NPU模型:Phi应用:OCR
这是什么微软演示如何在 Electron 桌面应用里调用 Windows 本地 AI：用 JavaScript 直接调用系统内置的 Phi Silica 模型做文本生成、摘要、改写、图像描述和文字识别。
有什么结果未报告
怎么做到提供实验性 Node.js 插件 @microsoft/windows-ai-electron，把 Windows AI API 投影给 JavaScript；配合 winapp CLI 初始化工程并声明 systemAIModels 权限，示例只能在带 NPU 的 Copilot+ PC 上运行。示例库还演示了通过本机智能体注册表发现并调用 MCP 服务器。
评分依据：明确是在 Copilot+ PC 的 NPU 上跑本地模型，属于 PC 端侧推理落地，但只是开发集成教程而非智能体闭环；工程整合为主，贡献偏低。教程只演示用法，没有给出时延、功耗等量化结果，因此效果写未报告。
