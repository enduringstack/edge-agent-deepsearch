Microsoft at NVIDIA GTC: New solutions for Microsoft Foundry, Azure AI infrastructure and Physical AI

5 官方动态 2026-03-16 · Microsoft / Microsoft
Microsoft方向:云端serving方向:端云协同应用:机器人硬件:GPU
这是什么微软在英伟达 GTC 大会上发布与英伟达合作的一揽子更新：Foundry 上构建和运营生产级 Agent、面向推理负载的 Azure 新基础设施，以及物理 AI 工具链。
有什么结果未报告（文中提到已在全球数据中心部署数十万块液冷 Grace Blackwell GPU，并成为首个点亮 Vera Rubin NVL72 的超大规模云，但没有性能对比数字）
怎么做到Foundry Agent Service 和可观测控制面正式商用，英伟达 Nemotron 模型上架 Foundry，可经 Fireworks AI 微调成低时延模型下发到边缘；Azure Local 初步支持 Vera Rubin 平台以满足主权与合规场景；把英伟达物理 AI 数据工厂蓝图接入 Azure，并开源 Azure Physical AI Toolchain 仓库，打通 Fabric 与 Omniverse 的实时运营数据和数字孪生。
评分依据：主体是云端推理基础设施与 Agent 平台，与端侧关系弱；只有模型微调后下发到边缘和物理 AI 落地两处与边缘场景沾边，且没有设备端细节。
