HGP:An on-device personalized agent memory via hybrid graph storage

11 学校预印本 开源 2026-10-07 · Ran Zhou; Xueming Han; Jiaheng Liu; Yuyao Zhang; Fanyu Meng; Junlan Feng; Yuxiang Ren / arXiv
方向:记忆方向:高效推理应用:RAG
这是什么端侧个人助理需要长期记住用户的经历、偏好和习惯，但常见记忆方案把所有记忆压成单一向量，类型和关系都混在一起。HGP 用混合图结构分别存储不同类型的记忆，并用轻量分类器决定新信息该写到哪里。
有什么结果在 PAL-Set 方案选择任务上 S-score 为 35.58，比最强基线高近 7 分；记忆路由分类器宏 F1 为 0.9339、平均时延 4.98 毫秒，约比固定大模型路由快 360 倍；大模型调用次数从 2400 降到 807，减少 66.4%。
怎么做到用小型 RoBERTa 分类器做记忆路由，只有低置信度样本才调用大模型标注，再用这些标注增量更新分类器；情景记忆存成事件图、语义记忆存成知识图谱、程序性记忆存成规则树，工作记忆用状态轨迹图记录当前状态和隐含约束。
评分依据：目标明确是端侧个性化智能体记忆，毫秒级路由分类器能减少大模型调用，可直接迁移到设备端；但论文没有在任何设备上实测，记忆抽取和回答生成仍调用云端 deepseek-chat 与 gpt-4o-mini，作者也说明端侧主张只针对在线路由和检索，因此不算端侧智能体。
