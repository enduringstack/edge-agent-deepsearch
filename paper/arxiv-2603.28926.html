A Computational Framework for Cross-Domain Mission Design and Onboard Cognitive Decision Support

5 学校预印本 开源 2026-03-30 · J. de Curtò; Adrianne Schneider; Ricardo Yanez; María Begara; Álvaro Rodríguez; Javier López; Martina Fraga; Ignacio Gómez / arXiv
方向:规划推理方向:评测基准模型:Llama模型:DeepSeek模型:Qwen
这是什么为远离地面通信的航天、水下等自主系统建立一套统一指标，量化“通信延迟越大越需要自主决策”，并测试大模型做任务异常决策支持的效果。
有什么结果在 10 个结构化异常场景上测试 Llama-3.3-70B、DeepSeek-V3、Qwen3 三个模型，表现最好的模型对照物理推导的标准答案达到 80% 决策准确率，全部 180 次调用都在 2 秒时延预算内完成。
怎么做到提出基于对数延迟的自主必要性评分，结合覆盖、探测、链路预算等九项计算研究，再通过云端 API 调用大模型回答从这些分析推出的异常场景。
评分依据：大模型通过 Nebius 云端 API 调用，并未在星上或设备端运行，与端侧推理关系很弱，相关度 2。主体是任务设计方法学，大模型部分是简单评测，贡献 3。
