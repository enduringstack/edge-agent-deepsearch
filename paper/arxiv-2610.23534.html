From Billion-Scale to Million-Scale Language Models: Operational Capabilities for Embedded Post-Exploitation

8 学校预印本 开源 2026-10-16 · Gabriel Hortea; Simon Pietro Romano; Juan Tapiador; Mario Varlese / arXiv
方向:安全隐私方向:评测基准应用:代码模型:Qwen模型:SmolLM
这是什么研究不到 20 亿参数的小模型能否被塞进恶意软件、在没有云端的情况下自己生成攻击代码，从安全角度评估超小模型的本地代码生成能力。
有什么结果评测 7 个 2000 万到 15 亿参数的开源小模型：配合算法化任务描述和少样本提示，Qwen2.5-Coder 1.5B 在目录枚举任务上 Python 与 Lua 的 Pass@5 均达 100%，后门生成 Python 100%、Lua 99.2%；能力并不随参数量线性增长。
怎么做到设计目录枚举和后门生成两类任务，在 Python 与 Lua 两种语言下系统比较提示策略、任务表述、语法约束解码、迭代推理和执行反馈闭环，并在沙箱里实际运行生成代码验证。
评分依据：关注的是小模型脱离云端在受限环境中自主运行的安全风险，对端侧小模型的威胁建模有参考价值，但实验在服务器 V100S GPU 上用 vLLM 完成，未在嵌入式设备实测；属系统性评测，方法创新有限。作者来自那不勒斯费德里科二世大学和马德里卡洛斯三世大学。
