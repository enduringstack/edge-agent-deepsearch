SkillSmith: Compiling Agent Skills into Boundary-Guided Runtime Interfaces

10 学校预印本 开源 2026-05-12 · Duling Xu; Zheng Chen; Zaifeng Pan; Jiawei Guan; Dong Dong; Jialin Li; Bangzheng Pu / arXiv
方向:工具调用方向:编译部署方向:高效推理
这是什么Agent 使用技能包时通常把整段技能说明塞进上下文，并重复推理规划。SkillSmith 先把技能包离线编译成最小可执行接口，运行时只调用相关部分。
有什么结果在 SkillsBench 上，相比直接使用原始技能，求解阶段 token 用量减少 57.44%，思考迭代次数减少 42.99%，求解时间减少 50.57%（快 2.02 倍）；强模型编译的产物可复用给更小的运行时模型，在原始技能读不懂的情况下提升准确率。
怎么做到从技能包中提取细粒度的操作边界，离线编译成边界优先的运行时接口，Agent 执行时按需访问和执行相关组件，减少无关上下文注入和重复推理。
评分依据：属于 Agent 运行时的上下文与推理开销优化，且编译产物可交给更小的模型执行，对端侧 Agent 有迁移价值，相关度 4；把技能“编译”成接口的思路新颖，贡献 6。代码已开源。
