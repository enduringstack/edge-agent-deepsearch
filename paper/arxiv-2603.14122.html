Towards Agentic Honeynet Configuration

5 学校预印本 2026-03-14 · Federico Mirra; Matteo Boffa; Idilio Drago; Danilo Giordano; Marco Mellia / AgenNet 2026（NOMS 2026 研讨会）
方向:规划推理应用:安全
这是什么用 AI Agent 自动管理蜜罐暴露：根据入侵检测告警推断攻击进度，动态决定开放哪些诱饵服务。
有什么结果在攻击者执行已知 CVE 概念验证利用的模拟环境中，初步结果显示 Agent 能有效推断攻击意图，并在资源受限下提升暴露效率；未给出具体数字。
怎么做到Agent 读入 IDS 告警和网络状态，判断哪些资产已被攻破、预测下一步目标，再重新配置蜜罐网络。
评分依据：属于网络安全领域的 Agent 应用，运行在服务器侧，与端侧推理关系很弱；尚处初步阶段。
