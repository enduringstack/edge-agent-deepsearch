Agent Memory as Rate-Limited Filtering: Explicit State Outlasts Long Context Beyond a Reader-Dependent Horizon

10 学校预印本 2026-11-02 · Tianhao Guo; Chongyao Guo / arXiv
方向:记忆方向:评测基准应用:长上下文推理
这是什么智能体到底该把历史全塞进长上下文，还是维护一个显式状态？这篇用权限日志判断任务做实验，并把智能体记忆看成“限速滤波”问题来分析。
有什么结果7B～32B 开源模型读完整历史时，准确率从 8～16 个事件时的 72%～86% 掉到 256 个事件时的 48%～55%，而读当前状态的 32B 推理模型达到 96%～98%；先逐行解析再按规则更新的过滤器在 256 个事件时达到 80%～89%，优于相关性检索、模型自记账本、StateMem 和 Mem0。
怎么做到把决策需要的信息看作由被跟踪键数量决定大小的状态，记忆存储容量不够就会按其容量对应的时间尺度遗忘；用模型解析每条日志、显式规则更新状态，相当于在写入时就按状态依赖做了筛选。
评分依据：智能体记忆设计的理论与实证分析，显式小状态替代长上下文对内存受限的端侧智能体有直接参考价值，但未涉及设备部署（相关度 4）；用滤波视角解释记忆容量与遗忘的关系有新意（贡献 6）。论文未标注作者机构。
