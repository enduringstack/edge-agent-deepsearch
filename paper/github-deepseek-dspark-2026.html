DSpark：DeepSeek 投机解码 draft 模型（DeepSpec 框架）

13 开源大项目 开源 2026-06-27 · DeepSeek AI / GitHub
方向:投机解码方向:推理框架模型:DeepSeek模型:Qwen模型:Gemma
这是什么DeepSeek 开源的投机解码训练与评测代码库 DeepSpec，内含其新算法 DSpark 以及 DFlash、Eagle3 两种对照草稿模型，并放出基于 Qwen3-4B/8B/14B 与 Gemma-4-12B 训练好的草稿模型权重。
有什么结果配套论文报告：在 DeepSeek-V4 线上服务中，与原有 MTP-1 基线相比，DSpark 在相同吞吐下让单用户生成速度提升 60% 到 85%。
怎么做到DSpark 用并行骨干加轻量顺序模块的半自回归结构生成草稿，减轻长草稿后段接受率下滑；再根据每条请求前缀的存活概率和引擎吞吐曲线动态决定验证长度，避免把算力浪费在大概率被拒的词上。
评分依据：投机解码是端侧推理可直接借鉴的加速技术，且发布了 4B 级小模型的草稿权重，但论文实验面向数据中心服务，端侧相关度中等；半自回归草稿加负载感知验证有明显新意。公司归属依据配套论文 arXiv 2607.05147 首页署名：多数作者属 DeepSeek-AI，邮箱为 deepseek.com。
