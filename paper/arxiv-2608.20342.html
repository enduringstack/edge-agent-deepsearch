PrimeAgentOrchestrator: Memory-Primed Agent Spawning for Personal AI Infrastructure

8 学校预印本 2026-05-08 · Myron Koch / arXiv
方向:记忆应用:代码
这是什么编码 Agent 每次新会话都从空上下文开始，之前积累的知识全丢了。PrimeAgentOrchestrator 在启动 Claude Code 新实例时，自动从用户已有的个人数据库里取出相关记忆预先注入。
有什么结果论文是四个月（2025 年 12 月至 2026 年 3 月）日常使用的经验报告，记录了三代上下文注入方式及促使每次重设计的失效模式，未报告量化结果。
怎么做到启动时并行查询两个独立的记忆后端（PostgreSQL 实体观察库和 Cloudflare Worker 语义检索索引），按后端分别融合结果，再借助 Claude Code 启动时自动读取配置文件的机制把整理好的简报写入文件系统。
评分依据：关注 Agent 跨会话记忆，和个人电脑上的 Agent 使用相关，但推理仍依赖云端 Claude，电脑只是入口，不算端侧 Agent。单人工程经验报告，方法偏工程整合。
