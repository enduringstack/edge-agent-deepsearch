ICAE-Bench: Evaluating Coding Agents as Interactive Project Builders

7 公司项目 开源 2026-07-23 · Zhongyuan Peng, Dan Huang, Chuyu Zhang, Caijun Xu, Changyi Xiao, Shibo Hong, David Lo, Lin Qiu, Xuezhi Cao, Jiyuan He, Yixin Cao / arXiv
Meituan方向:评测基准方向:工具调用应用:代码
这是什么ICAE-Bench：评测编程智能体能否从模糊的产品需求出发，通过向模拟用户提问澄清，最终搭出可用项目的基准。
有什么结果包含 12 种编程语言的 480 个任务；在 Claude Code 框架下测试 GPT-5.5、Claude-Opus-4.8 等六个模型，结果显示智能体通常能复现可见行为，但在隐藏约束、边界情况和长程集成上明显吃力。
怎么做到从可运行的真实开源仓库出发，先写出完整需求文档再逐步“模糊化”，被隐藏的约束交给基于数据的模拟用户智能体按需透露；用黑盒测试加语义、结构、设计和交互质量等多维指标评分。
