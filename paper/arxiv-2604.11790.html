ClawGuard: A Runtime Security Framework for Tool-Augmented LLM Agents Against Indirect Prompt Injection

10 学校预印本 开源 2026-04-13 · Wei Zhao; Zhe Li; Peixin Zhang; Jun Sun / arXiv
方向:安全隐私方向:工具调用
这是什么工具增强的大模型 Agent 容易被工具返回内容里夹带的恶意指令劫持（间接提示注入）。ClawGuard 是在每次工具调用边界做确定性拦截的运行时安全框架。
有什么结果在 5 个主流模型、6 个注入基准（覆盖网页、本地文件、MCP 和 skill 通道）以及 3 个 OS/网页/代码任务基准上，能稳健防御间接提示注入，且不损失 Agent 任务效用、不明显增加 token 开销；摘要未给具体数字。
怎么做到在调用任何外部工具前，先根据用户目标自动推导出本任务的访问约束规则并让用户确认，之后每次工具调用都按规则检查，不改模型也不改基础设施。
评分依据：属于 Agent 工具调用运行时的安全层，可直接用于本地运行的 Agent，但论文未涉及端侧部署；把防御从依赖对齐转为规则拦截，工程价值较好。
