microsoft/onnxruntime: [WebGPU] Add int8 kv cache block quantization (#32284)

14 开源大项目 开源 2026-09-08 · microsoft / GitHub
方向:推理框架方向:KV cache方向:量化方向:编译部署硬件:GPU应用:长上下文推理
这是什么ONNX Runtime 的 WebGPU 执行提供器新增 int8 分块 KV 缓存量化，让浏览器和本地 GPU 上跑长上下文模型更省显存。
有什么结果PR 说明给出：Q8 分块量化在 4K 上下文下省 7.8% 显存、保留 97.9% 的 FP16 生成吞吐；Q4 省 13.4% 显存但生成吞吐掉 7.5%；两者的预填充性能与 FP16 相差都在 2.2% 以内。
怎么做到把原来只支持 Q4 TurboQuant 的 KV 缓存扩展成按位宽可配（0 不量化、4 位、8 位），并把 Flash Attention 泛化成能直接读量化后的 KV 缓存；改动集中在 WebGPU 着色器模板、量化算子和注意力实现，共 23 个文件、新增 2350 行。
评分依据：ONNX Runtime 的 WebGPU 路径正是浏览器和本地设备上跑模型的主力后端，KV 缓存显存又是长上下文的第一瓶颈，端侧相关性明确；给出了显存与吞吐的完整折中数据，工程价值扎实。
