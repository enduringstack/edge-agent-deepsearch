AI Development on Windows: from PyTorch and llama.cpp to Windows ML

13 官方动态 开源 2026-10-07 · Microsoft / Microsoft
Microsoft方向:推理框架方向:编译部署方向:投机解码方向:量化硬件:NPU硬件:GPU硬件:CPU应用:语音
这是什么微软给 Windows 本地推理框架 Windows ML 加入实验性 llama.cpp 支持，开发者可以直接在 PC 上跑 GGUF 模型，并通过 OpenAI 兼容的本地接口调用，方便在 Windows 上搭建本地智能体。
有什么结果正文未给出性能数字。已上线文本生成 API（同时接收 GGUF 和 ONNX 模型并自动选择执行引擎）和语音识别 API（ONNX Whisper），并预览了 Windows 原生 Runtime API；微软与 NVIDIA 还为 llama.cpp 贡献了内核融合、CUDA Graph、Eagle-3/MTP/D-Flash2 投机解码、多 GPU 和 NVFP4 支持；PyTorch 推出官方 Windows Arm64 原生构建。
怎么做到Windows ML 作为统一的本地推理层，覆盖 AMD、Intel、NVIDIA、高通的 CPU、GPU 和 NPU；任务级 API 在底层按模型格式自动路由到 llama.cpp 或 ONNX 引擎，Runtime API 则提供零拷贝输入、按阶段指定设备的多模型流水线和提前编译。
评分依据：这是 Windows PC 官方本地推理栈的更新，直接面向 GPU、NPU、CPU 本地部署，端侧相关度高。主要是把 llama.cpp 生态接入系统框架的工程整合，且没有给出性能数据，贡献中等。
