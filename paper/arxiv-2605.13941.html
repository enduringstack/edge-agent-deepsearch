EvolveMem:Self-Evolving Memory Architecture via AutoResearch for LLM Agents

8 学校预印本 开源 2026-05-15 · Jiaqi Liu, Xinyu Ye, Peng Xia, Zeyu Zheng, Cihang Xie, Mingyu Ding, Huaxiu Yao / HuggingFace Daily
方向:记忆应用:RAG方向:规划推理
这是什么让记忆系统不只更新存的内容，连检索打分、融合策略和回答方式这套配置也自己迭代改。
有什么结果LoCoMo 上相对最强基线提升 25.7%、相对最小基线提升 78.0%；MemBench 上相对最强基线提升 18.9%；演化出的配置迁移到其他基准时是正迁移而非灾难性迁移，说明学到的是通用检索原则而不是基准专用技巧。
怎么做到把完整的检索配置暴露成一个结构化动作空间，由一个大模型驱动的诊断模块优化：每轮读逐题失败日志、定位根因、提出针对性的配置调整；一个带防护的元分析器负责应用这些调整，并自动在退步时回滚、在停滞时转向探索。整个闭环相当于系统对自己的架构做自动化研究，替代人工调参。
评分依据：记忆检索配置的自动优化对端侧助理有间接参考价值，但论文不涉及设备端执行，端侧相关性很低。指出现有系统只让存储内容演化、检索机制却在部署时冻结，并把两者一起纳入演化，问题提法有新意。
