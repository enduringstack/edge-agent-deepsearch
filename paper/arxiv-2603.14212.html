Memory as Asset: From Agent-centric to Human-centric Memory Management

6 学校预印本 2026-03-15 · Yanqi Pan; Qinghao Huang; Weihao Yang / arXiv
方向:记忆方向:安全隐私
这是什么提出“记忆即资产”的理念：Agent 记下的用户经历和知识应归用户本人所有，并能在群体之间共享、交换和共同演化。
有什么结果未报告
怎么做到提出三层记忆基础设施构想：每个人自己掌控的个人记忆存储、部署在用户或 Agent 侧负责更新记忆的演化层，以及用于发现和交换记忆资产的去中心化网络；并定义了带所有者、访问权限和版本信息的记忆对象。
评分依据：涉及 Agent 记忆管理和个人数据归属，与端侧个人 Agent 有概念关联；但作者自述是早期草稿，只有架构设想，没有实现和评测，因此效果写未报告。作者机构依据：arXiv PDF 首页共同一作 Qinghao Huang 署名 Brachisto Ltd.（香港），其余作者来自哈尔滨工业大学（深圳）。（首页另署名小型公司 Brachisto，不计为公司项目）
