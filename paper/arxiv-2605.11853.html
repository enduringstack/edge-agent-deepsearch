GEAR: Granularity-Adaptive Advantage Reweighting for LLM Agents via Self-Distillation

8 公司项目 2026-05-12 · Sijia Li; Yuchen Huang; Zifan Liu; Yanping Li; Jingjing Fu; Li Zhao; Jiang Bian; Ling Zhang / arXiv
Microsoft方向:工具调用方向:蒸馏方向:规划推理模型:Qwen
这是什么用强化学习训练大模型 Agent 时，奖励通常只在最后给一次，很难知道长轨迹里哪一段做对了。GEAR 用自蒸馏信号自适应地把奖励分配到具体的 token 或片段上。
有什么结果在 8 个数学推理和 Agent 工具调用基准上（Qwen3 4B、8B）稳定优于标准 GRPO、纯自蒸馏和按 token/轮次分配的方法；在 GRPO 基线较弱的基准上最高提升约 20%。
怎么做到对比学生模型与“看过标准答案”的教师模型的分布差异，差异突增处作为片段起点：学生与教师一致的地方保留 token 级权重，偏离的地方合成片段并按偏离程度调整优势值。
评分依据：这是云端 Agent 后训练方法，不涉及推理部署，相关度低；用分布差异自适应划分信用区间的思路有新意。PDF 首页作者 Li Zhao、Jiang Bian、Ling Zhang 等署名 Microsoft Research Asia，邮箱 microsoft.com。 作者机构依据：arXiv PDF 首页署名 Microsoft（PDF 首页作者署名 Microsoft Research Asia，邮箱域名 microsoft.com）。
