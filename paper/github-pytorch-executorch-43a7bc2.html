pytorch/executorch: Add the WebGPU Playground (experimental) (#23944) (#23944)

13 开源大项目 开源 2026-10-19 · pytorch / GitHub
方向:推理框架方向:编译部署方向:多模态应用:语音硬件:GPU模型:Qwen模型:Llama
这是什么ExecuTorch 官网上线实验性的 WebGPU 演练场：在浏览器里直接用 WebGPU 本地跑 ExecuTorch 模型，包括对话、语音转文字、分割、深度估计、目标检测等演示。
有什么结果未报告
怎么做到所有演示共用一个约 1.4 MB（gzip 后）的 ExecuTorch Wasm 运行时和 WebGPU 后端；对话可选 Qwen3 0.6B 或 Llama 3.2 1B，并配 Whisper 语音输入，模型从 Hugging Face 按固定版本下载、逐文件校验后缓存在浏览器里。
评分依据：这是在用户自己设备的浏览器里完成推理的端侧部署示例，覆盖小语言模型、语音和视觉模型；属于运行时打包和演示工程，方法本身不新，贡献中等偏低。
