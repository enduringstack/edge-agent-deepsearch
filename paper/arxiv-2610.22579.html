MemLLM: End-to-end In-Storage Acceleration of On-device Retrieval-Augmented Generation using Precomputed KV Caches

16 学校顶会 2026-10-15 · Seungkwan Kang; Hyungseok Ko; Heemin Kim; Myoungsoo Jung / MICRO 2026
方向:KV cache应用:RAG硬件:Jetson硬件:FPGA硬件:CIM
这是什么在端侧设备上做 RAG 时，预先算好的 KV cache 动辄几 GB，从 SSD 经 PCIe 搬到 GPU 比重新计算还慢。MemLLM 直接在 SSD 内部完成基于预计算 KV cache 的整段注意力计算。
有什么结果在 8 个真实 RAG 数据集和 6 个端侧大模型上，端到端平均比 GPU 基线快 4.06 倍；即使叠加各种 KV 压缩方法，仍保持 2.0–4.4 倍加速。
怎么做到在每个 NAND 通道端放轻量 SIMD 加速器吃满聚合闪存带宽；用融合的重算-查询内核加硬件过滤把 NAND 读取量减半；基于 SRAM 的状态化归约引擎完全绕开 SSD 内部 DRAM，使 PCIe 输出量保持常数级。在 16nm FPGA 上做了 RTL 原型，并结合 Jetson Orin NX 实测和周期精确 SSD 模拟评估。
评分依据：针对端侧 RAG 的预填充与 I/O 瓶颈，用 Jetson Orin NX 作为端侧基线并做了 FPGA 原型，端侧相关度高；把完整注意力流水线下沉到 SSD 存内计算，系统设计新颖，已被 MICRO 2026 接收。作者来自 KAIST，无公司署名。
