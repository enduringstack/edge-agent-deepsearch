NavJev: Efficient Vision-Language Navigation via Action-Centric Visual Compression and Discriminative Action-Semantic Memory

10 学校预印本 2026-09-28 · Kai Sheng; Liuyi Wang; Jinlong Li; Haojie Dai; Chengju Liu; Qijun Chen / arXiv
方向:多模态方向:记忆方向:高效推理应用:机器人
这是什么零样本视觉语言导航方法每走一步都要调用多模态大模型生成推理文本，时延很高。NavJev 把每一步决策改成“先把候选动作压缩成简短的文字表示，再做一次轻量的结构化选择”，大幅缩短单步耗时。
有什么结果在 R2R-CE 上成功率 27.0%、SPL 22.4%，单步平均仅 0.65 秒，相比 Open-Nav、SmartWay、P2DNav 分别约快 41.5、8.2、7.6 倍；成功率比使用 GPT-4o 的 Open-Nav 高 8.0 个点；办公室和咖啡馆的真实环境实验显示效率优势可以迁移到实物导航。
怎么做到动作中心视觉压缩把航点几何、BLIP 描述和 RAM 语义标签合成每个候选动作的紧凑表示；判别式动作语义记忆过滤各候选共有的语义，只保留能区分动作的证据并跨步累积；最后由决策模型在候选动作集合上直接做概率化选择。
评分依据：降低具身导航智能体单步决策时延的思路对端侧部署有借鉴，但模型推理在 RTX PRO 6000 服务器和云端 API 上完成，真实机器人只负责采集画面，相关度中等；用压缩表示加结构化选择替代逐步生成的做法有新意。
