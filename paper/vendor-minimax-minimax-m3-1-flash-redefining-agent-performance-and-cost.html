MiniMax M3.1 Flash: Redefining Agent Performance and Cost

8 官方动态 2026-10-19 · MiniMax / MiniMax
MiniMax方向:高效推理方向:剪枝稀疏方向:工具调用
这是什么MiniMax 推出面向智能体任务的 M3.1 Flash 模型，在编码、电脑操作和网络安全任务上接近一线模型，同时大幅降低推理成本。
有什么结果BankerToolBench 76.2 分、DeepSWE v1.1 73.7%、OSWorld V2 61.7 分、Agents Last Exam 29.6 分、CyberGym 82%；在线推理速度提升近 3 倍，输出可达每秒 200 个以上 token（中位数 170 以上），智能体场景使用成本比上一代低 70%。
怎么做到通过更激进的稀疏化提升推理效率，以每百万 token 输入 0.15 美元、输出 0.60 美元的价格提供云端 API；权重将在之后开放。
评分依据：模型目前只以云端 API 提供，与端侧部署无直接关系；稀疏化带来的推理提速对高效推理有参考，但官方未披露具体方法。
