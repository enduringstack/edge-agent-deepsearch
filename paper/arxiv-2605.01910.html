Stochastic Sparse Attention for Memory-Bound Inference

13 学校预印本 开源 2026-05-03 · Kyle Lee; Corentin Delacour; Kevin Callahan-Coray; Kyle Jiang; Can Yaras; Samet Oymak; Tathagata Srimani; Kerem Y. Camsari / arXiv
方向:稀疏注意力方向:KV cache方向:高效推理方向:能耗功耗硬件:GPU模型:Llama
这是什么S²ANTA 针对长上下文解码受显存带宽限制的问题，只随机抽取少量 value 行参与注意力计算，减少 KV cache 读取量。
有什么结果在 Llama-3.1-8B-Instruct、32k 上下文下精度与基线持平，在 RTX 6000 Ada 上解码注意力内核比 FlashInfer、FlashDecoding 最多快 1.5 倍；批量长上下文生成中端到端解码时延最多加速 1.25 倍。
怎么做到按 softmax 后的概率分布采样少量索引，只聚合这些 value 行，得到无偏估计并把乘加换成取数加法；再用分层/系统采样降方差，并用三值随机 query 稀疏化打分阶段。
评分依据：解码访存瓶颈是端侧大模型推理的核心痛点，免乘法、稀疏访存的思路对低功耗硬件尤其有迁移价值，但实验在桌面 GPU 上完成。用随机采样做无偏注意力估计的思路新颖，内核开源。
