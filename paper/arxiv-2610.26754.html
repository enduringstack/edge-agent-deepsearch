TokenGate: Adapting LLMs for Fast and Memory-Efficient Prefill with Learned Token Pruning

13 学校预印本 开源 2026-10-19 · Liana Patel; Rishabh Ranjan; Ion Stoica; Matei Zaharia; Carlos Guestrin / arXiv
方向:剪枝稀疏方向:高效注意力方向:高效推理应用:长上下文推理模型:Qwen
这是什么长文档、代码仓库这类长输入让模型的预填充阶段又慢又占内存。TokenGate 是一个可直接插进现有模型的小组件，让模型学会像人一样“略读”，只对重要 token 做完整计算。
有什么结果在代码补全、多跳问答、摘要等任务上，首 token 时延缩短 1.4-11.3 倍、预填充峰值内存降低 1.5-3.4 倍且精度不降；比最好的已有 token 剪枝方法预填充快最多 6.4 倍、峰值内存低 2 倍；在混合注意力的 Qwen3.5-2B 上首 token 时延降 3.8 倍。
怎么做到借鉴混合专家的门控思路，用 token 重要性分数重新加权注意力 logits，绕开 top-K 不可微的问题，实现端到端可学习的 token 剪枝；训练开销与 LoRA 这类参数高效微调相当。
评分依据：面向长上下文预填充的时延和内存，直接适用于内存紧张的设备，但实验在 A100 GPU 上进行，未在端侧设备实测，相关度中等偏上；可学习的 token 剪枝能直接扩展到混合注意力模型，创新度较高。作者来自斯坦福大学和加州大学伯克利分校。
