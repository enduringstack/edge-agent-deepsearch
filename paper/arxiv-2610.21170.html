MemScope: Evolving Agent Memory Architectures through Localized Code Repair

9 公司项目 2026-10-15 · Miao Su; Yucan Guo; Zixuan Li; Long Bai; Zhongni Hou; Xiaolong Jin; Jiafeng Guo / arXiv
Meituan方向:记忆方向:工具调用模型:DeepSeek
这是什么智能体的记忆架构部署后通常固定不变，自我进化方法又只拿到分数或摘要这类粗反馈，往往一改就是大面积重写。这篇工作让一个修补智能体根据细粒度执行证据，对记忆架构代码做小范围就地修复。
有什么结果GAIA 上同时检查轨迹和记忆状态的版本准确率 86.67%，只看轨迹为 70.00%、只看摘要为 63.33%；xBench 上进化后的记忆架构用 DeepSeek V3.2 从 49 题升到 55 题、用 Kimi K2.7 Code 从 50 题升到 53 题；ALFWorld 未见任务成功率从 50.75% 升到 71.64%；代码改动比例中位数仅 4.4%。
怎么做到修补智能体同时检查原始执行轨迹、运行时记忆状态和现有架构代码，定位出错位置，在提供方身份和记忆兼容约束下做有界的就地修改。
评分依据：Agent 记忆架构演化属于 Agent 运行时技术，但依赖云端大模型、无端侧内容；以细粒度证据驱动局部修复的思路有新意。作者主要来自中国科学院计算技术研究所，另有一位作者署名美团。 作者机构依据：arXiv PDF 首页署名 Meituan（PDF 首页作者 Zhongni Hou 署名 Meituan，其余作者来自中国科学院计算技术研究所，公司为参与方而非主导方）。
