Safeguarding LLM Agents against Long-Horizon Threats via Shadow Memory

11 公司项目 开源 2026-05-04 · Yuhui Wang; Tanqiu Jiang; Jiacheng Liang; Charles Fleming; Ting Wang / ACM CCS 2026
Cisco方向:记忆方向:安全隐私
这是什么大模型 Agent 在多轮交互中可能被一步步诱导去做坏事。这篇给 Agent 加一块专门记录安全相关上下文的“影子记忆”，在每个动作执行前先评估风险。
有什么结果在多种长程攻击上检测准确率明显优于现有防御，多数攻击能在早期被发现，对 Agent 正常能力的影响可忽略；摘要未给出具体数值。
怎么做到借鉴系统安全里的影子栈思路，单独维护一份从整个执行轨迹中提炼的安全记忆，在待执行动作落地前用它做风险判断。
