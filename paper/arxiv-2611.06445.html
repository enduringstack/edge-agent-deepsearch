SUMONE: A Simple and Efficient Summarizer for Plug-and-Play Agent Memory

11 学校预印本 2026-11-04 · Jizhe Zhang; Ang Li; Chenheng Zhang; Yisen Wang / arXiv
方向:记忆方向:高效推理应用:长上下文推理模型:Qwen
这是什么长时间运行的 Agent 历史越积越长，必须压缩上下文。SumOne 是一个可以直接插到现有 Agent 上的独立摘要模型，不依赖具体任务训练。
有什么结果在 DeepSearchQA 和 SWE-bench Verified 上，相比保留完整上下文，估计推理成本分别降低约 78% 和 75%，绝对得分只下降 0.04；同一模型无需再微调即可迁移到其他下游模型和 Agent 框架。
怎么做到以 Qwen3.5-2B 为摘要器：先给过期历史写摘要，再让一个冻结的重建模型根据摘要恢复被随机遮掉的原始轨迹片段，用恢复质量加长度惩罚作奖励，以 GRPO 训练，无需参考摘要或执行下游任务。
评分依据：2B 规模的 Agent 记忆压缩器对端侧 Agent 的上下文预算有直接参考价值，但实验在云端 API 上进行（相关度 5）。用遮盖重建作为任务无关奖励训练摘要器思路较新（贡献 6）。作者来自北京大学，代码承诺接收后开源。
