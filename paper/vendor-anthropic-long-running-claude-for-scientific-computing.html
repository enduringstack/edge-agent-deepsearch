Long-running Claude for scientific computing

6 官方动态 2026-03-23 · Anthropic / Anthropic
Anthropic方向:记忆方向:规划推理应用:代码
这是什么Anthropic 研究员演示如何让 Claude 连续多天自主完成科研编程：用 Claude Opus 4.6 从零实现一个可微分的宇宙学玻尔兹曼求解器。
有什么结果Claude 用几天时间从零完成项目，各项输出与参考实现 CLASS 达到亚百分比级一致，但作者也承认并非所有参数区间都达到可用精度。
怎么做到给智能体一个明确的测试基准（对照参考实现）、一份记录进度和失败尝试的长期记忆文件，以及循环执行直到达标的编排脚本，在集群上用 tmux 挂着 Claude Code 长时间运行。
评分依据：云端大模型驱动的科研编码智能体实践，与端侧无关。进度文件作为跨会话长期记忆、测试基准驱动迭代的做法对智能体记忆设计有参考意义，属经验分享，贡献中等偏低。
