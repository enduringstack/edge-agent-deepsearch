Alibaba Cloud ClawHub Skill Scan: Security Metrics Across 30,000 AI Agent Skills

10 官方动态 2026-03-27 · Qwen / Qwen
Qwen方向:安全隐私应用:安全方向:工具调用
这是什么阿里云安全团队扫描了 3 万多个 AI Agent 技能包（多数来自 OpenClaw 等框架使用的 ClawHub 平台），统计这类“AI 时代软件包”里藏着多少恶意或高危内容。
有什么结果共扫描去重后的 30,068 个技能（其中 26,353 个在 ClawHub 上架）；恶意投递和下载器占威胁样本 34.6%，凭证窃取 15.7%，提示词注入 11.8%；只用传统扫描会漏掉 84.6% 的语义层威胁，传统引擎与 AI 引擎检出交集仅 3.4%。
怎么做到把技能看作提示词、执行脚本和权限声明的混合体，归纳出 12 类攻击面，并用读懂 SKILL.md 自然语言意图的 AI 检测引擎与传统代码特征扫描互补。
评分依据：OpenClaw 这类个人 Agent 常在用户自己的电脑上执行技能，技能供应链安全直接关系到本地 Agent 能否放心使用；数据规模大、结论具体，但本身是安全扫描报告而非端侧技术。
