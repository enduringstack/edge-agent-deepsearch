NORmal: Architecting 3D Ferroelectric NOR Flash as Main Memory -- From Co-Fabricated BEOL Arrays to 200B-Class Multi-Agent LLMs in a Smartphone

16 学校预印本 2026-10-29 · Zhuoran Li; Chen Gu; Zhuohang Bian; Haochen Yu; Yibo Zhao; Xuxiao Yang; Zhaori Cong; Jinshan Yue / arXiv
方向:KV cache方向:MoE方向:能耗功耗硬件:手机
这是什么想在手机上跑由 200B 级规划模型带多个工作模型组成的智能体团队，内存远远不够；本文提出用 3D 铁电 NOR 闪存直接充当手机主存的一部分。
有什么结果在用真实智能体轨迹回放的服务级仿真中，比 UFS 卸载快 8.9–28.0 倍（智能体团队场景 21.4 倍），与无限 DRAM 理想情况只差 0.4%；在超过 256K token 的会话上比移动高带宽闪存快 2.8–6.3 倍，每 token 内存能耗低 8.1–17.8 倍。团队已流片实测铁电阵列感测时间低于 7.5 纳秒。
怎么做到把高密度 3 比特 MLC 与可原位快速写入的 SLC 铁电 NOR 阵列共同制造，通过阵列下方的 DRAM 仿真桥接成为不改 SoC 的 LPDDR6 第二个内存 rank；按数据是否可变与生命周期（而非冷热）放置权重和规划器上下文，并按智能体阶段动态划分子通道。
评分依据：直接面向手机端运行大模型智能体团队的内存墙问题，从器件流片到系统设计都有覆盖，创新度高；但智能体部分只在仿真中评测，不属于端侧 Agent 实机证据。作者来自北京大学、中科院微电子所和港科大（广州）。
