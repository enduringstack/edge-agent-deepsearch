SAW-INT4: System-Aware 4-Bit KV-Cache Quantization for Real-World LLM Serving

8 学校预印本 开源 2026-04-21 · Jinda Jia; Jisen Li; Zhongzhu Zhou; Jung Hwan Heo; Jue Wang; Tri Dao; Shuaiwen Leon Song; Ben Athiwaratkun / arXiv
方向:KV cache方向:量化方向:云端serving硬件:GPU
这是什么大模型服务里 KV cache 太占显存，但很多 KV 压缩方法和分页内存、融合注意力等真实系统约束冲突。这项工作找出在真实服务约束下仍然好用的 4 bit KV cache 量化方案。
有什么结果按 token 的 INT4 量化加分块对角 Hadamard 旋转，几乎找回朴素 INT4 损失的全部精度；融合的旋转加量化内核接入分页 KV cache 后端到端开销不可测，各并发等级下吞吐与普通 INT4 持平。向量量化、Hessian 感知等复杂方法只带来边际增益。
怎么做到先梳理服务系统对 KV 量化的约束（分页布局、规则访存、融合注意力），在约束内比较多种方案，再实现把旋转和量化融合在一起的 GPU 内核。
评分依据：面向云端服务的 KV cache 量化，结论对端侧 KV 压缩选型也有参考，但未涉及端侧设备。方法以系统化对比和工程实现为主。
