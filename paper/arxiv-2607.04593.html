TORINO: Token Reduction via Interpretable Concept Overlap in Vision-Language Models

9 学校预印本 2026-07-06 · Riccardo Renzulli; Gabriele Spadaro; Shruthi Gowda; Alaa Eddine Mazouz; Van-Tam Nguyen / arXiv
方向:多模态方向:剪枝稀疏方向:高效推理
这是什么TORINO 是一个即插即用的视觉 token 精简方法：先用稀疏自编码器给每个视觉 token 找出可解释的“概念”，再把概念重叠的 token 合并或剪掉。
有什么结果原文称在多个视觉语言基准上以很小的性能损失减少了视觉 token 数，摘要未给出具体数字。
怎么做到用稀疏自编码器把视觉 token 投影到可解释的潜空间，按激活概念的重叠程度分组，组内剪枝或合并；精简比例随图像复杂度自适应，不需要微调原模型。
评分依据：视觉 token 精简可直接降低端侧多模态推理成本，但未做设备端实测；用可解释概念做 token 分组有一定新意。
