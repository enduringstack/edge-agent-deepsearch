98$\times$ Faster LLM Routing Without a Dedicated GPU: Flash Attention, Prompt Compression, and Near-Streaming for the vLLM Semantic Router

7 公司项目 2026-03-13 · Xunzhuo Liu; Bowei He; Xue Liu; Andy Luo; Haichen Zhang; Huamin Chen / arXiv
AMD; Red Hat方向:云端serving方向:高效注意力硬件:GPU应用:长上下文推理
这是什么给 vLLM 语义路由器做的三步提速，让做安全分类、领域路由的路由器不必独占一块 GPU，能和大模型服务挤在同一张卡上。
有什么结果在 AMD Instinct MI300X 上，自研 Flash Attention 算子把端到端时延从 4918ms 降到 127ms（38.7 倍），提示压缩再降到 62ms，近流式处理再降到 50ms，累计提速 98 倍；16K token 路由 108ms，路由器总显存不到 800MB。
怎么做到一是给 ROCm 上的 ONNX Runtime 写 CK Flash Attention 算子，把注意力显存从平方级降到线性；二是用 TextRank、TF-IDF 等传统方法把输入压到约 512 token；三是分块近流式处理请求体并零拷贝解析 JSON。
评分依据：场景是数据中心大模型网关，属云端 serving；但在显存受限下共置小分类模型、免神经网络的提示压缩等做法可迁移。贡献主要是工程优化组合。 作者机构依据：arXiv PDF 首页署名 AMD, Red Hat（arXiv 首页作者署名：Andy Luo、Haichen Zhang 为 AMD，Huamin Chen 为 Red Hat）。
