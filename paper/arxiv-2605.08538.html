Human-Inspired Memory Architecture for LLM Agents

8 公司项目 2026-05-08 · Doga Kerestecioglu; Alexei Robsky; Clemens Vasters; Anshul Sharma; Yitzhak Kesselman / arXiv
Microsoft方向:记忆
这是什么智能体长期交互后记忆越堆越乱。本文借鉴人脑机制，给大模型智能体设计了一套包括睡眠期整合、干扰遗忘、检索时再巩固等 6 种机制的记忆架构。
有什么结果在 VSCode 议题追踪数据（1.3 万议题、12 万事件）上，去重整合保留精度 97.2%，存储减少 58%，比基线高 21.8 个百分点；在 LongMemEval 上 20 万 token 预算下准确率 70.1%，与原始检索 71.2% 相当。
怎么做到6 种机制各自针对一种记忆堆积失败模式，并用合成数据标定全部阈值，避免在评测集上调参造成泄露。
评分依据：属于 Agent 记忆管理，可为端侧 Agent 控制记忆体积提供参考，但无设备评测，相关度偏低；以机制组合为主。PDF 首页 5 位作者均署名 Microsoft。 作者机构依据：arXiv PDF 首页署名 Microsoft（PDF 首页 5 位作者均署名 Microsoft）。
