WindowQuant: Mixed-Precision KV Cache Quantization based on Window-Level Similarity for VLMs Inference Optimization

12 公司项目 2026-05-04 · Wei Tao; Xiaoyang Qu; Peiqiang Wang; Guokuan Li; Jiguang Wan; Kai Lu; Jianzong Wang / ACM TACO
Ping An方向:KV cache方向:量化方向:多模态应用:视频硬件:GPU
这是什么WindowQuant 针对视频语言模型视觉 token 太长导致 KV cache 占显存、拖慢推理的问题，按窗口而非按 token 做混合精度 KV cache 量化。
有什么结果相比 FP16 基线，GPU 显存占用降低约 15%，解码吞吐提升约 3 倍，精度优于现有 VLM KV cache 量化方法。
怎么做到先根据每个视觉 token 窗口与文本提示的相似度快速搜索各窗口的比特宽度，再在量化前按窗口重排 KV cache，避免混合精度带来的硬件低效。
评分依据：KV cache 量化是端侧多模态长上下文推理的关键技术，方法以硬件友好为目标、可迁移到端侧，但实验在 GPU 上进行。已被 ACM TACO 接收；PDF 首页显示第 2 作者和通讯作者署名平安科技（Ping An Technology），其余为华中科技大学和清华大学。 作者机构依据：arXiv PDF 首页署名 Ping An（PDF 首页作者 2 Xiaoyang Qu 与作者 7 Jianzong Wang 署名 Ping An Technology (Shenzhen) Co., Ltd.）。
