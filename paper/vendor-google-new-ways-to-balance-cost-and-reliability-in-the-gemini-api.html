New ways to balance cost and reliability in the Gemini API

4 官方动态 2026-04-02 · Google / Google
Google方向:云端serving方向:调度服务
这是什么Gemini API 新增 Flex 和 Priority 两档服务，让开发者在同一个同步接口里为后台任务和交互任务分别选择成本与可靠性。
有什么结果Flex 价格为标准档的 50%，以更高时延和更低可靠性换成本；Priority 溢价但优先级最高，超出额度的请求降级到标准档而不是失败。
怎么做到通过 service_tier 参数选择档位，响应头告知实际服务档位；后台智能体浏览、思考类任务可走 Flex，面向用户的请求走 Priority。
评分依据：云端推理服务的分级调度与计费，与端侧无关；可作为端云协同中云侧兜底的成本参考。
