IWP: Token Pruning as Implicit Weight Pruning in Large Vision Language Models

11 学校预印本 2026-04-01 · Dong-Jae Lee; Sunghyun Baek; Junmo Kim / arXiv
方向:剪枝稀疏方向:多模态方向:高效推理
这是什么视觉语言模型的视觉 token 太多导致计算量大，这项工作给出一种免训练的 token 剪枝方法，用注意力的“对偶形式”来挑出最值得保留的 token。
有什么结果在 LLaVA-OneVision-7B 等模型上，相比已有剪枝方法取得更好的性能与效率平衡；摘要未给出统一的加速倍数。
怎么做到把注意力看成一个隐式线性层，每个 token 贡献一个秩一权重更新；剪枝就变成挑一组更新去逼近原权重，并用同时衡量信息量和冗余度的指标分块逐步挑选。
评分依据：视觉 token 剪枝能直接降低多模态模型在端侧的计算量，属于可迁移技术，但没有设备端实测；从注意力对偶视角解释剪枝有一定新意。
