Memory Tax: Dissecting the Net Value of Agent Memory

9 学校预印本 开源 2026-10-25 · Xuan He; Sining Zhoubian; Ruozhen Yang; Yuhao Wen; Zhineng Wang; Yuyang Hu; Ke Yang; Yuyu Zhang / arXiv
方向:记忆方向:评测基准应用:RAG
这是什么很多智能体都在搭专门的记忆系统，但它们真比直接从原始历史里检索（朴素 RAG）更好吗？这项研究做了大规模对比，并提出“记忆税”来描述记忆加工丢失证据带来的损失。
有什么结果在多个基准和多种模型上，许多专门的记忆系统在不少情况下不如朴素 RAG，净收益为负；逐题对比显示记忆系统能解决一些 RAG 做不到的问题，但同时会丢掉 RAG 本已答对的问题。
怎么做到以朴素 RAG 为参照，把记忆系统的净价值拆成“记忆收益”和“记忆税”两部分，再从系统设计和评测方式两个角度分析记忆税从哪里产生。
评分依据：智能体记忆是端侧智能体的关键组件，这项评测对选择轻量方案（直接检索）有参考价值，但没有涉及设备或资源约束，相关度 4；属于评测与分析类贡献。作者来自 UIUC、清华等高校，另有一位来自小型公司 Verdent.ai，不计公司归属。
