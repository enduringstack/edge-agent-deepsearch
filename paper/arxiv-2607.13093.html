Efficient and Privacy Aware Edge Cloud Collaborative Inference for Large Language Models

14 学校预印本 2026-07-14 · Yi Li; Chen Li; Jiexiong Liu / arXiv
方向:端云协同方向:安全隐私方向:投机解码方向:KV cache方向:量化硬件:CPU
这是什么一套兼顾时延和隐私的端云协同大模型推理框架：终端只做轻量部分并持有关键模块，云端承担主要解码，用户提示不必明文上传。
有什么结果以 7B 级模型为目标，在 20 ms 往返时延的受控网络下，相比朴素切分推理，CPU 终端、GPU 终端和 8GB 嵌入式 ARM 终端的单 token 时延分别降低 29.4%、46.1% 和 26.8%；下行数据量最多减少 67.4%。
怎么做到终端负责输入预处理、嵌入计算、KV cache 认证、投机解码草稿和低维输出头，云端做经认证的解码与 token 校验；传输张量与截断 logits 先 8 bit 量化再 AES-GCM 加密，并按语言裁剪词表。不同终端分别用分块流式、模型切片或 ONNX Runtime 8 bit 执行。
评分依据：在纯 CPU 电脑、消费级显卡和嵌入式 ARM 设备上实测端云协同推理，端侧部署相关度高；把投机解码、KV cache 认证和加密传输组合进切分推理，属于有一定新意的工程整合。署名单位为 KunlunMeta，无法确认其公司属性，未标注公司归属。
