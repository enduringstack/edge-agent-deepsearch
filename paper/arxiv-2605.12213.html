Goal-Oriented Reasoning for RAG-based Memory in Conversational Agentic LLM Systems

10 学校预印本 2026-05-12 · Jiazhou Liang; Armin Toroghi; Yifan Simon Liu; Faeze Moradi Kalarde; Liam Gallagher; Scott Sanner / arXiv
方向:记忆方向:规划推理应用:RAG
这是什么对话 Agent 用外部记忆检索时，常常只按用户原话的语义相似度去找，漏掉推理所需的中间事实。Goal-Mem 把用户问题当目标倒推，逐个子目标去记忆里取证。
有什么结果在两个数据集上与九个强记忆基线比较，均稳定提升，在多跳推理和隐含推断类问题上提升最明显；摘要未给出具体数字。
怎么做到把目标拆成原子子目标，针对每个子目标定向检索记忆，解决不了时再判断还缺什么信息继续检索；整个过程用结合一阶逻辑可验证性与自然语言表达力的“自然语言逻辑”形式化。
评分依据：Agent 记忆检索方法，对端侧 Agent 的记忆模块可迁移，但未涉及设备部署或资源开销。
