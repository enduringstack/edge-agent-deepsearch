SPEM: Structure-Aware Procedural Memory for Efficient Skill Use in LLM Agents

9 学校预印本 2026-10-19 · Ran Zhou; Zehui Kong; Fanyu Lin; Jiaheng Liu; Zhen Zhang; Yuxiang Ren / arXiv
方向:记忆方向:工具调用方向:规划推理
这是什么智能体可用的技能越来越多，全部塞进上下文太贵，单纯按语义检索又不懂技能之间的先后依赖。SPEM 给智能体做了一套懂结构的“程序性记忆”。
有什么结果在 ALFWorld 上成功率 87.1%，在 SkillsBench 上奖励 38.38%，同时比强基线更省 token 和运行时间，取得最好的效果与效率折中。
怎么做到分两层记忆：单个技能的原子记忆，以及从成功执行中沉淀出的技能有向图模板；新任务优先复用高置信模板，否则用图神经网络按状态和结构挑技能，成功后再写回新模板。
评分依据：属于智能体记忆与技能调用运行时，减少 token 和运行开销对资源受限部署有借鉴意义，但实验未涉及端侧设备；结构化技能记忆的设计有一定新意。
