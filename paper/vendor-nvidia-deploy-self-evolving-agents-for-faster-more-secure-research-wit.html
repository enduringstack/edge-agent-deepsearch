Deploy Self-Evolving Agents for Faster, More Secure Research with a Hermes Agent and NVIDIA NemoClaw

8 官方动态 2026-06-02 · NVIDIA / NVIDIA
NVIDIA方向:安全隐私方向:工具调用方向:记忆
这是什么一个开源示例：让会自我改进的研究智能体在受控运行时里同时读内部数据和公开资料。
有什么结果该智能体跨 Outlook、Slack 和 GitHub 做产品调研，边用边学用户偏好并把学到的技能写成技能文件，通过快照与恢复脚本在多次部署之间保留，无需重新训练；运行时按策略文件只放行指定端点，未列出的目的地返回 403 并被当作工具错误处理；可观测性通过 NeMo Relay 和 Arize Phoenix 捕获轨迹。文中未给出效率提升数字。
怎么做到用 OpenShell 作为经过安全审核的运行时来管理凭据并限制网络访问，防止智能体在接触敏感内部数据时还能访问公网；技能以文本文件形式持久化，从而在不重训的前提下保留格式与行为。
评分依据：沙箱运行时与技能持久化的做法对本地智能体同样适用，但本文场景是企业内部研究而非端侧（相关性 3）。把安全边界、技能沉淀和可观测性串成一个可复制的开源示例，工程参考价值不错（贡献 5）。
