GRKV: Global Regression for Training-Free KV Cache Compression in Long-Context LLMs

11 学校预印本 开源 2026-05-29 · Junjie Peng; You Wu; Haoyi Wu; Jialong Han; Xiaohua Xie; Kewei Tu; Jianhuang Lai / arXiv
方向:KV cache方向:高效推理应用:长上下文推理
这是什么KV 缓存按连续片段保留时，被丢的信息总挤在少数边界 token 上，这套方法把它摊开。
有什么结果在 LongBench 和 RULER 长上下文基准上，它是唯一能以很小开销提升整体表现的合并方法。代码已开源。
怎么做到指出片段式保留配合驱逐后合并，会让合并集中到少数片段边界的承载 token 上，造成过度合并和信息损失；于是改用岭回归式的合并步骤直接最小化压缩缓存与完整缓存注意力输出之间的差异，把被驱逐 token 的信息分摊到所有保留 token 上，并对更新做正则以避免过度平滑。整套方法免训练。
评分依据：长上下文 KV 缓存压缩对端侧内存受限场景直接有用，且方法免训练（相关性 5）。指出片段保留与合并结合时的不均衡问题并给出闭式解法，针对性强（贡献 6）。
