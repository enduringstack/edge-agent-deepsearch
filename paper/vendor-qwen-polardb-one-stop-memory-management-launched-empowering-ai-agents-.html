PolarDB One-Stop Memory Management Launched: Empowering AI Agents with Persistent, Cross-Session Memory

6 官方动态 2026-05-11 · Qwen / Qwen
Qwen方向:记忆方向:KV cache应用:RAG
这是什么阿里云 PolarDB for PostgreSQL 推出一站式智能体记忆管理，把向量库和图库合在一起，让智能体跨会话、跨应用记住用户偏好、事实和历史交互。
有什么结果官方给出的数字：图加向量的混合记忆让记忆召回率提高 40%；库内模型算子使推理时延降低 30% 以上；同等记忆规模下检索效率提升 50% 以上；百亿级数据下 QPS 超过 1 万、时延低于 50 毫秒；结合会话内 KV Cache 加速，在 20 万上下文、30 并发下请求时延降低 88.3%。
怎么做到在数据库内集成兼容 Mem0/Mem0g 的记忆引擎、向量与图数据库和模型算子，形成“记忆读写、上下文注入、模型推理、结果反馈”的闭环，免去分别维护多套数据库的一致性问题。
评分依据：讨论的是智能体长期记忆，但完全运行在云数据库上，与端侧部署无直接关系；性能数字来自官方介绍，未说明对比基线细节，属于云产品功能整合。
