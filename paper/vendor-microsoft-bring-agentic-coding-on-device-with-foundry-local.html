Bring Agentic Coding On-Device with Foundry Local

14 官方动态 2026-11-05 · Microsoft / Microsoft
Microsoft方向:端侧agent方向:投机解码方向:量化方向:KV cache应用:代码硬件:GPU硬件:DGX模型:Qwen
这是什么微软用 Foundry Local 在自己电脑上本地运行 Qwen3.8-27B，并通过“自带密钥”接入 GitHub Copilot 应用，让编程智能体在不上云的情况下读代码、改代码、调用工具，也能离线工作。
有什么结果4 比特模型约 18 GB，24 GB 显存的消费级显卡可用 64K 上下文，32 GB 以上可用满 262K；在 RTX 5090 和 DGX Spark 上用真实 GitHub issue 数据对比 llama.cpp，各提示长度下生成速度都更快，超过 13.1 万 token 后差距进一步拉大。
怎么做到基于 ONNX Runtime，叠加 DFlash2 投机解码（轻量草稿模型一次预测多个 token）、针对 SM121 调优的 CUDA 图融合与内核、INT4 权重、KV cache 量化、嵌入内存共享与 CPU 卸载，再配合前缀缓存和连续批处理。
评分依据：模型推理和编程智能体的读码、改码、执行工具循环都在开发者本机上完成，与 Android Studio 经本地模型跑智能体模式的判例一致，属于 PC 端侧智能体；技术上是投机解码、量化和内核优化的工程整合，速度对比只以图表给出。
