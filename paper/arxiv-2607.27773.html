ChronoMem: Version Control and Semantic Rollback for Large Language Model Agent Memory

9 学校预印本 2026-07-30 · Yongye Su; Wujiang Xu; Chaoji Zuo; Elisa Bertino / arXiv
方向:记忆方向:评测基准
这是什么现有智能体记忆只会往前累积、合并和覆盖，没法查看历史版本，更没法“撤销”。ChronoMem 给智能体记忆加上版本控制，并支持用自然语言要求回滚到某个过去状态。
有什么结果LoCoMo 上版本选择 Recall@1 从 12.0% 提到 20.5%、Recall@5 从 28.1% 提到 38.9%；MAB 上 Recall@1 从 24.3% 提到 39.4%、Recall@5 从 53.8% 提到 65.2%；回滚后的问答和摘要在三种底座模型上都优于仅提示和仅检索的基线（如 Llama-3.1-8B 上 ROUGE-1 为 0.25 对 0.21）。
怎么做到在 Google 的 Agent Development Kit 中实现：每次记忆写入都提交一次整体快照并维护版本历史；收到“撤销”类自然语言请求时，用词法加语义的混合检索、排序融合和重排把它映射到具体历史版本，再确定性地恢复该版本，并配了一套回滚后行为评测协议。
评分依据：属于智能体记忆运行时的能力扩展，对设备上长期使用的个人助理有参考价值，但不涉及端侧资源约束，相关度 4。把版本控制和语义回滚系统化地引入智能体记忆并配评测协议，贡献 5。
