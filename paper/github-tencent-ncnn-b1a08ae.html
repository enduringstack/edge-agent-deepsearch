Tencent/ncnn: packed shape hint for vulkan layers (#6553)

9 开源大项目 开源 2026-02-26 · Tencent / GitHub
方向:推理框架方向:编译部署硬件:GPU硬件:手机
这是什么腾讯 ncnn 移动端推理框架给 Vulkan GPU 后端的大量算子层加上“打包形状提示”，统一处理数据打包布局下的张量形状。
有什么结果未报告
怎么做到在卷积、矩阵乘、激活、归一化等 50 多个 Vulkan 算子实现里引入打包形状提示，替换原先各层分散的形状推断代码，整体删掉的代码比新增的多约 900 行。
评分依据：ncnn 是手机端常用推理框架，这次改动涉及移动 GPU 的 Vulkan 后端，属于端侧推理栈；但属于内部代码整理（56 个文件，净删约 900 行），提交没有给出任何性能数据，因此效果写未报告。
