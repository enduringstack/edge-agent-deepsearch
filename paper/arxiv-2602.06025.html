Learning Query-Aware Budget-Tier Routing for Runtime Agent Memory

12 学校顶会 开源 2026-02-05 · Haozhen Zhang; Haodong Yue; Tao Feng; Quanyu Long; Jianzhu Bao; Bowen Jin; Weizhi Zhang; Xiao Li / ICML 2026
方向:记忆方向:高效推理应用:长上下文推理模型:Llama模型:Qwen
这是什么大模型 Agent 的记忆系统要么离线建好不看问题，要么运行时现建但开销大且难控。BudgetMem 让 Agent 在运行时按问题挑选每个记忆模块用“低/中/高”哪一档预算，显式权衡效果和成本。
有什么结果在 LoCoMo、LongMemEval、HotpotQA 上，效果优先时超过强基线（如 LongMemEval 上 LLaMA-3.3-70B 的评审分 60.50，最强基线 LightMem 为 48.51）；HotpotQA 上用 Qwen3-Next-80B-A3B 以 0.22 的成本拿到最佳评审分 72.08，另一变体以 0.17 的成本得到 70.83；预算收紧时准确率-成本前沿更优。
怎么做到把记忆处理拆成多个模块，每个模块提供三档预算实现；一个用强化学习训练的小型路由策略按查询决定各模块用哪一档，并比较了按方法复杂度、推理方式、模块模型大小三种分档方式。
评分依据：“按预算动态选记忆处理档位”正是端侧 Agent 在算力和电量受限时需要的能力，可直接迁移；但实验仍用云端大模型，未在设备上验证。已被 ICML 2026 接收，代码开源。
