Team Edition OpenClaw: HiClaw Open Source, Build a One-Person Company in 5 Minutes

14 官方动态 开源 2026-03-05 · Qwen / Qwen
Qwen方向:端侧agent方向:记忆方向:工具调用方向:安全隐私方向:端云协同
这是什么阿里云开源 HiClaw，相当于 OpenClaw 的团队版：在自己电脑上用 Docker 一键部署一个由“管理者智能体 + 多个工作者智能体”组成的私有协作平台，解决凭证泄露、记忆膨胀和多智能体手动协调的问题。
有什么结果原文给出的成本示例：同一项目全用 Sonnet 需 3.45 美元，按任务分配便宜模型后为 0.70 美元，节省约 80%（文中称可省 60% 到 80%）。未给出任务成功率等指标。
怎么做到管理者智能体负责拆任务、分派和心跳监督，工作者各自在隔离容器里拥有独立技能和记忆；真实 API 密钥集中放在本地 AI 网关，工作者只拿调用令牌；协作通过本地 Matrix 群聊进行，大文件走本地 MinIO 共享存储以控制上下文长度，手机端可用 Matrix 客户端查看和干预。
评分依据：多智能体的编排、记忆、凭证管理和任务执行都在用户本地电脑的容器里完成，只有大模型推理调用云端，符合 PC 端侧 Agent 判例。管理者加工作者的分工与凭证隔离设计实用，但整体是开源组件的工程组合。
