Port x64 Windows projects to Windows on Snapdragon using agentic AI

9 官方动态 开源 2026-10-20 · Qualcomm / Qualcomm
Qualcomm方向:工具调用应用:代码硬件:Snapdragon硬件:CPU
这是什么高通开源 WoS Porter，一个以 Copilot 扩展、Claude Code 插件和 Codex 插件形式提供的移植智能体，帮开发者把 x64 Windows 项目迁移到骁龙 Windows 电脑原生运行。
有什么结果官方测算移植工作量：简单库省 90%~100%、中等项目省 60%~70%、复杂项目省 40%~50%；NEON 优化后 CRC32C 从 4.45 GB/s 提到 23.12 GB/s（5.2 倍），Crypto++ SM4 提升 2.5 倍，OpenCV 旋转提升 2.67 倍。
怎么做到智能体按 8 步流程工作：分析代码中的 x64 专用指令、迁移构建系统、把 SSE/AVX 指令改写为 NEON、用 MSVC 编译并迭代修错、校验二进制架构、在骁龙硬件上测试、做 NEON 热点优化，最后生成报告和提交记录。
评分依据：服务骁龙 PC 生态的开发者工具，但智能体依托 Copilot、Claude Code、Codex 等默认调用云端模型的编码工具，按判例不算端侧智能体（相关度 4）；把移植流程完整产品化并给出实测收益（5）。
