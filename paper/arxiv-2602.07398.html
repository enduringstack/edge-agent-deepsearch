AgentSys: Secure and Dynamic LLM Agents Through Explicit Hierarchical Memory Management

10 学校预印本 开源 2026-02-07 · Ruoyao Wen; Hao Li; Chaowei Xiao; Ning Zhang / arXiv
方向:安全隐私方向:记忆方向:工具调用
这是什么间接提示注入会把恶意指令藏进工具返回内容里，长期留在 Agent 的上下文记忆中。AgentSys 借鉴操作系统的进程内存隔离，从源头减少这类内容进入负责决策的顶层 Agent 记忆。
有什么结果仅隔离一项就把攻击成功率降到 2.19%；在 AgentDojo 和 ASB 上攻击成功率分别为 0.78% 和 4.25%，同时正常任务效用略高于无防御基线。
怎么做到顶层 Agent 为每次工具调用派生独立上下文的工作 Agent，外部数据和子任务轨迹不进入顶层记忆，只有经过模式校验的 JSON 返回值能跨边界传递，再辅以事件触发的校验器。
评分依据：属于 Agent 运行时的记忆管理与安全机制，对端侧 Agent 的安全设计有参考价值，但与设备部署无关；用分层记忆隔离防注入的思路新颖且效果明显。
