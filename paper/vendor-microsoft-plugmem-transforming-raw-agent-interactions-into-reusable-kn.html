PlugMem: Transforming raw agent interactions into reusable knowledge

13 官方动态 开源 2026-03-10 · Microsoft / Microsoft
Microsoft方向:记忆应用:RAG
这是什么微软研究院提出 PlugMem：一个可插到任意大模型 Agent 上的通用记忆模块，把杂乱的交互历史整理成可复用的知识，而不是原样检索旧文本。
有什么结果在长对话问答、跨维基多跳事实查找、网页决策三类基准上都优于通用检索和专用记忆方法，同时占用更少的记忆 token；博文未给出具体数值。
怎么做到把对话、文档和网页记录抽取成“事实”和“可复用技能”两类知识单元组成记忆图，按任务意图检索，再提炼成简短指导放进上下文。
评分依据：更省上下文的 Agent 记忆对内存和算力受限的端侧 Agent 有直接迁移价值，但原文未涉及设备部署；把记忆单元从文本块换成事实与技能的思路有新意，代码已开源。
