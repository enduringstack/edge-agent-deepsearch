Reimagining LLM Memory: Using Context as Training Data Unlocks Models That Learn at Test-Time

14 官方动态 开源 2026-01-09 · NVIDIA / NVIDIA
NVIDIA方向:记忆方向:测试时自适应方向:高效注意力应用:长上下文推理硬件:H100
这是什么NVIDIA 介绍 TTT-E2E：让大模型在读上下文时顺手用“预测下一个词”的方式把内容训练进自己的权重，从而像 RNN 一样，不管上下文多长推理时延都基本不变。
有什么结果在 H100 上，3B 模型于 128K 上下文比全注意力快 2.7 倍、2M 上下文快 35 倍，且长上下文下损失仍优于全注意力；代价是目前元学习实现在 8K 上下文下比常规预训练慢 3.4 倍。
怎么做到推理时对读到的上下文做下一词预测训练、直接更新权重；训练阶段用元学习让初始权重适合这种测试时更新，内外两层目标端到端联合优化。
评分依据：用权重代替不断膨胀的 KV cache 存长上下文、时延恒定，对内存吃紧的端侧长上下文推理和 Agent 记忆很有迁移价值，但实验只在 H100 上；把测试时训练做成端到端可扩展方案，新意较高，论文与代码均已公开。
