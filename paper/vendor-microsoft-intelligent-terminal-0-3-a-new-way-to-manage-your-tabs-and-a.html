Intelligent Terminal 0.3: A new way to manage your tabs and agents

5 官方动态 2026-11-04 · Microsoft / Microsoft
Microsoft方向:调度服务应用:代码
这是什么微软 Intelligent Terminal 0.3 加入竖向侧边栏，把终端标签页和各类编程智能体命令行会话放在一起管理，能看到智能体是在工作、等待输入还是请求运行工具。
有什么结果未报告
怎么做到自动检测已安装的智能体命令行工具（如 GitHub Copilot CLI、Claude）并加入新建标签菜单，支持全局搜索历史智能体会话、只看智能体的筛选，以及关闭窗口后继续在后台运行的无界面模式。
评分依据：这是 Windows 电脑上管理智能体会话的终端工具，本身不运行本地模型，所管理的编程智能体默认调用云端模型，按判例不算端侧 Agent；属于交互体验更新。
