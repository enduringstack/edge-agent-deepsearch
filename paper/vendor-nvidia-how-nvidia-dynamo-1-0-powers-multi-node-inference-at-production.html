How NVIDIA Dynamo 1.0 Powers Multi-Node Inference at Production Scale

7 官方动态 开源 2026-03-16 · NVIDIA / NVIDIA
NVIDIA方向:云端serving方向:KV cache方向:调度服务方向:MoE硬件:GPU模型:DeepSeek
这是什么英伟达分布式推理框架 Dynamo 1.0 正式可用，用于在多台 GPU 服务器上部署大模型和推理型模型，支持 SGLang、TensorRT LLM 和 vLLM 作为后端。
有什么结果在 SemiAnalysis InferenceX 测试（DeepSeek R1-0528，FP4，1k/1k）中，配合 GB200 NVL72 的大规模专家并行，服务请求数最高提升 7 倍；面向智能体的前端和 KV 感知路由在 Hopper 上把首 token 时延降低最多 4 倍、吞吐提高 1.5 倍；大型 MoE 模型启动最高快 7 倍。
怎么做到把预填充和解码拆到不同节点，用 KV 感知路由和 KV cache 管理器复用上下文，并通过 NIXL 与 NVLink 流式加载权重加快冷启动。
评分依据：这是数据中心多节点 serving 框架，与端侧设备无直接关系；分离式服务和 KV 感知路由有一定工程价值，但整体属于既有思路的产品化。
