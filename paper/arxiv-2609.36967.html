Beyond Token Importance: Preserving Spatial Scaffolds for Efficient Vision-Language-Action Inference

12 学校预印本 2026-09-29 · Jiayu Chen; Shuyong Gao; Jingkai Jia; Xiaosheng Bu; Jiyuan Fu; Lingyi Hong; Kaixun Jiang; Yipan Xu / arXiv
方向:剪枝稀疏应用:机器人方向:多模态方向:高效推理
这是什么给机器人视觉语言动作模型剪视觉 token 时，大家都按语义相关性挑，却忽略了操作本身需要的空间信息。
有什么结果作者构造了一个纯几何的均匀采样基线，发现它在某些剪枝比例下竟然优于语义剪枝和随机剪枝，但 token 预算稍微再降一点就会崩；进一步用「空间覆盖半径」——剪枝后保留 token 集合造成的最大空间盲区——刻画这一现象，发现保留 token 的空间结构与任务成功率强相关。
怎么做到免训练的视觉 token 剪枝方法：把每张图划分成若干空间区域，用任务相关性权重在区域之间分配 token 预算，再在每个区域内部挑选起支撑作用的「脚手架」token，从而既保住任务相关内容又不留下空间盲区。
评分依据：视觉 token 剪枝直接决定机器人模型能否在本体算力上跑起来，免训练也便于落地，但论文没有给出设备端时延数字。先用一个「本不该赢」的几何基线反证出被忽略的空间因素，再定义空间覆盖半径把它量化，诊断过程很有说服力。
