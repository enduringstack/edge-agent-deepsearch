TRIAGE: Reliability- and Load-Conditioned Escalation for Two-Tier LLM Serving with a Semantic Evidence Judge

5 学校预印本 2026-10-31 · Basavaraj R M; Aryan Bharat Kumar / arXiv
方向:云端serving方向:调度服务应用:RAG模型:Qwen
这是什么小模型答不好时升级给大模型的“两级服务”，常见路由只看提示词、也不管 GPU 负载。TRIAGE 尝试按生成后的可靠性和随负载变化的 GPU 成本来决定是否升级，并如实报告了哪些假设没成立。
有什么结果在单张 A40 上用 vLLM 跑 Qwen2.5-7B/32B：升级成本从 1 到 10 请求/秒涨了 21.9 倍；预注册的可靠性检测假设失败（AUROC 0.571）；事后加入语义证据评判后检测升到 0.846，GPT-3.5→GPT-4 级联在差距约 3 个百分点内省下 79.5% API 成本，但开源模型对上反而不如随机路由。
怎么做到在小模型生成后计算可靠性状态，并把 GPU 负载折算为升级价格；再用一个语义证据评判器判断检索证据是否支撑答案，据此决定是否升级到大模型。
评分依据：云端两级 LLM 服务路由的技术报告，与端侧关系弱（相关度 2）；包含较多负结果，方法增量有限（贡献 3）。两位作者为独立研究者。
