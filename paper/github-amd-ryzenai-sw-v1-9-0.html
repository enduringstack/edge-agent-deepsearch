RAI 1.9.0 Release

15 开源大项目 开源 2026-10-31 · amd / GitHub
方向:推理框架模型:Gemma硬件:NPU
这是什么AMD 锐龙 AI PC 的 NPU 推理工具链 Ryzen AI Software 发布 1.9.0 正式版：NPU 上的大模型不再受此前 4K/16K 上下文长度上限，新增 Gemma-4-E2B/E4B（文本）与 Hy-MT2-1.8B 的优化支持，Qwen 小模型支持动态 LoRA。
有什么结果发布说明没有给出速度或能效数字；Phi-4-14B、Qwen3.5-9B、Granite-4.1-8B、Gemma-4-12B 标注为“仅功能可用、性能未优化”。
怎么做到在 NPU 执行路径上扩展大模型上下文长度；为 Gemma-4-E2B/E4B、Hy-MT2-1.8B 提供优化部署，为 Qwen2.5-3B、Qwen3-4B、Qwen3.5-4B 提供运行时动态加载 LoRA 适配器；CNN/Transformer 部分为缺陷修复。
评分依据：AMD 官方 PC NPU 推理栈，直接决定锐龙 AI PC 上本地大模型能跑多长上下文、支持哪些端侧模型；去掉 4K/16K 上限对本地长上下文和智能体场景是实质改进，但发布说明没有性能数字。amd/RyzenAI-SW 于 2026-10-31 经用户同意加入开源大项目白名单后补收。
