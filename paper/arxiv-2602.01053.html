LRAgent: Efficient KV Cache Sharing for Multi-LoRA LLM Agents

13 学校预印本 开源 2026-02-01 · Hyesung Jeon; Hyeongju Ha; Jae-Joon Kim / arXiv
方向:KV cache方向:记忆方向:高效推理
这是什么多个智能体共用同一个基座模型、只是挂不同 LoRA 适配器时，各自还会重复存一份 KV 缓存。LRAgent 让它们共享缓存，省内存也省重复计算。
有什么结果在多个智能体问答基准上，吞吐量和首 token 时延接近完全共享缓存的水平，准确率接近不共享缓存的基线。
怎么做到把 KV 缓存拆成基座部分和适配器部分：基座部分在智能体之间共享，适配器部分以低秩形式保存；配合共享 A 矩阵的多 LoRA 结构和专门的 Flash-LoRA-Attention 内核，避免把低秩缓存展开成全尺寸。
评分依据：多智能体共享模型时的 KV 缓存开销在内存紧张的设备上更突出，方法可迁移到端侧多 Agent 运行时，但论文没做设备实测；按基座和适配器拆分缓存的观察有新意，代码已开源。
