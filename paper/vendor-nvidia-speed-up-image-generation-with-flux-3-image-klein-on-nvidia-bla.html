Speed Up Image Generation with FLUX 3 Image Klein on NVIDIA Blackwell GPUs

6 官方动态 2026-11-06 · NVIDIA / NVIDIA
NVIDIA方向:量化方向:稀疏注意力方向:云端serving方向:多模态硬件:GPU
这是什么英伟达教程：在 TensorRT LLM 的 VisualGen 运行时里配置 Black Forest Labs 的 FLUX 3 Image Klein 图像生成与编辑模型，用融合算子、NVFP4 低精度、量化与稀疏注意力、步间缓存和多卡并行加速生成。
有什么结果在单张 B200 上生成 2048×2048 图像，各项优化叠加后 Base 模型文生图比未编译的 BF16 快 3.46 倍、图生图快 4.45 倍；NVFP4 单项比 BF16 快约 1.6 倍，Cache-DiT 步间缓存让 Base 文生图提速约 1.9 倍；8 卡 DGX B200 把 Base 文生图中位时延从 14.90 秒降到 3.00 秒。
怎么做到以 NVFP4 预量化检查点为起点，换用针对 FLUX 3 张量形状调优的 FP8/NVFP4 矩阵乘内核，再叠加 FP8 量化注意力或 Sol 稀疏注意力、跨去噪步复用中间结果，并用 CFG 分组和 Ulysses 序列并行扩展到多卡。
评分依据：面向数据中心 Blackwell GPU 的扩散模型服务优化，与端侧设备无直接关系，相关度低；低比特量化、稀疏注意力和步间缓存的组合与实测数据对做端侧图像生成有一定借鉴价值，但属于工程整合。
