AMV-L: Lifecycle-Managed Agent Memory for Tail-Latency Control in Long-Running LLM Systems

11 学校预印本 2026-02-22 · Emmanuel Bamidele / arXiv
方向:记忆方向:调度服务方向:云端serving
这是什么长期运行的大模型智能体记忆越攒越多，检索候选集膨胀会拖出严重的长尾延迟。AMV-L 把智能体记忆当成系统资源来管理，按价值分层并限制每次检索的范围。
有什么结果相比按存活时间淘汰（TTL），吞吐提升 3.1 倍，中位/p95/p99 延迟分别降低 4.2/4.7/4.4 倍，超过 2 秒的请求比例从 13.8% 降到 0.007%；相比 LRU，p99 再降 15%，每请求 token 少约 6%。
怎么做到给每条记忆维护持续更新的效用分，按分数晋升、降级和淘汰到不同层级；检索只在有上限的分层候选集中进行，使请求路径的工作集与总记忆量脱钩。
评分依据：智能体记忆运行时的工程优化，在服务器全栈系统上评测，思路可迁移到内存受限的端侧智能体（相关度 5）。用价值驱动的生命周期管理控制长尾延迟有新意（贡献 6）。
