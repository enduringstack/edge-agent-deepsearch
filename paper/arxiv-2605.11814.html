MedMemoryBench: Benchmarking Agent Memory in Personalized Healthcare

8 公司项目 开源 2026-05-12 · Yihao Wang; Haoran Xu; Renjie Gu; Yixuan Ye; Xinyi Chen; Xinyu Mu; Yuan Gao; Chunxiao Guo / arXiv
Ant Group; Alibaba方向:记忆方向:评测基准
这是什么医疗健康 Agent 需要长期、精准地记住用户的健康信息，现有记忆基准多是日常闲聊。MedMemoryBench 是面向个性化医疗场景的 Agent 记忆评测集。
有什么结果构建了约 2000 个会话、16000 轮交互的专家校验数据集；评测发现主流记忆架构在复杂医学推理和抗噪方面存在明显瓶颈，并出现“记忆饱和”导致检索与推理退化的现象。
怎么做到以临床依据构造的合成患者画像为基础，人机协作生成长周期医疗对话轨迹，并采用“边构建边评测”的流式协议，模拟线上记忆不断累积的过程。
评分依据：Agent 记忆评测基准，场景是云端服务的健康管理 Agent，与端侧部署关系较远。PDF 首页作者署名 Ant Group 与 Alibaba Group。 作者机构依据：arXiv PDF 首页署名 Ant Group, Alibaba（PDF 首页作者 Renjie Gu、Chunxiao Guo、Peng Wei、Jinjie Gu 等署名 Ant Group，作者 Yixuan Ye 署名 Alibaba Group）。
