DeepSeek-V4.1-Flash: Pushing the Limits of KV Cache Compression

14 公司项目 2026-09-17 · DeepSeek-AI; :; Anyi Xu; B. Li; Bangcai Lin; Bing Xue; BingCheng Xian; Bingzheng Xu / arXiv
DeepSeek方向:KV cache方向:MoE方向:量化方向:模型架构应用:长上下文推理模型:DeepSeek
这是什么DeepSeek 发布 V4.1-Flash，一个 5520 亿参数主干、支持百万 token 上下文的多模态混合专家模型，重点是把 KV cache 压到极限。
有什么结果常驻显存的全局 KV cache 降到每 token 890 字节，约为上一代 DeepSeek-V4-Flash 的四分之一；解码时每 token 激活 160 亿参数，预填时只激活 80 亿。
怎么做到因果编码器—解码器架构让预填和解码的激活量解耦；KV 压缩上把跨层 KV 复用（压缩稀疏注意力 CSA2）和 FP4 KV 缓存结合，再用名为 SWA Bounded Replay 的部署优化进一步压常驻缓存。
评分依据：每 token 890 字节的 KV 占用是目前公开模型里非常激进的数字，虽然这是云端大模型，但预填/解码激活解耦和 FP4 KV 的做法对端侧长上下文有直接迁移价值。作者署名首位为 DeepSeek-AI，机构证据取自 arXiv 论文 PDF 的作者署名。
