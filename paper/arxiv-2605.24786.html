CONF-KV: Confidence-Aware KV Cache Eviction with Mixed-Precision Storage for Long-Horizon LLM

12 学校预印本 2026-05-29 · Yubo Li, Yidi Miao / HuggingFace Daily
方向:KV cache方向:量化方向:高效推理应用:长上下文推理
这是什么按模型当前「有多确定」来决定这一步该留多少 KV 缓存：没把握就多留，有把握就狠删。
有什么结果在四个模型家族、生成长度最长 4K 的设置下，占用接近固定 512 token 滑动窗口，而困惑度与完整 KV 相差仅 1.5 到 2.1；在最长 32K 的大海捞针任务上检索准确率 91.4%，滑动窗口为 53.8%、H2O 为 80.6%；在 75 个 VisualWebArena 任务上以 2.8 倍更低的峰值显存保住完整 KV 成功率的 95.3%。
怎么做到把下一个 token 的分布转成一个标量置信度，用它决定每一步的缓存预算；预算内按累计注意力质量和新近度的综合分排序，并保留一个受保护的最近窗口维持局部连贯。再配分块在线 softmax 注意力、FP16 与 INT8 混合存储和逐层金字塔预算变体。
评分依据：峰值显存降低 2.8 倍对端侧长程推理意义直接，混合精度存储也便于端侧落地（相关性 6）。用每步都已算出的置信度当信号是个现成却被忽略的杠杆，配套实现也完整（贡献 6）。
