KAIROS: Stateful, Context-Aware Power-Efficient Agentic Inference Serving

10 学校预印本 2026-04-17 · Yichao Yuan; Mosharaf Chowdhury; Nishil Talati / arXiv
方向:云端serving方向:能耗功耗方向:调度服务硬件:H100
这是什么Agent 类请求的上下文会随着工具调用不断变长，传统针对单轮对话的 GPU 降频省电策略会让系统陷入显存抖动。KAIROS 是专为 Agent 服务设计的功耗管理系统。
有什么结果在 H100 GPU 上用 vLLM 跑 SWE-bench Verified、DABStep、Terminal-Bench 2.0 等 Agent 任务，满足性能目标的同时平均省电 27%，最高 39.8%。
怎么做到以 Agent 为粒度追踪请求，把上下文增长和 Agent 进度作为控制信号，联合调节 GPU 频率、单实例并发度和跨实例请求放置，在显存有余量时降频省电、避免抖动。
评分依据：面向云端 GPU 的 Agent 推理服务，与端侧部署关系较远；把“Agent 上下文”作为功耗控制信号是新的视角，对理解 Agent 负载特性有启发。
