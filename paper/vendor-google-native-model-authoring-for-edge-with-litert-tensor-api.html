Native Model Authoring for Edge with LiteRT Tensor API

16 官方动态 开源 2026-10-19 · Google / Google
Google方向:推理框架方向:编译部署硬件:GPU硬件:NPU硬件:手机硬件:Apple-Silicon模型:Gemma
这是什么谷歌发布 LiteRT Tensor API：开发者可以像用 MLX 一样用 C++ 逐个算子手写模型，但同一份代码能在 CPU、GPU、NPU 和网页 WebGPU 上跑，不用为每种硬件重写。
有什么结果同一份 SAM 2 C++ 代码在 MacBook Pro 上比 Apple MLX 快约 1.5 倍（fp16，编码器加解码器）；编码代理把 WebGPU 上 512×512 的 SAM 2 从不到 10 帧优化到超过 30 帧，输出掩码与 PyTorch 参考逐像素一致。
怎么做到直接从 safetensors 加载权重构建计算图，可导出 .tflite 交给 LiteRT 在 CPU/GPU/NPU 上运行，或经 XNNPACK 直接在 CPU 上跑；前后处理也用同一套 API 编写，经共享加速器缓冲区零拷贝串联。
评分依据：这是谷歌端侧推理栈的新编程层，直接面向手机、电脑和浏览器部署，并在 macOS、iOS、安卓三类设备上实测；把手写模型的灵活性和跨硬件可移植性结合起来，还适合让编码代理自动调优，创新度较高。
