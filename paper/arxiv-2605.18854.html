Evaluating Memory Condensation Strategies for Coding Agents in Data-Driven Scientific Discovery

7 学校预印本 2026-05-13 · Renuka Chintalapati; Sid Raskar; Anurag Acharya; Jared Willard; Patrick Emami; Sameera Horawalavithana / arXiv
方向:记忆方向:评测基准应用:代码
这是什么编码 Agent 长时间运行会把上下文窗口塞满，只能截断或失败。这篇系统比较了八种记忆压缩策略在科学数据发现任务上的效果。
有什么结果用 GPT-4o 在 60 个 DiscoveryBench 任务上共 480 次评测：没有哪种压缩策略显著改变假设质量；基于大模型摘要的压缩反而让 token 成本上升 24%-94%，而屏蔽工具调用输出能净省 8.6%。最优策略随学科领域和任务长度而变。
怎么做到把滑动窗口、大模型生成摘要、屏蔽工具输出等八种上下文压缩方式放在同一套科学发现任务里对比质量和 token 成本。
评分依据：Agent 记忆压缩直接关系到上下文受限时的运行成本，结论对端侧 Agent 的上下文管理有参考价值，但实验完全基于云端 GPT-4o。属于对比评测，没有新方法。
