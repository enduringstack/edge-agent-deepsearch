这是什么苹果 MLX 机器学习框架发布 0.30.6 小版本，重点是让 macOS 26.3 及以上多台 Mac 互联跑大模型时的 JACCL 通信带宽大幅提高，并修复若干内核问题。
有什么结果发布说明链接的实测（4 台 M3 Ultra、2048 token 提示、生成 128 token）：Devstral2 123B（4bit）预填充从 135 提到 303 token/s（+124%），GLM 4.7 358B（6bit）从 309 提到 719 token/s（+133%）；逐 token 生成只提升 1%–7%。批大小 8 时 MoE 模型 4 机加速比从 1.6 倍升到 2.6 倍。
怎么做到JACCL 改用大缓冲区修正带宽，并新增可连接任意多台 Mac 的环形拓扑；同时修复 M2 以下芯片两段式注意力、小 N 量化矩阵向量乘、WSL 统一内存等问题。
评分依据：MLX 是在 Apple Silicon 上本地跑模型的主流框架，本版把多台 Mac 组成的本地集群跑百亿到千亿级模型的预填充速度提高一倍以上，对本地大模型部署有参考价值，但不是单设备端侧场景。改动以通信实现优化和缺陷修复为主。
