GraMRAG: Orchestrating Multi-Agent Multi-Step Reasoning via Graph Memory with Reinforcement Learning

8 学校预印本 2026-09-12 · Zhongyu Wang / arXiv
方向:记忆应用:RAG方向:多模态方向:规划推理
这是什么给多智能体检索增强系统加一张动态的多模态记忆图，把推理过程显式建成有向无环图来减少重复检索。
有什么结果在多个多模态基准上稳定优于已有方法，在复杂长链推理任务上达到最好水平；摘要未给出具体分数。
怎么做到用视觉文本桥接的推理范式把多尺度实体裁剪和 ReAct 式视觉工具链结合；再把智能体推理形式化成动态有向无环图显式建模动作与观察的依赖；最后用拓扑感知的策略优化按图结构找关键路径并做定点剪枝，实现细粒度的信用分配。
评分依据：图记忆和冗余检索抑制对端侧受限算力有迁移价值，但论文完全面向云端多模态推理（相关性 3）。方法组合较多但单点创新一般（贡献 5）。
