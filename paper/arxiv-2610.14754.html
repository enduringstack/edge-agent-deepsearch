GateSight: Recurrent Memory Anticipates Attention Memory for Query-Agnostic KV Eviction in Hybrid LLMs

12 学校预印本 开源 2026-10-10 · Junjie Li; Jiong Lou; Jie Li / arXiv
方向:KV cache方向:模型架构应用:长上下文推理模型:Qwen
这是什么混合架构大模型（线性递归层 + 全注意力层）里，KV cache 随上下文增长成为显存大头。GateSight 发现递归层在预填充阶段输出的门控信号，就能提前预测哪些 KV 条目以后有用，从而在还不知道问题时就裁掉无用缓存。
有什么结果在 Qwen3.8-27B 与 Qwen3.8-Flash-Next 上、最长 262K token 的 SCBench 和 RULER-4096 测试中，只保留十分之一注意力 KV cache 时，在 4 组模型-基准中有 3 组是五种与问题无关的裁剪方法里最准的，并在全部 4 组上领先 KVzip 9.5 到 47.2 分；打分开销相对预填充可忽略。
怎么做到用每个注意力头一个的小型多层感知机读取递归层的写门、衰减和写入幅度，预测每条 KV 的未来效用，再用模型自带的注意力输出门决定每层保留多少，预填充后一次打分并真正释放被丢弃的条目。
评分依据：KV cache 压缩是端侧长上下文推理的关键技术，可迁移但实验面向服务器大模型；利用递归层信号预测注意力缓存价值的思路新颖。
