microsoft/onnxruntime: [MLAS] Add an NHWC implementation of convolution to avoid transposes (#26834)

10 开源大项目 开源 2026-05-14 · microsoft / GitHub
方向:推理框架方向:高效推理硬件:CPU
这是什么ONNX Runtime 的 CPU 数学库新增 NHWC 数据布局的卷积实现，省掉卷积前后插入的转置操作，目前只在启用 Arm KleidiAI 时生效。
有什么结果对应 PR 讨论中作者贴出的 MobileNet 单线程测试：平均推理时延从 6.66 毫秒降到 5.64 毫秒，吞吐从每秒 150 次提高到 177 次（约 18%）。
怎么做到CPU 执行器在输入为 NHWC 时标记通道在后，新增融合的 NHWC 卷积算子并在 KleidiAI 路径里实现，图优化阶段据此去掉多余的转置；目前只支持普通卷积，深度可分离卷积后续跟进。
评分依据：由 Arm 工程师贡献（提交署名为 arm.com 邮箱），直接针对 Arm CPU 上的卷积推理去掉布局转换开销，对手机和嵌入式设备的视觉模型有迁移价值；PR 里给出了 MobileNet 约 18% 的提速，但属于常规算子优化。
