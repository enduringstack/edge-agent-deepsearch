Muse Glimmer: an open-weight model built for local agents

16 官方动态 开源 2026-08-12 · Meta / Meta
Meta方向:端侧agent方向:工具调用方向:量化方向:投机解码方向:多模态硬件:GPU硬件:Apple-Silicon
这是什么Meta 超级智能实验室发布 300 亿参数的开放权重模型 Muse Glimmer，专门为常驻在个人 Mac 或单张消费级显卡上的本地智能体设计，采用 Apache 2.0 许可，无需 API 密钥、请求不离开本机。
有什么结果官方称约 4 比特量化后语言模型部分小于 20GB，可放进 24–32GB 显存/内存，并为 KV cache、视觉编码器和投机解码草稿模型留出余量；默认上下文 128K。官方基准表称其在工具编排、智能体搜索、智能体编程、指令遵循和长上下文记忆上领先，但正文未列出具体分数。
怎么做到针对工具调用循环做训练：长序列多次调用时保持参数格式稳定，工具失败时自行诊断并重试；带独立视觉编码器可读截图和文档；随模型附带轻量草稿模型做块式投机解码；提供 GGUF 与 ExecuTorch 量化版本，可经 llama.cpp、Ollama、LM Studio 在本机运行或用 ExecuTorch 部署到手机和边缘设备，并以 OpenClaw 作为本地智能体参考外壳。
评分依据：官方明确以本机常驻智能体为目标，并在 OpenClaw 中演示本地模型自主规划、多工具调用和拒绝破坏性操作，属于 PC 端侧智能体（相关度 9）。开放权重加 Apache 2.0、附带草稿模型和多种端侧量化包，工程完整度高，但正文缺少可核对的基准数字（贡献 7）。
