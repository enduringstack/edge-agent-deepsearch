MiniCPM5-1B

15 开源大项目 开源 2026-05-26 · OpenBMB / GitHub
方向:模型架构方向:工具调用方向:规划推理方向:编译部署模型:MiniCPM
这是什么面壁智能在 MiniCPM 仓库发布 5.0 版本，推出 MiniCPM5 系列首个模型 MiniCPM5-1B：一个专为端侧、本地部署和资源受限场景设计的 10 亿参数稠密模型。
有什么结果官方称在推理、知识、代码、指令跟随、数学、逻辑和智能体等基准上平均 42.57 分，高于同尺寸开源模型中的最高平均分 35.61，优势主要在智能体工具调用、代码和竞赛数学上。
怎么做到同一份权重内置思考模板，可用开关在快速回答和深度推理两种模式间切换；仓库为主流推理后端和微调框架各配一页部署手册与对应的智能体技能，并附带一个由本地 MiniCPM5-1B 驱动的桌面宠物示例。
评分依据：模型本身就是为端侧和本地部署设计的 1B 级基座，并配套多推理后端的部署手册（相关度 9）。属于国内头部端侧模型厂的新一代主力小模型，混合思考与工具调用能力在同尺寸里领先，但发布说明未披露新的架构方法（贡献 6）。
