MUSE: Multi-Level Memory with Selective Runtime Injection for Scientific Coding Agents

8 学校预印本 开源 2026-10-28 · Haoran Jin; Defu Lian; Xiting Wang; Hong Xie / arXiv
方向:记忆应用:代码
这是什么科研编程智能体可以借鉴过去的经验，但只在任务开始时检索往往会漏掉执行中才变得重要的实现细节。MUSE 把历史经验分成全局、方法、实现三层记忆，并在执行过程中按需注入。
有什么结果在数值求解、内核优化和科学软件修复四个基准上，所有评测指标都优于检索类和记忆类基线；迁移实验显示记忆在不同内核基准间仍然有用（摘要未给出具体数字）。
怎么做到从历史轨迹构建三层记忆：开始时给全局记忆和匹配的方法层记忆，执行中用当前交互检索实现层记忆，由大模型门控判断是否注入并生成具体审阅建议。
评分依据：属于智能体记忆管理方法，可迁移到任何带记忆的智能体，但面向云端科研编程场景、与端侧无直接关系；分层记忆加门控注入属于较常见的工程组合。作者来自中国科学技术大学与中国人民大学。
