ClawTrace: Cost-Aware Tracing for LLM Agent Skill Distillation

8 学校预印本 开源 2026-04-26 · Boqin Yuan; Yue Su; Renchu Song; Sen Yang; Jing Qin / Agent Skills '26 Workshop (CAIS 2026)
方向:蒸馏方向:评测基准方向:工具调用
这是什么从大模型智能体的执行轨迹里提炼可复用“技能”时，以往不知道每一步花了多少钱。ClawTrace 给每一步记上成本，再看提炼出的技能规则在新任务上是否真的有用。
有什么结果在 30 个 SpreadsheetBench 留出任务上，去掉“裁剪”类补丁后质量回退次数约增加到 3 倍，而中位成本并未下降；在完整 84 个 SkillsBench 迁移任务上整体没有省钱，3 次质量回退都来自“保留”类补丁，2 次质量提升都来自“裁剪”类补丁。
怎么做到把带成本归因的智能体轨迹整理成 TraceCard，再由 CostCraft 生成“保留、裁剪、修复”三类技能补丁，按规则类型分别评估迁移效果。
评分依据：研究对象是云端智能体的技能蒸馏与成本追踪，与端侧部署关系较远；按规则类型评估技能的视角有一定新意，并开源了追踪工具和技能集。
