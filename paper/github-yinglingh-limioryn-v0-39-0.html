Limioryn 0.39.0 — Initial Public Preview

16 开源大项目 开源 2026-08-07 · YINGLINGH / GitHub
方向:端侧agent方向:端云协同方向:工具调用方向:安全隐私硬件:MCU硬件:CPU应用:IoT命令
这是什么Limioryn 是一个把智能体和真实硬件连起来的开源框架，首个公开预览版提供 ESP32-S3、STM32 和 Linux 单板机的参考接入，让智能体能安全地驱动继电器、传感器等物理设备。
有什么结果未报告
怎么做到设备动作按“已接收→执行中→已执行→待确认”的生命周期逐步追踪，证据不足时标为未知并触发状态对账、观测或人工决定；默认走本地规则，配合能力白名单、输入范围检查、共享执行器冲突检查和人工确认来约束执行，云端智能体只能通过同一套设备契约调用设备能力。
评分依据：关键的动作执行、确认、状态对账和故障恢复落在 MCU 与单板机侧，属于端云协同的设备智能体，端侧相关度高；它把物理执行的确认与恢复做成框架级约束，思路有新意。原文是预览版发布说明，没有给出时延、测试规模等量化结果。
