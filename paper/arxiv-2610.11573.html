Memory Type Varies: Empowering LLM Agents for Long-Term Memory with Diverse Strategies

9 公司项目 开源 2026-10-08 · Yi Wen; Derong Xu; Pengyue Jia; Yichao Wang; Yingyi Zhang; Maolin Wang; Junyi Li; Wenlin Zhang / NeurIPS 2026
Huawei方向:记忆应用:RAG
这是什么现有基于检索的 LLM 记忆方法对所有记忆一视同仁，用同一种检索策略。MemoType 先识别记忆和问题各属于哪种类型，再为不同类型选用不同的检索策略。
有什么结果在三个数据集上持续优于现有方法，Recall@1 最高提升 16.18%。
怎么做到构建标注了记忆类型的多类别数据集 TriMEM，训练路由模型自适应识别每条记忆和每个查询的类型，按类型匹配检索并设计专门策略；理论上证明任何单一检索策略在多类别语料上都存在精度上限。
