Improved Python (PyPi/uvx) support in Azure MCP Server

4 官方动态 2026-02-24 · Microsoft / Microsoft
Microsoft方向:工具调用
这是什么Azure MCP Server 现在可以直接用 Python 的 uvx 或 pip 安装运行，Python 开发者不用再装 Node.js 或 .NET 就能让智能体调用 40 多种 Azure 服务。
有什么结果Python 开发者用一条 uvx 命令即可启动服务器，接入 40 多种 Azure 服务，能力与 Node.js、.NET 版本一致；要求 Python 3.10 及以上。原文没有性能或使用效果的量化数据。
怎么做到发布 PyPI 包 msmcp-azure，一条 uvx 命令即可按需启动服务器，在 VS Code、Claude Desktop、Cursor 等 MCP 客户端的配置里指向它即可；也能与 GitHub Copilot SDK 的智能体会话配合使用。
评分依据：属于智能体工具调用生态的分发方式更新，服务器虽可在本机启动，但调用的都是云端 Azure 服务，与端侧推理无关；工程便利性改进，创新有限。原文没有性能对比，效果里只有服务覆盖数量。
