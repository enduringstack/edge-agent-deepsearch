Azure MCP Server now available as an MCP Bundle (.mcpb)

6 官方动态 开源 2026-04-24 · Microsoft / Microsoft
Microsoft方向:工具调用方向:编译部署
这是什么Azure MCP Server 推出 MCP Bundle（.mcpb）安装包，用户无需装 Node.js、Python 或 .NET，就能把它装进 Claude Desktop 等本地客户端。
有什么结果安装后可在客户端里使用 100 多个 Azure 服务工具；未给出性能数据。
怎么做到MCP Bundle 是一个 ZIP 包，内含描述工具和运行要求的 manifest.json 以及自带全部依赖的服务器二进制，类似浏览器扩展，拖进客户端即可安装。
评分依据：工具服务器在用户电脑上本地运行，与 PC 端智能体的工具分发相关，但模型推理在云端，电脑只是入口（相关度 3）；属于分发格式适配（贡献 3）。
