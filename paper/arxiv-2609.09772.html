SymbolicLight V2: Hybrid Neuromorphic Architecture and Sparse Execution for Low-Energy Language Inference

16 学校预印本 2026-09-09 · Ting Liu / arXiv
方向:SNN方向:能耗功耗方向:高效注意力硬件:FPGA硬件:CPU硬件:神经形态
这是什么一个混合神经形态语言模型架构，稀疏事件计算配连续状态处理，实现在 FPGA 和 ARM CPU 上做低能耗推理。
有什么结果1.94 亿参数模型在 Alveo U50C FPGA 上 175MHz 运行，三次实现迭代把 32 token 前缀、128 输出的解码吞吐从 474.6 提到 643.2 token/s，每 token 估计整卡能耗从 0.06087 焦降到 0.04407 焦（降 27.6%），含预填充的完整请求能耗降 24.4% 到 27.7%；相对记录的 RTX 5090 编译 FP32 基线，短上下文解码整卡能耗低 89.1%；在 ROCK 5T 的四个 Cortex-A76 核上完整请求达 65.4 token/s、9.80 瓦、每 token 0.151 焦。
怎么做到在 V1 的脉冲门控双路径基础上，给更多投影加带符号的分级事件，并用免 softmax 的局部注意力；FPGA 上用定点数字算术实现，ARM 上用稀疏整数执行，再靠激活行权重聚集和有效状态 KV 加载提升解码吞吐。
评分依据：在 FPGA 和 ARM 开发板上都给出每 token 能耗实测，正是端侧低能耗语言推理的核心指标（相关性 9）。事件稀疏与连续状态混合的架构有新意（贡献 7）。
