Boost Inference Performance up to 15x on NVIDIA Blackwell Using DFlash Speculative Decoding

10 官方动态 2026-06-23 · NVIDIA / NVIDIA
NVIDIA方向:投机解码方向:高效推理方向:云端serving硬件:GPU模型:Llama模型:Qwen模型:Gemma
这是什么英伟达介绍 DFlash——一个用块扩散模型当草稿器的开源投机解码方案。
有什么结果在 Blackwell 上对 gpt-oss-120b 最高带来 15 倍吞吐提升（在每秒 500 到 600 token 的高交互档位下），比 EAGLE-3 快 1.5 倍；对 Llama 3.1 8B 的交互性接近翻倍；用 vLLM 跑 Gemma 4 31B 提速 5.8 倍，用 SGLang 跑 Qwen3 8B 提速 5.1 倍。
怎么做到自回归大模型逐 token 生成限制了 GPU 利用率，投机解码靠轻量草稿模型加并行验证来缓解。DFlash 是一个开源的轻量块扩散模型，作为块扩散草稿器在单次前向里就生成一整块候选 token，把顺序生成改成块式生成，再由目标模型一次性验证，从而把并行度放大而不损输出质量。
评分依据：实测平台是数据中心的 Blackwell GPU，与端侧部署只有宽泛关联，但块扩散草稿器这一思路本身对任何受带宽限制的推理场景都有迁移价值；用扩散模型替代自回归草稿器是投机解码范式上的实质创新，加速幅度也很大。
