Accelerated Execution of Bayesian Neural Networks using a Single Probabilistic Forward Pass and Code Generation

13 学校预印本 2026-10-16 · Bernhard Klein; Falk Selker; Hendrik Borras; Sophie Steger; Franz Pernkopf; Holger Fröning / ACM TACO
方向:编译部署方向:高效推理硬件:CPU
这是什么为贝叶斯神经网络做的端到端加速流程：用“单次概率前向传播”替代多次采样，并编译部署到嵌入式 ARM CPU 上，让带不确定性估计的模型也能低时延运行。
有什么结果在嵌入式 ARM CPU（如 Cortex-A72）上，小批量场景下比基于采样的随机变分推理最高快 3900 倍；在 Dirty-MNIST 不确定性分解和 CIFAR-10 对 SVHN 的分布外检测上，效果与采样方法相当。
怎么做到假设权重和激活都服从高斯分布，把不确定性解析地逐层传播，一次前向就得到预测分布；在 TVM 中实现专用高斯传播算子库，并结合手动和自动调优。
评分依据：在嵌入式 ARM CPU 上完成编译部署与实测，属于端侧推理技术栈；把概率前向传播落到编译器算子并给出大幅加速，有一定工程新意。
