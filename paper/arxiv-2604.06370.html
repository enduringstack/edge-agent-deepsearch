ForkKV: Scaling Multi-LoRA Agent Serving via Copy-on-Write Disaggregated KV Cache

11 学校预印本 2026-04-07 · Shao Wang; Rui Ren; Lin Gui / arXiv
方向:KV cache方向:调度服务方向:云端serving硬件:GPU
这是什么多个 Agent 共用一个基座模型、各挂一个 LoRA 时，共享上下文的 KV cache 因 LoRA 不同而无法复用。ForkKV 借鉴操作系统的写时复制，把共享部分和各 Agent 专属部分拆开存。
有什么结果在多种模型和数据集上，吞吐最高达到现有多 LoRA 服务系统的 3.0 倍，对生成质量影响可忽略。
怎么做到把 KV cache 拆成大的共享部分和小的 Agent 专属部分，用双基数树管理新分叉 Agent 继承共享缓存，并设计专用内核在片上 SRAM 中直接重组缓存做注意力计算。
评分依据：多 Agent 共享上下文的缓存复用思路新颖，对端侧多 Agent 同时运行也有借鉴价值；但系统面向 GPU 服务端。
