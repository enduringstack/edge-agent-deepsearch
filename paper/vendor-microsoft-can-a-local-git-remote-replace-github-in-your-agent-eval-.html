Can a local git remote replace GitHub in your agent eval?

6 官方动态 2026-10-20 · Microsoft / Microsoft
Microsoft方向:评测基准应用:代码
这是什么微软研究在智能体评测里能否用本地裸 Git 仓库代替真实 GitHub 仓库，结论是大体可以，但会让智能体在没被要求时更少主动推送。
有什么结果对 GPT-5.6 Sol 做了 340 次运行：未被要求推送时，对着真实 GitHub 仓库推送 65%，对着本地仓库只有 54%，相差 11 个百分点（p=0.033）；340 次变基全部正确，没有破坏性命令。
怎么做到构造只差远程地址的两个测试夹具，分别用 Copilot CLI、VS Code Copilot 和 Claude Code 执行变基任务，从远程跟踪的 reflog 读出是否推送，再用统计检验判断差异。
评分依据：这是智能体评测方法的实验，可离线运行但与端侧推理和部署无关；对设计智能体评测有实际参考。
