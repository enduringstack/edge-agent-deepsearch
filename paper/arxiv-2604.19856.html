ChipCraftBrain: Validation-First RTL Generation via Multi-Agent Orchestration

7 学校预印本 2026-04-21 · Cagri Eryilmaz / arXiv
方向:规划推理应用:代码
这是什么让大模型根据自然语言规格自动写芯片 RTL 代码的多智能体框架，目标是在更难的工业基准上也保持高通过率，同时压低 API 调用成本。
有什么结果VerilogEval-Human 平均 pass@1 为 97.2%（MAGE 为 95.9%）；在 NVIDIA CVDP 的 302 题非 agent 子集上平均 94.7%，各类别比单次生成基线高 36-60 个百分点，每题尝试次数约为 ACE-RTL 的三十分之一；RISC-V SoC 案例生成的 8 个模块全部通过 lint 并在 FPGA 上验证。
怎么做到用 PPO 策略在六个专职智能体之间自适应调度；卡诺图、真值表类题目改用符号算法直接求解；配合 321 条设计模式和 971 份开源参考实现做检索增强，并把大规格拆成按依赖排序的子模块逐个生成。
评分依据：这是用云端大模型做芯片设计的应用工作，与端侧推理部署关系很远，只在多智能体编排上有参考价值；工业基准上的实测结果扎实，贡献中等。公司归属依据 PDF 首页作者署名 ChipCraftX（chipcraftx.io 邮箱）。
