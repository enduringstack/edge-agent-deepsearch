Sparse Attention as a Range Searching Problem: Towards an Inference-Efficient Index for KV Cache

11 学校预印本 开源 2026-05-07 · Mohsen Dehghankar; Abolfazl Asudeh / arXiv
方向:KV cache方向:稀疏注意力方向:高效注意力应用:长上下文推理硬件:CPU硬件:GPU
这是什么稀疏注意力只挑一部分 KV 来算，但漏掉一个关键 key 就可能让长推理输出突然出错。这篇把“找出该看的 KV”改写成几何上的半空间范围检索问题，做了一个保证不漏的 KV cache 索引 Louver。
有什么结果论文称 Louver 在准确率和运行时间上都优于已有稀疏注意力方法，并且比高度优化的稠密注意力 FlashAttention 还快；摘要未给出具体倍数。
怎么做到把注意力分数超过阈值的 key 视为查询向量定义的半空间内的点，用专门设计的轻量索引结构检索，保证阈值以上的 key 零漏检，并针对 CPU 和 GPU 分别做了硬件优化。
评分依据：属于 KV cache 稀疏检索，长上下文推理的内存与算力优化可迁移到端侧，但论文没有端侧设备实验；把稀疏注意力做成有召回保证的索引是较新的视角。
