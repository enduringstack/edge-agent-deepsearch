Interactions API: our primary interface for Gemini models and agents

8 官方动态 2026-06-22 · Google / Google
Google方向:工具调用方向:调度服务方向:云端serving
这是什么Google 把 Interactions API 转正，作为调用 Gemini 模型和智能体的统一主入口。
有什么结果该 API 正式进入通用可用阶段，原有的 generateContent 接口仍然支持，但官方明确长时运行模型与智能体的前沿能力将越来越多地只落在新接口上；Python/JS SDK 以及 LiteLLM、Eigent、Agno 等合作方已可用。
怎么做到收敛成单一端点，支持服务端状态保存、后台执行、工具组合与多模态生成，并给出迁移指南；同时发布一个配套 Skill，把流式、函数调用、结构化输出、深度研究等最佳实践直接注入编码智能体的上下文。
评分依据：面向云端 Gemini 模型与智能体的接口收敛，不涉及设备端运行，相关度按宽泛关联计；把长时运行与状态保存做进协议层，对智能体应用形态有牵引作用。
