The Art of Building Verifiers for Computer Use Agents

6 官方动态 开源 2026-04-21 · Microsoft / Microsoft
Microsoft方向:评测基准
这是什么微软研究院分享为网页操作类 Agent 构建“验证器”的经验：自动判断一条操作轨迹到底有没有完成任务。
有什么结果其 Universal Verifier 的误判成功率接近零（WebVoyager 至少 45%、WebJudge 至少 22%），与人工标注的一致性达到人与人之间的水平（Cohen κ 0.64）；自动研究 Agent 用 5% 的时间能做到专家设计约 70% 的质量。
怎么做到约一半收益来自评分细则设计，另外把过程与结果分开评判、区分可控与不可控失败；验证器和 CUAVerifierBench 基准已开源。
评分依据：针对网页操作 Agent 的评测方法，与端侧无关；误判率大幅下降且开源，评测方法本身有价值。
