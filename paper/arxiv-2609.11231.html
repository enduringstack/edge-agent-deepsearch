A Voice-Interactive Multi-Agent System for Smart Operating Rooms: Architecture Design and Key Technologies

12 学校预印本 2026-09-10 · Tianxiang Zhou / arXiv
方向:KV cache应用:语音方向:工具调用方向:推理框架模型:Qwen
这是什么给智慧手术室做的语音交互多智能体系统，重点在把大模型的响应时延压到手术现场能接受的水平。
有什么结果KV 缓存前缀预热把重算开销从约 500 毫秒降到几十毫秒；流式部分 JSON 解析加提前并行执行把端到端时延降低约 30%；系统用 Qwen3-27B 配 llama.cpp/sglang，在 16384 token 上下文限制内有效运行，多设备并行控制响应时间满足手术室实时要求。
怎么做到分层架构包含语音交互流水线（唤醒、语音识别、轮次检测、智能体推理、语音合成）和智能体核心（技能注册表、任务规划器、设备管理器）；三项关键技术是按字节最长公共前缀复用的 KV 缓存预热、流式 JSON 解析提前并行执行，以及按用户角色、已连设备和手术阶段动态过滤系统提示。
评分依据：用 llama.cpp 在本地部署并做 KV 前缀预热和上下文裁剪，都是端侧智能体的实用优化（相关性 7）。工程技术成熟但组合合理（贡献 5）。
