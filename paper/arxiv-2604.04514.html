SuperLocalMemory V3.3: The Living Brain -- Biologically-Inspired Forgetting, Cognitive Quantization, and Multi-Channel Retrieval for Zero-LLM Agent Memory Systems

11 学校预印本 开源 2026-04-06 · Varun Pratap Bhardwaj / arXiv
方向:记忆方向:工具调用方向:量化应用:代码硬件:CPU
这是什么AI 编程助手每次开新会话都会忘记之前聊过的内容。SuperLocalMemory V3.3 是一个完全在本地 CPU 上运行、核心操作不依赖大模型的 Agent 记忆系统，模仿人类记忆的遗忘和多通道回忆。
有什么结果在 LoCoMo 长对话记忆基准上，不调用大模型的模式 A 得分 70.4%，多跳题提升 23.8 个百分点、对抗题提升 12.7 个百分点；上一版 V3.2 模式 A 为 74.8%。新距离度量在区分高保真与量化嵌入时准确率 100%（余弦距离为 85.6%）。
怎么做到按艾宾浩斯遗忘曲线管理记忆生命周期，越久不用的记忆嵌入压缩得越狠；检索同时走语义、关键词、实体图、时间等 7 个通道；用 SQLite 加向量扩展本地存储，通过 MCP 工具接入 Claude Code 等编程助手。
评分依据：记忆的存储、遗忘和检索完全在本地 CPU 运行，属于可直接用于端侧 Agent 的记忆运行时；但它服务的编程助手本身仍依赖云端模型，论文也没有给出具体设备上的性能测试，因此不算端侧 Agent。作者为独立研究者，评估以单一基准为主。
