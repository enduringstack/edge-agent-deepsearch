SuperLocalMemory V3.3: The Living Brain -- Biologically-Inspired Forgetting, Cognitive Quantization, and Multi-Channel Retrieval for Zero-LLM Agent Memory Systems

11 学校预印本 开源 2026-04-17 · Varun Pratap Bhardwaj / arXiv
方向:记忆方向:量化应用:RAG硬件:CPU
这是什么SuperLocalMemory V3.3 是给编程智能体用的本地记忆系统，不依赖云端大模型、只用 CPU 就能完成记忆的存储、遗忘和检索。
有什么结果在 LoCoMo 长对话记忆基准上，零大模型模式得分 70.4%，多跳题 +23.8 个百分点、对抗题 +12.7 个百分点；上一版 V3.2 该模式为 74.8%。新距离度量在区分高保真与量化向量时精度 100%（余弦为 85.6%）。
怎么做到用模仿人脑遗忘曲线的机制决定记忆何时逐步压缩成更低精度的向量，再用语义、关键词、实体图、时间、联想等 7 路通道联合检索；以守护进程常驻本机，通过 MCP 工具接入 Claude Code 等智能体。
评分依据：记忆存取与检索完全在本机 CPU 上运行，但它服务的编程智能体主体仍依赖云端模型，整体不算端侧智能体；作者为独立研究者，部分新颖性表述偏强，属工程整合。
