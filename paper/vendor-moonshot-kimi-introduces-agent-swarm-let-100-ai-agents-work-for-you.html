Kimi Introduces Agent Swarm: Let 100 AI Agents Work for You

8 官方动态 2026-02-09 · Moonshot / Moonshot
Moonshot方向:规划推理方向:工具调用
这是什么月之暗面为 Kimi 推出 Agent Swarm（智能体集群）：由一个“总指挥”自动拆分任务、按需创建并调度大量子 Agent 并行干活，突破单个 Agent 串行执行时被上下文窗口卡住的上限。
有什么结果借助 Agent Swarm，Kimi K2.5 可同时调度最多 100 个子 Agent、执行超过 1500 次工具调用，比串行执行快 4.5 倍并给出更好的结果。
怎么做到编排 Agent 先定义任务结构，再自主“招聘”研究员、分析员、核查员等子 Agent 分头并行，最后汇总并让不同结论相互对质以避免群体思维。
评分依据：这是云端多 Agent 并行编排，与端侧无关。把横向扩展 Agent 数量作为测试时扩展手段并给出规模数据，有一定新意。
