alibaba/MNN: [Vulkan:Feature] Support VulkanConv1x1CoopA8(dynamic quant with W8A8 coopMat)

13 开源大项目 开源 2026-05-20 · alibaba / GitHub
方向:量化方向:推理框架方向:高效推理硬件:GPU硬件:Snapdragon模型:Qwen
这是什么MNN 的 Vulkan 缓冲后端新增一个支持动态量化的 1x1 卷积算子，让手机 GPU 也能跑 8 比特权重加 8 比特激活。
有什么结果提交说明给的是骁龙 8 Gen5 上与半精度方案的对比：算子性能提升 30% 到 40%；Qwen3-4B 的预填充吞吐，INT4 从每秒 364.80 个词提到 435，INT8 从 339.99 提到 452.6。
怎么做到在 Vulkan 缓冲后端用协作矩阵指令实现 W8A8 动态量化的 1x1 卷积，并支持 INT4 和 INT8 的按通道非对称权重量化，配套新增了相应的计算着色器和权重求和内核。
评分依据：改动直接落在手机 GPU 的量化卷积算子上，并给出骁龙 8 Gen5 实测的端到端预填充吞吐，端侧契合度高。用协作矩阵指令做动态量化是具体而有效的工程优化，属于推理引擎的常规性能迭代。
