CLIP Tricks You: Training-free Token Pruning for Efficient Pixel Grounding in Large VIsion-Language Models

11 学校顶会 开源 2026-05-13 · Sangin Lee; Yukyung Choi / ICML 2026
方向:剪枝稀疏方向:多模态方向:高效推理
这是什么大视觉语言模型做像素级指代分割时视觉 token 太多，这篇给出一个不用训练的剪枝方法 LiteLVLM，专门照顾这类依赖文本的定位任务。
有什么结果在多种 token 预算下比现有剪枝方法高 5% 以上；不训练不微调即可保留原模型 90% 的性能，同时提速 22%、显存降低 2.3 倍。
怎么做到作者发现被指代区域的视觉 token 与文本的 CLIP 相似度反而偏低，于是把相似度排序反过来保留目标区域 token，再补回部分背景 token 以区分前景和背景。
评分依据：视觉 token 剪枝能直接降低多模态模型的算力和显存，属于端侧可迁移的推理优化，但实验未在端侧设备上做；“反向利用 CLIP 相似度”的观察有新意，已被 ICML 2026 接收。
