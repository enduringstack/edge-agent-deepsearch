Microsoft to expand Azure Maia system to multi-gigawatt deployments

8 官方动态 2026-10-12 · Microsoft / Microsoft
Microsoft方向:云端serving方向:能耗功耗方向:KV cache方向:量化应用:长上下文推理
这是什么微软宣布从 2027 年起把自研 AI 推理芯片 Azure Maia 扩展到数吉瓦级部署，让它成为微软产品的主力推理系统；Maia 200 已在承载 Copilot，下一代 Maia 300 面向长上下文推理和多步智能体任务。
有什么结果Maia 200 在 Teams、Copilot、Cowork 的内置 AI 上每瓦 token 数最高为主流 GPU 的 1.7 倍；Maia 300 预计每兆瓦 token 数比主流 GPU 系统多 40%，96 卡满配时机架级吞吐最高为 Maia 200 的 7 倍；单芯片 8 颗 HBM4 提供 18.0 TB/s 带宽、功耗 950W，整机架 96 卡 167kW、27.6TB HBM。
怎么做到Maia 300 采用软件定义的数据流架构加 AI 辅助的内核优化来减少数据搬运；多芯粒设计，计算芯粒用台积电 N2P 工艺；支持增强版 MXFP4 等低精度格式，同时压缩计算量和 KV cache 存储；片上 SRAM 作为软件管理的暂存区以减轻 HBM 压力。
评分依据：这是数据中心推理芯片，与端侧部署基本无关，只在低精度格式、KV cache 压缩等推理优化思路上有间接参考。官方给出了明确的能效和带宽指标，硬件系统层面的贡献中等。
