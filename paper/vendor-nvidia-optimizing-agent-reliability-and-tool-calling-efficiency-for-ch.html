Optimizing Agent Reliability and Tool Calling Efficiency for Chip Design Using NVIDIA NeMo Gym

6 官方动态 开源 2026-10-14 · NVIDIA / NVIDIA
NVIDIA方向:评测基准方向:工具调用
这是什么英伟达和西门子 EDA 用 NeMo Gym 评测环境，诊断芯片设计流程中智能体的出错环节并提升其可靠性和工具调用效率。
有什么结果在 Liberty 文件生成基准上，综合验证得分从约 55% 提升到约 95%；智能体轮次从 155 降到 53，输出 token 从约 8.1 万降到 2.9 万。
怎么做到用领域验证器检查最终产物的覆盖率、有效性、准确性和完整性，任一关卡不过即零分，再据诊断结果改进技能和 MCP 工具描述并反复试跑。
评分依据：属于云端工程智能体的评测与优化，与端侧无关；以最终产物打分并反推工具描述的方法对工具调用效率有参考。
