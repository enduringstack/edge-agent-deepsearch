RAC: A Relational Agent Contract for Constraint-Governed Engineering Tasks

7 学校预印本 2026-10-14 · Kaiyuan Zheng; Fengqing Jiang; Yichen Feng; Zubin Aaron Assadian; Yuetai Li; Bhaskar Ramasubramanian; Basel Alomair; Luyao Niu / arXiv
方向:工具调用方向:规划推理应用:代码
这是什么工程类 Agent 要产出满足精确约束的电路板布局、排程或嵌入式代码，常常因为既要做语义决策又要亲自推算几何、时序细节而出错。这篇工作给 Agent 的动作与反馈层定了一套契约：Agent 只决定关系，具体结果交给专用工具推导。
有什么结果PCB 布局、布线与修复任务上，九个模型的平均一次干净通过率为 90.9%，最强基线为 74.0%；作业车间排程中直接关系动作质量通过率 96.3%，代码中转方式为 59.6%；另在四种微控制器的 141 个嵌入式代码任务上做了评估。
怎么做到规定权威观测、语义动作、工具实现、独立验证和修复证据五个环节，Agent 声明产物应满足的关系，由专用工具算出具体参数并独立校验。
评分依据：属于 Agent 工具调用与运行时设计，评测涉及微控制器代码，但 Agent 本身不在设备上运行，端侧相关度低；把语义决策和机械推导分离的契约设计有实际效果。作者来自 University of Washington 等。
