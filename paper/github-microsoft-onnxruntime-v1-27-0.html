ONNX Runtime v1.27.0

14 开源大项目 开源 2026-06-19 · microsoft / GitHub
方向:推理框架方向:编译部署方向:量化方向:KV cache方向:高效推理硬件:Apple-Silicon
这是什么ONNX Runtime 发布 1.27.0 版，重点在安全加固和各执行后端的能力补全。
有什么结果该版本面向 ONNX 1.21，由 106 位开发者贡献；修复了 SoftmaxCrossEntropyLoss 的越界读取、OneHot 的输入校验、Expand 与 Tile 的溢出和输出尺寸问题等多个安全缺陷；同时宣布 CUDA 12 包进入弃用状态，建议尽快迁移到 CUDA 13。
怎么做到执行后端方面，CUDA 补上 ConvTranspose-22 支持并填平算子集缺口，WebGPU 增加 LSTM 支持和 FlashAttention 优化，CoreML 扩展算子覆盖；核心能力上新增 ONNX 重载函数与 FLOAT8E8M0 数据类型，量化工具链支持校准缓存；CPU 侧则补上 NHWC 卷积路径、分组查询注意力的量化 KV 缓存支持以及 RISC-V 优化。
评分依据：ONNX Runtime 是覆盖面最广的端侧推理运行时，本次 CoreML 算子扩展、WebGPU、RISC-V 优化和量化 KV 缓存都直接服务于移动与嵌入式部署，端侧契合度高；属大版本发布，安全修复与后端能力补全都较成体系。
