MemCompiler: Compile, Don't Inject -- State-Conditioned Memory for Embodied Agents

12 公司项目 2026-05-08 · Xin Ding; Xinrui Wang; Yifan Yang; Hao Wu; Shiqi Jiang; Qianxi Zhang; Liang Mi; Hanxin Zhu / arXiv
Microsoft方向:记忆方向:规划推理应用:机器人模型:Qwen
这是什么具身智能体常在任务开始时一次性塞入检索到的历史记忆，任务推进后这些记忆反而会干扰小模型执行器。MemCompiler 改成每一步按当前状态挑选并“编译”相关记忆，再交给执行器。
有什么结果在 AlfWorld、EmbodiedBench、ScienceWorld 上，开源模型相对无记忆最高提升 129%；AlfWorld 成功率从静态注入的 35.03% 提到 82.16%，执行器输入 token 减少一半以上，单步时延从 0.30 秒降到 0.12 秒。
怎么做到一个轻量的记忆编译模型读取结构化的“简要状态”，只挑出与当前步骤相关的记忆，分别以文字和一组潜在向量（Soft-Mem，承载难以用文字表达的空间和视觉信息）两路送给执行器。
评分依据：属于 Agent 记忆运行时，降低了小模型执行器的输入量和时延，可迁移到资源受限的端侧 Agent，但实验在服务器上跑 14B 以上模型，未做设备部署，相关度中等；按步编译记忆的思路新颖。PDF 首页有 3 位作者署名 Microsoft Research。 作者机构依据：arXiv PDF 首页署名 Microsoft（PDF 首页作者 Yifan Yang、Shiqi Jiang、Qianxi Zhang 署名 Microsoft Research）。
