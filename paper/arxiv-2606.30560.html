TraceLab: Characterizing Coding Agent Workloads for LLM Serving

9 学校预印本 开源 2026-06-29 · Kan Zhu, Mathew Jacob, Chenxi Ma et al. / arXiv
方向:云端serving方向:工具调用方向:KV cache方向:评测基准应用:代码
这是什么TraceLab 收集并公开了约 4300 个真实编码智能体会话的运行轨迹，用来分析这类负载对大模型推理服务的要求。
有什么结果数据集含约 35 万次大模型调用和 43 万次工具调用（来自 Claude Code 与 Codex 的日常使用）；分析发现编码智能体负载具有长自主循环、长上下文短输出、工具调用重尾分布、前缀缓存命中率高但不完美等特点。
怎么做到采集真实使用轨迹，统计循环长度、上下文与输出长度、工具调用分布和缓存命中，并据此提出低开销工具调用、按追加长度预填充、工具时延预测和改进 KV cache 管理等优化方向。
评分依据：面向云端推理服务的智能体负载刻画，与端侧部署关系较远，但对智能体运行时设计有参考；首批公开的真实编码智能体轨迹数据有价值。
