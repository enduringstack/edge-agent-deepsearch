From extraction to action: Using grounding and confidence to build reliable document workflows

4 官方动态 2026-10-14 · Microsoft / Microsoft
Microsoft应用:OCR
这是什么微软介绍 Azure Content Understanding 如何用溯源和字段级置信度，决定文档抽取结果中哪些需要人工复查，让文档自动化流程更可靠。
有什么结果一家大型保险机构的落地中，人工审核量减少近 50%，新表单接入提速 75%，页面级分类准确率超过 97%；把溯源合并进抽取流程后，平均推理 token 用量最多减少 28%。
怎么做到每个抽取值都关联回文档中的原文位置，并给出经过校准的置信度，再按置信度和溯源结果把可能出错的字段路由给人工处理。
评分依据：这是云端文档智能服务的实践文章，与端侧部署无关；置信度校准加人工路由属于成熟做法的工程落地。
