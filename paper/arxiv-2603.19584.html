PowerLens: Taming LLM Agents for Safe and Personalized Mobile Power Management

16 学校预印本 2026-03-20 · Xingyu Feng; Chang Sun; Yuzhu Wang; Zhangbing Zhou; Chengwen Luo; Zhuangzhuang Chen; Xiaomin Ouyang; Huanqi Yang / arXiv
方向:端侧agent方向:记忆方向:能耗功耗方向:安全隐私硬件:手机硬件:Snapdragon
这是什么手机省电一直靠固定规则，不懂用户在干什么、也不懂个人偏好。PowerLens 让多个 LLM Agent 根据当前界面判断用户场景，在 Android 手机上自动调整 18 项系统参数来省电，并从用户手动改回的操作里学习个人偏好。
有什么结果在 OnePlus ACE 5（骁龙 8 Gen 3，Android 15）真机上，动作准确率 81.7%，比原生 Android 省电 38.8%，优于规则和 LLM 基线；偏好学习 3-5 天收敛，系统自身只占每天 0.5% 电量。
怎么做到无障碍接口抓取界面树，活动 Agent 识别场景、策略 Agent 生成调参方案（默认调用云端 Gemini-2.5-Flash）；手机上的执行 Agent 先用 PDL 约束框架逐条校验再下发 shell 命令，反馈 Agent 检测用户手动改回并写入两级记忆，逐步沉淀成个人规则。
评分依据：真机部署在 Android 手机上，执行、安全校验、反馈检测和偏好记忆都作为手机系统服务运行，属于真正的手机端 Agent；把 LLM 常识推理和可验证执行结合到系统级电源管理，是少见的方向。
