Data Turnstile: A Scalable Open Framework for Function-Calling Data Generation

12 公司项目 开源 2026-07-31 · Goutham Ramakrishnan; Megha Sharma / arXiv
Amazon方向:工具调用方向:评测基准模型:Qwen
这是什么小模型做工具调用（function calling）缺的是高质量训练数据。Data Turnstile 是一个开源框架，按用户给的 API 规格自动生成多轮工具调用训练数据，专门用来把 0.6B~1.7B 级小模型调成能用的 Agent。
有什么结果在 BFCL 单轮榜上，用它的数据微调的 Qwen3-0.6B（不开思考）总准确率 75.9%，高于开思考的原模型 67.4%，接近 Qwen3-1.7B（78.4%）和 Qwen3-4B（79.9%）；在 τ²-bench 电信场景，Qwen3-1.7B 从 6.6% 提到 31.1%，超过 Qwen2.5-32B-Instruct 的 27.4%。
怎么做到把多轮工具调用对话拆成一步一步受约束的生成，每步都做校验并把错误反馈回去重生成，从而控制 API 多样性、对话复杂度和输出正确性；随框架开源了覆盖 1000+ API、10 万+ 多轮交互的数据集。
评分依据：论文明确以端侧隐私、低时延的小模型 Agent 为动机，并在 0.6B/1.7B 小模型上验证工具调用能力，但没有真机部署，属可直接迁移的端侧 Agent 技术栈（相关度 6）；数据生成流程扎实、开源，提升幅度大（贡献 6）。机构依据：arXiv 论文首页两位作者均署名 Amazon AGI（amazon.com 邮箱），并非此前标注的 Alibaba。 作者机构依据：arXiv PDF 首页署名 Amazon（arXiv 论文首页两位作者均署名 Amazon AGI（Bengaluru），邮箱为 amazon.com）。
