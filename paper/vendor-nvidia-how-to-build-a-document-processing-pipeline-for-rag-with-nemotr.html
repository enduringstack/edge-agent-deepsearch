How to Build a Document Processing Pipeline for RAG with Nemotron

5 官方动态 开源 2026-02-04 · NVIDIA / NVIDIA
NVIDIA方向:多模态应用:RAG应用:OCR硬件:GPU模型:Llama
这是什么英伟达的教程：教开发者用 NeMo Retriever 和 Nemotron RAG 模型搭一条多模态文档处理流水线，让 AI 助手能读懂复杂 PDF 里的嵌套表格和图表，并带出处回答。
有什么结果未报告
怎么做到先用 GPU 加速的微服务把文档拆成文本、表格和图表，再用 1B 级多模态向量模型 llama-nemotron-embed-vl-1b-v2 编码、用同尺寸重排模型筛选结果，最后由 Llama-3.3-Nemotron-Super-49B 生成带引用的答案；本地部署要求至少 24GB 显存的 GPU。
评分依据：这是数据中心 GPU 上的企业文档检索教程，和端侧部署关系很远，只有 1B 级检索与重排小模型有一点参考价值；内容是现有组件的工程串联，创新有限。原文是教程或开发指引，只描述搭建步骤，没有报告量化结果，因此效果写未报告。
