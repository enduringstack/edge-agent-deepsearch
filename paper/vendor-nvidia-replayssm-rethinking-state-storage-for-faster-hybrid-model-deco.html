ReplaySSM: Rethinking State Storage for Faster Hybrid-Model Decoding

11 官方动态 开源 2026-10-12 · NVIDIA / NVIDIA
NVIDIA方向:投机解码方向:量化方向:模型架构方向:云端serving硬件:H100模型:Qwen
这是什么针对 Mamba-2、GDN 这类“SSM 层加少量注意力层”的混合模型，NVIDIA 与普林斯顿 Dao AI Lab 提出 ReplaySSM，改变 SSM 状态的存储方式，解决大批量解码时状态读写占满显存带宽、投机解码难以回滚、量化状态误差不断累积三个问题。
有什么结果batch 256 时 SSM 内核比调优后的 vLLM 快 1.46-1.80 倍，整步解码快 1.20-1.47 倍（Nemotron-3 与 Qwen3.5 共四个模型，H100/B300 单卡）；batch 512 下投机解码吞吐分别是 vLLM 投机解码的 1.85 倍和 2.10 倍；Qwen3.5-4B 在 128K token 上的 KL 散度从 0.136 降到 0.0038。正文明确 batch 1 时没有加速。
怎么做到把状态表示为“检查点加最近输入缓冲”：多数解码步只追加输入，直接由检查点和缓冲算出输出而不写回状态，缓冲满了才一次性折叠写回显存；投机解码靠移动指针提交已接受的草稿，不用逐 token 存快照；高精度检查点负责递推，低精度副本只供读取，避免量化误差回灌。
评分依据：属于混合架构模型的高效解码与量化技术栈，但收益来自服务端大批量下的显存带宽节省，正文明确 batch 1 无加速，对端侧单用户推理的直接价值有限，相关度 4。“缓存输入而非状态”的思路新颖，并已并入 TensorRT-LLM、vLLM、SGLang 和 FlashInfer，贡献 7。
