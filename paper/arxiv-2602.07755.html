Learning to Continually Learn via Meta-learning Agentic Memory Designs

10 学校预印本 2026-02-08 · Yiming Xiong; Shengran Hu; Jeff Clune / arXiv
方向:记忆方向:规划推理
这是什么Agent 的记忆模块大多是人工设计、固定不变的，难以适应多样且变化的任务。ALMA 让一个元智能体自动搜索记忆设计，替代人工设计。
有什么结果在四个序列决策领域中，学到的记忆设计在所有基准上都比最先进的人工记忆设计学得更有效、更高效（摘要未给出具体数值）。
怎么做到元智能体以开放式方式搜索用可执行代码表达的记忆设计，包括数据库结构以及检索和更新机制，从而发现任意形式的记忆方案。
评分依据：属于 Agent 记忆机制的自动设计，对端侧 Agent 记忆运行时有间接启发，但没有部署层面的考虑；用元学习自动搜索记忆设计的思路新颖。
