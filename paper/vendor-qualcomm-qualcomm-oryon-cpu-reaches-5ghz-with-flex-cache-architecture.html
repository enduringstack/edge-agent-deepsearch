Qualcomm Oryon CPU reaches 5GHz with Flex Cache architecture

10 官方动态 2026-08-25 · Qualcomm / Qualcomm
Qualcomm方向:高效推理方向:调度服务硬件:CPU硬件:手机硬件:Snapdragon
这是什么高通在骁龙峰会前预告下一代旗舰手机平台的 Oryon CPU：首款达到 5GHz 的手机 CPU，并引入 Flex Cache 共享缓存架构，明确把智能体任务在多核之间迁移作为设计目标。
有什么结果官方称这是首款达到 5GHz 的手机 CPU、全球最快的手机 CPU；未公布 IPC、缓存容量、功耗或任何 AI 负载的量化结果。
怎么做到完全自研微架构与 CPU 子系统联合调优以在手机功耗约束下达到 5GHz；每核大容量 L1 指令缓存加紧贴 CPU 集群的 L2；新的 Flex Cache 让异构核心共用同一个按负载动态分配的缓存池，大核需要时可占用整个池，减少访问系统内存，使智能体规划、调用工具等跨核交接的任务数据常驻缓存。
评分依据：手机 SoC 厂商把“智能体多步任务在核间迁移”写成 CPU 缓存设计目标，直接关系到端侧智能体的编排开销（相关度 6）。但这是发布前的技术预热，只有设计思路，没有任何数字，NPU 与 GPU 细节留待后续（贡献 4）。
