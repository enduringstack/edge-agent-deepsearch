User as Code: Executable Memory for Personalized Agents

9 学校预印本 2026-06-15 · Bojie Li / arXiv
方向:记忆方向:工具调用应用:代码
这是什么个性化助手记用户，现在基本是存一堆零散事实再按相似度捞回来；这篇主张把用户记忆写成一个能跑的小程序。

怎么做到用带类型的 Python 对象保存用户状态，用普通 Python 函数表达约束用户状态的规则，于是「表示用户」和「对用户推理」在同一个解释器里完成，靠两阶段机制把对话内容编译进这份活的代码工程。
评分依据：可执行记忆能把大量判断从模型推理转移到本地解释器执行，对端侧智能体省算力有参考价值，但论文没有涉及设备约束，相关度较低。把用户模型当成一个持续演进的软件工程来维护，范式上有新意，贡献中等偏上。
