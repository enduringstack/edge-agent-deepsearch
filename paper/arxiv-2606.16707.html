User as Code: Executable Memory for Personalized Agents

11 学校预印本 开源 2026-06-15 · Bojie Li / arXiv
方向:记忆方向:工具调用
这是什么个性化智能体需要长期记住用户是谁，现在的记忆多是文本、知识图谱或事实库，靠相似度检索，难以处理矛盾、汇总统计和执行规则。User as Code 把用户记忆写成可执行的代码。
有什么结果在 LOCOMO 长期对话基准上召回率 78.8%，与全上下文上限和最强记忆系统持平；在“去年出过几次国”这类需要汇总的问题上，检索式记忆只有 6% 到 43%，本方法接近满分（99%）；还能在状态变化时主动发出安全提醒，例如新开的药与数月前记录的过敏冲突。
怎么做到把智能体对用户的认识做成一个持续维护的软件项目：类型化的 Python 对象保存用户状态，普通 Python 函数编码规则；先把每条事实写进只追加、不丢弃的日志，再定期整理成类型化代码，回答问题时直接运行代码。
评分依据：智能体长期记忆的表示方式对端侧个人助理有直接参考价值，但实验依赖云端大模型，没有设备侧部署；“记忆即代码”的思路新颖。PDF 首页作者署名 Pine AI。
