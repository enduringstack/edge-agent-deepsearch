Hybrid Distillation with CoT Guidance for Edge-Drone Control Code Generation

10 学校预印本 2026-01-13 · Yizhan Feng; Hichem Snoussi; Yuhang Wang; Jing Teng; Abel Cherouat; Tian Wang / DAUS 2026
方向:蒸馏方向:工具调用应用:代码应用:机器人模型:DeepSeek
这是什么让无人机机载小模型也能把自然语言指令翻译成多种无人机 SDK 的控制代码。作者把大模型的推理和写代码能力蒸馏到 1B 以下的小模型里。
有什么结果原文称蒸馏后的轻量模型（参数不超过 1B）在保持较高代码生成准确率的同时显著提升部署与推理效率；实验在 RTX 4090 桌面环境完成，未在机载硬件实测。
怎么做到先构建覆盖主流无人机 SDK 的“指令-推理-代码”数据集并加入反事实负样本；以 QLoRA 量化的 DeepSeek-Coder-V2-Lite 作老师，黑盒与白盒混合蒸馏出思维链软标签，配合硬标签加权训练学生模型，再针对 SDK 识别和函数调用匹配做提示调优。
评分依据：目标是机载运行的小模型控制代码生成，与端侧部署直接相关，但缺少真机评测（相关度 6）。蒸馏加思维链属常见组合（贡献 4）。
