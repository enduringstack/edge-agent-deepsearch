SAFE-Pruner: Semantic Attention-Guided Future-Aware Token Pruning for Efficient Vision-Language-Action Manipulation

14 学校预印本 2026-05-28 · Shilin Ma; Chubin Zhang; Changyuan Wang; Yuji Wang; Yue Wu; Zixuan Wang; Jingqi Tian; Zheng Zhu / arXiv
方向:剪枝稀疏方向:多模态方向:高效推理应用:机器人
这是什么视觉-语言-动作模型要实时控制机器人，这篇论文在剪视觉 token 时把深层会用到的注意力也考虑进去，避免过早剪掉关键信息。
有什么结果在多种评测设定下最高取得 1.89 倍加速，成功率下降不到 1.5 个百分点，并比此前最好的方法再高出最多 1.9 个百分点。
怎么做到作者观察到语义注意力一致性，即该类模型在连续控制步之间会把注意力集中在同一个语义实体上；据此设计前瞻策略预测 token 在深层的显著度，再配一个参考时间步刷新策略，一旦注意力发生偏移就触发更新以保证预测准确。
评分依据：机器人实时控制对推理时延的要求本身就是端侧约束，视觉 token 剪枝直接决定控制频率，端侧契合度高。贡献在于利用控制任务特有的跨时间步注意力一致性做前瞻预测，而不是沿用浅层线索。
