RepoOMP: Repository-Aware Hotspot OpenMP Parallelization via Dependency-Aware Context Reduction

8 学校预印本 开源 2026-08-06 · Yongjie Qian; Ke Gao; Zhibin Zhang; Shaohui Peng; Ling Li / arXiv
应用:代码方向:工具调用硬件:CPU
这是什么让大模型智能体帮成熟代码仓库里的热点循环加 OpenMP 并行，难点是并行是否安全往往取决于远处代码。RepoOMP 先把相关依赖证据找全，再交给模型改写。
有什么结果在 NPB、BOTS、FFmpeg、NCNN、GROMACS 共 951 个热点上，有 372 个通过编译、负载校验且确有加速；NPB 平均加速 8.23 倍、BOTS 8.96 倍；9 个真实内核上比 Claude Code 基线加速提高 18% 至 28%，智能体 token 成本降低 47% 至 68%。
怎么做到构建多粒度性能属性图，把热点在确定性规则和大模型智能体之间分流，并生成只包含依赖事实的结构化上下文，避免把无关代码塞给模型。
评分依据：是代码优化智能体，评测对象包含端侧推理框架 NCNN，但本身不涉及端侧推理部署（相关度 3）。依赖感知的上下文压缩有一定新意（贡献 5）。
