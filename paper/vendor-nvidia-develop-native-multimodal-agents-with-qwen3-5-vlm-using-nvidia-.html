Develop Native Multimodal Agents with Qwen3.5 VLM Using NVIDIA GPU-Accelerated Endpoints

4 官方动态 开源 2026-02-27 · NVIDIA / NVIDIA
NVIDIA方向:云端serving方向:MoE方向:多模态模型:Qwen
这是什么英伟达介绍如何通过其云端 GPU 接口试用阿里新开源的 Qwen3.5 原生多模态智能体模型，并用 NIM 容器和 NeMo 做生产部署与微调。
有什么结果文中只给模型规格，没有基准或吞吐数据：总参数 397B、每 token 激活 17B（激活率 4.28%），512 个专家中每 token 用 10 个路由专家加 1 个共享专家，60 层，上下文 256K 可扩展到 1M，支持 200 多种语言。
怎么做到Qwen3.5 采用 MoE 与 Gated Delta Networks 混合架构，能理解和操作界面；build.nvidia.com 上由 Blackwell GPU 提供免费调用接口，也可打包成 NIM 微服务部署，用 NeMo Automodel 做监督微调或 LoRA。
评分依据：内容是超大模型的云端托管与调用教程，端侧相关度低；混合线性注意力与高稀疏度 MoE 的架构信息对关注高效模型设计的读者有一定参考。
