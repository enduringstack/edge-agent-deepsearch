Build Specialized Agents on a Stack You Control with NVIDIA NemoClaw

13 官方动态 开源 2026-10-30 · NVIDIA / NVIDIA
NVIDIA方向:端侧agent方向:记忆方向:工具调用方向:安全隐私硬件:DGX硬件:GPU
这是什么英伟达说明 NemoClaw 开放蓝图如何把智能体框架、Nemotron 模型、NeMo 优化工具和 OpenShell 安全运行时组合成一套可自己掌控的智能体栈，可部署在云、数据中心，也可跑在 DGX Spark 和 RTX 个人电脑上。
有什么结果LangChain 为 Nemotron 3 Ultra 调优 Deep Agents 框架后，在不重训模型的情况下达到接近前沿模型的效果，每次运行成本约为领先闭源模型的十分之一。
怎么做到蓝图不替代现有框架，而是在 OpenClaw、Hermes Agent 或 LangChain Deep Agents 之上补齐调优过的模型配置、NeMo Relay 执行追踪和路由，以及管控文件、网络、凭证和工具访问的 OpenShell 运行时；示例是带持久记忆的“幕僚长”智能体。
评分依据：原文明确 NemoClaw 智能体可在 DGX Spark 和 RTX 个人电脑本地运行，OpenClaw 本身在用户自己的机器上维护会话、记忆和定时任务，属于本地智能体基础设施；本文以架构说明为主，新增技术细节不多。
