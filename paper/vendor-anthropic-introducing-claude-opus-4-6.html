Introducing Claude Opus 4.6

9 官方动态 2026-02-05 · Anthropic / Anthropic
Anthropic方向:规划推理应用:代码应用:长上下文推理
这是什么Anthropic 发布旗舰模型 Claude Opus 4.6，主打更强的编程与长时间智能体任务能力，并首次在 Opus 系列提供 100 万 token 上下文窗口（测试版）。
有什么结果在智能体编程评测 Terminal-Bench 2.0 上取得最高分，在 Humanity's Last Exam 和 BrowseComp 上领先；在知识工作评测 GDPval-AA 上比 OpenAI GPT-5.2 高约 144 Elo，比上一代 Opus 4.5 高 190 Elo。
怎么做到模型层面提升规划、长程任务和代码审查能力；配套推出 Claude Code 的智能体团队、API 端的上下文压缩（让模型自己总结上下文以延长任务）、自适应思考和推理力度控制，并更新 Excel 与 PowerPoint 插件。
评分依据：云端闭源前沿模型，与端侧部署无直接关系，只在智能体能力和长上下文管理上有间接参考。作为头部厂商的旗舰模型升级，在多项智能体评测上刷新最好成绩，贡献较高。
