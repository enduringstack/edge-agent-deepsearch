Repo launch: MiniCPM-Robot (On-Device AI Brain for Robots)

14 开源大项目 开源 2026-07-18 · OpenBMB / GitHub
应用:机器人方向:多模态模型:MiniCPM方向:高效推理
这是什么面壁 OpenBMB 开源机器人模型家族 MiniCPM-Robot，首发 1.5B 通用操作模型 MiniCPM-RobotManip 和 0.9B 端侧目标跟随模型 MiniCPM-RobotTrack。
有什么结果RobotManip 以 1.5B 参数在 RoboTwin2 上拿到 91.3/91.6，超过 3B 的 π0.5（82.7/76.8）；60 帧历史下流式推理每步只需 3.3 TFLOPs（重算需 125 TFLOPs）。RobotTrack 在宇树 Go2 EDU 机载算力上完全本地运行，5 帧/秒以上、端到端约 180 毫秒。
怎么做到操作模型沿用 MiniCPM-V 4.6 的视觉 token 压缩（每帧 256 压到 64），并用流式上下文复用历史帧；跟随模型基于 MiniCPM4-0.5B，从图像采集到下发控制指令整条链路针对 Go2 联合优化。
评分依据：跟随模型在四足机器人机载算力上真机本地运行，端侧相关度高；两款都是视觉-语言-动作策略，没有规划或工具闭环，属于端侧具身模型而非端侧 Agent。GitHub 仓库不能作为机构证据，未标公司归属。
