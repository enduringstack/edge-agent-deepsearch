Measuring AI agent autonomy in practice

9 官方动态 2026-02-18 · Anthropic / Anthropic
Anthropic方向:安全隐私方向:工具调用方向:评测基准应用:代码
这是什么Anthropic 用隐私保护分析工具统计了数百万次真实人机交互，研究人们实际给智能体多大自主权、这种放权如何随经验变化、智能体的动作风险有多高。
有什么结果最长的 Claude Code 会话里，智能体自主工作时长三个月内从不到 25 分钟增至 45 分钟以上；新用户约 20% 的会话全程自动批准，有经验后升到 40% 以上；在最复杂任务上，智能体主动停下来求澄清的次数是人类打断次数的两倍多；公开 API 上约一半的智能体活动是软件工程。
怎么做到以“带工具、能执行动作”定义智能体：公开 API 按单次工具调用分析风险和领域，Claude Code 则能串起整个会话，用来衡量自主时长、打断和批准行为。
评分依据：对智能体监督与授权设计有实证价值，可借鉴到端侧智能体的权限机制；但数据来自云端产品，不涉及设备端运行。
