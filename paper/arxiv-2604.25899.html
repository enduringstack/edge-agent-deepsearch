Pythia: Exploiting Workflow Predictability for Efficient Agent-Native LLM Serving

9 公司项目 2026-04-28 · Shan Yu; Junyi Shu; Yuanjiang Ni; Kun Qian; Xue Li; Yang Wang; Jinyuan Zhang; Ziyi Xu / arXiv
Alibaba; Intel方向:云端serving方向:调度服务方向:KV cache
这是什么面向多 Agent 应用的大模型服务系统：利用 Agent 工作流结构可预测的特点，让服务层提前做缓存、调度和扩缩容。
有什么结果基于 SGLang 实现，在代表性多 Agent 应用上平均任务完成时间最多缩短 2.9 倍，吞吐提升 1.96 倍。
怎么做到通过一个简单接口把工作流语义告诉服务层，据此提升前缀缓存命中、缓解长上下文请求造成的资源争抢，并按工作流预判提前扩缩容。
评分依据：面向数据中心的 Agent 服务，属于云端 serving；分析来自真实 Agent 平台与内部编码助手的生产轨迹，思路有新意。PDF 首页机构列表含 Alibaba Cloud Computing、Alibaba Group 和 Intel，对应作者均有署名。 作者机构依据：arXiv PDF 首页署名 Alibaba, Intel（PDF 首页机构列表：2 Alibaba Cloud Computing、3 Alibaba Group（多位作者）、4 Intel（作者 Yang Wang））。
