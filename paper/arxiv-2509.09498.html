SEDM: Selective Self-Evolving Distributed Memory for Agents

10 公司项目 2026-10-14 · Yichen Liu; Anna Min; Yinzhi Wang; Yuhang Yao; Yichen Han; Rui Zhang; Jiantao He; Zhiheng Li / arXiv
Amazon方向:记忆方向:评测基准
这是什么SEDM：多智能体之间共享经验记忆的框架，同时决定“哪些记忆值得分享”和“接收方什么时候该用”，避免乱塞记忆反而拖累任务。
有什么结果在 LoCoMo 开放域问答上比最强基线高 15.1 个 F1；在 FEVER 和 HotpotQA 上超过 G-Memory，同时少用 16%-32% 的提示词 token；校准记忆门控在 HotpotQA 上以少 18% 输入 token 达到与“总是用记忆”相当的成功率。
怎么做到发送端用成对执行测试筛选记忆，按相关性和实测效用排序并抽象成可跨领域复用的形式；接收端的校准记忆门控一次前向同时预测“用与不用记忆”的成功率，只在收益超过上下文成本时才注入。
评分依据：智能体记忆管理与上下文成本控制对端侧 Agent 的有限上下文有直接借鉴价值，但实验在云端模型上完成；“按需注入记忆”的门控设计比常见检索式记忆更进一步。 作者机构依据：arXiv PDF 首页署名 Amazon（论文首页作者 Yuxin Tang 署名 Amazon AGI Foundations）。
