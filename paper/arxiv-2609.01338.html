mzCache: On-Device LLM Memory Management under Multitasking

18 学校顶会 2026-09-01 · Hongseung Yu; Minsung Kim; Jongseok Park; Kyunghan Lee / MobiCom 2026
方向:推理框架方向:KV cache方向:高效推理硬件:手机硬件:GPU
这是什么手机上跑大模型时，系统内存一紧张就会把模型权重和 KV cache 踢出去；mzCache 是一套专门应对手机多任务切换的端侧大模型推理内存管理系统。
有什么结果相比把数据放存储里做部分卸载的做法，首个 token 的等待时间缩短 2.1 到 5.5 倍；真实多任务切换场景里能保住用户上下文，而基线会被系统杀掉并丢失上下文。
怎么做到把模型内存切成细粒度共享缓冲区，支持部分换出和部分恢复；再利用手机 SoC 的统一内存让 GPU 边算、CPU 边并发恢复，配合混合交换和倒序换出策略压低任何换出状态下的恢复延迟。
评分依据：问题和方案都长在手机上：针对安卓多任务内存压力做端侧大模型内存治理，并在真机上实测首 token 时延，端侧契合度满分。把内存管理从整块换出改成细粒度共享缓冲区加并发恢复，是系统层面的实质创新，已被 MobiCom 2026 接收。
