Formally verifying agent-written full-stack web apps with PDD Kit

6 官方动态 2026-11-05 · Microsoft / Microsoft
Microsoft方向:安全隐私应用:代码
这是什么微软研究院推出 PDD Kit 原型，把开发者的意图变成 Verus 形式化规约，再自动证明编程智能体写出的 Rust 代码对所有输入都满足规约，证不到的部分退回用测试检查。
有什么结果在约 5000 行的 Rust 全栈示例商店的登录逻辑上，两句话的需求被转成 8 条规约，证明覆盖 5 个函数、6 处仍靠测试兜底，并发现了已有缺陷（未给出数量）；小模块的验证通常几秒完成。
怎么做到先和开发者一起把需求写成机器可检查的规约，再让智能体生成代码和证明，由不依赖模型的 Verus 确定性地检查；它作为伙伴嵌在 GitHub Next 的 Chopin 规划环境里。
评分依据：这是编程智能体输出的可靠性验证，与端侧部署无关；把形式化证明接进智能体编码流程的思路有新意，但仍是研究原型、量化结果有限。
