LongMemEval-V2: Evaluating Long-Term Agent Memory Toward Experienced Colleagues

8 学校预印本 2026-05-12 · Di Wu; Zixiang Ji; Asmi Kawatkar; Bryan Kwan; Jia-Chen Gu; Nanyun Peng; Kai-Wei Chang / arXiv
方向:记忆方向:评测基准应用:RAG
这是什么一个检验 Agent 长期记忆的新基准：看记忆系统能不能从过往操作轨迹里学到某个网页环境的界面状态、工作流程和坑，像老同事一样有经验。
有什么结果AgentRunbook-C 平均准确率 72.5%，高于最强 RAG 基线的 48.5% 和现成编程 Agent 基线的 69.3%，但编程 Agent 类方法时延很高。
怎么做到收集 451 道人工标注问题，配上最多 500 条、共 1.15 亿 token 的历史轨迹；同时给出两种记忆方案：一种是分池存储的 RAG 记忆，另一种把轨迹存成文件、让编程 Agent 在沙箱里自己翻找证据。
评分依据：研究的是网页 Agent 的长期记忆评测，记忆机制对端侧 Agent 有参考价值，但实验全在云端大模型上，没有设备侧考虑；贡献主要是新基准和两个基线方法。
