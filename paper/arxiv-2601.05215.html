MineNPC-Task: Task Suite for Memory-Aware Minecraft Agents

6 公司项目 开源 2026-01-08 · Tamil Sudaravan Mohan Doss; Michael Xu; Sudha Rao; Andrew D. Wilson; Balasaravanan Thoravi Kumaravel / arXiv
Microsoft方向:评测基准方向:记忆方向:规划推理模型:GPT
这是什么微软研究院做的 Minecraft 智能体评测套件，任务来自真人玩家，专门测试带记忆、能和人互相澄清的大模型智能体。
有什么结果用 GPT-4o 与 8 名资深玩家完成 44 个任务、216 个子任务，其中 71 个失败（约 33%），失败集中在代码执行、物品与工具处理、指代和导航。
怎么做到通过与专家共同游戏收集任务，归一化为带前置条件和依赖结构的参数化模板，配合只依据游戏内证据的自动校验器，记录计划、行动和记忆读写事件。
评分依据：游戏内云端智能体的评测基准，与端侧部署无关（相关度 2）；以真人任务和记忆事件记录为特色（贡献 4）。PDF 首页作者均署名 Microsoft / Microsoft Research。 作者机构依据：arXiv PDF 首页署名 Microsoft（HTML/PDF 首页全部作者署名 Microsoft / Microsoft Research，邮箱为 microsoft.com）。
