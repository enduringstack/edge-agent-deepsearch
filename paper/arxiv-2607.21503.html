Agentic Context Management: Solving Agent Memory and Cost by Treating Them as Lifecycle and Architecture Problems

8 学校预印本 2026-07-27 · Gaurav Dadhich / arXiv
方向:记忆应用:长上下文推理
这是什么生产环境的智能体常常不是不会推理，而是管不好上下文：历史越积越长、工具输出越来越大、token 成本逐轮上涨。作者把这件事定义为“智能体上下文管理”，当作完整生命周期来设计。
有什么结果作者的参考实现 Maximem Synap 在 LongMemEval 上达到 92%，在 LoCoMo 上达到 93.2%；论文分析称简单累积上下文的 token 成本随对话长度呈平方增长，只有经验证的压缩能做到线性成本且不掉精度。
怎么做到把上下文管理拆成五个基本环节：架构设计、信息摄入、作用域划分、预判下一步所需、压缩与整合，覆盖记什么、怎么结构化、存到哪、何时遗忘并保留出处，并在组织层级的多租户服务中实现。
评分依据：智能体记忆与上下文压缩属于可迁移到资源受限场景的运行时技术，但方案是云端多租户服务，相关度 4；以框架梳理为主，评测来自作者自家产品，贡献 4。公司归属依据 arXiv PDF 首页脚注：作者单位 Maximem，邮箱为 maximem.ai。
