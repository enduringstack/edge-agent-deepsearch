NVIDIA, Microsoft Kick Off a New Beginning for Windows PCs With RTX Spark and AI Agents

13 官方动态 2026-10-07 · NVIDIA / NVIDIA
NVIDIA硬件:GPU硬件:CPU硬件:DGX方向:量化模型:Qwen
这是什么微软 Windows AI 与 Surface 发布会上，NVIDIA 与微软联合推出面向本地 AI 和常驻 Agent 的 Windows PC 平台 RTX Spark，并宣布微软执行容器（MXC）正式可用，让 Agent 在系统管控下安全地在后台持续运行。
有什么结果RTX Spark 集成最多 6144 核的 Blackwell RTX GPU 和最多 20 核 Grace CPU，CPU 与 GPU 之间带宽 600 GB/s，FP4 算力 1 PFLOPS，统一内存最高 128GB，可在本地运行 125B 的 Qwen 3.8 Flash Next；笔记本 10 月 16 日上市，小型台式机 11 月开售。同时预览的 DGX Station for Windows 有 748GB 一致性内存、最高 20 PFLOPS FP4 算力。
怎么做到把 Grace CPU 与 Blackwell GPU 做成统一内存的 PC 级平台，配合第五代 Tensor Core 的 NVFP4 低精度推理，让百亿到千亿参数级模型不上云也能在本机运行；小型台式机按 7×24 小时常驻 Agent 设计，Agent 的权限边界交给 MXC 管控。
评分依据：明确面向 PC 本地大模型推理和常驻 Agent 的硬件平台，端侧相关度 8。正文以硬件规格和上市信息为主，没有点名具体在本机运行的 Agent 闭环，因此按端侧硬件平台而不是端侧 Agent 归类；贡献给 5。
