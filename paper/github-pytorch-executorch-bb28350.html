pytorch/executorch: Vulkan: support Linux/Windows desktop GPUs and opt-in wheel builds (#20138)

14 开源大项目 开源 2026-06-25 · pytorch / GitHub
方向:推理框架方向:编译部署方向:高效推理硬件:GPU
这是什么ExecuTorch 的 Vulkan 后端从只服务安卓，扩展到 Linux 和 Windows 桌面显卡。
有什么结果本次提交改动 26 个文件、新增 747 行；新增了真实 NVIDIA 显卡和 Windows MSVC 构建的持续集成覆盖，并在 A100 上做过验证。
怎么做到构建侧补上 Windows 和 Linux 下通过 glslc 编译着色器的支持、修正 MSVC 与 GCC/Clang 的编译选项，并按 Vulkan 1.3 编译协作矩阵着色器；运行时侧打开着色器真正用到的 int16、int64、float64 设备特性，优先选独立显卡而非集成显卡，修掉仅计算队列上的图像拷贝问题和缓冲区大小校验；打包侧则在一个编译开关后面让 wheel 可以带上 Vulkan 二进制，默认 wheel 不受影响。所有改动都用平台和编译器判断包起来，安卓行为保持不变。
评分依据：ExecuTorch 是端侧部署主力框架，把 Vulkan 后端从安卓推广到桌面显卡，等于让同一套端侧图在 PC 上也能跑通，端侧契合度高；改动覆盖编译、运行时特性开关到打包与持续集成，是完整的一块后端能力落地。
