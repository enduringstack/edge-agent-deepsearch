Learning by Doing: Autonomously Compiling and Curating Agent Skills from Verified Traces

8 学校预印本 2026-11-01 · Daniel Chalef; Peter Evans; Pavlo Paliychuk; Mehul Patel; Preston Rasmussen; Jack Ryan / arXiv
方向:记忆方向:工具调用
这是什么Zep Agent Skills 是一个线上服务，把 Agent 执行成功并经过验证的过程自动整理成可复用的“技能”，给部署中的 Agent 提供程序性记忆。
有什么结果在 τ³-bench 银行、AppWorld 和 EnterpriseOps-Gym 上，用强模型轨迹编译出的技能让三个较弱执行模型通过率提升 4.5-18.8 个百分点；在 ALFWorld 上，用小模型自身轨迹编译的技能带来的提升与持续微调相当或更大，且无需训练。
怎么做到把每次任务尝试记录为带事件、结果和验证强度的轨迹，由“反思者”和“整理者”两个角色编译成带版本的技能，经扫描和准入门控后上线，按实际使用效果调整检索排序，通过 API 或 MCP 提供给 Agent。
评分依据：Agent 程序性记忆服务部署在云端，与端侧关系间接（相关度 3）；只用已验证轨迹并带证据引用和版本治理，工程完整度高（贡献 5）。作者来自初创公司 Zep AI，不在公司归属名单内，未填公司。
