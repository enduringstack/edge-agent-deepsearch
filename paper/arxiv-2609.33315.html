AgentLoop: Runtime Control of Slot-closed Execution Loops for Tool-augmented LLM Agents

9 学校预印本 2026-09-27 · Wanyi Zheng; Minxian Xu; Kan Hu; Kejiang Ye; Chengzhong Xu / arXiv
方向:工具调用方向:规划推理方向:高效推理模型:Qwen模型:Llama
这是什么带工具的大模型智能体经常在信息已经收集够了之后还继续推理、继续调用服务，白白消耗 token。AgentLoop 给智能体的执行循环加了一个运行时控制器，判断什么时候该继续调用、什么时候该汇总作答、什么时候该停下。
有什么结果与基线相比，总 token 开销最多降低 88.44%，平均服务调用次数最多减少 76.85%；消融实验显示，去掉以“信息槽”为中心的控制路径后执行轮数变多、准确率明显下降。
怎么做到把一个请求需要的信息拆成若干“槽位”，维护一个紧凑的运行时状态，用模型辅助的结构化校验检查答案是否完整、还缺哪些证据，再结合相邻几轮的稳定性和低增益信号，在“继续调用、汇总作答、终止迭代”三个动作里选一个。
评分依据：工作针对工具调用型智能体执行循环的开销，减少 token 和调用次数的思路可以迁移到资源受限设备上的智能体运行时，但实验面向服务计算场景、没有设备端评测，相关度 4。用槽位覆盖来判断何时停止是实用的运行时控制设计，贡献 5。
