DataFlow-Harness: A Grounded Code-Agent Platform for Constructing Editable LLM Data Pipelines

7 学校预印本 2026-07-22 · Runming He, Zhen Hao Wong, Hao Liang, Zimo Meng, Chengyu Shen, Xiaochen Ma, Wentao Zhang / arXiv
方向:工具调用应用:代码
这是什么用编程智能体自动搭数据处理流程时，生成的往往是一次性脚本，难以在平台上继续编辑。DataFlow-Harness 让大模型智能体直接在平台里一步步构建可视化、可编辑的数据流水线。
有什么结果在 12 个数据工程任务上端到端通过率 93.3%；相比原版 Claude Code 花费降低 72.5%、生成时延降低 49.9%；与带上下文的 Claude Code 通过率仅差 0.9 个百分点，成本低 42.8%。
怎么做到把平台算子注册表和当前流水线状态通过 MCP 暴露给智能体，配合流程技能说明，让智能体以带类型的增量修改来编辑有向无环图，并与可视化编辑器实时同步。
评分依据：属于云端编程智能体的工具调用平台，与设备端执行无关，相关度低；用 MCP 把智能体输出落到平台原生对象上的做法有一定工程价值。
