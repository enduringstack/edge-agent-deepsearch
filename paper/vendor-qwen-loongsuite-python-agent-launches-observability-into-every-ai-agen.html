LoongSuite Python Agent Launches: Observability Into Every AI Agent Action, Zero-code Integration

6 官方动态 开源 2026-04-09 · Qwen / Qwen

这是什么阿里云发布 LoongSuite Python Agent，这是它基于 OpenTelemetry 的发行版，不改代码就能记录 AI 应用每一步调用了哪个模型、哪些工具、检索了哪些文档。
有什么结果未报告
怎么做到通过自动插桩接入 DashScope、LangChain、MCP 等常见框架，新增调用智能体、执行工具、检索、重排、向量化、记忆等 7 类调用链节点，并记录 token 消耗和多智能体流水线中上下文的演变。
评分依据：面向云端 AI 应用和多智能体流水线的可观测工具，与端侧部署关系很弱，只对智能体运行时调试有参考；属于工程整合，正文没有性能开销等数据。
