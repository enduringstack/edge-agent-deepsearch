Memory as Middleware for Self-Improving AI Agents

9 公司项目 开源 2026-09-25 · K. R. Jayaram; Vatche Isahagian; Vinod Muthusamy; Gegi Thomas; Punleuk Oum; Gaodan Fang; Ashwath Vaithinathan Aravindan / Middleware 2026（有条件接收）
IBM方向:记忆方向:工具调用方向:安全隐私
这是什么现在的 AI 智能体每次会话都从零开始，记忆功能又各自手写、绑死在一个智能体和一种存储上。IBM 研究院主张把智能体记忆做成可插拔的中间件层，并给出参考实现 altk-evolve。
有什么结果在 AppWorld 多步任务基准上，加入记忆中间件后单任务完成率从 69.6% 升到 73.2%，整组场景完成率从 50.0% 升到 64.3%，困难档场景完成率从 19.1% 升到 47.6%；同一记忆层无需修改即可接入 Claude Code、Codex、Claw Code 和 IBM Bob 四种编程智能体。
怎么做到altk-evolve 捕获智能体执行轨迹，提炼成可复用的经验准则，再通过钩子、MCP 和技能等宿主原生接口注入；文章围绕双向可插拔、宿主原生接入、多租户隔离、写入一致性、带溯源的共享和生命周期治理六个系统问题提出研究议程。
评分依据：讨论的是云端软件智能体的记忆基础设施，属于 Agent 记忆运行时，端侧只能借鉴其接口设计。把记忆抽象成中间件并在四种宿主上验证可移植性，是有系统视角的贡献，论文已获 Middleware 2026 有条件接收。公司归属依据 PDF 首页全部作者署名 IBM Research。 作者机构依据：arXiv PDF 首页署名 IBM（PDF 首页全部 7 位作者署名 IBM Research, USA）。
