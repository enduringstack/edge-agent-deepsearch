ParetoBandit: Budget-Paced Adaptive Routing for Non-Stationary LLM Serving

7 学校预印本 开源 2026-03-31 · Annette Taberner-Miller / arXiv
方向:云端serving方向:调度服务
这是什么多家大模型 API 混用时，价格和质量随时会变，这个路由器在给定每次请求的美元预算下，自动决定把请求交给哪个模型。
有什么结果在 1824 条基准提示、三模型组合上，预算偏差控制在 0.4% 以内；价格或质量变化时质量最多提升 0.071；新模型约 142 步完成冷启动接入；路由本身在单个 CPU 核上每次约 43 微秒。
怎么做到把模型选择当成带成本的上下文多臂老虎机：用在线原始-对偶方法控制花费，再给统计量加几何遗忘，让它能跟上价格和质量的漂移，并支持运行时热插拔新模型。
评分依据：这是面向云端多模型 API 的成本路由，与端侧部署关系很弱；在线预算控制和漂移适应做得完整，属于有用的工程方法。
