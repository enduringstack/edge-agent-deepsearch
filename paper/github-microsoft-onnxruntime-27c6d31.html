microsoft/onnxruntime: Model Package Support (Phase 2) (#28271)

14 开源大项目 开源 2026-06-04 · microsoft / GitHub
方向:推理框架方向:编译部署方向:高效推理
这是什么ONNX Runtime 合入模型包功能的第二阶段：把面向不同执行后端的多个模型变体打成一个带元数据的包，运行时自动挑合适的那个。
有什么结果本次提交改动 33 个文件、新增 5220 行；把解析逻辑抽成一个不依赖 ONNX Runtime 的独立 C 库，新增基于虚表的模型包 C 接口，并补充了查询与遍历接口、安全与正确性加固。
怎么做到新增一个自包含的 model_package C 库负责解析清单、元数据和变体描述文件，ONNX Runtime 以静态库方式链接并直接使用其内部 C++ 类型以避免二次封装开销，公开的 C 接口留给外部使用方。
评分依据：同一个模型为不同执行后端准备多个变体、运行时自动选型，正是端侧设备硬件碎片化场景下的刚需（相关性 8）。把解析器拆成可独立复用的库并稳定接口，是推理框架层面的实质改动（贡献 6）。
