Why Cognitive Robotics Matters: Lessons from OntoAgent and LLM Deployment in HARMONIC for Safety-Critical Robot Teaming

7 学校预印本 2026-03-20 · Sanjay Oruganti; Sergei Nirenburg; Marjorie McShane; Jesse English; Michael Roberts; Christian Arndt; Ramviyas Parasuraman; Luis Sentis / arXiv
应用:机器人方向:规划推理方向:工具调用
这是什么在协作维修机器人系统里，把基于本体知识的认知架构换成大模型做决策，检验大模型能否胜任安全关键的长程规划。
有什么结果论文报告大模型在行动前不会稳定地评估自身知识状态，导致诊断推理和动作选择出错，即使给了同等的流程知识缺陷依旧存在；摘要未给具体数字。
怎么做到在 HARMONIC 架构中用六个前沿和高效级大模型（通过云端 API 调用）替换 OntoAgent，在原生和知识对齐两种条件下对比。
评分依据：机器人智能体规划研究，但大模型全部经云端 API 调用，没有设备端执行；价值在于指出纯大模型规划在安全关键场景的结构性缺陷。
