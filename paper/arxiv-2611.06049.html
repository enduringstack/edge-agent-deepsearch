Reglos: A Self-Evolving Personal Memory Agent with Recursive Self-Improvement

9 学校预印本 2026-11-04 · Sen Yang; Jiaduo Lin; Zehong Huang; Wen Liu / arXiv
方向:记忆方向:规划推理模型:Qwen模型:GPT
这是什么个人助理型 Agent 需要记住每个用户说过什么。Reglos 是一个无需训练的个人记忆 Agent，它的记忆会随对话自我更新，而把记忆变成模型上下文的那套程序也能自动改进。
有什么结果在同一底座模型下超过 Mem0、MemOS、EverOS 等记忆系统：用 Qwen3.8-27B 时在 PersonaMem-v2 和 LongMemEval-S 上分别为 61.3% 和 84.0%，用 GPT-5.6 Luna 时为 57.5% 和 87.2%。
怎么做到记忆按用户只追加记录，新偏好覆盖旧偏好、事实可以被遗忘；编码 Agent 根据失败轨迹提出改进补丁，由另一家族的模型担任评审筛掉刷榜补丁，冻结后再由固定评估器决定是否接受新补丁。
评分依据：属于 Agent 记忆运行时，可迁移到端侧个人助理，但实验全部基于云端 API 和服务器部署的模型，没有设备端证据（相关度 4）。防过拟合的递归自改进流程有一定新意（贡献 5）。作者来自初创公司 Reglos.ai，不在公司名单内，公司归属留空。
