Beyond MACs: Hardware Efficient Architecture Design for Vision Backbones

13 学校预印本 2026-03-27 · Moritz Nottebaum; Matteo Dunnhofer; Christian Micheloni / IJCV
方向:模型架构方向:高效注意力硬件:Jetson硬件:CPU硬件:GPU
这是什么论文指出用乘加次数衡量视觉模型快慢在边缘设备上并不靠谱，并据此设计了真正跑得快的视觉骨干 LowFormer。
有什么结果LowFormer-B0 与 EfficientMod-xs 准确率相当但吞吐翻倍、Jetson TX2 时延减半、ARM CPU 上快 38%；LowFormer-B3 与 FastViT-SA36 准确率相同，GPU 吞吐近 3 倍，TX2 上快 36%，ARM CPU 上快 67%。
怎么做到对比常见模块的乘加次数和实际执行时间，得出少用深度卷积、融合 MBConv、降低注意力分辨率等设计原则，并提出轻量注意力 Lowtention 替代多头自注意力，另有针对边缘 GPU 的版本。
评分依据：在 Jetson TX2 和 ARM CPU 等端侧硬件上实测速度，结论对端侧视觉模型设计有直接指导意义；已被 IJCV 期刊接收，不在本刊顶会名单内。
