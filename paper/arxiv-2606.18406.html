CoreMem: Riemannian Retrieval and Fisher-Guided Distillation for Long-Term Memory in Dialogue Agents

14 学校预印本 2026-06-16 · Jiaqi Chen; Yongqin Zeng; Shaoshen Chen; Yijian Zhang; Hai-Tao Zheng; Chunxia Ma; XiuTeng Zhou / arXiv
方向:端侧agent方向:记忆方向:端云协同硬件:GPU模型:SmolLM
这是什么个性化对话助手要跨多轮长期记住用户，但放到只有 8GB 显存的消费级设备上，记忆检索和上下文压缩都吃不消；这篇用信息几何重做这两步。
有什么结果在 LOCOMO 和 LongMemEval-S 上，开放域推理提升 4.51 个百分点、时序推理提升 4.17 个百分点；本地编码器加压缩模型峰值显存仅 3.2GB，压缩测试中 SmolLM2 版压缩率 67.4% 且准确率最高（0.9756），整体约省 20% 云端 API 费用。
怎么做到本地设备负责记忆的检索与压缩：检索把余弦相似度换成局部自适应的 Fisher-Rao 度量以压制枢纽记忆，并用 Woodbury 公式加速；压缩由 Fisher 信息引导，避免摘要把句子切碎；只把压缩后的上下文发给云端大模型。
评分依据：论文把 8GB 显存的消费级设备作为部署目标，在笔记本 GPU 上实测，智能体的长期记忆闭环就在本地运行，端侧语境确凿。用信息几何统一检索与压缩、并给出实时可行的加速方案，思路较新，贡献中等偏上。
