Strengthening Windows trust and security through User Transparency and Consent

9 官方动态 2026-02-09 · Microsoft / Microsoft
Microsoft方向:安全隐私
这是什么微软宣布 Windows 11 将推出“基线安全模式”和“用户透明与同意”机制：像手机一样，应用和 AI Agent 访问文件、摄像头、麦克风等敏感资源时要弹窗征得用户同意，行为也要对用户和管理员可见。
有什么结果未报告
怎么做到基线安全模式默认只允许签名正确的应用、服务和驱动运行，并允许用户或管理员为特定应用设例外；透明与同意机制统一权限弹窗、支持随时撤销授权，并为开发者提供配套工具和 API，分阶段推出。
评分依据：这是 PC 操作系统层面对本机应用和 AI Agent 权限的治理，会直接影响未来在 Windows 上运行的端侧 Agent，但文中没有具体 Agent 运行闭环，故不算端侧 Agent。属于平台政策与方向发布，没有量化数据。
