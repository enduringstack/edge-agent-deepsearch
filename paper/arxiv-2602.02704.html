InfMem: Learning System-2 Memory Control for Long-Context Agent

11 公司项目 开源 2026-02-02 · Xinyu Wang; Mingze Li; Peng Lu; Xiao-Wen Chang; Lifeng Shang; Jinping Li; Fei Mi; Prasanna Parthasarathi / COLM 2026
Huawei方向:记忆应用:长上下文推理方向:规划推理模型:Qwen
这是什么超长文档推理需要在有限记忆里保留零散证据，现有流式智能体被动更新记忆，容易丢掉多跳推理所需的桥接证据。InfMem 让智能体主动判断证据够不够、主动检索并压缩记忆。
有什么结果在 32K 到 1M token 的超长问答上，相比 MemAgent 平均准确率在 Qwen3-1.7B、Qwen3-4B、Qwen2.5-7B 上分别提升 10.17、11.84、8.23 个点，推理时间平均缩短 3.9 倍、最多 5.1 倍。
怎么做到采用“先思考、再检索、再写入”的流程：监控证据是否充足，有针对性地在文档内检索，联合压缩更新有界记忆；再用先监督微调后强化学习的方式训练检索、写入和停止决策。
