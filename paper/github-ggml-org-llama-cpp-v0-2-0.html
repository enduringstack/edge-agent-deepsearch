怎么做到发布分成两条线：vX.Y.Z 标签是节奏较慢的稳定版，推荐给下游分发和普通用户；原有的 b[NUM] 标签照旧几乎每次提交都打，作为功能最新但可能不稳的开发版。本版同时汇总了自 v0.1.2 以来的改动，包括 KleidiAI SME2 GEMV 内核、Adreno OpenCL 修复、Hexagon 后端 Flash Attention 队列修正等。
评分依据：llama.cpp 是端侧本地推理的主力引擎，稳定版本体系直接影响手机、PC 上下游应用如何选版本，端侧相关度高；本身是发布流程改进，不含新的推理算法，贡献分中等偏低。
