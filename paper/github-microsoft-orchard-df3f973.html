microsoft/Orchard: Orchard: an open foundation for agentic modeling research

6 开源大项目 开源 2026-07-30 · microsoft / GitHub
方向:评测基准方向:工具调用应用:代码
这是什么微软开源的智能体建模研究平台 Orchard 首次公开发布，提供在 Kubernetes 上批量管理沙箱容器的环境服务和 Python SDK，用于智能体的强化学习训练与评测。
有什么结果未报告
怎么做到用 FastAPI 编排器统一管理 Kubernetes 沙箱 Pod，并通过初始化容器向每个 Pod 注入自带解释器的轻量代理，命令执行和文件读写直接走 Pod IP，不经过 Kubernetes API 服务器；仓库同时预留强化学习训练栈目录，并附论文与数据集链接。
评分依据：这是在云端集群上训练和评测智能体的基础设施，智能体闭环不在手机或电脑本地运行，端侧相关度低；价值在于把大规模沙箱环境做成可复用的开源服务，属于工程整合。
