GhostServe: A Lightweight Checkpointing System in the Shadow for Fault-Tolerant LLM Serving

8 学校预印本 2026-03-26 · Shakya Jayakody; Youpeng Zhao; Chinmay Dhanraj Nehate; Jun Wang / MLSys 2026
方向:云端serving方向:KV cache硬件:GPU
这是什么百万 token 级的长任务推理一旦遇到硬件故障，GPU 上的 KV cache 丢失就得从头重算。GhostServe 在后台给 KV cache 做纠删码备份，故障后能快速恢复。
有什么结果与现有方法相比，单批次检查点时延最多降低 2.7 倍、恢复时延降低 2.1 倍，在有系统故障的情况下中位响应时延降低 1.2 倍。
怎么做到把 KV cache 按整数视角做纠删码编码，用定制 GPU 内核生成校验分片并存到主机内存；设备故障时用校验分片重建丢失的 KV cache，无需全量重算或整份复制，可作为插件接入 vLLM 等引擎。
评分依据：面向分布式 GPU 集群的容错 serving，与端侧部署关系较弱。用纠删码保护流式 KV cache 的思路较新，已被 MLSys 2026 接收，但该会议不在本栏目的顶会口径内。
