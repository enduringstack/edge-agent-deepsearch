SkCC: Portable and Secure Skill Compilation for Cross-Framework LLM Agents

9 学校预印本 开源 2026-05-05 · Yipeng Ouyang; Yi Xiao; Yuhao Gu; Xianwei Zhang / ACM CAIS 2026 Agent Skills Workshop
方向:工具调用方向:安全隐私方向:编译部署
这是什么Agent 的技能文件换一个框架就要重写，还常有安全漏洞。这篇把技能当程序来编译：先转成统一的中间表示，再针对不同 Agent 框架生成格式并做安全检查。
有什么结果在 SkillsBench 上，Claude Code 的通过率从 21.1% 提到 33.3%，Kimi CLI 从 35.1% 提到 48.7%；编译延迟低于 10 毫秒，主动安全拦截触发率 94.8%，运行时词元节省 10%–46%。
怎么做到设计强类型的技能中间表示，把技能语义和框架格式解耦，再由静态优化器在部署前检查安全约束，适配复杂度从技能数乘框架数降到两者相加。
评分依据：针对 Agent 技能的可移植与安全编译，属于 Agent 运行时工程，但实验对象是云端编程 Agent，与端侧关系较远。
