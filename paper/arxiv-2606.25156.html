ATMA: Long-Context Language Modeling via Polar Attention and Gated-Delta Compression Memory

11 学校预印本 开源 2026-06-23 · Habibullah Akbar / arXiv
方向:模型架构方向:高效注意力方向:记忆应用:长上下文推理
这是什么一个 3.78 亿参数的长上下文语言模型配方，把新型注意力和带门控的压缩记忆结合起来。
有什么结果在 20 组配对实验里，加记忆让 Polar 注意力的 64K 检索分全部提升，平均高出 47.8 分；在 256K 上下文下保留 34.4% 的教师强制目标 token 准确率和 9.0% 的五连 token 精确准确率，合成上下文精确检索 18.0%、FinePDFs 上下文为 0.0%；固定目标的每字节比特数平均退化控制在 1.26 倍。
怎么做到Polar 注意力把归一化的方向通道和有界的参与度幅值通道拆开，再搭配带门控增量的循环记忆；配方通过一次完整的 120 格、10 亿 token 因子扫描选出，然后把 NoPE、RoPE 和 Polar 三个变体在 2K 长度上各训 98.16 亿 token，再一路评测到 256K。
评分依据：模型只有 378M、显式把推理开销列为优化目标之一，这个规模和长上下文压缩记忆对端侧部署有直接迁移价值，但原文未做设备实测，相关度按可迁移工作计；用帕累托视角而非单点夸胜的实证方式扎实，架构设计也有新意。
