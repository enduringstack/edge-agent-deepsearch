Deploy Agentic-Ready AI at the Edge with Memory Efficiency in NVIDIA JetPack 7.2

15 官方动态 2026-06-01 · NVIDIA / NVIDIA
NVIDIA方向:端侧agent方向:编译部署方向:调度服务硬件:Jetson应用:机器人
这是什么英伟达 JetPack 7.2 让 Jetson 开箱即可部署智能体框架 NemoClaw，并围绕内存效率做了一批改进。
有什么结果支持一条命令部署 NemoClaw；新增面向 Jetson 的智能体技能，用可被智能体执行的指令自动完成 Linux 定制、内存优化和模型基准测试；Jetson Thor 支持多实例 GPU，可把 Blackwell GPU 切成两个隔离实例以支撑确定性的混合关键级负载；正式支持 Yocto 项目，可构建内存占用更小的定制 Linux；Jetson Orin 与 Thor 统一到 Ubuntu 24.04、内核 6.8 和 CUDA 13.0；Jetson AGX Orin 32GB 的超级模式把算力从 200 TOPS 提到 241 TOPS。
怎么做到JetPack 预置了运行 NemoClaw 所需的依赖和软件栈，免去手工配置环境；再通过多实例 GPU 分区保证机器人感知这类不能被其他推理打断的任务拿到独占算力，并用 Yocto 定制系统压低内存占用。
评分依据：整篇就是讲怎么把智能体部署到 Jetson 边缘设备上，内存占用、算力和确定性调度都是端侧硬约束（相关性 9）。软件栈、GPU 分区和系统定制三条线一起推进，落地性强（贡献 6）。
