PulseInfer: I/O-Centric Sparse KV Cache Offloading for Efficient Long-Context LLM Decoding

10 学校预印本 2026-09-28 · Qiuyang Zhang; Kai Zhou; Kai Lu; Haocheng Lu; Jian Zhou; Yuanpeng Su; Kun Bao; Jiguang Wan / arXiv
方向:KV cache方向:稀疏注意力方向:云端serving硬件:GPU应用:长上下文推理
这是什么长上下文大模型服务在解码阶段常被庞大的 KV cache 卡住。把大部分 KV 放到 CPU 内存、按需取回的稀疏卸载方案扩大了容量，却把瓶颈转移到了 CPU 到 GPU 的数据搬运上，PulseInfer 是专门围绕这段 I/O 重新设计的卸载系统。
有什么结果基于 SGLang 实现，解码吞吐最高比 SGLang 提升 4.7 倍、比现有最好的卸载方案提升 2.6 倍，每个输出 token 的时延（TPOT）最多降低 76%，精度接近无损。
怎么做到用可中断的逐层调度掩盖取回时延的波动，用 I/O 自适应的卸载准入策略决定哪些请求值得卸载，并通过 SoloHead 稀疏选择加聚合-分散 I/O 引擎，把零碎的小块 PCIe 传输合并成大块。
评分依据：面向数据中心 GPU 的长上下文服务，KV cache 卸载与 I/O 合并的思路对内存受限的端侧设备有借鉴意义，但本身不是端侧工作；针对卸载后 I/O 瓶颈的系统设计较扎实。公司归属依据 arXiv PDF 首页的 UCloud 署名。
