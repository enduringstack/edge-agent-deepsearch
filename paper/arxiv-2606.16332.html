SMEPilot: Characterizing and Optimizing LLM Inference with Scalable Matrix Extensions

16 学校预印本 2026-06-15 · Feiyang Chen; Haibo Chen / arXiv
方向:推理框架方向:高效推理方向:编译部署硬件:CPU硬件:手机硬件:Apple-Silicon模型:Llama模型:Qwen
这是什么新一代 Arm CPU 内置了可扩展矩阵扩展（SME）矩阵单元，但大模型推理的预填充、解码、注意力和 KV cache 各环节特性不同，矩阵单元并不总比普通 CPU 核快，还要抢内存带宽。SMEPilot 是一个按算子决定用谁算的推理引擎。
有什么结果在 Apple M4 Pro、联发科天玑 9500 手机芯片和鲲鹏 920 服务器 CPU 上，跑 Llama-3.2-3B、Qwen3-4B、Qwen3-30B-A3B，端到端推理相比 llama.cpp 最多加速 3.94 倍；预填充阶段加速 1.13 到 5.42 倍，解码阶段最多 3.48 倍。批大小为 1 或 2 时与基线相当。
怎么做到先用屋顶线模型刻画 SME 与 CPU 核在不同算子形状下的优劣，再对每个算子选纯 CPU、纯 SME 或二者协同执行；按 tile 粒度在 SME 和 CPU 核间切分矩阵计算，在注意力里让适合矩阵单元和适合向量单元的阶段重叠，并保持打包后的张量布局避免反复重排。
评分依据：直接在手机 SoC（天玑 9500）和 Apple M4 Pro 上实测大模型推理，抓住了端侧 CPU 新增矩阵单元该怎么用这个新问题，端侧相关度很高；基于屋顶线的算子级调度和协同执行有系统性贡献。作者来自上海交通大学 IPADS。
