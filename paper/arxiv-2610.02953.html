SlimKV: Joint Token-Feature KV Cache Compression with Reconstruction-Free Beacon Attention

13 学校预印本 2026-10-02 · Zihan Teng; Jiayu Zhao; Wentao Ren; Minhao Fan; Tianrui Ma; Song Chen; Weichen Liu / arXiv
方向:KV cache方向:高效推理应用:长上下文推理
这是什么长上下文推理最吃显存的是 KV cache。这份工作同时从「少存几个 token」和「每个 token 少存几维」两个方向压缩，并且解码时不用还原回全维。
有什么结果在 LongBench 上 16 倍和 32 倍压缩下优于各基线，4 倍和 8 倍压缩下保留了未压缩模型 96% 以上的分数；大海捞针测试显示对证据位置稳健；128K 长度下注意力最高提速 7.34 倍、端到端解码提速 3.38 倍。
怎么做到用低秩感知训练把长上下文压成带潜空间 KV 表示的信标状态，并按层自适应分配秩；再利用一个发现——去掉 key 侧旋转位置编码对信标 token 的影响远小于对原始 token，于是在无 K-RoPE 约束下训练信标投影，让解码直接在潜空间做注意力，省掉还原开销。
评分依据：KV cache 内存是端侧长上下文推理最硬的墙，论文明确把资源受限场景作为动机，且给了可观的端到端提速。同时做 token 和特征两个维度并解决还原时延，比单维度压缩更完整。
