Energy-Driven Adaptive Visual Token Pruning for Efficient Vision-Language Models

10 学校预印本 2026-03-06 · Jialuo He; Huangxun Chen / arXiv
方向:剪枝稀疏方向:多模态方向:高效推理模型:Qwen
这是什么视觉语言模型把图片切成大量视觉 token，计算开销很大；现有剪枝方法对每张图都留固定数量的 token。E-AdaPrune 根据图片信息量自动决定每张图该留多少 token。
有什么结果在 4 个 VLM 骨干、3 种 token 选择器、9 个基准上测试；在 SQA-IMG 上用 Qwen2.5-VL-3B 时，简单样本少用 35.8% 的 token、相对性能只降 0.52%，省下的预算让困难样本多用 52.5% 的 token、相对性能提升 1.94%。
怎么做到对视觉特征矩阵做奇异值分解，按保留一定比例的谱能量来确定该图的 token 预算，再交给已有的 token 选择器执行，不引入可学习参数。
评分依据：视觉 token 剪枝是端侧多模态推理常用的降本手段，可直接迁移；本文在已有选择器之上加一个自适应预算模块，思路简洁但属于增量改进，未做端侧设备实测。
