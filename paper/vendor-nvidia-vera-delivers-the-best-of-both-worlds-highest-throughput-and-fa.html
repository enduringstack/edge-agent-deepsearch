5 官方动态 2026-11-05 · NVIDIA / NVIDIA

这是什么英伟达认为智能体任务要在 GPU 推理和 CPU 执行（搜索、查库、跑代码）之间来回切换，因此数据中心需要既快又省电的 CPU，并以此推介 Vera CPU。
有什么结果在 100 兆瓦数据中心对比中，Vera 每瓦可承载的智能体数是最快 x86 CPU 的 1.6 倍，智能体速度是最省电 x86 CPU 的 2 倍；Daytona 用它 10.8 秒拉起 1000 个智能体沙箱（x86 需 88.4 秒）。
怎么做到单颗 CPU 同时兼顾单线程速度和核数密度，让智能体的工具执行、沙箱和编排步骤在同一类 CPU 上完成，省去混搭不同 x86 型号。
评分依据：面向数据中心的 CPU 产品宣传，和端侧设备无关；指出了智能体负载中 CPU 执行环节的瓶颈，但内容以厂商数据为主，方法贡献有限。
