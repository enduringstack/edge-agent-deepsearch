Caching is Efficiency: Achieving Precise LLM Cache Hits with Alibaba Cloud ACK GIE

7 官方动态 2026-02-26 · Qwen / Qwen
Qwen方向:KV cache方向:云端serving方向:调度服务
这是什么阿里云 ACK 推理网关新增“精确模式”的前缀缓存感知路由，让分布式 vLLM 集群里相同前缀的请求尽量落到已有 KV 缓存的实例上。
有什么结果高并发测试中精确模式 P90 首字时延 0.542 秒，随机调度超过 92 秒（约 170 倍）；吞吐接近随机调度的 2 倍；相对估算模式首字时延提升 57 倍。单实例下 1 万 token 长提示第二次请求首字时延从 4.3 秒降到 0.6 秒。
怎么做到网关直接订阅各 vLLM 实例上报的 KV 缓存事件，精确知道哪些前缀块缓存在哪里，再据此路由请求，而不是靠近似估算。
评分依据：KV 缓存复用属于推理技术栈，但场景是云端多副本 serving，对端侧只有间接参考；方案是工程整合，数字扎实。
