有什么结果实测一次 Claude Code 会话 33 分钟内发起 283 次请求、处理数百万输入 token；提示缓存命中率 95–98% 时输入成本约降 85%；上下文压缩可把窗口从峰值 156K token 降到约 2 万；目标是在 40 万上下文的万亿参数 MoE 上做到单用户每秒 400 token 以上。
怎么做到统计主智能体与子智能体的上下文增长和缓存命中，再给出对应栈：Vera Rubin NVL72、用 Vera CPU 卸载 KV cache、Groq 3 LPX 负责低抖动解码，软件上用 Dynamo 的注意力/FFN 分离、NVFP4、WideEP 和投机解码。
