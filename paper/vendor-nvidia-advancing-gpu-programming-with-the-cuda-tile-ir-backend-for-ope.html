Advancing GPU Programming with the CUDA Tile IR Backend for OpenAI Triton

6 官方动态 开源 2026-01-30 · NVIDIA / NVIDIA
NVIDIA方向:编译部署硬件:GPU
这是什么NVIDIA 把新的 CUDA Tile IR 做成 OpenAI Triton 的一个编译后端，让用 Triton 写的 GPU 算子不用改代码，就能按“块”为单位编译并更好地利用 Tensor Core。
有什么结果未报告
怎么做到Triton-to-TileIR 在编译时保留 Triton 的块级语义，直接生成 CUDA Tile IR 而不是逐线程的 PTX；用环境变量即可切换后端，也能按算子单独选择。目前需从源码构建、要求 CUDA 13.1 和 Blackwell GPU，部分操作不支持，指针张量写法性能偏低，建议改用 TMA 加载接口。
评分依据：面向数据中心新一代 GPU 的算子编译栈，对边缘 GPU 只有远期迁移价值，端侧相关度低。属于编译器后端集成，仍处早期，贡献中等偏低。
