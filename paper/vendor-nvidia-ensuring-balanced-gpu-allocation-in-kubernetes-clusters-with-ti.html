Ensuring Balanced GPU Allocation in Kubernetes Clusters with Time-Based Fairshare

5 官方动态 开源 2026-01-28 · NVIDIA / NVIDIA
NVIDIA方向:调度服务方向:云端serving硬件:GPU
这是什么NVIDIA Run:ai v2.24 推出按时间算账的公平调度，解决 Kubernetes 集群里大任务被源源不断的小任务饿死、拿不到超额 GPU 的问题。
有什么结果原文没有实测指标，只用一个 100 张 GPU 的集群示例说明：不开时间公平调度时，LLM 团队需要 60 张 GPU 的后训练任务被视觉团队持续占用的超额资源卡住；开启后该任务能被调度，两队资源随时间轮流均衡。
怎么做到基于开源 KAI Scheduler，记录各队列一段时间内的历史 GPU 用量，用得少的队列在分配超额资源时权重更高，从而在几天到几周尺度上按比例分配，同时保留保底配额和优先级。
评分依据：纯数据中心 GPU 集群调度，与端侧推理和端侧智能体基本无关；属于调度策略的工程改进，原文只有示例场景，没有实测数据。
