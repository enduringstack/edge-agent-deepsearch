When Malicious Instructions Persist: Persistent Memory Poisoning Attack on Harness-Based Agents

10 学校预印本 2026-09-12 · Shuhuai Huang; Jingfeng Zhang; Hong Jia / arXiv
方向:安全隐私方向:记忆方向:工具调用
这是什么演示了一种针对带持久记忆的智能体的投毒攻击：把恶意指令混进正常外部资料，诱导智能体自己把它写进长期记忆，之后每个新会话都会被触发。
有什么结果在 OpenClaw 和 Claude Code 上跨多种骨干模型测试，平均注入成功率和跨会话攻击成功率分别为 73.7%/55.5% 和 66.9%/81.7%，同时正常任务表现基本不受影响；针对性的提示级防御能减少注入，但记忆一旦被投毒后防护效果有限。
怎么做到不直接接触智能体框架，而是把恶意指令嵌入看起来正常的外部来源，等智能体把它写进持久记忆；之后的会话检索到这条记忆就会触发额外恶意动作并造成隐私泄露。
评分依据：持久记忆是端侧长期助手的核心组件，这类跨会话投毒同样适用，但论文测的是桌面编码智能体（相关性 4）。攻击面刻画清晰、实验覆盖面广（贡献 6）。
