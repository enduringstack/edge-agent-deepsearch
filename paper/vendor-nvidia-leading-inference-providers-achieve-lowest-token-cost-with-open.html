Leading Inference Providers Achieve Lowest Token Cost With Open Source Models on NVIDIA Blackwell

3 官方动态 2026-02-12 · NVIDIA / NVIDIA
NVIDIA方向:云端serving硬件:GPU
这是什么英伟达汇总 Baseten、DeepInfra、Fireworks AI、Together AI 等推理服务商的客户案例，说明在 Blackwell 上跑开源模型能大幅压低每 token 成本。
有什么结果服务商称每 token 成本比 Hopper 最多降低 10 倍；医疗平台 Sully.ai 借助 Baseten 推理成本下降 90%，医疗记录生成等关键流程响应时间缩短 65%；Baseten 在 Blackwell 上每美元吞吐比 Hopper 高最多 2.5 倍；游戏公司 Latitude 借助 DeepInfra 每 token 成本降低 4 倍。
怎么做到推理服务商在 Blackwell GPU 上组合 NVFP4 低精度格式、TensorRT-LLM 和 Dynamo 推理框架，托管 gpt-oss-120b 等开源模型。
评分依据：纯云端推理成本的商业案例汇总，与端侧部署关系很弱；技术上没有新方法。
