Foundry IQ in Microsoft Copilot Studio is now generally available

5 官方动态 2026-10-01 · Microsoft / Microsoft
Microsoft应用:RAG方向:安全隐私
这是什么微软宣布企业知识层 Foundry IQ 与 Copilot Studio 的集成正式可用，让企业内部的智能体能带着出处引用去回答问题。
有什么结果官方说明正式版可把 Foundry IQ 知识库接到 Copilot Studio 的智能体上，获得带引用的企业知识接地能力；支持 API 密钥、客户端证书、服务主体和企业身份集成四种认证方式；并通过私有链路与虚拟网络支持，让流量不必开放底层搜索服务的公网访问，满足零公网暴露要求；还可查看活动轨迹确认检索确实发生以及返回了哪些条目。
怎么做到Foundry IQ 作为受管的知识层，统一处理企业数据访问、检索、排序和权限，使开发者只需连一个知识库而不必逐个配置数据源；私有连通性由为搜索服务分配私有 IP 的私有链路，加上把连接流量路由进委派子网的虚拟网络支持共同实现。
评分依据：完全是云端企业知识接地与网络隔离的能力，与端侧部署没有关系，相关度按最低计。把权限、认证和网络隔离一起纳入知识层是企业落地必需的工程，但不涉及推理技术本身。
