这是什么轻量个人 AI 助手框架 nanobot 发布 v0.1.4.post3，重点是让智能体少看无用上下文，减少幻觉和死循环，并新增 Matrix 聊天渠道和实验性思考模式。
有什么结果未报告（版本说明给出的是合并 33 个 PR、16 位新贡献者，没有性能数字）。
怎么做到过滤空回复、不把模型报错写进会话历史以免陷入 400 错误循环；把时间、渠道等运行时元数据隔离成不可信层且不进历史；从历史中剥离 base64 图片防止上下文溢出；子智能体可被 /stop 取消。
评分依据：这是一个在用户自己机器上运行的智能体框架，但模型调用走云端服务商接口，原文没有本地推理的说明，因此按非端侧 Agent 处理；上下文清洗和会话安全的做法对端侧 Agent 运行时有参考价值，整体属于工程打磨。
