KnowU-Bench: Towards Interactive, Proactive, and Personalized Mobile Agent Evaluation

9 公司项目 开源 2026-04-09 · Tongbo Chen; Zhengxi Lu; Zhan Xu; Guocheng Shao; Shaohan Zhao; Fei Tang; Yong Du; Kaitao Song / arXiv
Apple; Tencent方向:评测基准方向:记忆硬件:手机
这是什么个性化手机助手不仅要会操作界面，还要能推断用户偏好、判断何时主动介入或保持沉默。KnowU-Bench 是在可复现安卓模拟环境中评测这些能力的在线基准。
有什么结果包含 42 个通用 GUI 任务、86 个个性化任务和 64 个主动任务；在需要推断偏好或判断介入时机的模糊指令下，即便 Claude Sonnet 4.6 等前沿模型成功率也跌到 50% 以下。
怎么做到向 Agent 隐藏用户画像、只暴露行为日志，迫使其真正推断偏好；用基于结构化画像的大模型用户模拟器支持多轮澄清与征求同意，并结合规则校验与大模型评审打分。
评分依据：面向手机助手的评测基准，但 Agent 在模拟器中调用云端大模型运行，不是端侧执行。贡献在于把偏好获取和介入时机纳入评测，而非 GUI 操作本身。 作者机构依据：arXiv PDF 首页署名 Apple, Tencent（PDF 首页作者 Kaitao Song 标注机构 2 为 Apple，作者 Xu Tan 标注机构 3 为 Tencent）。
