Coding Agent Memory Post-training: Unlocking the Memory Potential of Pre-trained File Operations for Long-Horizon Tasks via Reinforcement Learning

10 公司项目 2026-09-28 · Lirui Luo; Kelong Mao; Heming Xia; Rongqing Li; Xinwei Yang; Luyu Chen; Kieran Wong; Yudong Guo / arXiv
JD方向:记忆方向:工具调用应用:代码模型:Qwen
这是什么长任务里智能体的交互历史会超出上下文窗口，以往训练记忆能力多靠专门设计的记忆工具，换个环境就不灵。这篇让编码智能体直接用最熟悉的“读写文件”当记忆，并用强化学习把这种习惯练出来。
有什么结果从 Qwen3.5 训练出的 CAMG-RL-4B 和 CAMG-RL-9B，在 SWE-bench Verified 和 MLE-bench Lite 上分别能与 Qwen3.5-35B-A3B、Qwen3.5-122B-A10B 打成平手。
怎么做到搭建覆盖购物、编程、深度检索、自动科研四类长周期环境的训练场，每个环境都提供可执行的 shell 和整局保留的工作区，智能体可以新建、修改、搜索、复用文件来记事；再用全异步 PPO 在四个环境上联合训练同一个策略，只靠下游任务奖励学会这种文件记忆行为。
