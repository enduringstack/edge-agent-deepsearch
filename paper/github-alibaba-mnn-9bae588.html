alibaba/MNN: [CPU:Perf] Optimize ARM CPU flash attention decode and prefill scaling.

15 开源大项目 开源 2026-09-04 · alibaba / GitHub
方向:推理框架方向:高效注意力方向:编译部署方向:高效推理硬件:CPU硬件:手机
这是什么阿里的端侧推理引擎 MNN 本周合入一大批 ARM CPU 优化，重点是把 flash attention 的解码和预填充阶段在手机 CPU 上跑得更快。
有什么结果提交页未给出统一的加速倍数，只能看到改动规模：112 个文件、新增 7448 行、删除 3194 行。
怎么做到按线程切分 KV 块做 flash decoding 并按单线程 / 多线程自适应选择粒度；把 GQA 的多个查询头批量处理、把注意力缩放融进 Q 打包阶段以减少内存搬运；用融合归一化和向量化 fp16 softmax 去掉冗余计算；再对异构 SoC 上的线程调度加了有上限的自旋退避，避开性能悬崖。
评分依据：MNN 是专门面向手机和嵌入式的推理引擎，这次动的又是 ARM CPU 上的注意力算子和线程调度，端侧契合度很高；改动覆盖 v8.2 到 v9.2 多代 ARM 汇编，属于扎实的工程优化而非新算法。
