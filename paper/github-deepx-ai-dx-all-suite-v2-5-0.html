这是什么DEEPX 给自家 DX-M1 边缘 NPU 发布的整套软件栈 v2.5.0：编译器、运行时、驱动固件、模型库和开发工作台一起升级，并新增容器镜像、一行命令安装和 Kubernetes 调度支持。
有什么结果在 DX-M1 搭配 Arm Cortex-A53 主机上，后处理优化让 RTMDet-S 检测从 156.56 FPS 提到 290.16 FPS（1.9 倍），YOLOv8n 姿态估计提速 1.5 倍；树莓派 5 上 1080p 摄像头预处理改用 GPU 后 CPU 占用从 95.2% 降到 4.8%；NPU 省电模式空闲功耗降约 5–10%；模型库达到 497 个模型。
怎么做到编译器在后处理前先用 TopK 缩小候选框再做 Sigmoid、解码和 NMS 预筛，避免弱 CPU 主机拖累 NPU；运行时把裁剪缩放等预处理交给 OpenGL ES 并零拷贝传递，输入量化改用 NEON/SSE SIMD；3D 卷积等算子改为在 NPU 上执行，减少回退到 CPU。
评分依据：这是边缘 NPU 厂商的官方运行时正式版，在 Arm 嵌入式主机上给出了实测提速和功耗数字，端侧部署相关度较高；但内容集中在视觉检测类模型和工程易用性，没有大模型或智能体能力，属于常规版本迭代。
