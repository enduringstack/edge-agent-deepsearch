openvinotoolkit/openvino: [Core][GPU] Prefetch constants during model compilation in GPU (#38993)

8 开源大项目 开源 2026-10-31 · openvinotoolkit / GitHub
方向:编译部署方向:推理框架硬件:GPU
这是什么OpenVINO 在 GPU 插件编译模型时加入权重预取：提前把即将用到的常量权重读进内存、用完立即释放，缩短模型编译加载时间。
有什么结果未报告；提交说明本功能目前只在 Linux 启用，Windows 要等确认有编译耗时收益后再开。
怎么做到新增按算子顺序工作的预取调度器：对内存映射文件里的常量，在使用前异步发起预读，用完后驱逐并预取后面的权重，固定向前看若干个常量。
评分依据：缩短模型首次编译加载时间，对 Intel 集成显卡 PC 等本地部署的冷启动体验有帮助，属于端侧推理栈的周边优化；方法是常规的顺序预读加驱逐，未给出提速数据。
