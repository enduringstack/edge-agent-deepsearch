What Spatial Memory Must Store: Occlusion as the Test for Language-Agent Memory

8 学校预印本 2026-06-09 · Doeon Kwon; Junho Bang / arXiv
方向:记忆方向:规划推理方向:评测基准
这是什么检验语言智能体的空间记忆到底该存什么，用墙后物体这种遮挡情形来区分回忆和可见性两件事。
有什么结果预注册实验显示现有记忆宫殿把空间邻近度与新近度、重要度线性混合的默认做法并不管用（Delta-Hit@5 平均 -0.0375），而以几何为主导的加权大幅获胜（+0.3208）；在 849 个墙后目标上，纯文本和实时视野锥都得 0.000 分，加上射线体素遍历后达到 0.982；坐标回忆对近似重复位置的区分率为 1.000，而余弦相似基线只有 0.533。
怎么做到把记忆回忆和可见性拆成两件事：回忆按设计就该无视遮挡，可见性则是一个作用在已存几何上的感知判定，用一行射线对体素的数字微分分析器，复用智能体本来就在投射的视线射线来计算。
评分依据：空间记忆的组织方式对具身端侧智能体有参考价值，但本文实验在模拟世界里进行、不涉及设备部署。把回忆与可见性分离并用预注册实验测量，方法学上相当严谨。
