How to Train an AI Agent for Command-Line Tasks with Synthetic Data and Reinforcement Learning

8 官方动态 2026-01-15 · NVIDIA / NVIDIA
NVIDIA方向:工具调用硬件:GPU应用:代码
这是什么NVIDIA 演示如何让一个对某个命令行工具毫无了解的推理模型，学会安全地操作这个新 CLI（以 LangGraph Platform CLI 为例），每条命令执行前先请用户确认。
有什么结果未报告
怎么做到用 NeMo Data Designer 合成训练数据，再在 NeMo Gym 环境里用可验证奖励的强化学习（GRPO，经 Unsloth）微调 Nemotron-Nano-9B-V2；命令以不经 shell 的子进程方式执行，并强制人工确认。
评分依据：9B 小模型专精工具调用、走命令行而非图形界面路线，方法可迁移到本地运行的电脑 Agent，但原文没说明推理在本地进行，训练要求 80GB 显存 GPU；属于现有工具链的教程式整合。
