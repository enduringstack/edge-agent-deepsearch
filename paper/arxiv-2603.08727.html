ARKV: Adaptive and Resource-Efficient KV Cache Management under Limited Memory Budget for Long-Context Inference in LLMs

10 学校预印本 开源 2026-02-19 · Jianlong Lei; Shashikant Ilager / CCGRID 2025
方向:KV cache方向:量化应用:长上下文推理硬件:GPU模型:Llama模型:Qwen
这是什么长上下文推理时 KV cache 会吃掉大部分显存。ARKV 在显存预算很紧的情况下，按每个 token 的重要程度决定它保留全精度、降成低精度还是直接丢掉。
有什么结果在 LLaMA3 和 Qwen3 上，长上下文基准保持约 97% 的基线准确率，同时 KV 显存降为原来的四分之一，吞吐损失很小；短上下文任务与全精度持平，在 GSM8K 数学推理上明显好于统一量化。
怎么做到预填充阶段用注意力熵、方差、峰度估计每层适合量化的比例；解码时用快速的重要 token 打分，把每个 token 分到原精度、低精度、淘汰三种状态之一，无需重新训练。
评分依据：KV cache 混合精度与淘汰是端侧长上下文推理可直接迁移的技术，但实验在 A6000 服务器 GPU 上进行，相关度给 5。把量化和淘汰统一到逐 token 自适应决策中有一定新意，但属于该方向常见组合，贡献给 5。
