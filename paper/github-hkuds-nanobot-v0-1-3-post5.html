这是什么港大 HKUDS 的轻量开源 Agent 框架 nanobot 发布补丁版，新增通义、Kimi、DeepSeek 等模型接入和 Discord、飞书聊天渠道，并合入一批安全修复。官方提示该版本 WhatsApp 通道存在漏洞，应改装 v0.1.3.post7 或更高版本。
有什么结果未报告
怎么做到以插件式的模型提供方和聊天渠道扩展 Agent 的接入面；同时修补了 Shell 注入、路径穿越和 LiteLLM 远程执行等安全问题，并把运行环境摘要写进系统提示。
评分依据：nanobot 是可在个人电脑上运行的轻量 Agent 框架，但本版只是接入更多云端模型与聊天渠道并修补安全漏洞，未涉及本地模型或端侧推理，相关度中低。属于常规补丁版本，发布说明没有量化结果。
