KVCMAS: Efficient KV cache Correction for Shared Context in Multi-Agent Systems

11 学校预印本 2026-09-28 · Hyesung Jeon; Hyeongju Ha; Seoyoung Lee; Beomseok Kang; Jae-Joon Kim / arXiv
方向:KV cache方向:调度服务方向:多模态硬件:GPU模型:Llama
这是什么多个智能体共用同一个模型、只靠不同提示词分工时，每个智能体都要对不断增长的共享上下文重新预填充并单独保存一份 KV cache，计算和显存开销都很大。KVCMAS 用在线修正的方式让这些智能体共享缓存。
有什么结果在多种语言和视觉语言任务上，精度持平或优于已有 KV 共享方法，高并发服务下首 token 时延最低；在受控服务负载下相比不共享 KV 的推理首 token 加速 2.0 倍，峰值显存比已有 KV 修正方法最多降低 3.7 倍。
怎么做到用紧凑的低秩状态表示不同智能体之间的缓存偏差，沿智能体工作流把修正一路链式传递，不需要额外的参考预填充；第一个智能体的缓存保持精确，后续智能体在其基础上修正。
评分依据：多智能体共享 KV cache 能直接降低多智能体推理的显存和预填充开销，思路可迁移到内存紧张的端侧多智能体场景，但实验在 A6000/A100 服务器 GPU 上，相关度中等；低秩链式修正方案有一定新意。
