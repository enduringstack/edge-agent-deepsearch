Harness engineering: leveraging Codex in an agent-first world

7 官方动态 2026-02-11 · OpenAI / OpenAI
OpenAI应用:代码方向:工具调用模型:GPT
这是什么OpenAI 工程师分享一个几乎全部代码都由 Codex 智能体写出来的产品实践，讲工程师如何从写代码转向搭环境、写意图、建反馈回路。
有什么结果三名工程师驱动 Codex 约五个月，代码库增长到约一百万行，合并约 1500 个 PR，平均每人每天 3.5 个 PR；团队估计耗时约为手写的十分之一。
怎么做到把仓库文档作为唯一的记录系统，用简短的 AGENTS.md 充当目录，并持续补齐测试、可观测性和工具，让智能体能在仓库环境里自己验证和修正。
评分依据：云端编码智能体的工程方法论，与端侧部署无直接关系；对智能体工程实践有启发，但不是新技术。
