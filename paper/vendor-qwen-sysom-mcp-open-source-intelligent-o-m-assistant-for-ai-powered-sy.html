SysOM MCP: Open-Source Intelligent O&M Assistant for AI-Powered System Diagnostics

7 官方动态 开源 2026-03-05 · Qwen / Qwen
Qwen方向:工具调用应用:fault-detection
这是什么阿里云开源 SysOM MCP，把操作系统控制台里内存、IO、网络、内核崩溃等诊断能力封装成 MCP 工具，让 Qwen Code 等智能体用自然语言做系统运维诊断。
有什么结果提供 20 多个生产级诊断工具，支持本地 stdio 和 HTTP SSE 两种接入方式。未给出诊断准确率等量化结果。
怎么做到按 MCP 协议把原有诊断能力标准化为可被大模型自主调用的工具，智能体理解问题后自动调用工具、汇总结果并生成报告和修复建议。
评分依据：属于服务器运维场景的智能体工具调用，与端侧设备关系不大。工具封装本身是常见工程做法，但开源了可直接复用的工具集。
