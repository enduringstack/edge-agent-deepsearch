MemSifter: Offloading LLM Memory Retrieval via Outcome-Driven Proxy Reasoning

11 学校预印本 开源 2026-03-03 · Jiejun Tan; Zhicheng Dou; Liancheng Zhang; Yuyang Hu; Yiruo Cheng; Ji-Rong Wen / arXiv
方向:记忆方向:规划推理应用:RAG
这是什么长任务里大模型的长期记忆检索又贵又不准，MemSifter 把记忆检索交给一个小代理模型先推理再取回，减轻主模型负担。
有什么结果在 8 个大模型记忆基准（含深度研究任务）上，检索准确率和最终任务完成度达到或超过现有最好方法；模型权重、代码和训练数据已开源。
怎么做到小模型在检索前先针对任务推理，再用以主模型实际完成任务效果为奖励的强化学习训练，并辅以课程学习和模型合并。
评分依据：把记忆检索卸载给小模型的思路对资源受限设备上的 Agent 记忆很有迁移价值；但实验在通用服务器环境，未涉及端侧部署。作者均来自中国人民大学。
