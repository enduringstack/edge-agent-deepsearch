Storage Is Not Memory: A Retrieval-Centered Architecture for Agent Recall

12 学校预印本 开源 2026-05-06 · Joshua Adler; Guy Zehavi / arXiv
方向:记忆应用:RAG硬件:CPU
这是什么主张 Agent 记忆不该在写入时就提炼摘要，而应原样保存事件、把功夫放在检索上；True Memory 整个系统就是一个 SQLite 文件，普通 CPU 即可运行。
有什么结果在 LoCoMo 上，使用相同的 gpt-4.1-mini 答题模型时准确率 93.0%，高于 Mem0 的 61.4%、Supermemory 的 65.4% 和 Zep 的约 71%，略低于 EverMemOS 的 94.5%；LongMemEval 上 87.8%；BEAM-1M 上 76.6%，超过此前公开最好的 73.9%。
怎么做到六层架构：写入时只做准入与原文存储，后台做聚类摘要、意外度打分和说话人画像，查询时走词法、向量、重排等多阶段检索；不依赖外部数据库、向量索引或 GPU。
评分依据：记忆层可在本地 CPU 上以单文件运行，对端侧 Agent 记忆有直接迁移价值，但答题仍依赖云端模型，整体不算端侧 Agent；“存原文、重检索”的取舍清晰。代码开源，作者来自 Sauron Labs。
