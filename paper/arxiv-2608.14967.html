When Does Distributed AI Inference Need More Wide-Area Bandwidth? A Co-Design Evaluation of Optical, Packet, and Software Levers

5 学校预印本 2026-08-15 · Prasanna C / arXiv
方向:云端serving方向:KV cache
这是什么跨数据中心做大模型推理时，到底是把 KV 等推理状态通过广域网搬过去划算，还是在本地重算划算？这篇给出可量化的判断模型。
有什么结果对 70B 多头注意力模型，单条流带宽超过 74–111 Gbps 时搬运状态才优于重算；改用 KV 头数为八分之一的分组查询注意力后，门槛降到 9–14 Gbps；按 GPU 标价重算更便宜，只有 GPU 紧缺和 KV 复用让等效 GPU 成本放大约 5–20 倍时，搬运才更划算。
怎么做到建立“搬运还是重算”的负载模型，从上下文长度、注意力结构、排队、多步 Agent 叠加和丢包抖动五个维度做敏感性分析，并给出在三站点光纤测试床上的十项测量计划。
评分依据：讨论的是跨数据中心推理的网络带宽经济性，与端侧部署无关，相关度给 1。对 KV 搬运与重算的取舍给出了可量化门槛，有一定分析价值，贡献给 4。作者为 Lightstorm 单人署名，首页未写明机构类型，未标注公司归属。
