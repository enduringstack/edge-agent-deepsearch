How NVIDIA OpenShell Reference Architecture Secures and Governs AI Agent Workloads at Scale

8 官方动态 2026-10-21 · NVIDIA / NVIDIA
NVIDIA方向:安全隐私方向:工具调用硬件:CPU
这是什么英伟达发布 OpenShell 参考架构，用开源运行时为长时间自主运行、能访问文件、工具和网络的智能体提供隔离与治理。
有什么结果Vera CPU 在关键智能体任务上比 x86 最高快 2 倍；CoreWeave 实测沙箱启动快 3 倍以上、智能体循环完成快 1.8 倍，单机柜可承载 1.1 万个以上并发智能体环境。
怎么做到把智能体负载当作不可信对象，由网关管理沙箱生命周期、监督器在沙箱外审查外发请求并代管凭证、沙箱限制文件和进程访问、策略证明器用形式化方法检查权限不超上限。
评分依据：智能体运行时的安全隔离设计有参考价值，但本文场景是数据中心大规模部署，不涉及设备端运行。
