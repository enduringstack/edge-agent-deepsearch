6 官方动态 开源 2026-04-24 · NVIDIA / NVIDIA

这是什么NVIDIA FLARE 联邦计算框架的新版接口，让已有的本地训练脚本几乎不改就能变成联邦学习客户端，数据留在本地只交换模型更新。
有什么结果把本地训练脚本改造成联邦客户端只需约 5～6 行代码；同一份任务定义可在仿真、验证和生产环境间切换，正文未给出精度或效率数字。
怎么做到提供客户端 API 包住原有 PyTorch、TensorFlow 或 Lightning 训练循环，再用 Python 写的任务配方绑定联邦工作流，执行环境可直接替换。
