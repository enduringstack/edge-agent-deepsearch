Introducing Claude Haiku 5.5

8 官方动态 2026-10-07 · Anthropic / Anthropic
Anthropic方向:高效推理方向:工具调用方向:云端serving应用:代码
这是什么Anthropic 发布小模型 Claude Haiku 5.5：迄今最便宜、最快、能力最强的 Haiku，定位于摘要、上下文压缩、数据库查询、分类、编码子智能体，以及客服和浏览器操作等高频、对成本和速度敏感的任务。
有什么结果平均运行成本比 Haiku 4.5 低约 75%（10 万 token 以内的请求价格低 90%）；OSWorld 2.1 离线子集 72.4%（Haiku 4.5 为 15.7%），Terminal-Bench 4.0 为 39.2%（Haiku 4.5 为 0%），Humanity's Last Exam 无工具 45.9%、有工具 57.4%；同时 Sonnet 5.5 缓存读取价格减半，多数智能体任务约便宜 20%。
怎么做到这是首个支持可调推理强度的 Haiku 级模型，可在成本和能力之间取舍；换用与 Sonnet 5.5、Opus 5.5 类似的新分词器，并以 10 万 token 为界按提示长度分档定价。
评分依据：小模型担任子智能体、负责上下文压缩的定位与端侧智能体思路相近，但它只以云端 API 提供，没有端侧部署。属于模型迭代发布，能力和价格提升明显。
