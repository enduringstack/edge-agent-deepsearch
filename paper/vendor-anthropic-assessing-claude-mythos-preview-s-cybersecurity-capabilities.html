Assessing Claude Mythos Preview’s cybersecurity capabilities

7 官方动态 2026-04-07 · Anthropic / Anthropic
Anthropic方向:安全隐私方向:评测基准应用:安全
这是什么Anthropic 前沿红队公开了新模型 Claude Mythos Preview 网络安全能力的测试细节：它能自主发现并利用主流操作系统和浏览器中的零日漏洞。
有什么结果在 Firefox 147 JavaScript 引擎漏洞的利用测试中，上一代 Opus 4.6 在数百次尝试里只成功 2 次，Mythos Preview 写出可用利用 181 次，另有 29 次获得寄存器控制；已发现的漏洞超过 99% 尚未修补，最老的是一个已修复的 27 年前 OpenBSD 漏洞。
怎么做到让模型在带工具的脚手架里自主阅读代码、找漏洞、编写并验证利用程序，红队在真实开源代码库、闭源软件逆向和已知漏洞利用等场景中评估。
评分依据：这是云端前沿模型的安全能力评估，与端侧部署无关；但它对智能体自主攻防能力的量化对比信息量大。同日发布的 Project Glasswing 公告属同一事件，仅保留本篇。
