Joint Agent Memory and Exploration Learning via Novelty Signals

8 学校预印本 开源 2026-06-01 · Shizuo Tian; Xiaohong Weng; Rui Kong; Yuxuan Chen; Guohong Liu; Yuebing Song; Jiacheng Liu; Yuchen Li / arXiv
方向:记忆方向:规划推理方向:高效推理
这是什么让智能体的记忆和探索策略一起训练：靠「新鲜度」信号互相提供监督。
有什么结果在未见环境上能泛化，探索能力超过开源权重基线、逼近闭源模型的探索深度，同时降低 token 消耗；原文未给出具体数字。代码与模型已开源。
怎么做到观察到记忆和探索是互相依赖的回路——持续探索需要记忆来区分已穷尽和未见过的行为，而追新的交互又为记忆提供监督；于是用界面领域里确定且持久的新鲜度信号（如代码覆盖率）当作无需标注的天然监督来训练隐式记忆模块。
评分依据：用隐式记忆压缩交互历史、降低 token 消耗，对端侧长时运行有参考价值，但工作本身面向界面探索且无设备实验（相关性 3）。把新鲜度当免标注监督信号的设计有巧思（贡献 5）。
