PReCache: Efficient KV Cache Sharing for Multi-LoRA Agents via Low-Rank Precomputation and Neutral Reconstruction

11 学校预印本 2026-09-28 · Hyesung Jeon; Hyeongju Ha; Jae-Joon Kim / arXiv
方向:KV cache方向:高效推理硬件:GPU模型:Llama
这是什么多个 LoRA 智能体共享同一底座模型分工协作时，每个智能体都要重新处理共享轨迹并维护自己的 KV cache。PReCache 是一套无需训练的 KV 共享框架，让各智能体复用底座缓存，同时保住各自 LoRA 带来的角色行为。
有什么结果PreLRShared 相比不共享 KV 的推理首 token 最高加速 3.1 倍、单请求吞吐提升 2.3 倍；ReBaseShared 在评测的缓存共享方法中精度保持最好，平均只比不共享低 1.1 个点。
怎么做到共享用预训练权重算出的底座缓存，并在共享上下文首次被处理时就预先算好每个智能体专属的紧凑低秩缓存；另一种方案用不经过适配器的隐状态重建底座缓存，减少上一个智能体适配器带来的误差，并分别为单流推理和并发服务设计重建时机。
评分依据：多 LoRA 智能体共用一个底座正是端侧常见的省内存做法，这套 KV 共享方案可直接迁移，还专门考虑了单流推理场景，但实验在服务器 GPU 上进行，相关度中等；免训练的低秩预计算设计有新意。
