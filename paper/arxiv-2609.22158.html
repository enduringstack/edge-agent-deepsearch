StepKV: Step-Aware KV Cache Compression for LLM Agents

11 学校预印本 2026-08-26 · Boyu Feng; Jiahong Liu; Yifan Li; Wenhao Yu; Zexuan Qiu; Yuliang Sun; Ming Shen; Xiang Li / arXiv
方向:KV cache方向:记忆方向:高效推理方向:工具调用
这是什么多步智能体的 KV cache 涨得特别快，现有压缩方法把缓存当成一条扁平 token 流来排序，和智能体实际的推理单元对不上。
有什么结果未报告
怎么做到StepKV 按步感知来压缩：一次查询会展开成推理、工具交互和检索观察组成的轨迹，有用信息是按推理步组织的，所以压缩粒度也应当对齐到步，而不是按时近性或注意力显著度剪单个 token。
评分依据：KV cache 是端侧运行智能体最先撑爆的资源，按步压缩的思路可直接迁移，但论文没有设备端实测，端侧契合度中等。把压缩单元和推理单元对齐是有道理的观察，方法仍属 KV 剪枝路线。
