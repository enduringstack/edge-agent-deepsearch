StepKV: Step-Aware KV Cache Compression for LLM Agents

13 公司项目 2026-08-26 · Boyu Feng; Jiahong Liu; Yifan Li; Wenhao Yu; Zexuan Qiu; Yuliang Sun; Ming Shen; Xiang Li / arXiv
Huawei方向:KV cache方向:记忆方向:工具调用模型:Qwen模型:Llama
这是什么多步工具调用的智能体上下文越来越长，KV cache 压缩若只按单个 token 取舍，会把后面还要用的早期推理步骤删掉；StepKV 把“推理步骤”作为保留单位来压缩缓存。
有什么结果Qwen2.5-7B 在只保留 20% KV 时，HotpotQA EM 为 18.07，而 H2O、TOVA 只有 1.53 和 0.73（全量 KV 为 26.40）；保留 50% 时 EM 为 23.23，接近全量；Llama-3.1-8B 上结论一致。
怎么做到把每个缓存条目关联到生成它的推理步骤，根据后续轨迹对该步信息的复用来更新步骤价值，再与 token 级显著性结合，在预算内全局挑选保留条目。
评分依据：智能体的长轨迹 KV cache 是端侧运行智能体时最紧的内存瓶颈之一，这种压缩方法可直接迁移。以推理步骤为单位压缩、解决低预算下推理连续性断裂，是有新意的贡献。作者机构依据 arXiv PDF 首页署名：作者 8、9 来自 Huawei Technologies。 作者机构依据：arXiv PDF 首页署名 Huawei（PDF 首页作者 8、9（Xiang Li、Quanyu Dai）署名 Huawei Technologies Co., Ltd，其余作者来自香港中文大学）。
