A Hippocampus for Linear Attention: An Exact Memory for What the Recurrent State Forgets

11 学校预印本 2026-07-02 · Wanyun Cui / arXiv
方向:高效注意力方向:KV cache方向:记忆应用:长上下文推理
这是什么线性注意力把全部上下文压进固定大小的状态，记的东西多了旧事实会被覆盖。HOLA 给它配一个“海马体”：一个有上限的精确 KV 缓存。
有什么结果3.4 亿参数、150 亿 token 训练下，Wikitext 困惑度从 27.32 降到 22.92（-16.1%），低于全注意力 Transformer++ 的 26.88；RULER 大海捞针在 32k（训练长度 16 倍）上明显比 GDN 稳健。
怎么做到保留 delta 规则的压缩状态，同时把“写进状态时残差最大”的 token 存进精确缓存，不需要学习型淘汰模块；读取时用解耦的 RMSNorm 实现尖锐检索。
评分依据：固定显存的长上下文模型架构，对端侧长上下文推理有潜在价值（相关度 4）；用压缩状态加小精确缓存的互补记忆设计新颖（贡献 7）。作者机构为上海财经大学。
