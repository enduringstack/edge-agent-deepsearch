PrivGemo: Privacy-Preserving Dual-Tower Graph Retrieval for Empowering LLM Reasoning with Memory Augmentation

10 学校预印本 2026-01-13 · Xingyu Tan; Xiaoyang Wang; Qing Liu; Xiwei Xu; Xin Yuan; Liming Zhu; Wenjie Zhang / arXiv
方向:安全隐私方向:端云协同方向:记忆应用:RAG模型:Qwen
这是什么私有知识图谱要借闭源大模型 API 做多跳问答时，会把实体和图结构泄露出去。PrivGemo 让原始图谱留在本地，只把匿名化后的视图交给远端模型推理。
有什么结果在六个基准上取得整体最好结果，比最强基线最多高 17.1%；还能让 Qwen3-4B 这样的小模型达到与 GPT-4-Turbo 相当的推理表现。
怎么做到双塔设计：本地塔保存原始图谱并负责检索和校验，远端塔只看到同时隐藏语义与结构的匿名长路径；再用分层控制器和隐私感知的经验记忆减少不必要的探索和远程交互。
评分依据：本地保数据、远端做推理的分工思路可迁移到端云协同的隐私场景，但本地端是服务器侧的私有图谱而非终端设备（相关度 4）。超越名称遮蔽的结构级匿名有一定新意（贡献 6）。
