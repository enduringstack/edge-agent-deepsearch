Agent Distraction

7 官方动态 2026-11-06 · Google / Google
Google方向:规划推理应用:代码方向:评测基准
这是什么谷歌开发者博客分析编程 Agent 读代码时被过期 TODO 注释“带偏”的问题：Agent 会把早已修复或与任务无关的 bug 当成待办去追查甚至改代码。
有什么结果在谷歌内部数百万次会话中，13% 的会话接触到带 bug 编号的 TODO；其中 6% 触发后续动作，83% 是用户没要求的；无故绕路的会话多耗 70% 步数、77% token、105% 等待时间。
怎么做到把 Agent 遇到的每条 TODO(bug/…) 与该 bug 的实际状态和用户原始提示交叉比对，大规模区分有效工作与无谓绕路；随后用清理 Agent 追溯 bug、文件和改动历史，确认 TODO 已过时才提交删除。
评分依据：研究对象是云端编程 Agent 的上下文干扰，与端侧部署无关；对任何 Agent 的上下文管理都有启发，且有大规模真实会话数据支撑。
