CacheFlow: Efficient LLM Serving via Automated 3D-Parallel KV Cache Restoration

9 学校预印本 2026-04-28 · Sean Nian; Hanzhang Shen; Zhiyu Wu; Jiahao Fang; Qilong Feng; Fan Lai / arXiv
方向:KV cache方向:云端serving硬件:GPU应用:长上下文推理
这是什么长对话、Agent 和 RAG 场景下，云端 LLM 服务恢复 KV cache（重算还是从外存加载）成了瓶颈，CacheFlow 把恢复过程当成多维并行问题来优化。
有什么结果在多种稠密与混合架构模型上，KV cache 恢复延迟平均比现有方法降低 2.24-3.00 倍，端到端服务延迟改善 1.64 倍。
怎么做到把按 token 和按层的恢复统一成“阶梯式”切分，跨 GPU 分片并行恢复；再用批量感知的动态规划决定每段该重算还是加载，平衡算力和共享 I/O。
评分依据：面向数据中心多 GPU 的 KV cache 恢复，属于云端 serving，对端侧只有思路参考；把恢复视作 token-层-GPU 三维并行的建模有一定新意。
