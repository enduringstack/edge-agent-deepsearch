2026.4.1

12 开源大项目 开源 2026-10-01 · openvinotoolkit / GitHub
方向:推理框架方向:编译部署硬件:NPU方向:KV cache方向:量化
这是什么OpenVINO 发布 2026.4.1，重点改进大模型注意力算子的支持面，并修了一批显卡和 NPU 上出错的问题。
有什么结果官方发布说明列出：GroupQueryAttention 新增因果注意力与部分旋转位置编码支持，MatMulNBits 扩展 bfloat16 并调整权重、缩放、零点的排布以正确解码更多量化模型；修复滑动窗口 KV cache 路径上会导致显存损坏或驱动崩溃的越界索引，以及低精度数据类型下的形状推断错误；显卡侧修复动态形状加零拷贝输出张量时的结果错误、GRU 序列模型的错误结果和布局传播问题；NPU 侧修复在 Intel Core Ultra 第三代处理器上的崩溃并加固了对畸形数据的导入校验。
怎么做到在 2026.4 基础上做维护更新，扩展注意力与量化矩阵乘算子的能力边界，并逐项修复显卡、NPU、CPU 后端上的正确性与稳定性缺陷。
评分依据：OpenVINO 是 PC 和边缘设备上做本地推理的主力运行时之一，这次修的正是 NPU 崩溃和滑动窗口 KV cache 的显存越界，对本地跑大模型的稳定性影响直接。属于维护版本，技术贡献按低计。
