MemDecay: Region-Aware KV Cache Eviction for Efficient LLM Agent Inference

11 学校预印本 开源 2026-07-12 · Venkatesha Matam; Keon Kim / arXiv
方向:KV cache方向:记忆方向:高效推理模型:Qwen
这是什么MemDecay：专为大模型智能体设计的 KV 缓存淘汰策略。智能体上下文里系统指令、计划、工具输出、草稿推理等“区域”寿命差别很大，它按区域分别设定保留优先级和衰减速度，在固定缓存预算下决定丢哪些。
有什么结果在 Qwen2.5-1.5B 和 3B、约 450 与 1,700 token 上下文下测得：系统指令 token 的注意力半衰期为 148–189 个解码步，草稿区仅 14–16 步；钉住关键区域后系统区事实在所有设置下保持满缓存准确率，而基线最多只保住 24 条中的 13 条；对未钉住的内容，累计注意力策略反而更好。
怎么做到无需训练：给每个 token 按所属区域分配基础优先级和衰减率，被注意到时刷新分数，按页淘汰分数最低者，关键区域可直接钉住；衰减率可根据实测的注意力寿命标定。
评分依据：智能体长上下文的 KV 缓存显存瓶颈在端侧小模型上同样突出，实验用的就是 1.5B/3B 小模型，可直接迁移到端侧推理栈。利用智能体编排器已知的提示结构做淘汰是个清晰的新信号，但实验规模较小、论文也承认分数归一化方式有局限。两位作者均为纽约独立研究者，没有公司署名。
