RLM-Cascade: Response-Level Speculative Decoding for Cost-Efficient LLM API Serving

8 学校预印本 2026-06-22 · Haifeng Wu; Srinivasan Manoharan; Fangbo Tu; Junhua Zhao; Jian Wan / arXiv
方向:投机解码方向:云端serving方向:调度服务应用:代码
这是什么在 API 代理层做「整条回复级别」的投机解码，用便宜模型先答、贵模型按需复核。
有什么结果在真实的智能体编码负载上，125 条生产请求中草稿模型采用率 88.8%，API 成本相比直连 Opus 基线降低 45.8%；端到端延迟反而更低，中位响应时间 2026 毫秒对 3698 毫秒，p50 提速 1.83 倍；质量上在 20 项代码、数学和指令任务基准上通过率 100%，高于原生 Opus 的 95%。
怎么做到不需要访问模型架构、也不要求共享词表：一个便宜的快模型先生成候选回复，再由一个轻量复杂度路由器决定强模型是接受、增强还是干脆跳过；配套还有一个基于规则的复杂度路由器，对简单的智能体回合直接走跳过路径，以及一种绕过部分调用的混合工具调用策略。
评分依据：投机解码思路放到回复粒度上确有巧思，但落点是云端 API 成本与代理层，与端侧部署只有宽泛关联；属已有范式的层级迁移，生产数据较实在。
