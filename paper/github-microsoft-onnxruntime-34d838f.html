microsoft/onnxruntime: [CUDA] Add 2-bit MatMulNBits support (#32693)

11 开源大项目 开源 2026-09-21 · microsoft / GitHub
方向:量化方向:推理框架硬件:GPU方向:编译部署
这是什么ONNX Runtime 给 MatMulNBits 算子加上 CUDA 的 2 比特权重支持，把量化位宽进一步往下压。
有什么结果未报告
怎么做到本次提交改动 21 个文件、新增 1459 行，新增专用的 2 比特反量化内核和融合的 GEMV/批量内核，覆盖 fp16、fp32、bf16 三种输入类型，权重与零点按 2 比特布局打包；校验要求分块大小在 16 到 256 之间，并明确拒绝 g_idx 重排等尚未支持的特性。
评分依据：2 比特权重是把大模型塞进小内存的极限手段之一，工业级运行时把它做进主线算子，说明这条路线开始进入可用阶段。
