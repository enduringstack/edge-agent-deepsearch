Long Live the Librarian! A Persistent Search Sub-Agent for Energy-Efficient Multi-Agent Software Engineering Systems

9 学校预印本 开源 2026-05-27 · Seunghyuk Cho; Sunghyun Choi; Jaeseung Heo; Youngbin Choi; Saemi Moon; MoonJeong Park; Dongwoo Kim / arXiv
方向:能耗功耗方向:工具调用应用:代码
这是什么多智能体软件工程系统很费电，这篇论文发现电主要耗在各个智能体重复探索同一片代码产生的冗余输出上。
有什么结果逐 token 能耗归因显示，一个输出 token 的能耗是输入或缓存 token 的 30 到 1000 倍；在 SWE-Bench Verified 和 SWE-Bench-Live 上，引入持久化检索子智能体后，现有多智能体系统每个任务回合的 GPU 能耗降低 11% 到 30%，任务表现不变。代码已开源。
怎么做到引入一个持久化的检索子智能体，记录整个仓库的搜索历史并抑制各智能体之间的重复探索动作；返回结果时只给文件区域的简短引用而不是完整代码片段，进一步压低输出 token 量。
评分依据：能耗归因与输出 token 削减的思路对端侧智能体同样适用，输出 token 能耗远高于输入这一实测结论尤其有参考价值；但实验对象是服务器 GPU 上的多智能体系统，相关度中等偏下。贡献在于把能耗问题定位到冗余输出这一具体来源。
