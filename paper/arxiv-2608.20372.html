Edge-Based Agentic Retrieval-Augmented Generation for Autonomous FHWA Bridge Inspection Compliance

15 学校预印本 2026-06-23 · Viraj Nishesh Darji; Hemaliben Rakeshkumar Darji / arXiv
方向:端侧agent方向:工具调用方向:规划推理应用:RAG
这是什么一个完全断网、跑在普通边缘硬件上的智能体，自动核对桥梁巡检数据是否符合联邦公路局规范。
有什么结果分节感知的切块算法把条款完整率做到 94.2%，而朴素定长切分只有 28.4%；在特拉华州 2023 年全量 874 座桥和得州 200 座桥样本上，结构性缺陷桥梁识别准确率分别为 99.77% 和 100.0%。
怎么做到把对规范手册的向量检索和对桥梁清单表格的结构化 SQL 查询结合起来，由一个有状态的多步 ReAct 规划循环在本地普通边缘硬件上调度这两类工具；切块时用分节感知算法保住法规条目的层级边界，避免定长切分把条款切碎。
评分依据：规划、检索和工具调用这套完整闭环明确运行在现场的普通边缘硬件上且全程离网，针对的正是野外弱连接场景，端侧契合度高；把向量检索与结构化查询放进同一个 ReAct 循环并用分节切块保住法规层级，是面向真实合规场景的扎实系统工作。
