Introducing Claude Sonnet 4.6

7 官方动态 2026-02-17 · Anthropic / Anthropic
Anthropic方向:规划推理方向:工具调用应用:代码应用:长上下文推理
这是什么Anthropic 发布 Claude Sonnet 4.6，在编码、电脑操作、长上下文推理和智能体规划等方面全面升级，并成为免费版和 Pro 版的默认模型。
有什么结果Claude Code 早期测试中用户约 70% 的情况下更偏好 Sonnet 4.6 而非 Sonnet 4.5，59% 的情况下偏好它而非 Opus 4.5；上下文窗口提供 100 万 token 测试版，价格维持每百万 token 3/15 美元。
怎么做到原文未披露训练方法，只说明在一致性、指令遵循和抗提示注入方面做了改进，并经过完整安全评测。
评分依据：云端旗舰模型更新，电脑操作和智能体规划能力与端侧智能体相关但不涉及设备端部署；模型能力提升明显，属于常规代际升级。
