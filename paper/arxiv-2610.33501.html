DualPace: Decoupled Scheduling and Cooperative GPU--CPU Decoding for LLM Serving

10 学校预印本 2026-10-24 · YuXuan Lin; KeQiang Wu; Kingsum Chow / arXiv
方向:云端serving方向:调度服务方向:KV cache硬件:CPU硬件:GPU
这是什么大模型服务里 KV cache 会挤占显存，把部分请求卸载到 CPU 内存是常见办法，但现有系统中 CPU 只能等 GPU 调度。DualPace 把 CPU 变成独立调度的解码引擎，与 GPU 分工协作。
有什么结果在解码为主的场景下，吞吐比 CPU 卸载系统 NEO 高 6.9%–43.2%，比 vLLM 高 11.5%–90.6%，延迟水平不变；在相同 P99 逐词延迟下可承受的请求率比 NEO 高 7.3%–50.5%。
怎么做到GPU 引擎负责预填充和显存内请求的解码，支持 AMX 指令的 CPU 引擎独立批处理并推进内存中请求的解码；需要时 CPU 可把稠密计算部分交给 GPU 协助，离线性能画像指导批大小和路由。
评分依据：面向服务器 GPU+CPU 的大模型服务，属于云端 serving，但 CPU/GPU 异构协同解码的思路对统一内存的端侧设备有一定借鉴意义，相关度 4。作者来自浙江大学宁波全球创新中心。
