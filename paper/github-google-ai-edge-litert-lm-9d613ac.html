google-ai-edge/LiteRT-LM: Let callers verify a draft with DecodeConfig::SetDraftTokenIds.

11 开源大项目 开源 2026-10-31 · google-ai-edge / GitHub
方向:投机解码方向:推理框架方向:高效推理应用:语音
这是什么Google 端侧大模型运行时 LiteRT-LM 新增公开接口 DecodeConfig::SetDraftTokenIds，调用方可以自己提供一串“草稿” token，让模型先并行校验再继续解码，典型用途是流式语音识别里复用上一次的临时转写结果。
有什么结果未报告
怎么做到解码开始时先把调用方给的草稿 token 一次性送进模型并行校验，输出取草稿中与正常解码结果一致的最长前缀，再接一个新解码的 token 后照常往下解码；草稿长度超过剩余输出预算时自动截短。接口打通了会话、任务和串行/多线程执行管理器。
评分依据：LiteRT-LM 是手机和边缘设备上的大模型运行时，把投机解码的草稿校验开放给调用方后，流式语音识别、增量改写等有现成候选文本的端侧场景可以少走逐 token 解码，与端侧推理直接相关；本次是接口层的工程扩展，没有给出提速数字。本周已收录的 76e08ce 是执行器内部的 MTP 草稿校验，本条是面向调用方的外部草稿接口，属于不同功能。
