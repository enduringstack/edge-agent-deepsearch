SeKV: Resolution-Adaptive KV Cache with Hierarchical Semantic Memory for Long-Context LLM Inference

11 公司项目 开源 2026-06-30 · Amirhossein Abaskohi, Giuseppe Carenini, Peter West et al. / arXiv
Microsoft方向:KV cache应用:长上下文推理硬件:GPU
这是什么长上下文推理时 KV 缓存会把显存吃满。SeKV 把上下文切成语义片段，分层存放在 GPU 和 CPU 内存里，需要时再按需还原细节，而不是直接丢弃信息。
有什么结果四个基准上平均比最强的语义压缩基线高 5.9%，在 128K 上下文下比完整 KV 缓存节省 53.3% 的 GPU 显存；新增可训练参数不到 0.05%。
怎么做到按熵把上下文分成语义片段，每段在 GPU 上只留一个摘要向量用于粗路由，在 CPU 上存低秩 SVD 基用于逐 token 重建；解码时用训练好的“放大”机制只展开与当前查询相关的片段，基座模型保持冻结。
评分依据：KV 缓存压缩与 GPU-CPU 分层存放对内存受限设备有直接迁移价值，但实验面向服务器 GPU；分辨率自适应的还原机制有新意。PDF 首页作者署名英属哥伦比亚大学与 Microsoft Research，一作部分工作在微软研究院温哥华实验室实习期间完成。 作者机构依据：arXiv PDF 首页署名 Microsoft（PDF 首页作者机构列有 Microsoft Research，并注明一作部分工作在微软研究院温哥华实验室实习期间完成；其余署名为英属哥伦比亚大学）。
