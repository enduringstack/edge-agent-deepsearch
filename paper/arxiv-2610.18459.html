Teacher-Guided Tool Learning for Small Language Models via Bidirectional KL Constraints

11 公司项目 2026-10-13 · Haoxuan Gao; Qin-Wen Luo; Xiang Chen; Yu Tian; Zequn Sun; Xiaofeng Cao; Jiangchao Yao; Sheng-Jun Huang / arXiv
Qihoo 360方向:工具调用方向:蒸馏
这是什么小语言模型借助外部工具才能在资源受限环境里干更多事，但它们自己靠强化学习很难学会用工具，直接模仿大模型老师又会有行为分布不匹配。SeTPO 是一种有选择地让老师指导学生的训练方法。
有什么结果在 BFCL v4 和 API Bank 上，三种规模的学生模型使用 SeTPO 后整体表现都优于监督微调、纯强化学习和蒸馏基线；摘要未给出具体数字。
怎么做到只在低奖励的轨迹上，把反向 KL 得到的逐 token 老师反馈加进策略优势；同时用正向 KL 持续保留老师示范的行为，并从理论上证明最优策略的期望奖励不低于老师。
评分依据：目标是让可部署在资源受限环境的小模型学会工具调用，对端侧 Agent 有直接迁移价值，但没有设备端实验，相关度给 5。选择性师生双向 KL 约束有理论保证，贡献中等偏上。作者署名中有一位来自 360 安全能力中心。 作者机构依据：arXiv PDF 首页署名 Qihoo 360（arXiv HTML 作者署名中第 4 位作者 Yu Tian 单位为 360 Security Capability Center，其余作者来自南京航空航天大学等高校）。
