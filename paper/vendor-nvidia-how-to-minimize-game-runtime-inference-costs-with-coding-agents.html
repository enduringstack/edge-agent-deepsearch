How to Minimize Game Runtime Inference Costs with Coding Agents

16 官方动态 开源 2026-03-03 · NVIDIA / NVIDIA
NVIDIA方向:端侧agent方向:工具调用方向:安全隐私方向:高效推理硬件:GPU
这是什么英伟达游戏内推理 SDK（NVIGI）1.5 新增代码智能体示例：玩家电脑上本地运行的小语言模型充当游戏队友，一次性写出完整的 Lua 程序来执行指令，而不是反复调用工具，从而少占用与画面渲染争抢的 GPU。
有什么结果原文以“瞄准最近的敌人”为例：工具调用方式需要 3 次推理调用，代码智能体只需 1 次；所选 Lua 运行时约 200 kB、启动不到 1 毫秒。没有给出整体帧率或时延数据。
怎么做到给模型提供获取敌人、设定目标等简单游戏原语，模型生成带循环和筛选的 Lua 代码后由游戏直接执行，在下条指令前不再调用模型；并用选择性加载库、内存分配上限、指令数与调用栈钩子、禁止修改元表等手段把生成的代码关进沙箱。
评分依据：智能体理解指令、生成行动程序和执行的闭环都在玩家 PC 上完成，由本地小模型和本机 GPU 承担，是明确的端侧 Agent；用代码代替多轮工具调用直接针对端侧推理资源紧张的问题，并给出了完整的沙箱安全设计。
