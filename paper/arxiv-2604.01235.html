Runtime Burden Allocation for Structured LLM Routing in Agentic Expert Systems: A Full-Factorial Cross-Backend Methodology

7 学校预印本 2026-03-26 · Zhou Hanlin; Chan Huah Yong / arXiv
方向:评测基准方向:工具调用模型:Llama模型:GPT
这是什么Agent 系统里让大模型输出结构化路由结果，这篇认为这不只是写提示词的问题，而是“结构化工作该放在模型生成、传输压缩还是本地重建”的系统分配问题。
有什么结果在 OpenAI、Gemini、Llama 三类后端上跑了 48 种部署配置、15552 个请求，结论是没有通用最优的路由方式：在 Gemini 和 OpenAI 上很稳的方式到 Llama 上正确率会明显下降，压缩方式的效率收益也强依赖后端。
怎么做到把结构化输出的生成方式、传输压缩、生成后本地重建作为因子做全因子实验，比较正确率、时延和成本。
评分依据：讨论 Agent 系统中结构化路由的运行时开销分配，主要基于云端 API 后端，与端侧关系较弱。贡献是一套跨后端评测方法和部署建议，方法本身较常规。
