ForestPrune: High-ratio Visual Token Compression for Video Multimodal Large Language Models via Spatial-Temporal Forest Modeling

11 学校预印本 开源 2026-03-24 · Shaobo Ju; Baiyang Song; Tao Chen; Jiapeng Zhang; Qiong Wu; Chao Chang; HuaiXi Wang; Yiyi Zhou / arXiv
方向:剪枝稀疏方向:多模态应用:视频
这是什么视频多模态大模型要处理的视觉 token 太多，ForestPrune 是一种免训练的高比例视觉 token 剪枝方法。
有什么结果在 LLaVA-OneVision 上剪掉 90% 的 token 仍保留 95.8% 的平均精度；在 LLaVA-Video 上比 FrameFusion 在 MLVU 上精度高 10.1%，剪枝耗时减少 81.4%。
怎么做到按语义、空间和时间约束在帧间构建 token 森林，再根据树深度和节点角色评估重要性，得到全局剪枝决策。
评分依据：视觉 token 剪枝能直接降低多模态模型推理开销，对端侧视频理解有迁移价值；但实验在服务器 GPU 上，未涉及设备部署。
