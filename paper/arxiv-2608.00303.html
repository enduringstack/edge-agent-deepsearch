CrystalMem: Elastic Memory for Self-Evolving LLM Agents via Knowledge Crystallization

16 学校预印本 2026-07-31 · Beining Wu; Jun Huang / arXiv
方向:端侧agent方向:记忆方向:端云协同方向:能耗功耗硬件:Jetson模型:Qwen
这是什么CrystalMem 为持续自我演化的大模型智能体设计可伸缩的记忆层：存储配额被压缩后再恢复时，能把智能体能力重新找回来，而不是像删除或单向压缩那样永久损失。
有什么结果七个环境、六种骨干模型下恢复后的能力都最高；只用 50% 字节预算即可追平最强基线在满配额时的表现，同等预算下平均领先 4.6 个百分点。在 Jetson 真机上恢复到压缩前 2.0 个百分点以内（CURATOR 为 6.1、LRU 为 9.1），重结晶每批中位 586 毫秒，仅 2.9% 时间阻塞前台推理，同步数据量从 16-17MB 降到 3.4MB。
怎么做到把每条记忆放在四个保真度等级之间升降：按“结晶能量”调度、按优势加权影响力和依赖关系决定先降级哪条；配额回升时在计算和字节上限内做经过验证的“重结晶”，把降级的记忆恢复出来。
评分依据：论文在由一台 Jetson AGX Thor 和两台 Jetson AGX Orin 组成的真实端侧测试床上，让智能体的记忆管理在 Orin 本地运行并驱动机械臂，端侧证据充分；“记忆迟滞”问题和可逆的记忆降级/恢复设计有明显新意。作者来自南达科他州立大学。
