DualDecoder: Accelerate Long Context LLM Inference by Predictive Prefetch

10 公司项目 2026-07-29 · Zuning Liang; Zhiyi Yao; Qi Chen; Yuedong Xu; Hao Dai; Zhiqiang Ding; Tongkai Yang; Jinlong Hou / arXiv
Ant Group方向:KV cache方向:稀疏注意力方向:云端serving应用:长上下文推理硬件:GPU
这是什么DualDecoder 是一个长上下文大模型推理系统，把大部分 KV cache 放在主机内存里，并提前预测下一步要用哪些 KV 再预取回 GPU，省下 GPU 显存。
有什么结果解码吞吐量比现有最好系统最高提升 2.62 倍，同时保持解码延迟和模型质量。
怎么做到利用“前一个推测 token 就能准确预测下一步需要的关键 KV”这一观察，设计双 token 解码流水线识别关键 KV，并按层调度传输让预取与计算重叠，再用分层显存管理器缩小运行时缓冲。
评分依据：稀疏 KV cache 卸载与预取，主要面向云端高并发服务，但对内存受限设备的长上下文推理有迁移价值（相关度 4）；用推测 token 预测关键 KV 的思路有新意（贡献 6）。PDF 首页署名含蚂蚁集团（3 位作者），与复旦大学合作。 作者机构依据：arXiv PDF 首页署名 Ant Group（PDF 首页作者 Hao Dai、Zhiqiang Ding、Tongkai Yang 署名 Ant Group 并使用 antgroup.com 邮箱，与复旦大学合作）。
