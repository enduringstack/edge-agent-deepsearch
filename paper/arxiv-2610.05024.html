LightVLN: Efficient Aerial Vision-and-Language Navigation with Compact Memory and History-Guided Local Aggregation

14 学校预印本 2026-10-04 · Yiming Zhao; Tianshun Li; Jingle He; Ruonan Chai; Xinhu Zheng / arXiv
方向:多模态方向:记忆方向:高效推理方向:编译部署应用:机器人硬件:Jetson模型:Qwen
这是什么无人机按自然语言指令在三维环境里长距离飞行导航，现有模型多依赖 7B 级大模型和稠密的历史画面，算力和内存开销太大，难以放到机载计算机上。LightVLN 用 0.5B 语言骨干配合压缩后的历史记忆和当前画面表示，做成能在机载算力上运行的轻量导航模型。
有什么结果在 OpenFly 数据集上 Test-Seen 成功率 50.93%、Test-Unseen 36.14%，多数指标超过所评估的 7B 骨干基线；AerialVLN-S Val-Seen 成功率 25.83%；在重建的陌生校园场景中，部署在 DJI M350 RTK 外挂的 Jetson Orin NX 16GB 上做闭环硬件在环测试，模型推理 14.61Hz，端到端决策更新 11.13Hz。
怎么做到历史帧直接复用策略已经算好的视觉特征、每帧压成 1 个 token；当前画面用结合历史和指令的局部聚合从 256 个视觉 token 压到 32 个，16 帧历史时观察相关 token 最多 48 个；机载端用 TensorRT 和 TensorRT-LLM 混合精度部署，整个策略约 12.8 亿参数，其中语言骨干 0.5B。
评分依据：在无人机搭载的 Jetson Orin NX 上完成闭环硬件在环部署并给出机载推理频率，端侧证据明确，相关度 8；它是端到端的导航动作模型，环境画面由仿真器提供，不含独立的规划或工具调用闭环，按动作模型归为非端侧智能体。用复用特征的单 token 历史记忆和指令引导的视觉 token 压缩，让 0.5B 模型超过 7B 基线，贡献 6。
