Compressing Long Context into Answer-Aligned Memory Embeddings for LLM Inference

11 学校预印本 2026-09-22 · Md Mostafizer Rahman; Md Faizul Ibne Amin; Md Shahajada Mia; Yutaka Watanobe; Fang Liu / arXiv
方向:KV cache方向:记忆方向:高效推理方向:蒸馏应用:长上下文推理
这是什么长上下文推理被注意力的平方复杂度和 KV cache 的线性增长拖住，CMC 把长输入压成一组对齐到解码器嵌入空间的记忆向量。
有什么结果在九种编码器—解码器组合和四个问答基准上稳定优于基线，SQuAD 上精确匹配最多高 7.3 分、F1 高 4.0 分；生成 3000 个 token 时推理时间和能耗最多降低 20%，峰值保留显存降低最多 50%。
怎么做到把长上下文压成与任意冻结解码器嵌入空间对齐的上下文记忆向量，不改解码器权重；再用两级 KV cache 结合问题引导的记忆选择与局部上下文窗口，压缩器用冻结大模型的答案定向蒸馏来训练。
评分依据：同时压时延、能耗和显存，三项都是端侧长上下文最关心的指标，方法可直接迁移；实验平台是 GPU，没有端侧数据。
