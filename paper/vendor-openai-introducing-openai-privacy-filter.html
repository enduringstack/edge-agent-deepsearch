Introducing OpenAI Privacy Filter

13 官方动态 开源 2026-04-22 · OpenAI / OpenAI
OpenAI方向:安全隐私方向:MoE方向:模型架构方向:高效推理
这是什么OpenAI 开源了一个专门找出并遮盖文本中个人隐私信息的小模型 Privacy Filter，可以在本地、浏览器或笔记本上运行。
有什么结果官方模型卡称总参数 1.5B、每个 token 只激活 50M 参数，支持 128K 上下文，可在网页浏览器或笔记本上运行；准确率原文只称达到业界最好水平，未给出可核对的数字。
怎么做到先按类似 gpt-oss 的结构自回归预训练，再改成双向带状注意力的 token 分类器，一次前向就给所有 token 打上 8 类隐私标签，用约束解码拼成完整片段；前馈层是 128 个专家、每 token 选 4 个的稀疏 MoE。
评分依据：极小激活量的 MoE 分类模型，官方明确定位为可在浏览器和笔记本本地运行，适合在数据上云前做端侧脱敏；把生成式模型改造成单次前向分类器的做法有一定新意。
