Confidence-Driven Multi-Scale Model Selection for Cost-Efficient Inference

8 学校预印本 2026-02-25 · Bo-Wei Chen; Chung-Chi Chen; An-Zi Yen / EACL 2026 Findings
方向:端云协同方向:高效推理方向:评测基准
这是什么大模型越大越准但越贵。这篇让小模型先判断自己有没有把握，有把握就自己答，没把握再交给大模型，用来省算力和 API 费用。
有什么结果在 MMLU 上准确率接近最大模型，同时计算成本降低 20%–40%；用于 GPT-4o API 调用时 token 用量减少约 60%。
怎么做到同时估计模型“是否知道正确答案”和“回答是否准确”两种置信度，按置信度把任务留在小模型或升级给更大模型。
评分依据：模型级联/按置信度路由是端云协同的常见思路，作者也提到边缘设备场景，但实验只在云端模型和 API 上做，没有设备实测；方法属于常见的置信度路由改进。
