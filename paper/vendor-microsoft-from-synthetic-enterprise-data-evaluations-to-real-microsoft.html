From synthetic enterprise data evaluations to real Microsoft Copilot AI confidence

5 官方动态 2026-10-30 · Microsoft / Microsoft
Microsoft方向:评测基准方向:安全隐私
这是什么微软研究院搭建了行业评测数据生成平台，用公开数据合成完整的虚拟企业环境，在不碰真实敏感数据的前提下评测 Microsoft Copilot。
有什么结果相比最初的生成方法，衡量合成数据与真实企业环境相似程度的综合质量指标提升 39%。
怎么做到以 O*NET 职业数据、招聘信息和美国证券交易委员会文件等公开数据为基础，生成模拟真实业务流程的企业环境，并自动做内容安全和个人信息检查。
评分依据：面向云端办公助手的评测方法，与端侧部署无关；用合成企业环境替代敏感数据的思路有一定参考价值。
