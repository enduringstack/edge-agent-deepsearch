这是什么Google 端侧推理运行时 LiteRT 发布 2.3.0，重点提升大语言模型在手机和电脑 GPU、NPU 上的效率，并新增 iOS/macOS 的 Swift 接口和三星 Exynos NPU 支持。
有什么结果Metal 上的 FlashAttention 让解码最高快 38%、预填充最高快 2.98 倍，32K 上下文时峰值内存减少 4GB 以上；新的融合 GPU 内核让解码快约 12%；Intel NPU/GPU 通过权重共享把预编译 LLM 体积减少约一半；联发科 NPU 支持扩展到所有 Android S 及以上版本。
怎么做到在 Apple GPU 上用 FlashAttention 和 QKV-RMSNorm-RoPE、SwiGLU 融合内核减少访存；iOS/macOS 用 Metal 内存驻留避免换页，程序缓存用零拷贝 mmap 降低峰值内存；GPU 加速器 ML Drift 独立开源，GPU 和各厂商 NPU 库拆成独立的 Maven 包按需引入。
评分依据：谷歌官方端侧推理运行时的版本更新，改动全部面向在手机和电脑本机运行 LLM，相关度 8。多为成熟优化手段（FlashAttention、算子融合、权重共享）在端侧落地，但给出了明确的提速和省内存数字，贡献 5。
