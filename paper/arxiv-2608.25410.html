方向:端云协同方向:多模态方向:高效推理
这是什么在资源受限的边缘系统里做端云协同推理，直接传 token 嵌入既费带宽又不能跨模型通用；这篇改成按 token 相关性传压缩后的图像潜变量。

怎么做到框架由 token 级的任务相关性决定哪些压缩后的图像潜变量需要传输，实现 token 粒度的传输而不直接发送 token 嵌入；三个预训练组件模块化协同工作。
评分依据：明确面向资源受限边缘系统的端云协同推理，通信量是端侧的真实瓶颈，端侧契合度较高。用 token 相关性驱动的潜变量传输回避了嵌入空间不通用的问题，属于合理设计。
