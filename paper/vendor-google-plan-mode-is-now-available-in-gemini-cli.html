Plan mode is now available in Gemini CLI

8 官方动态 开源 2026-03-11 · Google / Google
Google方向:规划推理方向:工具调用应用:代码
这是什么谷歌给终端编码 Agent Gemini CLI 加入“计划模式”：先只读地研究代码库、理清依赖并提出方案，确认后再动手改代码。
有什么结果未报告
怎么做到计划模式把 Agent 限制在 read_file、grep_search、glob 等只读工具和只读 MCP 工具上，可调用 codebase_investigator 等子智能体，并新增 ask_user 工具在规划中途向用户澄清需求。
评分依据：Gemini CLI 在用户电脑终端里运行，但规划阶段调用的是云端 Gemini 3.1 Pro，本质是云端模型驱动的编码 Agent，按同类编码 CLI 的一贯口径不算端侧 Agent；“先只读规划、再动手修改”的模式对设计本地工具调用的 Agent 有参考价值。原文是功能介绍，没有给出任何效果数据。
