Skilled AI Agents for Embedded and IoT Systems Development

11 学校预印本 2026-03-20 · Yiming Li; Yuhan Cheng; Mingchen Ma; Yihang Zou; Ningyuan Yang; Wei Cheng; Hai "Helen" Li; Yiran Chen / arXiv
方向:评测基准方向:工具调用应用:代码硬件:MCU
这是什么让 AI 编程 Agent 给单片机写固件时，代码能编译却常在真板子上跑不起来。作者做了一套“技能包”式的嵌入式开发 Agent 框架，并配套一个必须在真实硬件上验证的评测集 IoT-SkillsBench。
有什么结果评测覆盖 ATmega2560/Arduino、ESP32-S3/ESP-IDF、nRF52840/Zephyr 三种平台、23 种外设、42 个任务，共 378 次真机验证实验；简洁的人类专家技能能让成功率在各平台接近满分，而 LLM 自动生成的技能收益不稳定，有时反而更差。
怎么做到给 Agent 注入结构化的平台专家知识（技能），在无技能、LLM 生成技能、专家技能三种配置下让 Agent 写代码，并把代码烧录到真实开发板上跑行为测试来判定成败。
评分依据：评测对象是运行在开发机上的编程 Agent，嵌入式板子只是被编程的目标，所以端侧相关度中等；但全部结果都经过真实 MCU 硬件验证，对“Agent 帮写端侧固件”很有参考价值。
