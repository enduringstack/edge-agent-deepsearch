GroupMemBench: Benchmarking LLM Agent Memory in Multi-Party Conversations

9 公司项目 2026-05-14 · Jingbo Yang; Kwei-Herng Lai; Xiaowen Wang; Shiyu Chang; Yaar Harari; Evgeniy Gabrilovich / arXiv
Microsoft方向:记忆方向:评测基准
这是什么现有 Agent 记忆系统和评测都假设一对一聊天，但真实部署常是多人群聊。GroupMemBench 专门评测 Agent 在多人对话中的记忆能力。
有什么结果最强的记忆系统平均准确率只有 46.0%，知识更新类只有 27.1%，术语歧义类只有 37.7%；一个简单的 BM25 基线就能持平或超过大多数 Agent 记忆系统。
怎么做到用基于图的合成流程生成带可控回复结构、按用户画像和目标听众生成发言的多人对话，再用对抗式查询流程把每个问题绑定到具体提问者，覆盖六类记忆能力。
