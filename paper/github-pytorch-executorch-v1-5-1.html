这是什么PyTorch 的端侧推理运行时 ExecuTorch 发布 v1.5.1，主要扩展 Arm、高通、CUDA、Core ML、MLX 和 ROCm 后端并改进下沉流程。
有什么结果发布页记录本次有 18 位首次贡献者。
怎么做到把 CMSIS-NN 升级到 v8.0.0，新增公开的 get_thread_count() 接口，扩展 Arm 对符号形状和动态卷积、池化的支持，在共享的 to_edge 下沉路径里折叠冗余的量化/反量化算子对，并把 Python wheel 扩成带可链接库的 C++ SDK。
评分依据：端侧推理运行时的正式发布，Arm、Core ML 和 MLX 三条端侧后端都有改动，对做设备端部署的人是要跟的版本；本次是补丁版本，改动以增量完善为主。
