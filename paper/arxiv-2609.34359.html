Improving Large Language Models for Code through Runtime Program-State Reasoning

7 公司项目 2026-09-28 · Hongwei Li; Spandan Garg; Yufan Huang / arXiv
Microsoft方向:规划推理应用:代码模型:Qwen
这是什么大模型很少被专门训练去推演程序运行时的状态。这篇设计了两类“程序状态推理”训练任务，检验它们能否让代码模型在修 bug、写回归测试等软件工程任务上更强，并训练出 9B 的 Comet-9B。
有什么结果在问题修复的监督微调中加入两类任务后，SWE-bench Pro 成功率提升 7.25 个百分点、SWT-Bench Verified 提升 9.70 个百分点；继续在两类任务上做强化学习，SWE-bench Pro、SWT-Bench Verified、CyberGym 再分别提升 7.25、26.79、4.67 个百分点；9B 的 Comet-9B 在 SWE-bench Pro 上与 GPT-5.2 的公开成绩相当。
怎么做到一类任务给出有 bug 的程序，让模型构造能暴露它与正确实现差异的输入并预测执行结果；另一类让智能体符号化描述触发 bug 的前置条件、预测后置条件并解释因果，再写成可执行的回归测试。基于 Qwen3.5-9B Base 分阶段做监督微调和强化学习。
评分依据：核心是代码模型的能力训练，与推理部署和端侧运行关系不大；但 9B 小模型达到 GPT-5.2 级别的软件工程成绩，对本地运行的编码智能体有一定参考，相关度 2；训练任务设计有新意，贡献 5。机构依据：arXiv PDF 首页作者 2、3（Spandan Garg、Yufan Huang）署名 Microsoft，作者 1 署名加州大学圣塔芭芭拉分校。 作者机构依据：arXiv PDF 首页署名 Microsoft（PDF 首页作者 2、3（Spandan Garg、Yufan Huang）署名 Microsoft）。
