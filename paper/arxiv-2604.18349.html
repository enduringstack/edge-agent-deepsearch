HiGMem: A Hierarchical and LLM-Guided Memory System for Long-Term Conversational Agents

11 学校预印本 开源 2026-04-20 · Shuqi Cao; Jingyi He; Fei Tan / ACL 2026 Findings
方向:记忆应用:RAG应用:长上下文推理
这是什么长期对话 Agent 的记忆检索常只靠向量相似度，结果塞进很多相似但没用的对话。HiGMem 用“事件摘要—具体对话”两级记忆，让大模型先看摘要再决定读哪些对话。
有什么结果在 LoCoMo10 上，五类问题中四类 F1 最好，对抗类问题 F1 从 A-Mem 的 0.54 提升到 0.78，同时检索的对话轮数少一个数量级。
怎么做到把对话历史组织成事件和对话两层，事件摘要作为语义锚点，由大模型推理预测哪些相关对话值得读，得到更精简的证据集合。
评分依据：Agent 记忆系统检索更少、上下文更短，对端侧内存受限的 Agent 有迁移价值，但未涉及端侧部署；两级记忆加模型引导检索有一定新意。ACL 2026 Findings 接收。
