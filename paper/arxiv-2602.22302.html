Agent Behavioral Contracts: Formal Specification and Runtime Enforcement for Reliable Autonomous AI Agents

10 学校预印本 2026-02-25 · Varun Pratap Bhardwaj / arXiv
方向:安全隐私方向:工具调用方向:评测基准
这是什么AI Agent 靠提示词运行，没有像软件接口那样的“合同”约束，容易跑偏。这篇给 Agent 定义可在运行时强制执行的行为合同：前置条件、不变量、治理策略和恢复机制。
有什么结果在 200 个场景、7 个模型、1980 次会话上，带合同的 Agent 每次会话多发现 5.2–6.8 个基线完全漏掉的软违规，硬约束遵守率 88%–100%，行为漂移被限制在 0.27 以内；每个动作额外开销低于 10 毫秒。
怎么做到把契约式设计搬到 Agent 上，提出带概率的合规定义并证明漂移上界，再实现为运行时检查库 AgentAssert，在每步动作前后检查并触发恢复。
评分依据：属于 Agent 运行时的可靠性与治理机制，开销很低、可迁移到本地 Agent，但论文与设备端部署无关。
