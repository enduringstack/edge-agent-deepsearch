One Token per Multimodal Evidence: Latent Memory for Resource-Constrained QA

14 学校预印本 开源 2026-06-09 · Zhi Zheng; Ziqiao Meng; Hao Luan; Wei Liu; Wee Sun Lee / arXiv
方向:记忆应用:RAG方向:多模态方向:高效推理
这是什么把检索增强问答里的每条文本或图片证据压成一个隐空间 token，让内存和 token 预算紧张的场景也用得起外部记忆。
有什么结果在七个纯文本问答基准和多模态问答基准上与先进 RAG 基线持平，生成端 token 消耗少 3 到 10 倍；在 WebQA 的图像问答上表现最好。
怎么做到用一个小的压缩模型把每条证据编码成单个高维隐 token，查询也映射到同一隐空间做检索，检索到的隐 token 直接喂给预训练大模型生成答案；压缩器用重建、对比和蒸馏三个目标端到端一起训练。
评分依据：明确以资源受限应用用不起原始证据检索为动机，token 和存储开销的下降对端侧助手直接有用，但没有设备端实测。用单个隐 token 同时承担重建、检索和生成三项目标，是比较激进也比较干净的设计。
