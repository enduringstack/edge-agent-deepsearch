Crab: A Semantics-Aware Checkpoint/Restore Runtime for Agent Sandboxes

11 学校预印本 2026-04-30 · Tianyuan Wu; Chaokun Chang; Lunxi Cao; Wei Gao; Wei Wang / arXiv
方向:工具调用方向:调度服务应用:代码
这是什么Agent 在沙箱容器里跑工具时，出错回滚需要保存文件系统和进程状态，但每轮都做快照太贵；Crab 是一个能看懂 Agent 每轮操作语义、只在必要时做检查点的运行时。
有什么结果在 shell 密集和代码修复任务上，恢复正确率从只保存对话历史的 8% 提升到 100%，检查点流量最多减少 87%，整体耗时只比无故障执行多 1.9%。
怎么做到用 eBPF 监视每轮工具调用在操作系统层面产生的实际改动，据此决定检查点粒度；把检查点对齐到对话轮次边界并与等待大模型回复的时间重叠，再统一调度同机多个沙箱的检查点流量。
评分依据：这是云端/服务器上 Agent 沙箱的容错运行时，不在终端设备上运行，但“按 Agent 轮次语义决定状态保存”的思路对端侧 Agent 的回滚恢复有借鉴价值；发现超过 75% 的轮次无需检查点，方法新颖、数字扎实。
