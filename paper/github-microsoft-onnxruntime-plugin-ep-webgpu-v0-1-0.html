ONNX Runtime WebGPU Plugin EP v0.1.0

14 开源大项目 开源 2026-05-29 · microsoft / GitHub
方向:推理框架方向:编译部署方向:量化方向:高效注意力硬件:GPU
这是什么ONNX Runtime 把 WebGPU 执行后端拆成独立插件发布，不用换核心包就能用上 WebGPU 加速。
有什么结果首个版本提供常见 Transformer、视觉和生成式负载所需算子的原生 WebGPU 内核，含各类卷积、矩阵乘与通用矩阵乘、归一化、三种注意力变体、旋转位置编码、量化矩阵乘和量化混合专家等；性能侧提供 DP4A 与子组矩阵的低比特矩阵乘、FlashAttention 内核以及面向 Intel 优化的矩阵乘路径；发布 Windows x64/arm64、Linux x64 和 macOS arm64 原生二进制，以及可与主包并存安装的 Python 包。
怎么做到把 WebGPU 支持从核心二进制中剥离，做成独立版本号的库，在运行时注册到已安装的兼容版本 ONNX Runtime 上，从而让该后端能按自己的节奏迭代。
评分依据：WebGPU 是浏览器与跨平台客户端本地推理的重要通路，拆成插件后用户不必更换核心包即可启用（相关性 8）。算子覆盖和量化内核都比较齐全，打包方式的改变也解决了版本耦合问题（贡献 6）。
