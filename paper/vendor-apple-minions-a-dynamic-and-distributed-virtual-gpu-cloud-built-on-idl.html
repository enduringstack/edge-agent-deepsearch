Minions: A Dynamic and Distributed Virtual GPU Cloud Built on Idle Apple Silicon Devices

10 官方动态 2026-10-12 · Apple / Apple
Apple方向:调度服务方向:高效推理硬件:Apple-Silicon硬件:GPU
这是什么Apple 机器学习研究团队提出 Minions：把平时闲着的大量 Mac（Apple Silicon GPU）拼成一朵分布式虚拟 GPU 云，专门跑大规模机器学习推理任务，缓解集中式 GPU 昂贵、排队久、弹性差的问题。
有什么结果页面未给出量化数字；结论是闲置的 macOS 设备可以在集中式 GPU 资源紧张的环境里组成实际可用的分布式 GPU 推理平台，团队无需额外采购 GPU。
怎么做到系统动态汇聚多台 Mac 的空闲 GPU，统一调度推理任务，并提供容错和资源利用率优化，让任务在设备上下线时仍能继续执行。
评分依据：推理实际跑在 Apple Silicon 终端设备的 GPU 上，属于把端侧算力聚合起来做推理调度，对端侧资源利用有参考价值，但服务对象是团队级批量推理而非用户本机。页面只有系统思路和定性结论，没有性能数据，贡献按工程整合计。
