ActiveMem: Dynamic Latent Memory Trees for Long-Horizon Agents

11 公司项目 2026-09-27 · Song-Li Wu; Jingyi Wang; Zhaocheng Du; Weinan Gan / arXiv
Huawei方向:记忆方向:规划推理应用:长上下文推理模型:Qwen模型:SmolLM
这是什么长流程 LLM Agent 依赖外部记忆，但把历史轨迹当成零散片段来检索，会丢掉步骤之间的依赖、还会串任务。ActiveMem 把经验组织成按执行依赖连接的记忆树，按当前执行阶段取出一整条推理路径。
有什么结果在 Qwen2.5-1.5B、SmolLM3-3B、Qwen3-8B 上覆盖网页搜索、具身任务、数学、代码等九个数据集，均优于现有记忆型 Agent；任务目标数增加时峰值 token 占用几乎不变；在 Qwen3-8B 上去掉层级记忆树后，GPQA 从 54.49% 跌到 44.53%，BigCodeBench 从 84.39% 跌到 69.88%。
怎么做到把轨迹抽象成可复用的子任务节点并保留执行转移关系，由一个独立的轻量控制器读取检索到的路径、生成潜在前缀注入冻结的 LLM；记忆的扩展、检索和剪枝策略用 GRPO 强化学习训练。
评分依据：Agent 长期记忆的组织与检索属于可直接迁移到端侧 Agent 运行时的技术，且在 1.5B–8B 小模型上验证、记忆开销随任务变长基本不涨，但没有设备端实测，相关度 5。依赖感知的潜在记忆树加强化学习维护策略有一定新意，贡献 6。PDF 首页显示作者 3、4（含通讯作者 Zhaocheng Du）署名 Huawei Noah’s Ark Lab。 作者机构依据：arXiv PDF 首页署名 Huawei（PDF 首页作者 3 Zhaocheng Du（通讯作者）、作者 4 Weinan Gan 署名 Huawei Noah’s Ark Lab）。
