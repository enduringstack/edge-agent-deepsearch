GeoGR: Spatial-Semantic Token Compression and Group Routing for Efficient 3D VLMs

10 学校预印本 开源 2026-10-09 · Yongxin Zheng; Hao Wu; Fang Li; Hu Fu; Peiran Yin; Xudong Wang; Haozhe Hu; Xinghao Chen / arXiv
方向:多模态方向:高效推理方向:剪枝稀疏
这是什么让图像/视频大模型理解 3D 场景时，多视角输入带来的视觉 token 序列很长，推理很贵。GeoGR 同时压缩场景表示和 LLM 内部的视觉计算，给 3D 视觉语言模型提速。
有什么结果在 LLaVA-OneVision-7B 和 Video-3D LLM-7B 上分别保留稠密后训练模型 95.2% 和 96.8% 的性能，同时 LLM 预填充阶段分别加速 6.8 倍和 6.1 倍；压缩感知后训练只用了原训练池 30% 的 6.7 万条样本。
怎么做到投影层把多视角观测合并成 3D 体素 token，按语义显著性和空间覆盖挑出紧凑子集，未选中的特征聚合成上下文锚点；LLM 层内让低相关 token 成组跳过整层计算但保留隐状态，并可在后续锚点层重新加入。
评分依据：视觉 token 压缩和逐层跳过是端侧多模态推理可借鉴的提速手段，但实验针对服务器 GPU 上的 7B 模型，相关度 4；跨视角体素合并加可恢复的分组跳层设计较完整，贡献 6。作者来自宁波东方理工大学、上海交通大学、香港理工大学和慕尼黑大学。
