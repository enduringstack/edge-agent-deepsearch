OntoAR-HAR: Ontology-Guided Agentic RAG with Personalized Memory for Human Activity Recognition

8 学校预印本 2026-10-11 · Xiangqing Lu; Tao Zhu; Liang Yu; Shuangjian Li; Lulu Ban; Furong Duan; Mingxing Nie; Liming Chen / arXiv
方向:记忆应用:RAG
这是什么用可穿戴传感器识别人的活动时，大模型检索增强方法常用一套静态的人群知识去比较大量无关候选。OntoAR-HAR 用活动本体树和个人记忆来组织检索，让大模型逐层做局部判断。
有什么结果在跨被试和异构传感实验中，层次检索与个人记忆带来互补收益，在多个大模型上达到最优；具体数字原文摘要未给出。
怎么做到把活动分类拆成沿本体树的逐层局部决策，静态库提供该节点的示例，离线挖掘的可执行信号特征提供数值证据，个人库收集用户观测，由大模型综合后走到叶子标签。
评分依据：面向可穿戴活动识别，但大模型推理通过云端 API 完成，没有端侧执行；个人化记忆加本体检索的组合有一定新意。
