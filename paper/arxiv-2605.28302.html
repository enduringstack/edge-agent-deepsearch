How Far Can Disaggregation Go? A Design-Space Exploration of Attention-FFN Disaggregation for Efficient MoE LLM Serving

8 公司项目 2026-05-27 · Hanjiang Wu; Abhimanyu Rajeshkumar Bambhaniya; Sarbartha Banerjee; Tuhin Khare; Sudarshan Srinivasan; Suvinay Subramanian; Souvik Kundu; Madhu Kumar / arXiv
Intel; Google方向:云端serving方向:MoE方向:调度服务硬件:GPU模型:DeepSeek
这是什么混合专家模型的推理服务正越拆越细，这篇论文系统评估了把注意力和专家前馈网络拆到不同 GPU 组上到底什么时候划算。
有什么结果在严格的首 token 时延和逐 token 时延约束下，该拆分方式在 DeepSeek-V3.2 上于聊天、编码和智能体编码三类负载上维持约每秒 4000 token 的系统吞吐，而不拆分的部署方式在同样约束下根本不可行。
怎么做到用一个把设备上实测算子性能与高保真网络仿真结合起来的框架，在输入输出长度、前缀缓存复用率和单用户时延约束等多个维度上，对比分块预填充、预填充解码分离和算子级注意力-前馈分离三档方案，并给出按负载与模型结构划分 GPU 的设计原则。
