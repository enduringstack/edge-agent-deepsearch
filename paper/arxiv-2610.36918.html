TrawMem: Reframing Agent Memory as Task-Oriented Role-Adaptive Workspaces

9 学校预印本 2026-10-27 · Mingyu Zhang; Zixu Li; Zhiheng Fu; Zhiwei Chen; Jinhe Bi; Yupeng Hu / arXiv
方向:记忆模型:Qwen模型:DeepSeek
这是什么大模型智能体的长期记忆通常只按“和当前问题像不像”来取，但同一条记忆在不同任务里作用不同。TrawMem 把记忆检索改成按任务需要的角色来组织一个工作区。
有什么结果在 LoCoMo 和 MemGallery 上，用四种开源/闭源底座模型，宏平均 F1 比代表性记忆系统高 2.23–3.14 分；LoCoMo 上用 Qwen3.5-9B 和 DeepSeek-V4-Flash 时，LLM 评审分比 SimpleMem 高 4.07 和 4.31 个百分点，同时上下文 token 分别少约 12.8% 和 5.1%。
怎么做到先把交互历史整理成若干条本地线索，再给候选记忆分配“直接支撑答案”“连接补充信息”等角色，联合挑选互补记忆组成任务工作区。
评分依据：属于智能体记忆运行时，省上下文 token 的思路对资源受限设备有迁移价值，但实验未涉及端侧部署；方法是对现有记忆检索的有意义改进，属中等贡献。
