GAAMA: Graph Augmented Associative Memory for Agents

9 学校预印本 开源 2026-03-29 · Swarna Kamal Paul; Shubhendu Sharma; Nitin Sareen / arXiv
方向:记忆应用:RAG
这是什么让聊天 Agent 拥有跨会话的长期记忆：GAAMA 把对话整理成带概念节点的知识图谱，比普通向量检索更能保留记忆之间的关系。
有什么结果在 LoCoMo-10 上平均得分 79.1%，比调优后的 RAG 基线高 4.2 个百分点；在 MemoryArena 三项任务上分别比全上下文基线高 0.4、3.4、0.7 个百分点，对话越长优势越大。
怎么做到三步建图：保存原始对话片段、用大模型抽取事实和主题概念、再合成更高层反思；检索时结合向量近邻和按边类型加权的个性化 PageRank，并在检索失败时自动修补图谱。
评分依据：Agent 长期记忆是端侧 Agent 运行时的关键组件，方法可迁移，但本文没有讨论端侧开销；作者来自 Nagarro 公司，代码已开源。
