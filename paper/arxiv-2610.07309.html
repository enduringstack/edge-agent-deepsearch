The Right Memory in the Wrong Context: Verifying Retrieval Admissibility in Long-Term Agent Memory

这是什么长期记忆智能体可能检索到相关但不该用的记忆，比如属于别的用户、违反策略或已经过期的内容，而召回率和最终答案准确率都看不出这个问题。论文提出一套检索可准入性验证框架，单独检查候选记忆是否允许进入提示词以及是否被泄露。
有什么结果在 RHELM 和 MemOps 两个公开长期记忆基准的 3,767 个查询上，按命名空间过滤后 top-20 关键证据召回从 0.432 升到 0.533，达到 80% 召回的可行比例从 0.237 升到 0.311，精确相似度计算量减少 98.3%；在 1,523 个配对样本上，命名空间路由与 0.053 到 0.068 的评判准确率提升相关（作者说明这是观察性结果）。
怎么做到给每个记忆和查询的组合标注可准入、不可准入或无法判定三种状态，在相同必要证据召回率下比较不同检索路线，并跟踪记忆 ID 从进入提示词到出现在答案里的全过程，把暴露和泄露分开度量。
