Reorienting the Vector Axis: Restructuring FlashAttention for Long-Vector Processors

11 学校预印本 2026-10-21 · Emmanuel Irabor; Marc Casas / arXiv
方向:高效注意力方向:编译部署硬件:CPU硬件:FPGA
这是什么FlashAttention 几乎都在为 GPU 优化，在长向量 CPU（一个向量寄存器可装 512 个单精度数）上效率很低。这篇工作重排了注意力内核的向量化方向。
有什么结果原样移植的 PyTorch CPU 版 FlashAttention 只用到峰值浮点算力的 16.2%；两项改动让整个内核周期在头维度 64 时减少 1.84 到 2.08 倍，利用率升到 29.7%，softmax 部分的向量访存指令减少 78.7%；同一设计的 FPGA 实现上加速达 2.71 倍。
怎么做到把分数块和输出转置，让查询沿连续轴排列，这样一个参数就能决定整个内核的向量长度，两次归约也随之消失；再把指数函数多项式系数挪到标量寄存器，消除寄存器溢出。
评分依据：在 RISC-V 长向量处理器真实芯片上优化注意力内核，对端侧 CPU 推理有直接参考，但主要面向高性能向量处理器。分析细致、改动巧妙。
