Multi-task LLMs for Bug Classification: Efficient Inference with Auxiliary Decoding Heads

10 学校预印本 2026-06-08 · Nikolai Rozanov / arXiv
应用:代码方向:高效推理方向:模型架构
这是什么用一个轻量多任务模型做行级别的缺陷定位，替代动辄几分钟推理、上千 token 的智能体式查错。
有什么结果在同类设定里的行级缺陷定位上取得当时最好表现（带整文件上下文）；在 Defects4J 和 PypiBugs 基准上达到与智能体方法相当的水平，而推理时延降低数个数量级，每个文件只需生成一个 token；在小规模的域外 Python 数据集上也显示出较强泛化。
怎么做到三部分：一个解决此前工作中分词对齐难题的算法、一个支持行级缺陷分类的轻量多任务模型，以及一套面向多行预测的训练配方；模型用辅助解码头一次性给出各行判断，而不是逐 token 生成推理过程。
评分依据：用轻量模型加辅助解码头把时延压掉数个数量级，这条用小模型替代长链推理的路线对端侧可直接迁移，但原文不涉及设备部署。每文件只出一个 token 的设计相当干净。
