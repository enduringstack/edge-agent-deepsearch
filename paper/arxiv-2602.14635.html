Alignment Adapter to Improve the Performance of Compressed Deep Learning Models

9 学校预印本 2026-02-16 · Rohit Raj Rai; Abhishek Dhaka; Amit Awekar / arXiv
方向:蒸馏方向:剪枝稀疏
这是什么压缩后的小模型往往比原始大模型效果差，这篇提出一个轻量对齐适配器 AlAd，把压缩模型的 token 表示拉回到和原模型一致。
有什么结果在 BERT 系列模型的三个 token 级 NLP 任务上显著提升压缩模型效果，只增加少量参数和延迟；最小的 BERT-T 推理加速最高 2.80 倍。
怎么做到用滑动窗口对齐压缩模型与原模型的逐 token 向量，保留局部上下文，与具体压缩方法无关，可冻结压缩模型即插即用，也可联合微调。
评分依据：面向资源受限部署的压缩模型补偿方法，可迁移到端侧小模型；但只在 BERT 系列上验证，方法整体属于常见的蒸馏式对齐。
