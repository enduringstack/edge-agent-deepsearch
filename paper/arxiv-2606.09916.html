IntentKV: Cross-Turn Intent-Aware KV Cache Pruning for Agent Inference

11 学校预印本 2026-06-06 · Junjie Li; Jiong Lou; Jie Li / arXiv
方向:KV cache方向:工具调用方向:高效推理模型:Qwen
这是什么多轮智能体一次提问会展开成很长的工具调用轨迹，这篇让 KV 缓存按跨轮意图来淘汰，而不是无差别保留。
有什么结果在紧预算下几乎没有精度损失：8k 的 KV 预算下，Qwen3-8B 的请求峰值 token 平均降低 23.9%、Qwen2.5-14B 降低 30.7%；在所有方法都能跑完的 100 条最长查询上，最坏情况的请求峰值 token 从 9.23 万降到 2.05 万（降 77.8%），最坏情况的原始 KV 读取量从 4.11 亿降到 3100 万（降 92.6%）。
怎么做到主模型保持冻结，维护一个会话级的查询记忆来保存跨轮意图，用记忆注意力规则给历史 token 打分，并加一个零初始化的残差头对当前查询的键向量做交叉注意力；淘汰通过槽位映射重定向实现，被丢弃的位置指向一个哨兵空槽，而存活的键值行、位置编码相位和槽位身份保持不动，因此能与前缀缓存共存。
评分依据：长程智能体的 KV 内存和读带宽是端侧最先撞墙的资源，这项工作把峰值占用压下近八成，迁移价值明确，但实验在服务器模型上。用槽位重定向保持与前缀缓存的可组合性，是很实际的工程考虑。
