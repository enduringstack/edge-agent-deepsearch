方向:KV cache方向:高效推理模型:Qwen模型:Llama模型:Gemma
这是什么“把提示词重复一遍”能提升大模型推理效果，但会让 KV cache 翻倍。PartRep 只重复最有信息量的那部分 token，用更少开销拿到大部分收益。
有什么结果在 MMLU、GSM8K、RULER 等 8 个基准和 Qwen2.5、Llama3.2、Gemma4 三个模型族上，保留了完整重复的大部分收益，而 KV cache 只用完整重复的 59.4%，预填充计算量为 79.0%。
怎么做到用逐 token 负对数似然衡量“难预测”的 token 并优先重复；为避免额外完整前向，训练一个读取浅层隐状态的轻量门控，在预填充中途提前退出完成挑选。
评分依据：直接压缩 KV cache 与预填充开销，可迁移到端侧长上下文推理（相关度 4）；对提示重复做选择性改进，思路简洁但属渐进式（贡献 5）。作者来自万隆理工学院和浦项科技大学。
