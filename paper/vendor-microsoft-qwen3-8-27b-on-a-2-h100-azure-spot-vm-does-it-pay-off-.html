Qwen3.8-27B on a $2 H100 Azure Spot VM: does it pay off?

5 官方动态 开源 2026-10-10 · Microsoft / Microsoft
Microsoft方向:云端serving方向:投机解码方向:KV cache方向:量化硬件:H100模型:Qwen
这是什么Azure 博客：在单张 H100 的 Spot 虚拟机上用 vLLM 自托管 Qwen3.8-27B（混合线性注意力、带 MTP 层），搭好监控后算一笔账，看自托管是否比按 API 价格调用更划算。
有什么结果10 月 9 日最忙的 3 小时里，一张 H100 服务了 1434 个请求、1.687 亿输入 token 和 127 万输出 token，按 API 价约值 24.35 美元，而虚拟机成本只有 4.65 美元；忙时每小时约产出 8.12 美元的 token，GPU 约四分之一时间在忙即可回本，但首周整体约 86 美元的 token 对应约 98 美元算力。FP8 版单请求 172 token/s（BF16 为 124），KV cache 容量 145 万 token（BF16 为 80.5 万）。
怎么做到选用 FP8 检查点降低显存占用、使 KV cache 容量接近翻倍，并开启前缀缓存和 MTP 投机解码；用 OpenTelemetry 采集 vLLM、LiteLLM 网关和 GPU 指标，在 Grafana 看板里按缓存输入、计算输入和输出分别计价。
评分依据：这是云端单卡自托管的成本分析，与端侧部署无关。内容是实用的部署和算账经验，技术新意较少。
