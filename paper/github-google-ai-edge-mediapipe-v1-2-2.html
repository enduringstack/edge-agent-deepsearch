MediaPipe v1.2.2

7 开源大项目 开源 2026-11-03 · google-ai-edge / GitHub
方向:推理框架方向:编译部署硬件:NPU硬件:Snapdragon硬件:手机
这是什么谷歌端侧机器学习框架 MediaPipe 发布 1.2.2，大部分是代码迁移到 Abseil 的整理，端侧相关的改动包括可配置高通 HTP 的 PD 会话、LiteRT 推理输出带上量化参数、共享内存管理器等。
有什么结果未报告
怎么做到新增高通 HTP（Hexagon NPU）PD 会话配置；LiteRT 推理输出附带模型量化信息，CPU 输出视图在非 AHWB 时提前释放；任务可注册共享 MemoryManager；iOS 增加 C API 转换辅助，Web SDK 移除非 SIMD 的 WebAssembly 构建。
评分依据：MediaPipe 是手机端常用推理框架，高通 NPU 会话配置和内存管理改动对端侧部署有实际意义；但本版以重构和小修为主，没有性能数据，贡献较低。
