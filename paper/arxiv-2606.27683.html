CBD: API-Only LLM Black-Box Unlearning through Controlled Behavioral Divergence

7 学校预印本 开源 2026-06-26 · Zhiqiang Xie, Yijing Lin, Zhipeng Gao et al. / arXiv
方向:安全隐私
这是什么CBD 是一种只靠 API 调用、不碰模型参数的大模型“遗忘”方法：当边缘设备通过 API 使用云端大模型时，把需要遗忘的数据对模型行为的影响去掉，同时尽量保留其他能力。
有什么结果在 TOFU forget10 上接近重新训练的参考效果，模型效用达到 74.90，比第二名高约 15%；在 WMDP 上把危险知识准确率降到 25.68，接近随机猜测，同时 MMLU 保持 52.67。
怎么做到用两个辅助模型制造“保留数据”和“遗忘目标”之间的行为差异并转换成相关度分数，把与遗忘目标相关的提问绕开目标模型；再用费舍尔信息构造判别方向，避免误伤句式相似的正常问题。
评分依据：边缘设备只是调用云端大模型的背景，方法本身作用在云端 API 层，端侧相关度低；黑盒遗忘的设计有一定新意。
