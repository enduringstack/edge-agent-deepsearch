Domain-Adaptive Small Language Models for Structured Tax Code Prediction

6 公司项目 2026-11-03 · Souvik Nath; Sumit Wadhwa; Luis Perez / arXiv
Dell方向:模型架构方向:评测基准
这是什么戴尔团队用一个只有 6050 万参数的小型编码器-解码器模型（T5-small），根据商品描述逐级生成海关/税务编码，替代传统平铺分类器和调用大模型 API。
有什么结果T5 精确率 70%、召回 61%、F1 65%，优于 DistilGPT2（F1 62%）、BERT（56%）和 MLP（22%）；作者引用行业估算称自托管小模型单次请求 10-50 毫秒、每百万 token 约 0.04 美元，商用大模型 API 为 200-300 毫秒、4-5 美元。
怎么做到把税码拆成章、目、子目、税号几级，用带专用税码 token 的序列生成方式逐级输出，让生成过程贴合编码层级。
评分依据：属于企业场景的小模型微调应用，部署在本地服务器而非端侧设备；小模型替代大模型 API 的成本和时延对比有参考，但方法常规，成本数字引自行业估算。 作者机构依据：arXiv PDF 首页署名 Dell（PDF 首页三位作者均署名 Dell Technologies，邮箱为 dell.com）。
