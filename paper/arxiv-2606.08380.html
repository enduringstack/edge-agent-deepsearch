Programming Domain-Specific FPGA Hardblocks from HLS: An RTL Blackbox Approach

14 学校预印本 2026-06-07 · Ruthwik Reddy Sunketa; Jeevesh Choudhury; Aman Arora / arXiv
方向:编译部署硬件:FPGA方向:推理框架
这是什么让高层次综合工具能直接从 C/C++ 代码调用 FPGA 上的张量切片等专用硬件块，不必再手写寄存器传输级代码。
有什么结果在基于张量切片的 FPGA 架构上用 AMD 的高层次综合工具和开源布局布线工具链评估，跨多种矩阵尺寸，所生成设计的面积时延积低于行为级综合基线，并且在计入开发效率后显著优于手写寄存器传输级实现。
怎么做到用寄存器传输级黑盒抽象把架构硬件块暴露成可调度的 C 级算子，并给出明确的时延和启动间隔契约，让综合调度器能围绕专用硬件做优化；与传统把黑盒当外部 IP 集成不同，这里把黑盒当成架构抽象，从而无需改编译器就能组合 C 级算子。
评分依据：降低了面向 AI 负载的专用 FPGA 架构的使用门槛，对边缘侧定制加速器落地有直接价值。把黑盒重新定位成架构抽象而非外部 IP，是一个小而关键的视角转换。
