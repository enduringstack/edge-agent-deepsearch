Tropical: Enhancing SLO Attainment in Disaggregated LLM Serving via SLO-Aware Multiplexing

7 公司项目 2026-06-15 · Jinming Ma; Jiefei Chen; Xiuhong Li; Jiangfei Duan; Haojie Duanmu; Xingcheng Zhang; Chao Yang; Dahua Lin / arXiv
SenseTime方向:云端serving方向:调度服务
这是什么大模型服务要同时满足首 token 时延和每 token 时延，预填充和解码放在同一个节点会互相干扰，分开放又会排队等待。Tropical 在两种架构之间取长补短。
有什么结果在真实数据集上，与最好的非分离式和分离式系统相比，在 90% 服务目标达成率下最多多服务 2.09 倍请求；相比分离式系统 P90 首 token 时延改善 9 倍，P90 每 token 时延只下降 15%；相比非分离式系统 P90 每 token 时延改善 2.8 倍，首 token 时延持平。
怎么做到根因分析发现分离式部署干扰小但排队长、非分离式排队短但干扰大，于是设计按服务目标感知的复用策略，在排队时间和干扰之间动态平衡预填充与解码的放置。
