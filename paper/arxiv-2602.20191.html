MoBiQuant: Mixture-of-Bits Quantization for Token-Adaptive Any-Precision LLM

13 公司项目 2026-02-21 · Dongwei Wang; Jinhee Kim; Seokho Han; Denis Gudovskiy; Yohei Nakata; Tomoyuki Okuno; KhayTze Peong; Kang Eun Jeon / arXiv
Panasonic方向:量化方向:高效推理
这是什么在运行时根据资源状况切换大模型量化精度时，固定精度校准的方法表现会变差。MoBiQuant 让每个 token 自己选用合适的比特数，实现任意精度的弹性推理。
有什么结果精度与当前最好的单一精度训练后量化相当或更好，同时具备弹性，相比现有任意精度方法吞吐最高提升 1.34 倍并显著节省内存。
怎么做到发现不同精度下敏感 token 的分布会迁移（异常值迁移），于是用递归残差量化把多种精度装进一套权重、运行时逐级重建高精度，再用 token 感知路由器为每个 token 选择推理精度。
评分依据：任意精度量化正对应端侧设备资源动态变化的需求，可直接迁移，但实验未在端侧设备上做；按 token 路由比特数并解释异常值迁移现象有较好新意。 作者机构依据：arXiv PDF 首页署名 Panasonic（PDF 首页作者 1、4–7 署名 Panasonic AI Lab）。
