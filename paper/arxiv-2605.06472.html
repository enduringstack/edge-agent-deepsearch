Efficient Serving for Dynamic Agent Workflows with Prediction-based KV-Cache Management

9 学校预印本 2026-05-07 · Haoyu Zheng; Fangcheng Fu; Jia Wu; Binhang Yuan; Yongqiang Zhang; Hao Wang; Yuanyuan Zhu; Xiao Yan / arXiv
方向:KV cache方向:云端serving方向:调度服务
这是什么多个 Agent 组成的工作流会共享大量上下文，本可复用 KV 缓存，但实际工作流往往是动态的，下一步调用哪个 Agent 事先不知道。PBKV 通过预测后续调用来管理 KV 缓存。
有什么结果在三个工作流基准上，动态工作流中比 LRU 最高提速 1.85 倍，静态工作流中比此前最优的 KVFlow 最高提速 1.26 倍；完整版本的缓存命中率达 69.10%，而 LRU 低于 30%。
怎么做到结合历史工作流和当前上下文预测接下来几步会调用哪些 Agent，据此估算每个缓存条目的复用价值，把高价值条目留在 GPU 显存；预测只被保守地用于淘汰和预取，以容忍预测错误。
评分依据：面向 GPU 服务器上的多 Agent 工作流服务，与端侧部署只有间接关系；用调用预测指导 KV 缓存管理是对现有方案的有效改进。
