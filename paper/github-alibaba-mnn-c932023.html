alibaba/MNN: Announce MNN-Pocket-0.3B in all README languages (#5096)

14 开源大项目 开源 2026-11-04 · alibaba / GitHub
方向:模型架构方向:量化方向:推理框架硬件:手机硬件:Apple-Silicon
这是什么阿里 MNN 团队发布 3 亿参数的中英文指令模型 MNN-Pocket-0.3B，与 MNN 推理引擎协同设计、专为设备端部署，支持 32K 上下文，以 Apache 2.0 开源。
有什么结果官方称 INT4（W4A16）量化感知训练后的 MNN 版本只占 174 MB，在 iPad Pro M5 上用 Metal 后端、512 token 上下文解码最高 466 tokens/s。
怎么做到模型与 MNN 推理引擎协同设计，用量化感知训练得到 W4A16 的 INT4 版本，直接以 MNN 格式发布；模型合集、MNN INT4 模型和技术报告放在 ModelScope。
评分依据：MNN 是手机淘宝等 30 多个 App 在用的端侧推理引擎，这次发布的是为设备端专门设计的 0.3B 模型及其 INT4 部署包，与端侧部署直接相关；方法上是小模型加量化感知训练的工程整合。来源为 alibaba/MNN 仓库 11-04 的 README 新闻提交（白名单大项目），GitHub 采集器只看 release 和大规模代码提交，因而漏采，经漏检对账补收。
