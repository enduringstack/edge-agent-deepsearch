这是什么开源轻量个人助理 Agent 项目 nanobot 发布 0.1.4.post5，主要是稳定性和记忆、渠道、模型接入方面的打磨，并新增 Ollama 本地模型接入。
有什么结果未报告（版本说明给出的是合入 57 个 PR、新增 29 位贡献者，没有性能数字）
怎么做到Agent 循环与 MCP 连接的异常处理更稳；记忆改为后台异步整理、写入前校验；新增基于 token 的上下文压缩和大模型调用指数退避重试；渠道层改为插件化，新增企业微信等渠道；模型侧新增 Ollama 本地模型、火山引擎、BytePlus 和 OpenRouter 接入。
评分依据：这是常规的 Agent 框架维护版本；新增 Ollama 让 Agent 可以接本地模型，但版本说明没有给出在个人设备上本地运行的实测或设备信息，所以按普通 Agent 运行时更新给中等偏低相关度。
