Entropy Gate: Entropy Quenching for Near-Lossless Token Compression in LLM Pipelines

8 学校预印本 2026-06-02 · Justice Owusu Agyemang; Jerry John Kponyo; Kwame Opuni-Boachie Obour Agyekum; Francisca Adoma Acheampong; Kwame Agyeman-Prempeh Agyekum; James Dzisi Gadze / arXiv
方向:高效推理方向:记忆应用:长上下文推理
这是什么借热力学「淬火」的比喻给提示里的 token 打能量分，低能量的逐步冻掉以压缩上下文。
有什么结果第一阶段的启发式方法在五类提示上实现 40% 到 60% 的压缩且语义相似度保持在 0.80 以上，能量平方放大再加 10 到 25 个百分点；上下文去重在重复块上另省 50% 到 70%；与外部记忆结合后，智能体类负载的总削减可达 88% 到 96%。
怎么做到每个 token 按统计、结构和位置三方面算一个信息能量，再用随时间下降的淬火温度把玻尔兹曼存活概率低于阈值的 token 删掉，同时用保真度门控在能量加权相似度跌破阈值时停止压缩；整套机制无状态、与模型无关，以兼容 OpenAI 接口的 HTTP 代理形式部署。
评分依据：上下文压缩直接减少端侧推理的计算和内存压力，而且实现为模型无关的代理，容易套用（相关性 4）。热力学类比包装下的本质仍是重要性打分加阈值剪枝（贡献 4）。
