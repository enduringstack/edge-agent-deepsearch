Loosely-Structured Software: Engineering Context, Structure, and Evolution Entropy in Runtime-Rewired Multi-Agent Systems

7 学校预印本 2026-03-16 · Weihao Zhang; Yitong Zhou; Huanyu Qu; Hongyi Li / arXiv
方向:规划推理方向:记忆应用:代码
这是什么讨论基于大模型的多智能体系统越做越大后出现的上下文膨胀、协作出错和系统漂移问题，提出一套叫“松散结构软件”的工程方法论。
有什么结果在 RepoBench-R（Python 子集）跨文件代码检索上，加入“语义透镜”后 Hit@5 从 0.70 升到 0.78，再加索引生成器达到 0.84，但 Top1 准确率始终只有 0.10–0.12；执行 Agent 的平均输入从 1543 个 token 降到 1395 个，代价是总 token 数因多出的编排调用而上升。
怎么做到借鉴面向对象编程的经验，把智能体系统分成视图/上下文工程、结构工程、演化工程三层，并给出一组设计模式，例如用专门的“透镜”Agent 替执行 Agent 挑选上下文、用索引把检索负担从执行 Agent 挪走。
评分依据：关注 Agent 运行时的软件工程与上下文管理，与端侧部署没有直接关系，相关度低；以概念框架为主，只在代码检索基准上做了小规模验证。
