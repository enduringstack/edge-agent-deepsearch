AgentWall: A Runtime Safety Layer for Local AI Agents

11 学校预印本 开源 2026-03-24 · Ashwin Aravind / arXiv
方向:安全隐私方向:工具调用应用:安全
这是什么开发者在自己电脑上跑的编程 Agent 能直接执行命令、改文件、调 API，一旦出错后果是真实的。AgentWall 在 Agent 动作落到本机之前拦一道，按策略放行、拒绝或请人确认。
有什么结果在 macOS 上的 14 个基准测试中正确执行策略 13 个（92.9%），平均判定时延 0.198 毫秒、P95 为 0.745 毫秒。
怎么做到以 MCP 代理和 OpenClaw 原生插件的形式拦截每个工具调用，对照声明式策略文件判断，敏感操作要求人工批准，并记录完整执行轨迹用于审计和回放；可用于 Claude Desktop、Cursor、Claude Code 等。
评分依据：直接面向在个人电脑上执行动作的本地 Agent 运行时安全，但被保护的 Agent 规划仍依赖云端模型，论文本身也不涉及本地推理，因此不算真正端侧 Agent。工程实现完整且开源，评测只有 14 个用例，规模偏小。
