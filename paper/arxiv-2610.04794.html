Knowing the Store: What a Memory Backend Must Write Down Before an Agent Can Read It

7 学校预印本 开源 2026-10-03 · Ansuman Mullick; Eray Tüzün / arXiv
方向:记忆方向:评测基准模型:GPT
这是什么带长期记忆的智能体可能会用到已经作废的记录，比如用户后来取消的计划。这篇工作研究记忆库在被检索之前需要向智能体暴露哪些元数据，智能体才能事先判断“这条记录还能不能用”，并为这种判断（元记忆监控）单独构建了评测。
有什么结果在 148 个问题上，当属性名列表较短（平均 2.6 个）时，五个语言模型都没有稳定胜过对属性名做余弦相似度查找的简单方法；列表扩到 60 个名称时，查找法下降 0.18，GPT-5.6 Luna 和 Sol 只下降 0.06 到 0.07、领先 0.13 到 0.14；改用 FR-Bank 自带的元数据后，GPT-4.1 mini、Haiku 4.5 和查找法分别从 0.73、0.82、0.75 降到 0.60、0.71、0.59，说明现有记忆后端缺失或写错了这类信息。
怎么做到只给模型一份不含具体值的记忆库摘要（各生命周期状态的记录数和属性名列表），每个问题针对只差一个属性的三个版本记忆库提问，避免措辞泄露答案，从而单独衡量模型对记忆可用性的判断。
评分依据：关注智能体长期记忆后端的元数据设计，对端侧智能体的本地记忆库也有参考价值，但研究完全基于云端模型和合成数据，相关度 2。把检索前判断记忆是否可用单独拿出来评测，问题定义新颖，贡献 5。
