Microsoft Execution Containers: Policy-driven containment for AI agents

14 官方动态 开源 2026-10-07 · Microsoft / Microsoft
Microsoft方向:安全隐私方向:工具调用应用:代码
这是什么微软执行容器（MXC）正式可用：一个由策略驱动的执行层，把 AI Agent 及其生成的代码、插件和工具关进容器，在用户自己的电脑上限定它能碰哪些文件、网络、进程和界面。
有什么结果已在 Windows 11 正式可用，进程容器后端同时支持 macOS 和 Linux；GitHub Copilot、OpenAI Codex、OpenClaw、Replit、LM Studio、Unsloth 已经支持，Claude Code、Manus、Perplexity 等宣布将接入，NVIDIA 已把 OpenShell 集成进 MXC；正文没有给出性能开销数字。
怎么做到开发者用统一的 JSON 配置声明工作负载需要的文件、网络等资源，MXC 在 Agent 控制范围之外强制执行边界，并按需映射到进程容器（Windows AppContainer、macOS Seatbelt、Linux Bubblewrap）、独立账户和桌面的会话容器、WSL 容器或实验性的硬件隔离微型虚拟机；支持强制、学习（拦截并记录）和宽松（放行并记录）三种模式，企业还可叠加 Intune 策略。
评分依据：直接服务于在个人电脑本机执行动作的 Agent，是 PC 端 Agent 运行时的安全底座，相关度 8。把多系统的隔离后端统一成一套声明式策略并已有多家 Agent 接入，工程价值高，但核心隔离技术沿用操作系统现有机制，贡献 6。
