OCR-Agent: Agentic OCR with Capability and Memory Reflection

7 学校预印本 开源 2026-02-25 · Shimin Wen, Zeyu Zhang, Xingdou Bian, Hongjie Zhu, Lulu He, Layi Shama, Daji Ergu, Ying Cai / arXiv
方向:记忆方向:规划推理方向:多模态应用:OCR
这是什么视觉语言模型做 OCR 时出错后常常反复犯同样的错。OCR-Agent 给模型加了一套“反思能力边界 + 回顾历史尝试”的自我纠错循环，无需额外训练就能提升识别和推理。
有什么结果在 OCRBench v2 上，英文子集比开源最优模型 InternVL3-8B 高 2.0 分、中文子集高 1.2 分，视觉理解 79.9、推理 66.5 均为最优，超过更大的微调模型。
怎么做到先做能力反思：诊断错误并生成修正计划；再做记忆反思：回顾此前尝试避免重复；最后基于两者重新推理优化答案。
评分依据：属于 Agent 式自我纠错，但运行在通用 VLM 上，与端侧部署无关，相关度低。反思机制组合有一定新意。
