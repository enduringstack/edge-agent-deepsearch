Remember Your Trace: Memory-Guided Long-Horizon Agentic Framework for Consistent and Hierarchical Repository-Level Code Documentation

8 学校顶会 2026-05-14 · Suyoung Bae; Jaehoon Lee; Changkyu Choi; YunSeok Choi; Jee-Hyong Lee / NeurIPS 2026
方向:记忆方向:规划推理应用:代码
这是什么为整个代码仓库自动生成文档时，逐个组件独立处理会导致重复检索、描述冲突、缺乏层级。MemDocAgent 让一个长程 Agent 带着共享记忆按依赖顺序写完整个仓库的文档。
有什么结果在多维度评测中，相对开源和闭源基线都取得最佳表现；摘要未给出具体数字。
怎么做到先按依赖和粒度层级预先确定遍历顺序，再让 Agent 通过读、写、校验操作与共享的仓库记忆交互，累积此前的工作痕迹，保证文档一致且有层级。
评分依据：属于 Agent 长程记忆的应用，运行在云端模型上，与端侧只有间接关系，相关度 3；记忆引导的仓库级文档生成是工程上的有效组合，贡献 5。已被 NeurIPS 2026 接收。
