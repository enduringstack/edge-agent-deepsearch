YAIFS: Yet (not) Another Intelligent Fog Simulator: A Framework for Agent-Driven Computing Continuum Modeling & Simulation

7 学校预印本 开源 2026-04-21 · Isaac Lera; Carlos Guerrero / arXiv
方向:工具调用方向:端云协同方向:调度服务
这是什么雾计算/云边仿真器通常是静态工具。YAIFS 把仿真变成可交互服务，并通过 MCP 协议让大模型 Agent 观察和控制仿真。
有什么结果通过两个示例展示：大模型助手用自然语言控制仿真，多智能体在运行时监控负载并调整服务放置；未报告量化指标。
怎么做到分层架构把仿真状态和操作暴露成统一 API，再用 MCP 作为 Agent 与仿真之间的标准工具层，让不同 Agent 共用一套工具访问状态、触发动作。
评分依据：与云边系统和 Agent 工具调用相关，但 Agent 只是操作仿真器，没有在设备端运行。主要是工程整合。
