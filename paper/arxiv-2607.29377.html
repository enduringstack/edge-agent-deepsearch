Zero-Mem: Zero-Token Memory Operations for LLM Agents

13 学校预印本 2026-07-31 · Yilin Xiao; Zhehan Zhu; Yujing Zhang; Jin Chen; Zijin Hong; Luyao Zhuang; Qinggang Zhang; Shengyuan Chen / arXiv
方向:记忆方向:高效推理应用:长上下文推理
这是什么很多 Agent 记忆系统每次存取记忆都要额外调用大模型去总结、检索，既费 token 又费时间。Zero-Mem 让记忆的写入和检索完全不调用大模型，只有最后回答问题时才用一次。
有什么结果在长记忆和长上下文问答基准上效果有竞争力，同时记忆操作的大模型调用和 token 消耗降为零；在相同回答模型和上下文预算下，记忆操作耗时比最快的对比方法再降 57.6%。
怎么做到原样保留交互记录，同时组织成两种结构：跨对话的实体-上下文图，以及保留会话局部性的时间层级；查询时按问题权衡两种视角检索，再用确定性规则剔除冲突证据，最后交给回答模型。
评分依据：Agent 记忆是端侧 Agent 运行时的核心部件，省掉记忆操作中的大模型调用对算力和电量有限的设备尤其有价值，但论文未做设备部署（相关度 6）；“零 token 记忆操作”思路新颖、收益明确（贡献 7）。作者来自香港理工大学、西南财经大学和吉林大学；代码承诺评审后公开。
