RelayCaching: Accelerating LLM Collaboration via Decoding KV Cache Reuse

12 学校预印本 2026-02-28 · Yingsheng Geng; Yuchong Gao; Weihong Wu; Guyue Liu; Jiang Liu / arXiv
方向:KV cache方向:高效推理模型:Llama模型:Qwen
这是什么多个大模型智能体协作时，后一个智能体要重新预填充前一个智能体生成的内容，浪费显存和首 token 时延。RelayCaching 直接复用前一个智能体解码阶段的 KV 缓存。
有什么结果在数学推理、知识问答和代码生成的协作任务上，KV 缓存复用率超过 80%，首 token 时延比标准流程最多降低 4.7 倍，精度几乎无损。
怎么做到作者发现同一段内容在解码和预填充阶段的 KV 缓存高度一致，偏差只集中在少数层和位置；因此只对这些位置重算，其余直接复用，无需训练。
评分依据：多智能体协作的 KV 缓存复用对资源受限设备上的多 Agent 推理有直接迁移价值，实验用 Llama-3.1-8B、Qwen3-0.6B 等小模型，但未在端侧设备测试。
