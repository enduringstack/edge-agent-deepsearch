From fine-tuning to shared serving: Multi-LoRA deployment on Foundry Managed Compute

5 官方动态 2026-10-26 · Microsoft / Microsoft
Microsoft方向:云端serving方向:调度服务模型:Qwen模型:GPT
这是什么微软 Foundry 托管计算推出多 LoRA 适配器部署预览：多个基于同一基座模型微调出的 LoRA 适配器可以共用一个基座部署和 GPU 资源，不必为每个专用版本单独开算力。
有什么结果未报告性能数据；官方说明单个目标部署最多可挂 8 个适配器，适配器本身不单独计费，首批支持 Qwen3.8-27B、Qwen3.6-35B-A3B、GPT-OSS-120B 等模型。
怎么做到平台托管基座模型和支持 LoRA 的服务运行时，每个适配器以独立部署名挂到共享目标上，应用通过兼容 OpenAI 的接口按部署名选择适配器，服务在内部解析到共享基座。
评分依据：这是云端托管服务的产品功能，与端侧部署只有宽泛关联（多 LoRA 共享基座的思路端侧也在用），相关度 2；属于已有技术的产品化。
