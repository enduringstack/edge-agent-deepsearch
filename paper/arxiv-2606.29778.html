Mandol: An Agglomerative Agent Memory System for Long-Term Conversations

11 公司项目 开源 2026-06-29 · Yuhan Zhang, Zhiyuan Guo, Ziheng Zeng et al. / arXiv
Microsoft方向:记忆应用:RAG应用:长上下文推理
这是什么Mandol 是给长期对话智能体用的记忆系统：把原本分散在向量库、图数据库里的记忆统一到一套存储结构中，检索时不调用大模型。
有什么结果在 LoCoMo 和 LongMemEval 上综合准确率在代表性记忆系统中最好；10 QPS 并发下检索快 5.4 倍、写入快 4.8 倍，在配 RTX 5090 笔记本 GPU 的笔记本上仍保持低时延。
怎么做到记忆分为原始层和抽象聚合层，统一表示成语义图；底层数据结构同时融合键值、向量和图三种形式，提供统一混合检索算子，并按查询自适应路由、去噪和按 token 预算生成上下文。
评分依据：智能体记忆运行时是端侧 Agent 的关键组件，论文在笔记本上验证了本地运行时延，但主实验在云端 H800 服务器、整体闭环未在设备端评测；统一存储与免大模型检索的设计有新意。 作者机构依据：arXiv PDF 首页署名 Microsoft（arXiv 首页作者 Wentao Wu 署名 Microsoft Research，其余作者为中国科学院软件研究所）。
