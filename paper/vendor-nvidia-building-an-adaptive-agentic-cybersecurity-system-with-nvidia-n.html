Building an Adaptive Agentic Cybersecurity System with NVIDIA Nemotron

9 官方动态 2026-09-01 · NVIDIA / NVIDIA
NVIDIA方向:工具调用方向:规划推理方向:云端serving应用:安全
这是什么NVIDIA 和 CrowdStrike 搭了一套攻防闭环的智能体系统：红队智能体在隔离环境里发起攻击，蓝队智能体用专门的 Nemotron 模型生成并验证检测规则。
有什么结果回测里平均检出率 41.9%，基线是 16.5%；实弹测试中开放模型生成的检测规则有 45% 能泛化，前沿系统是 29%；三条开放检测达到最高等级并覆盖全部八种未见攻击，前沿系统为零。
怎么做到蓝队侧用结构校验、遥测对齐、专用检测编写、静态检查、回放测试和独立复核六道关卡约束生成；把 Nemotron 3 Super 在 9349 条检测样本上微调，并用可执行查询验证做强化学习，编排交给 Nemotron 3 Ultra。
评分依据：全流程跑在数据中心侧，与端侧部署没有直接关系，只在智能体校验骨架的设计上有参考价值。用六道可执行校验把生成结果钉死在可回放的证据上，方法本身比较扎实。
