pytorch/executorch: [ET-VK][runtime] Preserve binary and permute zero padding

9 开源大项目 开源 2026-11-07 · pytorch / GitHub
方向:推理框架方向:编译部署硬件:GPU硬件:手机
这是什么ExecuTorch 的 Vulkan GPU 后端重写了逐元素二元运算和转置的着色器：缓冲区和纹理两种存储共用同一个向量化着色器，并保证输出的补齐位始终为零，同时修正了几处计算错误。
有什么结果未报告
怎么做到缓冲区张量按 4 对齐补齐并统一写零，使二元运算可以每个线程一次读写 4 个元素；广播判断从编译期常量改为运行时按张量元数据计算，修复了输入尺寸变化后广播结果出错的问题；int32 整除改为向负无穷取整，不支持的取整模式退回 CPU 执行。
评分依据：Vulkan 是安卓手机 GPU 上跑 ExecuTorch 的主要后端，这次改动让缓冲区存储的二元运算走向量化路径并修正了正确性问题，对端侧推理有实际意义；但属于后端内部的算子重构，提交未给出性能数字。
