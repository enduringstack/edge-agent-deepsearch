Physically Partitioned KVCache Format for CPU--GPU Load Balancing in MoE Inference

14 学校预印本 2026-09-13 · Enda Yu; Dezun Dong; Xiangke Liao / arXiv
方向:KV cache方向:MoE方向:高效推理方向:推理框架
这是什么单卡跑长上下文 MoE 模型时 KV 缓存要溢出到内存，这套格式在写入时就定死每个字节放在哪，之后调 CPU/GPU 分工不用再搬数据。
有什么结果在 DeepSeek-V2-Lite、Qwen3-30B-A3B、Mixtral-8×7B 三个 MoE 模型上，32GB 显存预算内支持百万 token 级的端到端推理；长上下文（8K 以上）区间几何平均加速 1.5 到 2.5 倍。
怎么做到提出按设备归属和访问模式两个维度切成四个区域的 KV 缓存布局，写入时固定每个字节的物理驻留位置，把负载均衡变成纯调度问题；再用 WriteScope 沿序列维度切分 CPU 与 GPU 份额，由可移植的屋顶线模型随序列长度决定最优 CPU 占比并在线跟踪偏差。
评分依据：单卡加内存卸载正是消费级硬件跑大模型的常见配置，格式层面的设计很扎实（相关性 7）。写入即定驻留的抽象是有新意的系统设计（贡献 7）。
