ByteRover: Agent-Native Memory Through LLM-Curated Hierarchical Context

11 学校预印本 2026-04-02 · Andy Nguyen; Danh Doan; Hoang Pham; Bao Ha; Dat Pham; Linh Nguyen; Hieu Nguyen; Thien Nguyen / arXiv
方向:记忆
这是什么这是一种“Agent 原生”的记忆架构：由执行任务的同一个大模型自己整理、组织和检索知识，全部以本地 markdown 文件存储，不需要向量库或图数据库。
有什么结果在 LoCoMo 上评测准确率 96.1%，比次优系统高 6.2 个百分点；在 LongMemEval 上结果有竞争力；多数查询不调用大模型，检索时延低于 100 毫秒。
怎么做到把知识组织成“领域-主题-子主题-条目”的文件树，每条带关系、来源和重要度衰减；检索按 5 级逐步升级，只有新问题才动用 Agent 推理。
评分依据：记忆完全落在本地文件系统、免外部基础设施，对 PC 端个人 Agent 有直接参考价值，但评测中的大模型和裁判均为云端 Gemini，不算设备端闭环。公司归属依据 arXiv 首页作者机构。
