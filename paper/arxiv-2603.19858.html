Beyond detection: cooperative multi-agent reasoning for rapid onboard EO crisis response

14 公司项目 2026-03-20 · Alejandro D. Mousist; Pedro Delgado de Robles Martín; Raquel Lladró Climent; Julian Cobos Aparicio / ESA 4S Symposium 2026
Thales方向:端侧agent方向:工具调用方向:多模态方向:量化硬件:CPU模型:Qwen
这是什么地球观测卫星发现火灾、洪水后要先把数据传回地面再分析，延迟很高。这项工作在星上部署分层多智能体：预警 Agent 先快速判断，再按需唤起火灾或洪水专家 Agent 调用遥感工具，最后由决策 Agent 发出告警。
有什么结果在国际空间站上 IMAGIN-e 边缘计算平台的工程样机（ARM 16 核、32 GB 内存）上实测 27 个样本：无灾害场景平均加速 4.78 倍、计算量减少 73.2%；有灾害场景平均加速 1.3 倍、减少 13.5%。
怎么做到预警 Agent 用 4-bit 量化的 Qwen2-VL-2B 视觉语言模型给出初判，只激活相关的专家 Agent 运行传统遥感分析工具，决策 Agent 汇总证据输出事件类型、置信度和解释，避免对每个场景都跑全套分析。
评分依据：规划、工具调用和决策闭环全部在星载边缘计算平台样机上运行，属于真正的其他端侧 Agent；分层路由思路本身不复杂，但把多智能体推理真正搬上轨道硬件是少见的落地验证。 作者机构依据：arXiv PDF 首页署名 Thales（PDF 首页作者邮箱域名为 thalesaleniaspace.com）。
