ShuntServe: Cost-Efficient LLM Serving on Heterogeneous Spot GPU Clusters

6 学校预印本 2026-06-17 · Seungwoo Jeong; Moohyun Song; Juhyun Park; Kyungyong Lee / arXiv
方向:云端serving方向:调度服务硬件:GPU模型:Llama模型:Qwen
这是什么云上便宜的 GPU 抢占式实例最多能省九成费用，但随时会被回收；这篇把多种 GPU 型号混合起来做大模型服务，扛住频繁中断。
有什么结果在 AWS 的 L4、A10G、L40S 混合集群上服务 Llama-3.1-70B 和 Qwen3-32B，吞吐比现有最好方案高 1.42 倍和 1.35 倍；相比按需实例，离线和在线服务的成本效率分别提升 31.9% 和 31.2%。
怎么做到跨多种 GPU 型号做模型放置，用一次性硬件标定的性能估计器（平均误差 6.63%）挑并行配置，并配合容错机制在实例被回收时迁移或重算请求。
评分依据：纯云端 GPU 集群的成本优化，与端侧部署无关，相关度很低，按推理服务相邻工作保留。异构抢占式集群上的放置与容错设计完整，贡献中等。
