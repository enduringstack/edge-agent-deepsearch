KEEPER: Learning Control-Sufficient Textual Memory for Long-Horizon LLM Agents

7 学校预印本 2026-10-30 · Jinkyeong Choi; Chaebin Jeong; Junsung Jeon; Donghyeon Park / arXiv
方向:记忆方向:评测基准
这是什么长任务智能体常用递归更新的文字记忆，但早先写错的内容会一路被带下去，只看任务成功率看不出记忆是否可靠。KEEPER 专门分析这种“记忆自我延续偏差”。
有什么结果在比较的四种辅助训练目标中，预测奖励相关信息的目标在离线强化学习前后任务表现都最好，优于联合监督；摘要未给出具体分数。
怎么做到在统一的递归记忆接口下，按信息含量和更新敏感度两个维度比较四种辅助监督目标，并对一条基线轨迹做逐条论断分析，追踪错误如何在纠正信号出现后仍被保留。
评分依据：研究智能体文字记忆的可靠性，属于 Agent 记忆的通用问题，与设备端部署无直接关系；以对比分析为主，方法创新有限。
