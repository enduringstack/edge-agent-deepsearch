OccamToken: Efficient VLM Inference with Training-Free and Budget-Adaptive Token Pruning

14 学校预印本 2026-05-28 · Geng Li; Guohao Chen; Ting Chen; Shilin Shan; Kuangji Zuo; Bofan Lyu; Tuo An; Gen Li / arXiv
方向:剪枝稀疏方向:多模态方向:高效推理模型:Qwen
这是什么视觉语言模型的图像部分会变成很长一串 token，这篇论文提出一种免训练的剪枝方法，按需决定每张图该留多少。
有什么结果在 LLaVA-NeXT、LLaVA-v1.5 和 Qwen3-VL 上都改善了准确率与效率的权衡；在 LLaVA-NeXT 上把 2880 个视觉 token 压到约 40 个，仍保留超过 93% 的原始准确率，即保留率低到 1.4% 时依然稳定。
怎么做到不再给 token 打分取固定的前 K 个，而是以寄存器 token 作为参照来做相对证据检验：寄存器 token 天然吸收低信息量的注意力，于是可以作为稳定基准，判断某个视觉 token 是否带来了超出基准的信息；再由寄存器注意力推出动态阈值，同时做图像级冗余剪枝和问题相关性剪枝。
评分依据：视觉 token 剪枝直接决定多模态模型在端侧的预填充开销与显存占用，免训练且预算自适应的特点便于迁移到设备端，相关度较高；但论文本身没有端侧实测。贡献在于用寄存器 token 作参照替掉了脆弱的绝对排序范式。
