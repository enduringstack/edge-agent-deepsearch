AgentTrust: Runtime Safety Evaluation and Interception for AI Agent Tool Use

9 学校预印本 开源 2026-05-06 · Chenglin Yang / arXiv
方向:工具调用方向:安全隐私
这是什么AI Agent 调用文件、Shell、网络等工具时一个危险动作就可能造成不可逆损失，AgentTrust 是一个在工具真正执行前拦截并给出放行/警告/阻止/人工审查结论的运行时安全层。
有什么结果内部 300 场景基准上结论准确率 95.0%、风险等级准确率 73.7%，端到端延迟为毫秒级；在 630 个独立构建的对抗场景上（使用修补后的规则）结论准确率 96.7%，混淆 Shell 载荷上约 93%。
怎么做到先对 Shell 命令去混淆，再用规则识别多步攻击链并给出更安全的替代写法，规则拿不准时才调用带缓存的大模型裁判；以 MCP 服务器形式接入兼容的 Agent。
评分依据：属于 Agent 工具调用运行时的安全组件，毫秒级规则层可在本地运行，但论文不涉及端侧设备；工程整合完整并已开源。
