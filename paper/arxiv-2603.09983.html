MoE-SpAc: Efficient MoE Inference Based on Speculative Activation Utility in Heterogeneous Edge Scenarios

14 学校预印本 开源 2026-02-12 · Shuhuai Li; Jianghao Lin; Dongdong Ge; Yinyu Ye / arXiv
方向:MoE方向:投机解码方向:高效推理硬件:GPU硬件:CPU模型:Qwen模型:DeepSeek
这是什么显存有限的设备上跑 MoE 大模型时，专家权重只能放在内存里来回搬，I/O 成了瓶颈。MoE-SpAc 把投机解码的草稿当成“提前预报”，预测接下来要用哪些专家，提前搬运、及时腾位置。
有什么结果单张 RTX 4090（经 PCIe 4.0 连 CPU 内存、显存只缓存 17% 专家）运行 Qwen3-30B-A3B，七个基准平均 25.06 token/s，比最强基线 llama.cpp+投机解码（17.66）高约 42%，比全部标准基线平均快 4.04 倍；在 DeepSeek-V2-Lite 上也比最佳基线快约 53%。
怎么做到用小草稿模型 Qwen3-4B-FP8 先猜几个 token，统计这些 token 会激活哪些专家来估计专家“效用”；再用在线整数优化把计算在 GPU 和 CPU 之间动态分配，并由异步执行引擎统一预取与淘汰。
评分依据：针对显存受限、单请求的本地 MoE 推理，在消费级 GPU 加 CPU 内存的配置上实测，直接适用于 PC 本地跑大 MoE 模型，但没有手机或 NPU 上的结果。把投机解码从“加速计算”改用作“预测专家需求”的信号，思路新颖。
