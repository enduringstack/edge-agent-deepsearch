Analyzing Quality-Latency-Resource Trade-offs in a Technical Documentation RAG Assistant Using LoRA Adaptation

9 学校预印本 开源 2026-05-27 · Evgenii Palnikov; Elizaveta Gavrilova / arXiv
应用:RAG方向:高效推理方向:评测基准模型:Llama
这是什么针对技术文档问答这类检索增强系统，这篇论文系统评估了用 LoRA 微调生成器时质量、时延和资源三者怎么权衡。
有什么结果在 5144 组人工核验的 Kubernetes 文档问答对上，对两个 Llama 模型做了 20 种 LoRA 配置的消融；帕累托分析显示只在注意力的查询和值投影上加适配器的配置始终占优，而 30 亿与 80 亿参数的选择主要决定工作区间；参数量对齐的对照实验进一步说明这种优势是结构性的而非单纯来自参数量。基准、适配器和代码均已开源。
怎么做到固定一套混合检索流水线（稠密加稀疏检索、倒数排名融合、交叉编码器重排），只变动生成器的 LoRA 秩与作用模块，并同时测量 token 级 F1、模型评判的依据充分性与正确性、推理时延、推理内存和训练成本，全部带自助法置信区间。
评分依据：把时延与内存和质量放在同一张帕累托图上比较，这种口径对资源受限部署很实用，模型规模也落在端侧可及区间，相关度中等；但实验环境未针对设备端。贡献是扎实的消融实证而非新方法。
