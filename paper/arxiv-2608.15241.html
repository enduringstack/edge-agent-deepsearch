LOCAL: Enabling Learning On-device Contiguously for Agent LLMs

13 学校预印本 2026-08-15 · Xinxin Liu; Jiaxin Li; Zibo Wang; Yun Ji; Zhangqi Zhu; Qing Hu; Zhibin Wang; Rong Gu / arXiv
方向:KV cache方向:记忆硬件:GPU
这是什么这项工作提出 LOCAL，让大模型 Agent 在单张本地 GPU 上一边服务用户、一边利用私有交互持续学习，不必把数据上传或暂停前台推理。
有什么结果在单张 24 GB GPU 和 7B 级模型上，前台排队等待时间 p95 比 FIFO 降低 3.1 倍，首次 token 时间 p95 比不可抢占训练降低 1.55 倍；模型更新后的首次缓存预填充 p99 降低 25.6%，跨 Agent 首次 token 时间 p99 降低 21.9%。
怎么做到系统让协作式调度器、版本感知 KV 缓存管理器和多 Agent 模型运行时共享适配器版本、任务优先级与缓存状态，使训练更新、请求抢占和失效缓存清理保持一致。
评分依据：论文明确实现单 GPU 上的本地 Agent 连续学习和在线推理，设备侧闭环证据强，相关性高；把调度、适配器版本与 KV 缓存一致性联合起来解决运行时冲突，贡献度中等。
