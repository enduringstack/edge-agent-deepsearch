VeriAgent: A Tool-Integrated Multi-Agent System with Evolving Memory for PPA-Aware RTL Code Generation

8 学校预印本 2026-03-18 · Yaoxiang Wang; Qi Shi; ShangZhan Li; Qingguo Hu; Xinyu Yin; Bo Guo; Xu Han; Maosong Sun / arXiv
方向:记忆方向:工具调用应用:代码
这是什么让大模型写芯片 RTL 代码时不只追求功能正确，还同时兼顾功耗、性能和面积（PPA）的多智能体框架。
有什么结果原文称在保持较高功能正确率的同时 PPA 指标有明显改善；摘要未给出具体百分比数字。
怎么做到由程序员、正确性、PPA 三个智能体轮流调用 EDA 工具形成闭环，再把历次优化经验沉淀为结构化记忆节点，由记忆管理器动态维护，无需重训模型即可持续改进。
评分依据：面向芯片设计流程的云端多智能体工作流，与端侧部署无直接关系；可迁移之处是 Agent 记忆与工具调用闭环的设计，方法属已有范式的工程组合（贡献 5）。
