SinkPruner: Sink-Free Visual Token Pruning for Multimodal Large Language Models

12 学校预印本 开源 2026-09-01 · Shiyu Li; Zi-Yuan Hu; Shijia Huang; Yanyang Li; Yiwu Zhong; Liwei Wang / EMNLP 2026 Findings
方向:剪枝稀疏方向:多模态方向:高效推理模型:Qwen
这是什么多模态大模型处理大量视觉 token 时计算很重；SinkPruner 发现特征范数异常大的“离群” token 其实高度冗余，据此做免训练的视觉 token 剪枝。
有什么结果削减 89% 视觉 token 时，LLaVA-1.5 保留原始性能的 96.5%，Qwen2.5-VL 保留 91.8%；在 12 个图文和 4 个视频基准上验证，其视觉净化模块还能提升其他剪枝方法。
怎么做到先用视觉净化器剔除高范数冗余 token，缓解注意力汇聚和注意力分散，再用文本引导的剪枝器保留与问题语义相关的 token，由粗到细两步完成。
评分依据：视觉 token 剪枝能直接降低端侧多模态模型的计算和显存开销，免训练、易迁移。对高范数离群 token 的观察有新意，代码已开源。作者机构依据 arXiv PDF 首页署名：作者 3、4 来自 Weitu AI。
