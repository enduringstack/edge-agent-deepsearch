MemOS Local Plugin v2.0.21-beta.1

6 开源大项目 开源 2026-11-04 · MemTensor / GitHub
方向:记忆方向:推理框架
这是什么MemOS 本地记忆插件发布 v2.0.21-beta.1 预发布包，主要让本地记忆插件兼容 DeepSeek Harness 0.1.7/0.2.x 的预览版本，方便在新版宿主里继续挂载。
有什么结果未报告
怎么做到把插件对宿主服务的可选依赖改成明确的有界版本范围，替换宿主工具包里已迁走的类型定义，并新增针对多个宿主版本的编译、构建和适配测试矩阵；记忆存储与检索逻辑本身没有变化。
评分依据：记忆存储和检索运行在用户本机，属于智能体记忆运行时，对端侧部署有参考；但这是兼容性预发布，宿主智能体默认调用云端大模型，且正式版 v2.0.21 已在上期收录，本次增量很小。
