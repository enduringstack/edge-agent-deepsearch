OpenRath: Session-Centered Runtime State for Agent Systems

8 学校预印本 2026-06-23 · Fukang Wen, Zhijie Wang, Ruilin Xu / HuggingFace Daily
方向:工具调用方向:记忆方向:调度服务
这是什么给多智能体多会话系统做一个统一的运行时状态抽象，让执行过程可检查、可回放。
有什么结果未报告
怎么做到针对对话记录、工具副作用、记忆事件、工作区位置、分支来源和回放证据各自分开记录、难以检查复现的问题，提出一个类似 PyTorch 的编程模型，核心抽象是在智能体和工作流之间传递的会话值：它可分支、可检查、可回放、感知后端且可组合，记录对话片段、沙箱位置、血缘元数据、token 用量、待办工作和工具证据。由于这份状态就是程序执行时传递的那个值，分叉、合并和回放成为显式的运行时操作，而不必从外部轨迹事后重建。
评分依据：智能体运行时的状态管理与可回放性对端侧 Agent 的可靠性同样重要，但原文无设备端部署内容，相关度按宽泛关联计；把运行时状态提升为一等值从而让回放成为原生操作，抽象设计较有章法。
