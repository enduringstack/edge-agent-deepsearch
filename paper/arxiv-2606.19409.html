OpenRath: Session-Centered Runtime State for Agent Systems

8 学校预印本 2026-06-23 · Fukang Wen, Zhijie Wang, Ruilin Xu / arXiv
方向:记忆方向:工具调用方向:调度服务
这是什么智能体系统的对话记录、工具副作用、记忆读写、沙箱位置和分支来源通常散落在各处，事后很难检查和复现。OpenRath 提出以“会话（Session）”为核心的编程模型，把这些运行时状态收进同一个可传递的值里。
有什么结果未报告
怎么做到Session 是在智能体和工作流之间传递的一等运行时对象，记录对话片段、沙箱位置、血缘元数据、token 用量、待办任务和工具证据，因此分叉、合并、回放都变成显式的运行时操作；另定义 Sandbox、Tool、Agent、Memory、Workflow、Selector 等组件，Selector 把控制流变成运行时路由决策。
评分依据：属于智能体运行时的状态管理与可回放设计，对端侧 Agent 的可调试性有参考价值，但没有任何设备端部署内容，相关度按宽泛关联计；把运行时状态做成一等值的思路清晰，但原文明确不提供定量对比，贡献中等。
