Microsoft Sovereign Cloud adds governance, productivity and support for large AI models securely running even when completely disconnected

7 官方动态 2026-02-24 · Microsoft / Microsoft
Microsoft方向:编译部署方向:安全隐私方向:多模态
这是什么微软主权云新增完全断网可用的能力：Azure Local 断网运维、Microsoft 365 Local 断网版正式可用，Foundry Local 支持把大模型和多模态模型放到客户自有硬件上离线推理。
有什么结果未报告
怎么做到以 Azure Local 作为本地基础设施，在客户自己的机房内完成管理、策略和负载执行；Foundry Local 借助 NVIDIA 等合作方硬件在本地跑大模型，不依赖公有云连接。
评分依据：大模型离线本地推理和数据不出域属于本地部署方向，但目标是企业机房级服务器而非手机或电脑；以产品可用性公告为主，没有技术细节和性能数字。
