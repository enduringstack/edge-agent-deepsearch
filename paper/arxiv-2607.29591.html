ResKV: Reconstructing Omitted Attention Contributions for Fixed-Budget KV Cache Compression

12 学校预印本 2026-07-31 · Yuhang Zhan; Lisi Chen; Shuo Shang / arXiv
方向:KV cache方向:高效推理应用:长上下文推理
这是什么KV cache 压缩通常把没选中的 token 直接扔掉，连同它们对注意力的总贡献也一起丢了。ResKV 把固定的 KV 预算分成精确主缓存和一个小的残差缓存，用来补回被省略 token 的贡献。
有什么结果在 LongBench 和 RULER 上、多种骨干模型和缓存预算下，相同 KV 预算时普遍优于原有压缩方法，紧预算下收益尤其明显，同时峰值显存和长上下文解码吞吐基本不变。
怎么做到把被逐出 token 对 softmax 分子和分母的贡献表示为残差统计量，让残差条目和主缓存一起参与同一次 softmax 归一化；每层每头的残差分配由构建期验证代理决定，解码时再用动态门按查询调节。
评分依据：KV cache 压缩直接决定长上下文模型在内存受限设备上能否跑得动，属端侧可直接迁移的推理技术（相关度 6）；补回被逐出 token 注意力质量的思路扎实（贡献 6）。作者来自电子科技大学。
