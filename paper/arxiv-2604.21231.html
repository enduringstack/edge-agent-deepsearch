SparKV: Overhead-Aware KV Cache Loading for Efficient On-Device LLM Inference

16 学校预印本 2026-04-23 · Hongyao Liu; Liuqun Zhai; Junyi Wang; Zhengru Fang; Jingshu Chen; Jun Huang / arXiv
方向:KV cache方向:端云协同方向:能耗功耗硬件:Jetson硬件:GPU硬件:手机模型:Qwen模型:Llama
这是什么端侧大模型处理长上下文时，预填充阶段（算出 KV 缓存）又慢又耗电。SparKV 让设备在「从云端下载现成 KV 缓存」和「本地自己算」之间按块灵活选择。
有什么结果在 RTX 5080 笔记本 GPU 和 Jetson AGX 上，相比已有高效 KV 加载方案首字时延降低 1.3-5.1 倍，单次请求能耗降低 1.5-3.3 倍，回答质量几乎不受影响；前期测量还覆盖了 Redmi K80 Pro 手机 NPU 和 Jetson Orin。
怎么做到为每个 KV 块估算下载与本地计算的代价，决定走哪条路径，并让两条路径并行重叠；运行时再根据无线网络波动和设备负载实时调整离线排好的调度。
评分依据：在笔记本、Jetson 和手机 NPU 等真实设备与真实 Wi-Fi 网络上测试，直接面向端侧长上下文推理，相关度高；按块权衡传输与计算并在线自适应调度，贡献较高。
