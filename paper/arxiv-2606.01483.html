MURMUR: An Efficient Inference System for Long-Form ASR

11 学校预印本 开源 2026-05-31 · Wei-Tzu Lee; Keisuke Kamahori; Baris Kasikci / arXiv
方向:KV cache方向:高效推理方向:调度服务应用:语音
这是什么长音频转写要么准要么快，这套推理系统想两头都占。
有什么结果在 AMI-IHM 上达到单次通过方案的准确率，同时把时延降低 4.2 倍；再叠加 token 驱逐后相对 tcpWER 退化不到 1%。代码已开源。
怎么做到两个层面：块间层面把分块大小当作可调超参重新审视分块流水线，发现中等块长在精度和时延之间最平衡；块内层面利用注意力稀疏性，对输出 token 和语音 token 都施加滑动窗口的 KV 缓存驱逐。
评分依据：低时延长音频转写是端侧语音助手的典型需求，KV 驱逐和分块策略都可迁移，但系统未在设备上实测（相关性 5）。两个层面的处理配合得当，收益明确（贡献 6）。
