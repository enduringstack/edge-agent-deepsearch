DualMap: Enabling Both Cache Affinity and Load Balancing for Distributed LLM Serving

8 公司项目 2026-02-06 · Ying Yuan; Pengfei Zuo; Bo Wang; Zhangyu Chen; Zhipeng Tan; Zhou Yu / arXiv
Huawei方向:KV cache方向:调度服务方向:云端serving
这是什么分布式大模型服务里，想复用相同前缀的 KV cache 就得把请求集中到同一台实例，想负载均衡又得把请求打散，两者经常冲突。DualMap 想同时兼顾这两件事。
有什么结果在真实负载上，同样的首字时延 SLO 约束下，有效请求容量比现有最优方案最高提升 2.25 倍。
怎么做到每个请求按提示词用两个独立哈希映射到两台候选实例，再根据实时负载二选一；另外加了超 SLO 时切换到负载优先、热点请求迁移和双哈希环快速扩缩容。
评分依据：这是数据中心多实例 LLM 服务的调度工作，和端侧设备关系较远，只有前缀缓存复用的思路可参考；方法把“二选一”负载均衡用到缓存亲和调度上，属扎实的工程整合。论文首页显示多位作者来自华为、通讯作者使用 huawei.com 邮箱。 作者机构依据：arXiv PDF 首页署名 Huawei（论文首页作者 2、3、4、6 署名 Huawei，通讯作者 Pengfei Zuo 使用 huawei.com 邮箱，第一作者注明在华为实习期间完成）。
