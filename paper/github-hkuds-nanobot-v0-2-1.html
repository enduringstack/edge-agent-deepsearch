这是什么开源个人智能体 nanobot 发布 v0.2.1，重点把网页工作台、长时任务的稳定性和扩展接入做扎实。
有什么结果本次发布合入 84 个 PR、新增 17 位贡献者；网页界面上文件改动会实时显示为活动、工具轨迹渲染更清晰、新会话刷新后不丢失；长时任务方面提高了目标迭代预算、加入会话锁防止回合重叠、修复了自动压缩与整合的竞态和会话归档的多处数据丢失问题；命令行应用与 MCP 统一了扩展路径，并新增扩展注册表。
怎么做到把设置、侧边栏、模型切换、上下文窗口控制、斜杠命令、项目工作区和访问模式收敛到同一套控制面；把心跳改到定时任务上执行，并统一命令行应用与 MCP 的扩展接入方式。
评分依据：本地运行的开源个人智能体框架，长时任务的会话锁与归档可靠性对设备侧常驻 Agent 有直接参考价值，但推理仍主要依赖外部模型提供方（相关性 6）。属于一次覆盖面较广的工程化迭代（贡献 5）。
