ST-Lite: Training-Free KV Cache Compression with Spatio-Trajectory Guidance for Long-Horizon GUI Agents

12 学校预印本 开源 2026-02-27 · Bowen Zhou; Zhou Xu; Wanli Li; Jingyu Xiao; Pingan Gan; Haoqian Wang / EMNLP 2026 Findings
方向:KV cache方向:多模态方向:高效推理
这是什么视觉语言 GUI 智能体的长轨迹会让 KV cache 暴涨，这项工作针对 GUI 截图序列的特点做免训练的 KV cache 压缩。
有什么结果在 7 个 GUI 基准、两个 7B 主干上全面优于现有压缩方法；主主干在 20% 预算下准确率持平或超过完整缓存，5 倍压缩时解码最高提速 2.35 倍。
怎么做到三招各对一个特点：按轨迹语义过滤冗余历史帧、按 UI 组件保留细粒度元素边界的空间显著区域、各层使用平均预算避免层级分配失误。
评分依据：KV cache 压缩直接服务于显存受限设备上的长程智能体推理（相关度 6），虽面向 GUI 智能体但核心贡献是推理优化；针对 GUI 负载特征的压缩设计有新意（贡献 6）。
