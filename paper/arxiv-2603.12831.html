Serving Hybrid LLM Loads with SLO Guarantees Using CPU-GPU Attention Piggybacking

9 学校预印本 2026-03-13 · Zizhao Mo; Junlin Chen; Huanle Xu; Chengzhong Xu / arXiv
方向:云端serving方向:调度服务硬件:CPU硬件:GPU
这是什么OmniServe 是一个大模型服务系统，让同一集群里对时延敏感的服务和尽力而为的服务共存时少互相干扰。
有什么结果与现有最好的系统相比，时延敏感服务的 SLO 达成率最高提升 1.48 倍，尽力而为服务吞吐最高提升 9.85 倍。
怎么做到把尽力而为服务的注意力计算临时卸载到 CPU 上算，CPU 和 GPU 异步通信避免 GPU 等待；再配合按层批处理和动态批大小控制来适应请求波动。
评分依据：这是数据中心多租户 serving 工作，属云端；不过把注意力卸载到 CPU、与 GPU 异步协同的做法对 CPU+GPU 异构的 PC 端推理有一定借鉴意义。
