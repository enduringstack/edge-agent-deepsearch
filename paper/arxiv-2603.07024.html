Enhancing Web Agents with a Hierarchical Memory Tree

10 学校预印本 2026-03-07 · Yunteng Tan; Zhi Gao; Xinxiao Wu / arXiv
方向:记忆方向:规划推理
这是什么网页智能体靠历史轨迹做记忆，但扁平记忆把任务逻辑和具体网站操作混在一起，换个网站就不好用。HMT 把记忆整理成“意图-阶段-动作”三层树，提升跨网站泛化。
有什么结果在 Mind2Web 和 WebArena 上明显优于扁平记忆方法，跨网站、跨领域场景提升更明显；摘要未给出具体数值。
怎么做到自动把原始轨迹抽象成三层：意图层统一用户指令，阶段层记录带前后置条件的可复用子目标，动作层存可迁移的元素语义描述；推理时规划器先校验前置条件对齐子目标，执行器再按语义描述在页面上定位操作。
评分依据：属于 Agent 记忆结构研究，对端侧 Agent 的记忆模块设计有参考价值；但面向云端模型驱动的网页自动化，没有设备端执行，创新在记忆层级化而非 GUI 本身。
