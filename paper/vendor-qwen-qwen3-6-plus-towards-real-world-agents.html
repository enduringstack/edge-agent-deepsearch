Qwen3.6-Plus: Towards Real World Agents

8 官方动态 2026-04-02 · Qwen / Qwen
Qwen方向:工具调用方向:规划推理方向:多模态应用:代码模型:Qwen
这是什么通义千问发布 Qwen3.6-Plus，一个通过阿里云百炼 API 提供的托管旗舰模型，重点提升 Agent 编程、工具调用和多模态推理能力。
有什么结果默认 100 万 token 上下文；官方称代码修复基准接近业界领先模型，在终端操作、长程规划和多项工具调用基准上领先，但正文文字部分未逐项列出具体分数。
怎么做到把深度推理、长上下文记忆和精确工具执行结合在一起；API 新增 preserve_thinking 选项，在多轮 Agent 任务中保留此前各轮的思考内容。
评分依据：闭源云端托管模型，Agent 能力进步明显，但与端侧部署无直接关系；手机或 PC 只能作为调用入口，因此判为非端侧 Agent。
