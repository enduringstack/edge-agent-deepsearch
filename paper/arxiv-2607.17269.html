An Explicit World Model Based on Data-First Ontology: DaoQL Multimodal Storage Validation and Counterfactual Reasoning Evaluation

7 学校预印本 开源 2026-07-19 · Zhanbo Li; Shifeng Wu; Xiangjin Meng; Wenjie Cai / arXiv
应用:RAG方向:规划推理
这是什么主张把确定性知识从大模型权重里搬到一个显式的多模态数据库 DaoQL 中，大模型只负责推理和语言，以减少幻觉、便于修改和解释。
有什么结果同机嵌入式部署下图遍历 1.20 毫秒、HNSW 向量检索 83.1 微秒、混合查询 105.8 微秒；五个领域的反事实实验中，DaoQL+GPT-4o 的可组合反事实分解率达 94%，比单独 GPT-4o 高 49 个百分点。
怎么做到在一个进程内整合图、列存、向量和全文检索引擎，作为外部显式世界模型，大模型通过确定性查询路径读取和修改知识。
评分依据：属于大模型外部知识存储与检索层，和端侧部署关系较弱；论文自己说明 KV cache 图节点与 Agent 运行时仍是未来工作。理论框架有一定新意，但工程验证尚属初步。
