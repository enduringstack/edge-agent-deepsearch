M-Plan: Comprehensive Planning For LLM Agents with Memory Arrangement

7 学校预印本 2026-10-19 · Ziyang Liu; Jiakang Yuan; Jiayuan Fan; Tao Chen / arXiv
方向:记忆方向:规划推理
这是什么大模型智能体在长流程任务里容易迷路。M-Plan 是一个把长期记忆和短期记忆结合起来的多智能体规划框架，可以即插即用地套在不同模型上。
有什么结果在 ALFWorld、Webshop 和 PDDL 等多轮任务、多个模型上，准确率和效率都超过多种基线；摘要未给出具体数字。
怎么做到执行时给智能体下发任务里程碑和经验要点，只有在它困惑时才给局部提示，形成短期记忆；任务结束后把相关信息整理优化后存入长期记忆供下次检索。
评分依据：通用的智能体规划与记忆框架，未涉及端侧部署；全局与局部引导结合的做法属于常见思路的整合。
