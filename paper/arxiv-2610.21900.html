TEM: Temporal State Tracking Memory for Large Language Model Agents

8 学校预印本 2026-10-15 · Pengfeng Song; Yunkai Zhuang; Liye Shi / arXiv
方向:记忆应用:RAG应用:长上下文推理
这是什么智能体的对话记忆里，同一个事实会随时间被更新，但旧值对后续问题仍可能有用。TEM 是一个无需训练、专门追踪事实版本变化的记忆框架。
有什么结果在 60 个人设、600 段对话构造的 420 个问题上，四个开源模型的关键实体命中率为 75.71%–97.62%；给历史记录打标签使命中率提升 17.14–55.95 个百分点；每个回答只用 94–118 个 token 证据，比会话级 RAG 少 48.75%–56.73%；LoCoMo 上比会话级 RAG 高 7.92 和 10.58 个百分点。
怎么做到把事实存成带来源的版本化记录，检索时按来源顺序排列相关版本并标出哪些已是历史值，再配合事件记忆和原始对话补细节。
评分依据：属于智能体记忆运行时设计，证据更紧凑对资源受限部署有间接价值，但没有端侧实验；版本化记忆思路清晰但属增量改进。作者来自浙江万里学院。
