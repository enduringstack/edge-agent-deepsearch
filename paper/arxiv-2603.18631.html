D-Mem: A Dual-Process Memory System for LLM Agents

8 公司项目 2026-03-19 · Zhixing You; Jiachen Yuan; Jason Cai / arXiv
Amazon方向:记忆方向:规划推理
这是什么给 LLM 智能体设计的双过程记忆系统：常规查询走快速向量检索，遇到需要细粒度理解的查询再退回到高保真的完整推敲模块。
有什么结果LoCoMo 与 RealTalk 基准上，用 GPT-4o-mini 时多维质量门控策略 F1 达 53.5，优于静态检索基线 Mem0*（51.2），并恢复了完整推敲性能（55.3）的 96.7%，而计算成本显著更低。
怎么做到保留轻量向量检索处理常规查询，另建一个穷尽式的完整推敲模块作为高保真兜底，再用多维质量门控策略动态决定何时在两条路径间切换，兼顾准确与成本。
评分依据：面向通用 LLM 智能体的记忆系统，以云端大模型评测、与端侧部署无关（相关度 3）；双过程记忆加质量门控的设计属 Agent 记忆细分改进（贡献 5）。 作者机构依据：arXiv PDF 首页署名 Amazon（PDF 首页作者 Jason Cai 署名 AWS AI（amazon.com 邮箱））。
