A.R.I.S.: Automated Recycling Identification System for E-Waste Classification Using Deep Learning

8 官方动态 2026-02-25 · Apple / Apple
Apple方向:编译部署应用:视频
这是什么苹果研究人员做了一台低成本、可移动的电子垃圾分拣机，用视觉模型实时识别碎料里的金属、塑料和电路板。
有什么结果原文报告整体精确率 90%、平均精度均值（mAP）82.2%、分拣纯度 84%，并称推理延迟低。
怎么做到在分拣设备上用 YOLOx 目标检测模型实时识别材料类别，再接入传统分拣机构完成物料分离。
评分依据：这是部署在便携设备上的实时视觉检测应用，属于边缘视觉推理落地；方法是现成检测模型加工程集成，原文未给具体硬件和延迟数字。
