Code, Test, and Deploy on One Machine with NVIDIA RTX Spark

14 官方动态 2026-10-16 · NVIDIA / NVIDIA
NVIDIA方向:端侧agent方向:端云协同方向:编译部署硬件:GPU应用:代码
这是什么英伟达介绍开发者如何在 RTX Spark 一台 Windows PC 上运行本地编码智能体，并完成微调、测试和部署全流程。
有什么结果对比 Intel Panther Lake 12Xe，编码智能体性能为 4.6 倍（AA-AgentPerf-local，Qwen3.8-27B）、LoRA 微调 2.7 倍、内核编译 1.8 倍；llama.cpp 和 Unsloth 新支持的决策模型让智能体选择动作最多快 200 倍。
怎么做到依靠 GB10 芯片和最高 128GB 统一内存在本地跑 Qwen 3.8 Flash Next 等编码模型，配合本地/云端提示路由、OpenShell 或 MXC 沙箱，以及首个 PyTorch-CUDA 的 Windows on Arm 版本等开发栈。
评分依据：编码智能体用本机模型在笔记本上运行并有对比实测，端侧相关度高；贡献偏平台与生态整合。
