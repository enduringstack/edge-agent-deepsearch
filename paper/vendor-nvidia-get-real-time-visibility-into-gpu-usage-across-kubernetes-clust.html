Get Real-Time Visibility into GPU Usage Across Kubernetes Clusters

5 官方动态 2026-05-21 · NVIDIA / NVIDIA
NVIDIA方向:调度服务方向:云端serving硬件:GPU
这是什么NVIDIA 开源了一个 GPU 使用率监控工具，用来看清 Kubernetes 集群里 GPU 到底被用了多少。
有什么结果文中给出的观察是：很多负载实际只用掉分配 GPU 的 30% 到 50%，造成过度预留；工具本身没有给性能数字。
怎么做到把 DCGM Exporter、kube-state-metrics、Prometheus 和 Grafana 四个组件打包成一个 Helm chart 一键部署，提供按命名空间看分配趋势、按 Pod 看显存占用、按阈值看算力利用率以及待调度与运行中 Pod 数量的现成看板。
评分依据：面向数据中心 GPU 集群的可观测性，与端侧设备没有直接关系，端侧相关性很低。工具价值在于把成熟组件整合成开箱即用的部署包，属于工程整合。
