Stratum: Repository Memory for Coding Agents Beyond the Context Window

11 学校预印本 2026-10-26 · Yuvraj Sehgal; Mahsa Panahandeh; Naser Ezzati-Jivan / arXiv
方向:记忆方向:工具调用应用:代码
这是什么编码智能体每次新会话都从零开始，重复读文件、重复踩坑。Stratum 提出一套跟着代码仓库走的分层持久记忆，让后续会话能继承之前的排查经验。
有什么结果百万节点存储上检索中位延迟 1.7 毫秒；在 8 个真实 bug 的多会话实验中，继承前一会话记忆的新智能体在 24 次中有 21 次找到根因文件，纯检索基线只有 6 次，中位 token 成本低 4.5 倍。
怎么做到冷层用本机 SQLite 图存文件、测试、决策与根因结论，并从 git 历史挖掘共改关系；通过一组“分页安全”的 MCP 工具按 token 预算把工作集送进模型上下文。
评分依据：记忆库放在开发者本机、也可配本地模型，属于可迁移的 Agent 记忆运行时；但默认调用云端大模型的编码助手不算端侧 Agent，相关度按中等计，实验规模也较小。
