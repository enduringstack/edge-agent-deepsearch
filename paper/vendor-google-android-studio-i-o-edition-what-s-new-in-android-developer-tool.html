Android Studio I/O Edition: What's new in Android Developer tools

11 官方动态 2026-05-19 · Google / Google
Google应用:代码方向:工具调用模型:Gemma硬件:CPU
这是什么Android Studio 的 I/O 版本，把开发流程从「AI 辅助」推进到「智能体代劳」，并支持在本机跑 Gemma 4。
有什么结果新的安卓性能分析器渲染追踪数据的速度比旧工具最快提升 26 倍；其余功能没有给出量化数值。
怎么做到新增智能体技能这种模块化指令集，把大模型约束在特定工作流和领域知识里，还能让智能体在 IDE 内直接配置后端服务；模型可以选谷歌、Anthropic、OpenAI 的，也可以直接在 IDE 里下载并本机运行 Gemma 4，用于不联外部服务器的本地代码辅助；另外支持并行的多个智能体会话、无线调试 2.0、从 IDE 直接发布到应用商店和 AI 辅助崩溃分析。
评分依据：官方把 Gemma 4 作为可在开发者本机下载运行的模型，用于离线和隐私场景的本地代码辅助，这部分端侧相关性明确；但智能体能力本身与模型来源解耦，默认仍可走云端。把智能体技能、本地模型和性能分析整合进 IDE 是扎实的工具链工作。
