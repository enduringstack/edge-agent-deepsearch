Run Nexa AI agents locally on Snapdragon X PCs with Hexagon NPU

14 官方动态 2026-03-19 · Qualcomm / Qualcomm
Qualcomm方向:端侧agent方向:多模态硬件:NPU硬件:Snapdragon模型:Qwen模型:Phi模型:Mistral
这是什么高通开发者博客介绍 Nexa AI 框架如何在骁龙 X 系列 Windows 电脑的 Hexagon NPU 上完全离线运行多模态模型和智能体工作流。
有什么结果第一代骁龙 X 的 Hexagon NPU 算力最高 45 TOPS，骁龙 X2 最高 80 TOPS（提升 78%）；Nexa 自研 OmniNeural-4B 多模态模型可完全跑在 NPU 上，支持的 NPU 编译模型约在 40 亿参数规模内。
怎么做到Nexa 去年底发布针对 Hexagon NPU 优化的 SDK，把 OmniNeural-4B 以及 NPU 编译版 Ministral-3-3B、Granite-4、Phi-4 mini、Qwen3-4B 放到 NPU 上执行，不占用 CPU 和 GPU，支撑离线聊天、本地文档处理、本地语义搜索和多步骤智能体任务。
评分依据：模型推理和智能体的多步执行都在笔记本的 NPU 上完成、无需云端往返，是明确的 PC 端智能体；不过文章偏生态介绍，没有给出智能体任务的时延或功耗实测。
