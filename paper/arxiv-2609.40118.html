Persistent Context Graphs for Efficient Memory Compaction in LLM Agents

11 学校预印本 2026-09-30 · Jingbo Yang; Kwei-Herng Lai; Xiaowen Wang; Zhaoxuan Tan; Pei Zhou; Mengting Wan; Yaar Harari; Evgeniy Gabrilovich / arXiv
方向:记忆方向:KV cache方向:高效推理应用:长上下文推理
这是什么智能体的交互历史越来越长，必须压缩才能塞进上下文窗口。现有做法要么让模型重新总结、要么压 KV cache，都得再花一次模型计算。
有什么结果相比 Codex 默认的摘要式压缩，在 Qwen3-Coder 和 gpt-oss 上把压缩和冷恢复的估计时延降低约 95%，并把历史上下文大致砍掉一半。
怎么做到把注意力得到的重要性分数和消息之间的依赖关系存进一张轻量的持久上下文图；每来一个新请求，就把存下的重要性与请求本身的相关性线索结合，再顺着依赖链选出相关消息及其支撑上下文，整个选择过程不需要额外调用模型。
评分依据：上下文压缩的开销在算力受限设备上会被放大，而这个方案把选择过程做成零模型调用，迁移价值明确，但论文验证仍在服务端模型上。把历史重要性预先沉淀成图、再只在查询时算相关性，是一个干净的时间换空间设计。
