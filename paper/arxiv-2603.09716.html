AutoAgent: Evolving Cognition and Elastic Memory Orchestration for Adaptive Agents

8 学校预印本 2026-03-10 · Xiaoxing Wang; Ning Liao; Shikun Wei; Chen Tang; Feiyu Xiong / arXiv
方向:记忆方向:工具调用方向:规划推理
这是什么智能体框架普遍记性差、流程僵硬、上下文浪费。AutoAgent 让多个智能体在执行中持续更新对工具和同伴的认知，并弹性管理记忆。
有什么结果在检索增强推理、工具增强智能体基准和具身任务环境中，任务成功率、工具使用效率和协作鲁棒性均优于静态和带记忆的基线（摘要未给具体数字）。
怎么做到每个智能体维护关于工具、自身能力、同伴特长和任务知识的结构化认知；弹性记忆编排器保留原始记录、压缩冗余轨迹并构建可复用的情景摘要，按执行结果闭环更新认知。
评分依据：记忆编排与 token 节省对端侧智能体有借鉴价值，但框架运行在云端模型之上；组件集成为主。PDF 首页显示作者来自记忆张量（上海）科技有限公司等机构。
