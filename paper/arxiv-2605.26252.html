Is Agent Memory a Database? Rethinking Data Foundations for Long-Term AI Agent Memory

8 学校预印本 2026-05-25 · Abdelghny Orogat; Essam Mansour / arXiv
方向:记忆应用:RAG方向:规划推理
这是什么长期运行的智能体需要持久记忆，这篇论文主张现有的记忆系统和数据库范式都只把记忆当存储，因而注定会出问题。
有什么结果未报告。论文是立场与形式化工作，并给出一个基于属性图后端的原型验证可行性，没有报告量化指标。
怎么做到作者归纳出四种反复出现的失败模式（无节制增长、缺少语义修订、因容量而遗忘、只读检索），提出把长期记忆的正确性定义在状态轨迹而非单条记录上，用摄入、修订、遗忘、检索四个状态级算子替代记录级数据库操作，并给出六条正确性条件和三条结构性论证说明记录级系统无法满足这些条件。
评分依据：记忆的无节制增长和容量驱动遗忘正是端侧智能体在有限存储下必然遇到的问题，形式化视角有参考价值，但论文不涉及任何设备端实现，相关度低。贡献在于把长期记忆重新定位成一类新的数据管理负载。
