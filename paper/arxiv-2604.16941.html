MEMRES: A Memory-Augmented Resolver with Confidence Cascade for Agentic Python Dependency Resolution

9 学校预印本 2026-04-18 · Dao Sy Duy Minh; Tran Chi Nguyen; Trung Kiet Huynh; Pham Phu Hoa; Nguyen Lam Phu Quy; Vu Nguyen / FSE Companion 2026
方向:记忆方向:工具调用应用:代码模型:Gemma
这是什么给 Python 代码片段自动找齐依赖的 Agent 系统 MEMRES，大模型只作为最后手段，前面先走记忆和规则。
有什么结果在 HG2.9K 数据集上用 Gemma-2 9B（约 10 GB 显存）解决 2890 个片段中的 2503 个（成功率 86.6%，10 次平均），远高于 PLLM 的 54.7%。
怎么做到多级置信度级联：先查会自我积累技巧的会话记忆，再查 200 多条导入到包名的错误模式知识库、语义导入分析和 Python 2 识别规则，都不行才调用大模型。
评分依据：整套 Agent 在单台台式机（RTX 5070）上用 9B 本地模型运行，体现了“小模型 + 记忆 + 规则级联”降低大模型调用的思路；但面向的是软件工程流程，不是端侧设备上的 Agent 部署。
