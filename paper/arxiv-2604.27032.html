LLM-Guided Runtime Parameter Optimization for Energy-Efficient Model Inference

7 学校预印本 2026-04-29 · Katelyn Crumpacker; Dimitrios Nikolopoulos / arXiv
方向:能耗功耗方向:推理框架硬件:GPU模型:Llama
这是什么大模型推理引擎的运行参数很多，手工调到最省电既费时又需要专业知识。这篇工作让聊天大模型在人给出反馈的循环中，帮忙找出最省能耗的推理参数。
有什么结果在单张 16GB GPU 上用 vLLM 跑 Llama-3.2-3B，增强版提示模板平均 3.4 轮就收敛到每 token 1.80 焦耳的阈值以下，基线模板需 5.2 轮；最终每 token 能耗也更低，收敛速度优于 Sobol 采样。
怎么做到把参数空间、硬件约束和每轮实测能耗反馈写进结构化提示，让 Claude 迭代给出下一组 vLLM/PyTorch 运行参数，再实测能耗回填。
评分依据：推理能耗调参对资源受限部署有借鉴意义，但实验在桌面级 GPU 的服务引擎上完成。方法是提示工程加人机协作，创新有限。
