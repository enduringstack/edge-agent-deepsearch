怎么做到Codex CLI 在用户终端里循环执行“组装提示词、通过 Responses API 调用云端模型、执行模型请求的工具、把结果回填上下文”；刻意让每次新提示词以旧提示词为精确前缀以命中提示缓存，使采样成本从随对话平方增长降为线性，上下文超阈值时再调用专门接口压缩对话。
