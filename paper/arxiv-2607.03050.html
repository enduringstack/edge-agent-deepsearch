OmniFocus: Query-Guided Modality-Balanced Token Compression for Omni-Modal Large Language Models

9 学校预印本 开源 2026-07-03 · Shijie Cao; Qingyu Zhang; Boxi Yu; Yuzhong Zhang; Boxi Cao; Yaojie Lu; Hongyu Lin; Xianpei Han / arXiv
方向:多模态方向:高效推理应用:视频模型:Qwen
这是什么全模态大模型同时处理音频和视频时 token 数量巨大，OmniFocus 是一种无需训练、由用户问题引导的音视频 token 压缩方法，减少推理开销。
有什么结果在 Qwen2.5-Omni 系列和四个音视频基准上，25% token 保留率下多项指标优于现有方法；Qwen2.5-Omni-7B 在 DailyOmni 上保持 59.40 准确率，预填充最多快 1.38 倍。
怎么做到分别为视频和音频独立估计每个 token 与问题的相关度，两种模态对称压缩，既保留各自关键证据又维持音画对齐，避免只用单一模态指导造成偏差。
评分依据：token 压缩可直接迁移到资源受限设备上的多模态推理，但实验在服务器 GPU 上完成；属于常见 token 剪枝思路的音视频改进。
