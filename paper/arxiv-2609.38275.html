When Correct Memory Goes Wrong: Fuzzing Persistent Memory Use in LLM Agents

7 学校预印本 2026-09-29 · Yuqiao Meng; Luoxi Tang; Yingxue Zhang; Yuchen Yang; Zhaohan Xi / arXiv
方向:记忆方向:评测基准方向:安全隐私
这是什么智能体的持久记忆内容本身没错，用的时候也可能用错——查询变了、记忆状态变了就会出问题。这份工作把发现这类错误变成一个模糊测试问题。
有什么结果在多个记忆系统上与各类模糊测试基线对比，并额外测试了只能看到最终回复、检索过程不可见的闭源模型设置；在这些设置下该方法都发现了更多被确认的记忆使用错误。
怎么做到以记忆检查点作为测试种子，在明确的变异义务下对查询或记忆状态做变异，逐个验证变异体，再用观察到的记忆行为引导迭代测试，同时把失败标签排除在搜索过程之外以免泄题。
评分依据：与端侧部署没有直接关系。把「记忆内容对但用错了」单独拎出来并用模糊测试系统化地找，是对记忆可靠性评估的一个新角度，连检索不可见的黑盒设置也覆盖到了。
