microsoft/onnxruntime: [CUDA] Add KDA per-key-dim decay support to GatedDeltaNet across CPU, WebGPU, and CUDA (#33817)

10 开源大项目 开源 2026-11-08 · microsoft / GitHub
方向:推理框架方向:高效注意力方向:MoE硬件:CPU硬件:GPU
这是什么ONNX Runtime 为蚂蚁 inclusionAI 的 Ling-3.0-tiny 这类线性注意力加 MoE 混合模型补齐算子：GatedDeltaNet 支持按键维度衰减的 Kimi Delta Attention，覆盖 CPU、WebGPU 和 CUDA 三个执行后端，并新增若干融合算子。
有什么结果提交说明给出的 CUDA 数据：KDA 预填充在 H200 上快 1.40 倍，MoE 分组路由解码快 9.0 倍（17 个 MoE 层每步少 391 次内核启动），变长因果卷积预填充快 39.8 倍（2K token 下 26.29 ms 降到 0.66 ms），INT8 KV 分页解码快 2.44 倍，FP8 QMoE 解码快 2.46 倍；83 项 GatedDeltaNet 单测通过。
怎么做到新增按键维度衰减的状态更新与两阶段分块预填充内核，CPU 与 WebGPU 后端实现完整的循环、变长序列和投机解码状态回放；另把 24 个节点的 MoE 分组路由和线性注意力门控各融合为单个算子。
评分依据：CPU 与 WebGPU 后端同步支持新一代线性注意力，有利于这类小型混合模型在 PC 和浏览器本地运行；不过公布的加速数据都来自数据中心 GPU，属于推理框架的算子扩展。与上周的 GatedDeltaNet 基础算子是不同的新功能。
