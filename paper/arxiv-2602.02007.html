Beyond RAG for Agent Memory: Retrieval by Decoupling and Aggregation

11 公司项目 开源 2026-02-02 · Zhanghao Hu; Qinglin Zhu; Runcong Zhao; Di Liang; Hanqi Yan; Yulan He; Lin Gui / arXiv
Tencent方向:记忆应用:RAG模型:Qwen
这是什么普通 RAG 检索不适合智能体记忆：对话历史里大量内容高度相似，平铺检索会捞回一堆冗余片段。这篇提出 xMemory，把记忆先拆解再聚合成层级结构来检索。
有什么结果在 LoCoMo 上，用 Qwen3-8B 时平均 BLEU/F1 从 31.44/40.88（Nemori）提升到 34.48/43.98；用 GPT-5 nano 时 F1 从 48.17 提升到 50.00，同时每次查询的 token 数从 9155 降到 6581。
怎么做到把交互历史切成事件片段，再拆成可复用的记忆单元并聚合成高层分组；检索时自顶向下先选一小组互补的分组，只有在能降低不确定性时才展开到原始消息。
评分依据：智能体记忆运行时属于可迁移的端侧技术栈，省 token 对算力受限设备有意义，但实验在通用大模型上、未涉及设备端；层级化“先拆后聚”的记忆组织有新意。PDF 首页作者署名含 Tencent Yuanbao Team。 作者机构依据：arXiv PDF 首页署名 Tencent（PDF 首页作者 1、4 署名 Tencent, Yuanbao Team）。
