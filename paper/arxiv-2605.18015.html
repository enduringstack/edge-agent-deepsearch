LogRouter: Adaptive Two-Level LLM Routing for Log Question Answering in Big Data Systems

7 学校预印本 2026-05-18 · Mert Coskuner; Merve Zeybel; Melik Mert Dolan / arXiv
方向:调度服务方向:云端serving应用:RAG
这是什么一套日志问答系统，用两级路由决定每个问题该走便宜的检索还是贵的大模型，避免每次都调最大的模型。
有什么结果路由在四个 LogHub 数据集上平均准确率 88.4%、Linux 上 94.7%；完整流水线 ROUGE-1 为 0.373、BERTScore 0.879、RAGAS 忠实度 0.779、端到端时延 18.6 秒；离线对比中相比固定用 32B 的基线平均时延降 55%（46.3 秒对 102.1 秒），答案正确性只差 5.8 分。
怎么做到日志先经 PySpark 版 Drain3 做模板化入库，同时建 Apache Druid 和带 pgvector 的 PostgreSQL 双索引；一级路由按关键词词表把问题分到直接回答、Druid 关键词检索、模板查表加 SQL 生成、向量语义检索四条路径之一，二级路由再决定语义路径上用 14B 还是 32B 的生成模型。
评分依据：运行在自建的大数据平台上，属于服务端部署，与设备端没有直接关系；但成本感知的两级路由思路对端云分工有一定参考价值。系统整合扎实，方法本身是已有组件的组合。
