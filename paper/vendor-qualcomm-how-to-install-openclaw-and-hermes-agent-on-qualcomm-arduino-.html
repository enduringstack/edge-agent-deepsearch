这是什么高通开发者博客手把手教你把开源个人智能体 OpenClaw 和 Hermes Agent 装到 Arduino UNO Q、Rubik Pi 3 这类低价开发板以及骁龙 PC 上，让智能体在独立的小设备里常驻运行。
有什么结果在 4GB 内存、32GB 存储的 Arduino UNO Q 上可跑通，正确安装后仍剩 10GB 以上空间放技能和数据；Rubik Pi 3 一键安装约 5～10 分钟；未给出性能测试数字。
怎么做到OpenClaw 和 Hermes 本身不跑模型，而是在设备上负责任务编排、调用工具、读写文件和登录网站，再把请求发给云端大模型或骁龙 X Elite 笔记本上本地托管的模型；用独立开发板当“硬件沙箱”，限制智能体可接触的凭据和数据。
