Closing the knowledge gap with agent skills

7 官方动态 开源 2026-03-25 · Google / Google
Google方向:工具调用应用:代码
这是什么Google DeepMind 给编码智能体做了一个“Gemini API 开发技能包”，用轻量的技能文件补上模型训练截止后才出现的 SDK 和最佳实践知识。
有什么结果在 117 个生成 Gemini SDK 代码的测试题上，不加技能时 Gemini 3.0 Pro 和 Flash 通过率仅 6.8%、3.1 Pro 为 28%；加上技能后效果大幅提升，gemini-3.1-pro-preview 表现最差的 SDK 使用类别也有 95% 通过率。旧的 2.5 系列提升有限。
怎么做到技能包写明 API 功能概览、当前模型与各语言 SDK、示例代码和文档入口；评测时给模型“激活技能”和“抓取网页”两个工具，让它按需读取最新文档。
评分依据：技能文件是轻量的工具/知识注入机制，本地编码智能体也能用，但评测全在云端模型上，端侧相关度低。给出了技能机制有效性的实测数据，属工程经验分享。
