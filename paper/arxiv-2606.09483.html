Memory Beyond Recall: A Dual-Process Cognitive Memory System for Self-Evolving LLM Agents

9 学校预印本 2026-06-08 · Tianxiang Fei; Mingyang Song; Mao Zheng; Xiang Yu / arXiv
方向:记忆方向:规划推理
这是什么把长期智能体的记忆按认知能力分层重组，从原始输入和原子事实，一路到信念变化轨迹、领域图式和跨领域模式。
有什么结果在 LongMemEval、PersonaMem 和 PersonaMem-v2 上，开启慢思考引擎在需要跨会话隐式推断的评测上收益最大（PersonaMem-v2 最高提升 5.20），在片段召回类任务上收益最小，与架构预期一致。
怎么做到借双过程理论拆成两条流水线：一个同步的白天写入器把信念修订记成双向链接的取代链，一个异步的夜间引擎归纳出图式和潜在意图，并扫描跨领域冲突、抽象成更高层的核心图式。
评分依据：面向长期智能体的记忆分层组织，与端侧部署只有宽泛关联，但异步离线整理的思路对端侧设备在空闲时整理记忆有借鉴意义。按双过程理论拆同步写入与异步归纳，架构上有新意。
