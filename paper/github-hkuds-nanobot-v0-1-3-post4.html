这是什么港大 HKUDS 的轻量个人 Agent 助手 nanobot 发布 0.1.3.post4 版本，新增接入 vLLM 等本地大模型的能力，并扩充了 Gemini、智谱、Bedrock 等模型来源和 Telegram 图片、语音交互。注意：发布页提示该版本 WhatsApp 通道有安全漏洞，建议直接装 0.1.3.post7 及以上。
有什么结果未报告
怎么做到通过社区合并的一批改动实现：增加 vLLM/本地大模型提供方、Gemini/智谱/Bedrock 提供方，Telegram 通道支持图片识别和基于 Groq 的语音转写，新增 Docker 部署和 uv 安装方式；工具层面加强 web_fetch 的 URL 校验、为 exec 工具加安全防护并校验工具参数。
评分依据：nanobot 是可以自己部署的个人 Agent 运行时，本版加入本地大模型接入，对想在自有设备上跑 Agent 的人有参考价值；但发布说明没有给出在具体终端设备上运行的证据，按非端侧 Agent 处理。贡献以功能接入和安全修补为主，属于常规工程迭代。发布说明只列出改动清单，没有给出任何性能或评测数字，因此效果写未报告。
