A2UI v0.9: The New Standard for Portable, Framework-Agnostic Generative UI

7 官方动态 开源 2026-04-17 · Google / Google
Google方向:工具调用
这是什么Google 发布 A2UI 0.9：一个让 AI Agent 用应用自带组件库生成界面的开放标准，本地或远端 Agent 都能用，覆盖网页和移动端。
有什么结果未报告
怎么做到Agent 只声明“要展示什么界面”，由客户端用已有设计系统渲染；本版新增共享 web-core 渲染库和官方 React 渲染器、Agent SDK 生成缓存、客户端自定义函数和双向数据同步，并支持 MCP、WebSocket、A2A 等多种传输。
评分依据：这是 Agent 与前端交互的协议层，能跑在移动端客户端但不涉及端侧推理；属于规范和工程整合，创新中等偏低。
