Taking Tokenization off the Host for Agentic LLM Serving

8 学校预印本 开源 2026-10-09 · Mohammad Siavashi; Pascal Schwinte; Ali Banaei; Gerald Q. Maguire; Marco Chiesa; Dejan Kostić / arXiv
方向:云端serving硬件:GPU应用:长上下文推理
这是什么智能体类请求每次都重发很长且几乎不变的上下文，前缀缓存已经省掉了大部分预填充，但分词仍要在 CPU 上全量跑一遍，反而成了首 token 时延的最大头。GraphTok 把整个分词流程搬到 GPU 上。
有什么结果编码 100 万个 GPT-2 token 只需 1.7–3.2 毫秒（含数据传输）；在 Llama 3 上比最强 CPU 分词器 gigatoken 快 4.7–6.0 倍；在 vLLM 前缀命中场景下平均首 token 时延降低 2.1–2.4 倍；2 秒 P99 目标下单个 Dynamo 前端可支撑每秒 518 个 12.1 万 token 的请求，gigatoken 为 296、默认分词器仅 18.5。
怎么做到把预分词、BPE 合并到 token ID 拼装的整条流水线做成一个可重放的 CUDA Graph，逐位复现参考分词结果；短输入交给 CPU 引擎处理，可直接接入未修改的 vLLM 和 NVIDIA Dynamo。
评分依据：典型的云端多 GPU 推理服务优化，与端侧关系弱，相关度 2；指出分词成为智能体负载的新瓶颈并给出 GPU 全流程实现，贡献 6。作者来自瑞典皇家理工学院（KTH）。
