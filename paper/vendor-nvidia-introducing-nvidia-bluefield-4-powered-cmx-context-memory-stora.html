Introducing NVIDIA BlueField-4-Powered CMX Context Memory Storage Platform for the Next Frontier of AI

8 官方动态 2026-03-16 · NVIDIA / NVIDIA
NVIDIA方向:KV cache方向:记忆方向:云端serving
这是什么英伟达推出由 BlueField-4 驱动的 CMX 上下文内存存储平台，在 GPU 显存和普通共享存储之间加一层以太网闪存，专门存放可复用的 KV cache。
有什么结果与传统存储相比，token 吞吐最高提升 5 倍，能效最高提升 5 倍。
怎么做到把智能体长期记忆所需的 KV cache 放进专用存储层并提前预取到 GPU，减少解码卡顿；通过 Spectrum-X RDMA 低抖动访问，Grove 编排层按 KV 位置调度负载。
评分依据：这是数据中心级方案，本身不在端侧；但“KV cache 分层存放加提前预取”的思路和端侧内存、闪存分层卸载有相通之处，属于中等工程贡献。
