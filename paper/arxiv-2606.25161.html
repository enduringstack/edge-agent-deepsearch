TRUSTMEM: Learning Trustworthy Memory Consolidation for LLM Agents with Long-Term Memory

方向:记忆方向:安全隐私
这是什么让大模型智能体往长期记忆里写东西时更靠谱，别写漏、写坏或写进幻觉。
有什么结果原文称在多个记忆基准上取得当前最好结果，同时提升了记忆的可用性和可靠性；摘要未给出具体数值。
怎么做到核心是一个记忆转移校验器，从覆盖度、保留度和忠实度三个角度评估一次记忆更新的转移过程；再在同一记忆状态下的多个候选更新之间构造偏好对，用偏好引导的强化学习直接优化智能体的写记忆行为。
评分依据：记忆写入的可靠性是长期运行智能体的共性问题，对端侧 Agent 有一定迁移价值，但全文基于云端模型、无设备端约束，相关度按宽泛关联计；把记忆更新当成可校验的状态转移来优化，角度较新但仍属记忆治理细分。
