GEMS: Agent-Native Multimodal Generation with Memory and Skills

8 学校预印本 2026-04-01 · Zefeng He, Siyuan Huang, Xiaoye Qu, Yafu Li, Tong Zhu, Yu Cheng, Yang Yang / arXiv
方向:记忆方向:多模态方向:规划推理
这是什么借鉴 Claude Code 这类 Agent 框架，GEMS 给图像生成模型套上 Agent 外壳：多智能体循环优化、轨迹记忆和按需加载的技能库，提升复杂指令下的生成质量。
有什么结果在 5 个主流任务和 4 个下游任务上均有显著提升；让 6B 参数的 Z-Image-Turbo 在 GenEval2 上超过 Nano Banana 2。
怎么做到智能体循环反复生成和评估改进结果，分层记忆保存事实状态与压缩经验，技能库按需加载领域知识。
评分依据：这是云端多模态生成的 Agent 框架，没有端侧部署；但用 Agent 记忆和技能让小模型逼近大模型，对小模型能力扩展有启发。
