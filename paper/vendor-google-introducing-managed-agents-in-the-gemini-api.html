Introducing Managed Agents in the Gemini API

7 官方动态 2026-05-19 · Google / Google
Google方向:云端serving方向:工具调用方向:规划推理应用:代码
这是什么Gemini 接口新增托管智能体，开发者不用自己搭基础设施就能跑定制智能体。
有什么结果未报告量化指标。官方说明目前以预览形式推出，企业侧走 Gemini Enterprise Agent Platform。
怎么做到智能体跑在谷歌托管的远程 Linux 环境里，底层是基于 Gemini 3.5 Flash 的 Antigravity 智能体，通过 Interactions 接口访问；开发者用 AGENTS.md 和 SKILL.md 两个 markdown 文件定义自己的指令和技能来扩展它。每次交互会创建或复用一个保留状态和文件的环境，支持续接会话。
评分依据：官方明确说智能体运行在谷歌托管的远程 Linux 沙箱里，是纯云端方案，与设备端执行无关，端侧相关性很低。用 markdown 文件定义智能体指令与技能、并保留环境状态，是接口层面比较清晰的设计。
