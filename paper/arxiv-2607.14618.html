PolyQ: Codesigning End-to-End Quantization Framework for Scalable Edge CPU LLM Inference

15 学校顶会 2026-07-16 · Hyunwoo Oh; Suyeon Jang; Hanning Chen; KyungIn Nam; Sanggeon Yun; Ryozo Masukawa; Mohsen Imani / ICCAD 2026
方向:量化方向:编译部署硬件:CPU模型:Qwen模型:Llama
这是什么PolyQ 是一套面向 CPU 的大模型量化与编译协同框架，让用户按平均比特预算（如 3.x 比特）给每个通道分配不同位宽，并能在纯 CPU 上高效跑起来。
有什么结果3 比特目标下困惑度比已有方法改善 2.4%~32.1%；在工作站、笔记本和移动级三种 CPU 上，激活重排流量最多减少 70.8%，每 token 能耗相比优化过的查表后端只多 0.8%~1.9%，延迟随比特预算近似线性变化。
怎么做到按激活敏感度为每个通道在 2/3/4/8/16 比特中选位宽，编译期把通道重排聚成同位宽块，生成 SIMD 和查表兼容内核，并跨算子合并重排，避免运行时开销。
评分依据：直接面向端侧 CPU 大模型推理，在 Ryzen 9950X、Ryzen 7840U 笔记本和 Intel N250 移动级 CPU 上实测延迟与能耗；把细粒度混合精度真正落到 CPU 可执行，贡献扎实。作者来自加州大学尔湾分校。
