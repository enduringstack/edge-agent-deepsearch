LOCKS: Page-Local Compact Key Summaries for Efficient Long-Context Decoding

10 学校预印本 2026-07-27 · Junsung Hwang / arXiv
方向:KV cache方向:稀疏注意力应用:长上下文推理
这是什么长上下文解码的 KV 缓存页选择方法 LOCKS：给每一页 Key 存一个很小的低秩摘要，不读原始 KV 就能判断该读哪些页。
有什么结果2048 token 预算下在 10 万以上上下文与完整 KV 质量持平，只关注约 2% 的 token；摘要只占完整 KV 的 4%–10%；GH200 上 512K 上下文解码单步时间缩短 1.8 倍，KV 卸载到 Grace 内存时吞吐达到更快稠密后端的 3.82–4.22 倍。
怎么做到观察到注意力 Key 在页内近似低秩，于是为每页拟合一个秩 r 的谱摘要，重建页内 logits 后按 log-sum-exp 质量选页，候选页的 Key 和 Value 都不用读。
评分依据：KV 缓存稀疏读取是可迁移到端侧长上下文的推理技术，但实验在 GH200 数据中心平台上，相关度 4；按页拟合低秩基来做选页的思路清楚有效，贡献 6。
