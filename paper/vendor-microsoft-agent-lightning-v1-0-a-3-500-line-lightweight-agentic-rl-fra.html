Agent Lightning v1.0: A 3,500-Line Lightweight Agentic RL Framework for Training Agents with Real Harnesses

8 官方动态 开源 2026-10-07 · Microsoft / Microsoft
Microsoft方向:工具调用方向:规划推理应用:代码模型:Qwen
这是什么微软亚洲研究院开源重写后的 Agent Lightning v1.0：一个约 3500 行的轻量智能体强化学习框架，可以把 OpenHands、Claude Code、Codex 这类现成智能体连同其真实执行框架直接接入 RL 训练，不必在训练框架里重写一遍。
有什么结果用约 6000 条训练样本，把 Qwen3.5-9B 在 SWE-bench Verified 上的 Pass@1 从 41.8% 提升到 56.4%（提高 14.6 个百分点）；“同卡异步 RL”相比同步 RL 端到端约快 2 倍，且比常规异步 RL 占用更少 GPU。
怎么做到在智能体和模型之间插入一个 OpenAI 兼容的 LLM 代理，记录每次模型调用的提示、回复和概率；在整条 rollout 而非单个样本层面计算优势和归一化损失；rollout 与训练共用同一组 GPU 交替进行，智能体以标准 Kubernetes 任务运行，不依赖付费沙箱服务。
评分依据：这是云端智能体训练基础设施，与设备端执行无关，相关度低。“直接用真实执行框架做 RL”的范式和按 rollout 计算优势的处理有新意，并给出明确的 SWE-bench 提升。
