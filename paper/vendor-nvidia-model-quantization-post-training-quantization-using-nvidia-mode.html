Model Quantization: Post-Training Quantization Using NVIDIA Model Optimizer

7 官方动态 开源 2026-05-07 · NVIDIA / NVIDIA
NVIDIA方向:量化方向:多模态硬件:GPU
这是什么NVIDIA 量化系列教程第二篇：用 Model Optimizer 把 CLIP 模型做 FP8 训练后量化，以降低消费级显卡上的显存占用。
有什么结果在 CIFAR-100、ImageNet-1k 和 MS-COCO Captions 上，FP8 量化后的 CLIP 与 FP16 基线质量相当；关闭图像块嵌入层的量化器后影响可以忽略。
怎么做到用 8K 张 MS-COCO 图片做校准、AbsMax 算法定标，并替换 CLIP 注意力模块以插入量化器，流程分准备、校准、伪量化、评估、迭代和导出到 TensorRT 六步。
评分依据：面向 GeForce RTX 等消费级设备的本地推理量化，属于端侧技术栈；方法是成熟的 FP8 训练后量化，属教程性质，贡献分低。
