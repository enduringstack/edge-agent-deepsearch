Introducing GPT-5.4

6 官方动态 2026-03-05 · OpenAI / OpenAI
OpenAI方向:云端serving方向:工具调用模型:GPT
这是什么OpenAI 发布 GPT-5.4，定位为面向专业工作的前沿模型，首次在通用模型里内置电脑操作能力，并支持 100 万 token 上下文和工具搜索。
有什么结果OSWorld-Verified 电脑操作成功率 75.0%（GPT-5.2 为 47.3%，人类 72.4%）；GDPval 中 83.0% 的对比达到或超过专业人士（GPT-5.2 为 70.9%）；SWE-Bench Pro 57.7%，BrowseComp 82.7%；在 MCP Atlas 的 250 个任务上，工具搜索让总 token 用量减少 47% 且准确率不变。
怎么做到模型可以写 Playwright 代码或根据截图发出鼠标键盘指令来操作电脑；工具搜索只给模型一个轻量工具清单，需要时再查出具体工具定义追加到对话里，避免成千上万 token 的工具说明占满上下文。
评分依据：云端前沿模型发布，与端侧部署无关；但“按需检索工具定义”减少上下文开销的做法，对上下文有限的端侧 Agent 运行时有直接参考，电脑操作能力也与桌面 Agent 方向相关。
