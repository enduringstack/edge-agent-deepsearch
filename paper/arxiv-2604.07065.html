Trust-as-a-Service: Intelligent Collaboration Orchestration via Model Context Protocol-Aided Agentic AI

10 学校预印本 2026-04-08 · Botao Zhu; Xianbin Wang / arXiv
方向:工具调用方向:端云协同方向:安全隐私
这是什么TaaS 把“该信任哪台设备、选谁来协作”做成一项由 Agent 自动完成的服务：设备通过 MCP 暴露自己的能力和资源，中心 Agent 按任务挑合作者。
有什么结果在 MacBook 和多台 Dell 设备组成的协作系统上，人脸识别和病毒扫描任务的协作者选择准确率达 100%，任务成功率和设备利用率都高于随机和 TMFSC 基线。
怎么做到服务器端 Agent 先从任务描述中提取信任需求，再通过 MCP 调用各设备端 Agent 的工具查询算力、存储等信息，逐项评估后组建临时协作单元。
评分依据：设备端运行 Agent 并以 MCP 工具形式上报资源，但关键的信任评估与选择闭环在服务器端完成，设备只是被调用的工具提供方；用 MCP 做设备协作编排是较新的工程组合。
