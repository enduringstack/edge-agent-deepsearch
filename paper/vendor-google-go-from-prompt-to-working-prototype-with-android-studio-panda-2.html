Go from prompt to working prototype with Android Studio Panda 2

6 官方动态 2026-03-03 · Google / Google
Google方向:工具调用方向:规划推理应用:代码
这是什么Android Studio Panda 2 正式版上线：新建项目时，智能体能从一句提示生成可运行的 App 原型，另有版本升级助手自动更新项目依赖。
有什么结果未报告
怎么做到智能体先给出项目计划供开发者确认，再循环执行“写代码、构建、分析报错、自我修正”直到构建成功，并在 Android 模拟器里逐屏走查验证；默认免费模型无需密钥，接入付费 Gemini API 密钥可用 Gemini 3.1 Pro 预览版，也可接第三方远程模型。
评分依据：这是运行在开发者电脑上的 IDE 编程智能体，但原文只提到云端模型和远程模型，没有本地模型方案，按非端侧 Agent 处理，端侧相关度低；构建、修复、模拟器验证的闭环设计较完整。官方只是功能介绍，没有给出成功率等数字。
