Native Python on Windows on Snapdragon: a stronger foundation for developers and AI workflows

7 官方动态 2026-10-14 · Qualcomm / Qualcomm
Qualcomm方向:编译部署硬件:Snapdragon硬件:NPU硬件:CPU
这是什么高通介绍 Python 3.15 起 Windows on Snapdragon 成为 CPython 二级支持平台，原生 Arm64 Python 生态让开发者能直接在骁龙 PC 上搭建本地 AI 开发环境。
有什么结果截至 2026 年 6 月 6 日，下载量前 1000 的 Python 包中 95% 已有原生 wheel 或无需编译；PyArrow、gRPC、OpenCV、JAXlib 等仍缺原生支持。
怎么做到CPython 把骁龙 Windows 纳入常规发布测试，安装时默认选原生运行时；NumPy、ONNX、tokenizers 等包陆续提供原生构建，并可通过 Windows ML 或高通 QNN 调用 NPU。
评分依据：属于骁龙 PC 本地 AI 的开发工具链基础设施，文章也明说原生包不代表性能或模型执行位置；没有新技术，属于生态进展。
