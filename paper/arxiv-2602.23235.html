Spatio-Temporal Token Pruning for Efficient High-Resolution GUI Agents

11 学校预印本 2026-02-26 · Zhou Xu; Bowen Zhou; Qi Wang; Shuwen Feng; Jingyu Xiao / arXiv
方向:剪枝稀疏方向:多模态方向:高效推理模型:Qwen
这是什么纯视觉 GUI Agent 要处理高分辨率截图和历史轨迹，视觉 token 太多导致很慢。GUIPruner 不用训练就能剪掉冗余的视觉 token，同时保住点击定位精度。
有什么结果在 Qwen2-VL-2B 上 FLOPs 降低 3.4 倍、视觉编码时延加速 3.3 倍，同时保留原性能的 94% 以上。
怎么做到时间维度上对越早的历史截图用越低分辨率；空间维度上按结构分层剪枝，优先保留可交互前景和语义锚点，同时维持整体网格布局。
评分依据：GUI Agent 本身不在关注重点，但其视觉 token 剪枝属于推理优化，对端侧小视觉语言模型有迁移价值；没有设备端实测。
