SPICE: Speculative Prefetching with Low-Rank Expert Surrogates and Heterogeneous Orchestration for MoE Inference Acceleration

11 学校预印本 2026-08-21 · Yongxiang Lyu; Ning Li; Bonian Jia / ASP-DAC 2027
方向:MoE方向:投机解码方向:高效推理硬件:GPU硬件:CPU模型:DeepSeek模型:Qwen
这是什么SPICE 解决显存放不下 MoE 大模型、只能把专家放在内存里时的加载等待问题：提前预测下一步要用的专家并预取，预测不准时再在 CPU 和 GPU 之间灵活分工。
有什么结果在 DeepSeek-V2-Lite 和 Qwen2-57B-A14B 上、多种 GPU 平台测试，单 token 输出时延最多加速 3.12 倍，质量损失很小。
怎么做到用与目标模型结构对齐的轻量草稿模型和置信度自适应前瞻来预取高把握的专家；预测落空时，低置信的部分用常驻共享专家加低秩替身近似，精确的残差计算交给 CPU 与 GPU 并行执行。
评分依据：显存受限下的 MoE 卸载推理与消费级/边缘 GPU 场景直接相关；投机预取结合低秩替身的组合有一定新意。
