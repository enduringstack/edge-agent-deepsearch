PRISM: Pareto-Efficient Retrieval over Intent-Aware Structured Memory for Long-Horizon Agents

11 学校预印本 2026-05-12 · Jingyi Peng; Zhongwei Wan; Weiting Liu; Qiuzhuang Sun / arXiv
方向:记忆应用:RAG应用:长上下文推理
这是什么长周期对话 Agent 的历史远超上下文窗口，记忆检索既要准又要省。PRISM 是一个免训练的检索端框架，在图结构记忆上同时做检索和压缩。
有什么结果在 LoCoMo 基准上，以小一个数量级的上下文预算取得比所有同协议基线明显更高的 LLM 评审准确率；摘要未给出具体数字。
怎么做到在带类型的关系路径上做分层检索，按识别出的查询意图调整边代价，把候选证据压缩成紧凑上下文，并让大部分查询走不调用大模型的快速通道。
评分依据：把记忆检索的上下文预算压小一个数量级、多数查询不调用大模型，这对算力受限的端侧 Agent 记忆很有迁移价值，但本文没有设备部署。
