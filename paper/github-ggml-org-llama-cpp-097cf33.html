ggml-org/llama.cpp: model: support vllm decision 2 model (#30378)

8 开源大项目 开源 2026-10-12 · ggml-org / GitHub
方向:推理框架方向:调度服务模型:Qwen
这是什么llama.cpp 新增对 vLLM Semantic Router（vllm-sr）Decision 2 决策模型的支持（示例为 0.6B 的 Decision-2.0-Kai），让这类给候选项打分的小模型也能转成 GGUF 在本地运行。
有什么结果该提交改动 23 个文件、新增 549 行、删除 19 行，新增 GGUF 转换脚本、模型计算图和服务端决策接口支持；未报告性能数字。
怎么做到模型以标准 Qwen3 为骨干，外加一个决策头：读取问题和每个候选项的最后一个 token，经共享的双线性 MLP 为每个候选项打分；转换脚本把骨干和决策头权重合并进 GGUF（决策头强制 FP32）并写入分数偏置，llama.cpp 以关闭池化的嵌入模式运行它，llama-server 的决策接口也随之支持这一类型。
评分依据：llama.cpp 是端侧推理的主力引擎，这次让 0.6B 级的打分与决策小模型能在本地运行，对端侧做请求分类或端云路由有用，相关度 5。属于常规的新模型架构适配，贡献 3。
