Introducing GPT-5.4 mini and nano

6 官方动态 2026-03-17 · OpenAI / OpenAI
OpenAI方向:模型架构方向:工具调用模型:GPT
这是什么OpenAI 发布 GPT-5.4 mini 和 nano，是 GPT-5.4 的更小更快版本，面向编码、工具调用、多模态推理以及高并发 API 和子智能体场景。
有什么结果GPT-5.4 mini 比 GPT-5 mini 快 2 倍以上；SWE-Bench Pro 上 GPT-5.4 / mini / nano / GPT-5 mini 分别为 57.7% / 54.4% / 52.4% / 45.7%，OSWorld-Verified 为 75.0% / 72.1% / 39.0% / 42.0%，Toolathlon 为 54.6% / 42.9% / 35.5% / 26.9%；mini 支持 400k 上下文，每百万输入/输出 token 0.75 / 4.50 美元，nano 为 0.20 / 1.25 美元；在 Codex 里 mini 只占 GPT-5.4 额度的 30%。
怎么做到在保留 GPT-5.4 主要能力的前提下缩小模型规模、降低时延和成本，让它适合作为大量调用的子智能体。
评分依据：虽然是小模型，但只通过云端 API 提供，不能在设备上部署；官方给出的“大模型规划 + mini 子智能体并行执行”分工和各尺寸在工具调用、电脑操作基准上的差距，对设计端云分层的智能体系统有参考价值。
