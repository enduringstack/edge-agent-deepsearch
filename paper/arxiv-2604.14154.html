An Edge-Cloud Collaborative Architecture for Proactive Elderly Care: Real-Time Risk Assessment and Three-Level Emergency Response

11 学校预印本 2026-03-20 · Lijie Zhou; Luran Wang / arXiv
方向:端云协同方向:安全隐私硬件:CPU
这是什么独居老人监护如果全靠云端，报警慢且隐私风险大。这套边云协同架构把多传感器融合和风险评估放在家里的边缘网关上，再分三级通知家人、社区医生和志愿者。
有什么结果在 CASAS、MIMIC-III、SisFall 数据集上活动识别准确率 91%、异常检测 F1 为 84%，优于单传感器方法；部署在 Raspberry Pi 4 网关上推理时延低于 100 毫秒，端到端报警时延低于 3 秒。
怎么做到五层架构（设备、边缘、服务、数据、应用），边缘侧用带置信度传播的加权多模态融合，把跌倒概率、生理指标、行为模式和传感器异常合成统一风险分，按动态阈值触发分级响应。
评分依据：推理在 Raspberry Pi 4 边缘网关上实测，端侧部署证据明确，但并非 Agent 闭环，属普通端侧感知加规则响应。系统集成型工作，算法新意有限。
