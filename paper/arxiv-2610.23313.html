From Memory Hits to Answerable Evidence: Query-Conditioned Memory Compilation for Long-Term Agent Memory

10 学校预印本 2026-10-16 · Shangze Li; Yanyu Yao; Derong Xu; Zhi Zheng; Tong Xu / arXiv
方向:记忆应用:长上下文推理方向:评测基准
这是什么长期对话记忆里，答案相关的证据散落在多轮多会话中；MemCompile 不把检索结果直接塞给模型，而是先按问题把证据“编译”成紧凑、可直接作答的上下文。
有什么结果在 LoCoMo 上评审准确率达到 80.52%，把质量—成本帕累托前沿推向更高质量区间；在 LongMemEval-S 上同样表现强。
怎么做到“寻址层”用带来源的紧凑描述符和容量感知的单元定位相关内容，并把不同检索命中统一成稳定的证据包；“证据层”在有限预算内分配证据包并渲染成答案就绪的上下文。
评分依据：记忆压缩和上下文预算控制对端侧智能体有迁移价值，但实验未涉及设备部署；把寻址与证据呈现解耦有一定新意。
