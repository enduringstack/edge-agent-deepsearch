这是什么ONNX Runtime 为插件式执行后端补上事件级性能分析接口，第三方硬件后端可以把自己的算子耗时并入 ORT 的统一性能记录。

怎么做到把原先 C++ 版的 EpProfiler 移植到二进制稳定的 C API：提供创建/查询事件的接口和 StartEvent/StopEvent 回调，并直接给出基于纪元时间的关联 ID，方便后端对接 CUPTI 等性能工具。
评分依据：插件后端是 ONNX Runtime 接入各家 NPU/GPU 的通道，统一性能分析有助于端侧部署调优，但本身是工具链完善。提交说明只描述代码改动，没有给出性能或精度数据，因此效果写未报告。
