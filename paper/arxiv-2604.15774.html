MemEvoBench: Benchmarking Safety Risks from Memory Misevolution in LLM Agents

8 学校预印本 2026-04-17 · Weiwei Xie; Shaoxiong Guo; Fan Zhang; Tian Xia; Xue Yang; Lizhuang Ma; Junchi Yan; Qibing Ren / arXiv
方向:记忆方向:安全隐私方向:评测基准
这是什么给带长期记忆的大模型 Agent 做安全评测：记忆被污染或带偏后，Agent 行为会逐步漂移。MemEvoBench 专门衡量这种“记忆错误进化”。
有什么结果在代表性模型上，有偏的记忆更新会导致明显的安全性下降，基于静态提示词的防御效果不足（摘要未给出具体数值）。
怎么做到构建覆盖 7 个领域、36 类风险的问答任务，以及改编自 Agent-SafetyBench 20 个环境、带噪声工具返回的工作流任务，在多轮交互中混入正常和误导性记忆来模拟记忆演化。
评分依据：Agent 记忆安全评测，与端侧 Agent 的长期记忆模块相关，但不涉及设备或部署；作为首个面向记忆演化安全的基准有一定价值。
