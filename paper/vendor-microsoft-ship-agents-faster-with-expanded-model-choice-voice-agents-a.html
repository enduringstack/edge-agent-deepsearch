Ship agents faster with expanded model choice, voice agents, and continuous optimization

7 官方动态 2026-09-24 · Microsoft / Microsoft
Microsoft方向:云端serving方向:工具调用应用:语音
这是什么Microsoft Foundry 更新，扩充可选模型、把语音智能体做成原生类型，并加入持续优化能力。
有什么结果官方数据：工具检索把 50 个工具的工具箱输入 token 消耗降低 60% 以上，1000 个工具的工具箱降低 97% 以上；语音支持 80 多种语言和 140 多个区域设置；评估覆盖超过 4.4 万个工具和 7000 条查询；客户 Fashable 把实物样品预算降低 60%。
怎么做到语音智能体成为 Foundry Agent Service 的原生类型，可部署到网页、Teams、Teams 电话和基于 Twilio 的电话场景；长时间运行的智能体用框架级检查点在断连后恢复。
评分依据：云端智能体平台更新，工具检索大幅压低 token 消耗这一点对上下文预算紧张的端侧智能体有间接借鉴，但部署形态全在云上。
