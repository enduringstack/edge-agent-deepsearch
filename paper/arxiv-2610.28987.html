PerMIT: Securing Persistent Memory for LLM Agents via Machine-Checked Integrity Theorems and Scalable Community Trust

11 公司项目 2026-10-20 · Tanqiu Jiang; Min Bai; Sadat Shahriar; Wanyu Du; Sandesh Swamy / arXiv
Amazon方向:记忆方向:安全隐私方向:工具调用
这是什么智能体的持久记忆容易被注入和投毒，也让多个智能体之间不敢共享记忆。PerMIT 是一种带可证明完整性保证的智能体记忆架构。
有什么结果在 Trojan Hippo 攻击测试中，配合自我验证和轻量验证器观测到的攻击成功次数为零；在 τ²-bench 上最多 90 个自主智能体用它共建知识库，没有一条直接注入的记忆被提升，生成的知识显著提升了新智能体在未见任务上的表现。
怎么做到只信任用户输入和经“确认门”确认的内容，来自环境的数据只能经有限接口进入记忆；两条完整性定理在 Lean 4 中机器验证，确认记录可跨用户累积背书，足够多背书后成为社区确认知识。
评分依据：属于 Agent 记忆安全的运行时机制，可迁移到端侧智能体，但本身不涉及设备端部署。形式化可证明的记忆完整性加社区背书机制，创新度较高。 作者机构依据：arXiv PDF 首页署名 Amazon（PDF 首页作者 Min Bai、Sadat Shahriar、Wanyu Du、Sandesh Swamy 署名 AWS AI Labs，第一作者在 AWS AI Labs 实习期间完成）。
