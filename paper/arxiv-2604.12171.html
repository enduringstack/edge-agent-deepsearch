PipeLive: Efficient Live In-place Pipeline Parallelism Reconfiguration for Dynamic LLM Serving

8 公司项目 2026-04-14 · Xu Bai; Muhammed Tawfiqul Islam; Chen Wang; Adel N. Toosi / arXiv
IBM方向:云端serving方向:KV cache硬件:GPU
这是什么云端大模型服务的流水线并行切分通常是静态的，想调整就得停服重部署。PipeLive 支持在不中断推理的情况下原地重配流水线并行。
有什么结果与关闭 KV 扩缩相比首 token 时延降低 2.5 倍且无 KV 溢出；与无 KV 补丁的版本相比，重配开销从秒级降到 10 ms 以内，首 token 时延和每 token 时延分别最多改善 54.7% 和 14.7%。
怎么做到重新设计 KV cache 布局并扩展 PagedAttention，实现运行中扩缩 KV；再借鉴虚拟机热迁移，用增量 KV 补丁同步新旧配置并找安全切换点。
