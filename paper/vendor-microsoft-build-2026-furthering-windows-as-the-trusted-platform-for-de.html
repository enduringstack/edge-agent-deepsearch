Build 2026: Furthering Windows as the trusted platform for development

15 官方动态 2026-06-02 · Pavan Davuluri (Microsoft) / Microsoft
Microsoft方向:端侧agent方向:工具调用方向:规划推理方向:推理框架应用:语音硬件:NPU模型:Phi
这是什么微软在 Build 2026 公布 Windows 开发平台更新，核心是两款端侧模型 Aion 1.0：一款给浏览器和系统用的轻量指令模型，一款随 Windows 内置、能在本机推理和调用工具的规划模型，同时把 Windows AI 接口从 NPU 扩展到 CPU 和 GPU。
有什么结果Aion 1.0 Plan 为 140 亿参数、32K 上下文的推理与工具调用模型，将随 Windows 内置在性能足够的设备上；Aion 1.0 Instruct 已在 Edge 预览通道提供，7 月在 Hugging Face 开放权重。新的语音识别接口进入公开预览，可离线在本机转写；内置小模型 Phi Silica 可在 GPU 上运行，视频超分可在 CPU 上运行，语音识别可在 CPU 和 NPU 上运行。
怎么做到系统内置模型按需下载，应用通过 Windows AI 接口调用；Aion 1.0 Plan 让应用在本机完成意图推理、工具调用、文件管理和子智能体编排，形成完全本地的智能体工作流；GitHub Copilot CLI 计划由云端主智能体规划、把合适的子任务分给本地模型执行。
评分依据：Windows 将内置一个专门做本地规划和工具调用的 14B 模型，并把系统 AI 接口扩展到 CPU 和 GPU，直接决定 PC 端侧智能体的系统级底座（相关度 9）。属于平台级产品发布，给出了模型规格但没有公布评测数字（贡献 6）。
