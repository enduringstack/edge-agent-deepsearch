这是什么Meta 的端侧部署运行时 ExecuTorch 发布 v1.5.0，把原来的 Python 包扩成一套 C++ SDK，并明显加强了手机与嵌入式后端的覆盖。

怎么做到发布说明列出：为 CUDA、Core ML、MLX、OpenVINO 和高通 delegate 提供可链接库并打包 TorchAO 算子；LLM 服务支持多方法导出、批量请求调度、可中断取消和图外 KV cache 布局；AOTI CUDA 后端新增 ROCm 与打包 W4 执行；Arm 与 Cortex-M 侧补齐显式布局下降、更多 Ethos-U 目标和 Vulkan 量化执行。
评分依据：ExecuTorch 是端侧部署最主流的运行时之一，这一版同时动了手机 NPU delegate、Cortex-M 微控制器和本地 LLM 服务三条线，对端侧落地影响面很大。
