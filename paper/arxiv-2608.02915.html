LACE: Large Language Model Aided Multi-Agent Framework for Agile RISC-V Instruction Extension

7 学校预印本 开源 2026-08-03 · Pingqing Zheng; Jiayin Qin; Fuqi Zhang; Zishen Wan; Shang Wu; Yu Cao; Caiwen Ding; Yang Katie Zhao / arXiv
方向:工具调用应用:代码
这是什么给 RISC-V 处理器加定制指令扩展时，每换一个核都要重新适配接口和测试。LACE 用大模型多智能体流程，把自然语言描述的指令需求自动改成可验证的 RTL 代码。
有什么结果在四款嵌入式 RISC-V 核上，一次生成通过率从接近 0 提升到 72.8%，同时改善了代码定位并减少集成返工。
怎么做到先把指令需求翻译成操作级和硬件任务级两层中间表示，再在大型代码库中检索定位、做局部 RTL 修改，最后用 riscv-formal 形式化检查闭环验证。
评分依据：工作对象是嵌入式处理器的硬件设计流程，智能体本身运行在云端，与端侧 AI 推理关系较远。代码已开源。
