Mage-VL: An Efficient Codec-Native Streaming Multimodal Foundation Model

12 公司项目 开源 2026-07-27 · Senqiao Yang; Kaichen Zhang; Zhaoyang Jia; Jinghao Guo; Yifei Shen; Xinjie Zhang; Xiaoyi Zhang; Haoqing Wang / arXiv
Microsoft方向:多模态方向:高效推理应用:视频模型:Qwen
这是什么微软发布的流式多模态模型 Mage-VL：直接利用视频编码里的运动信息，只看画面中“动了”的区域，让视觉语言模型能高效地实时看视频并主动反应。
有什么结果视觉 token 消耗减少 75% 以上；Mage-VL-4B 在静态任务上与 Qwen3-VL-4B 持平，视频理解和 2D/3D 空间推理明显更强，在 NExT-QA 上评测墙钟时间从 1460 秒降到 415 秒（3.5 倍加速）且准确率更高，整体超过 15B 的 Phi-4-reasoning-vision。
怎么做到自研的 Mage-ViT 视觉分词器借助编解码器的运动矢量和残差能量，只对关键帧和预测帧里信息量大的块编码；再用“系统 1 轻量事件门 + 系统 2 因果解码器”的双系统结构，由轻量门决定何时唤醒大模型响应。
评分依据：按画面变化稀疏编码视频、用轻量门控决定何时调用大模型，正是端侧持续视觉感知最缺的省算力手段，但论文测速在 8 卡 B200 服务器上，未做端侧部署，相关度中等。编解码原生的视觉分词和双系统流式架构新意明显，且模型开源。作者机构依据 arXiv PDF 首页署名 Microsoft Mage Team。 作者机构依据：arXiv PDF 首页署名 Microsoft（PDF 首页作者署名为 Microsoft Mage Team，代码与模型发布在 microsoft 官方 GitHub 与 Hugging Face 组织）。
