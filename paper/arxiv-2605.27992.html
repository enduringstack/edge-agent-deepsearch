Patched-DeltaNet: Token-Level Event-Driven Memory for Linear-Time Anomaly Detection

12 学校预印本 2026-05-27 · Tae-Gyun Lee; Junyoung Park; Kyu Won Han / arXiv
方向:高效推理方向:模型架构方向:记忆应用:fault-detection
这是什么时序异常检测里 Transformer 效果好但计算量随序列长度平方增长，这篇论文把分块与门控增量网络结合，做成线性复杂度的架构。
有什么结果在 Server Machine Dataset 基准上，在统一评测约束与同等算力预算下严格优于近期架构，ROC-AUC 为 0.957、PA-F1 为 0.822，同时把计算复杂度降到按序列长度除以分块大小的理论下界。
怎么做到分块机制负责抽取局部语义片段，门控增量网络则只在出现显著变化时才更新循环状态，两者结合形成 token 级的事件驱动记忆，从而滤掉背景噪声、抓住突发的异常漂移。
评分依据：明确以资源受限环境下的部署为动机，把平方复杂度降到线性，时序异常检测本身也是边缘设备的高频任务，迁移价值明确，相关度较高；但论文未给设备端实测。贡献在于把两种已有机制组合出事件驱动的状态更新特性。
