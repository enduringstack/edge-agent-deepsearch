KVE-KD: Key Visual Evidence-Guided Knowledge Distillation for Vision-Language Models

10 学校预印本 开源 2026-10-02 · Jianbin Zhang; Xin Sun; Shanwen Wang; Wei Ye; Susanto Rahardja / arXiv
方向:蒸馏方向:多模态模型:Qwen
这是什么想把视觉语言模型压小放到资源受限设备上，常用知识蒸馏让小模型模仿大模型，但对所有视觉 token 一视同仁会让小模型学进大量背景噪声。KVE-KD 只挑出教师模型回答时真正依赖的关键视觉 token 来重点蒸馏。
有什么结果以 Qwen3-VL-8B 为教师、Qwen3-VL-2B 为学生，在六个基准上平均分 79.6，比未蒸馏的学生高 3.9 分，比同设置下复现的 Align-KD 高 1.6 分；MME 感知分提升 174.4，但 POPE 幻觉评测略降（87.5 对 89.2）。推理阶段不增加任何开销。
怎么做到以生成前最后一个文本 token 作为语义锚点，逐步移除视觉 token、观察锚点表示的变化，定位跨模态融合发生的层；在该层按锚点的注意力分布给视觉 token 排序，用归一化熵自适应决定保留多少，作为关键视觉证据，只对这些 token 做特征蒸馏。
评分依据：目标是把视觉语言模型压缩到资源受限设备上，2B 学生模型适合端侧，但没有设备实测，相关度 5。按样本动态选择关键视觉 token 做蒸馏，在 VLM 蒸馏里是较新的思路，贡献 5。
