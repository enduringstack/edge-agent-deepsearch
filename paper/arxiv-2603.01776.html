FreeAct: Freeing Activations for LLM Quantization

11 公司项目 2026-03-02 · Xiaohao Liu; Xiaobo Xia; Manyi Zhang; Ji-Fu Li; Xianzhi Yu; Fei Shen; Xiu Su; See-Kiong Ng / arXiv
Huawei方向:量化方向:多模态
这是什么现有基于正交变换的大模型量化方法对所有 token 用同一套变换，难以适应扩散语言模型和多模态模型里不同类型 token 的激活差异。FreeAct 放松了这一约束。
有什么结果在扩散语言模型和多模态大模型上明显优于基线，性能最多提升 5.3%。
怎么做到利用激活矩阵的秩亏性质，推出比简单逆矩阵更大的解空间，让激活侧可以按 token 类型（如视觉/文本、掩码 token）使用不同变换矩阵，而权重侧保持统一静态变换。
评分依据：大模型低比特量化是端侧部署的基础技术，可迁移性强；针对多模态和扩散模型的动态激活分布做了有针对性的改进。部分作者署名 Huawei Technology。 作者机构依据：arXiv PDF 首页署名 Huawei（首页作者 Manyi Zhang、Ji-Fu Li、Xianzhi Yu 署名 Huawei Technology）。
