DistillGuard: Evaluating Defenses Against LLM Knowledge Distillation

6 学校预印本 2026-03-08 · Bo Jiang / arXiv
方向:蒸馏方向:安全隐私方向:评测基准模型:Qwen
这是什么大模型厂商担心别人通过调用 API 把模型能力「蒸馏」走。这篇搭了一个评测框架，系统比较各类输出层防御到底有没有用。
有什么结果以 Qwen3-14B 为教师、Qwen2.5-7B-Instruct 为学生测试 9 种防御配置：多数防御基本无效，只有去掉思维链能明显削弱数学推理（31.4% 对比基线 67.8%），代码生成仍不受影响。
怎么做到把防御分为输出扰动、数据投毒、信息限流三类，在统一的蒸馏流程和 MATH-500、HumanEval+、MT-Bench 上对比学生模型质量。
评分依据：研究云端模型 API 的防蒸馏保护，与端侧部署关系很弱；评测框架工作量扎实但方法常规。
