Automating Inference Optimizations with NVIDIA TensorRT LLM AutoDeploy

10 官方动态 开源 2026-02-09 · NVIDIA / NVIDIA
NVIDIA方向:编译部署方向:推理框架方向:量化方向:KV cache硬件:GPU硬件:DGX
这是什么TensorRT LLM 新增 AutoDeploy 测试功能：直接把现成的 PyTorch 模型编译成推理优化图，不必为每个新模型手工重写推理代码。
有什么结果已支持 100 多个文本大模型；在单张 DGX B200 GPU 上跑 Nemotron 3 Nano，性能追平人工调优基线，单用户最高 350 token/s、总输出最高 13000 token/s；混合架构的 Nemotron-Flash 几天内完成接入，性能超过人工深度调优的 Qwen2.5 3B Instruct 基线。
怎么做到从 PyTorch 模型自动抽取计算图，再用一系列可复用的编译 pass 自动加上切分、量化、KV cache、注意力融合和 CUDA Graphs，原始 PyTorch 模型始终是唯一的代码来源。
评分依据：编译器驱动的自动部署思路可以迁移到端侧推理框架，但本身面向数据中心 GPU；把手工移植改成自动编译流程，工程价值较高。
