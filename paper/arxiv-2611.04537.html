BtsPruner: Role-Aware Visual Token Pruning for Large Vision-Language Models

10 学校预印本 开源 2026-11-03 · Zihao Qi; Zhibo Zhang; Miaoxin Zhang; Jincheng Cai; Zengqiang Yan / arXiv
方向:剪枝稀疏方向:多模态方向:高效推理
这是什么多模态大模型要处理成百上千个视觉 token，算力和内存开销大。BtsPruner 是免训练的视觉 token 剪枝方法，按 token 在编码过程中扮演的不同角色挑选保留哪些。
有什么结果LLaVA-1.5-7B 只保留 576 个视觉 token 中的 32 个（5.6%）仍保住 91.6% 的性能；高分辨率 LLaVA-NeXT-7B 上 CUDA 时延最高加速 5.95 倍。
怎么做到根据注意力集中度的变化找到 token 从“局部细节”转为“全局代表”的转折层，先从后期层挑出全局代表，再递归从前期层取回互补的局部细节 token。
评分依据：视觉 token 剪枝可直接降低端侧多模态推理开销，但实验在 GPU 上（相关度 5）；按 token 角色分阶段保留是对现有剪枝思路的改进（贡献 5）。作者邮箱来自南京大学和华中科技大学。
