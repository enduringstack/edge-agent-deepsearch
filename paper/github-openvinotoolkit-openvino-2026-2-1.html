11 开源大项目 开源 2026-06-17 · openvinotoolkit / GitHub
方向:推理框架方向:编译部署硬件:NPU硬件:GPU
这是什么OpenVINO 发布 2026.2.1 补丁版，修两个影响端侧部署的问题。
有什么结果版本说明列出两项修复：一是 YOLO26 在 GPU 上编译失败，二是 NPU 插件中共享的底层命令队列会破坏应用与推理优先级。
怎么做到补丁版本只做缺陷修复，不引入新功能；修复点集中在 GPU 编译路径和 NPU 插件的命令队列优先级处理上。
评分依据：OpenVINO 是边缘设备上的主流推理框架，NPU 插件的优先级问题会直接影响端侧推理的实时性，端侧语境明确。属于补丁级缺陷修复，贡献较低。
