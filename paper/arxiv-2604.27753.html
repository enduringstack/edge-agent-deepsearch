Autonomous Traffic Signal Optimization Using Digital Twin and Agentic AI for Real-Time Decision-Making

6 学校预印本 2026-04-30 · Salman Jan; Toqeer Ali Syed; Shahid Kamal; Qamar Wali; Ali Akarma / arXiv
方向:工具调用方向:规划推理应用:IoT命令
这是什么用数字孪生加多智能体大模型来自动调节红绿灯：传感器和边缘计算采集路况，Agent 在孪生体里模拟不同配时方案，再通过 MCP 调用交通管理接口执行。
有什么结果仿真场景中交通流效率 85%（强化学习 80%、固定配时 75%）；平均车辆延误 49 秒，比固定配时少 18%，比强化学习少 9%。
怎么做到三层结构：感知层接入传感器数据，概念层用 LangChain 编排感知、风险、仿真和解释四个 Agent 做决策，行动层通过 MCP 和交通管理 API 下发信号配时。
评分依据：有 Agent 规划与工具调用闭环，但论文只说数据采集借助边缘计算，Agent 决策并未证明在设备端运行，且结果来自仿真。属于常见框架整合。
