MomentKV: Closing the Directional Gap in KV Cache Eviction for Long-Context Inference

11 学校预印本 2026-06-01 · Yu Li; Binxu Li; Tian Lan / arXiv
方向:KV cache方向:高效推理应用:长上下文推理模型:Llama模型:Qwen
这是什么丢弃 KV 缓存时顺手记下被丢那批 token 的统计量，推理时再把它们的影响近似补回来。
有什么结果在 LongBench 和 RULER 上用 LLaMA-3.1-8B-Instruct 和 Qwen3-4B-Instruct 测试，各档缓存预算下都优于所有基线，压缩越激进优势越大。
怎么做到指出输出退化的主因不是被丢 token 的残余注意力质量，而是保留集与丢弃集之间的方向错配——实际被丢的 token 往往与保留的近乎正交。于是对丢弃集维护计数、键均值、值均值和值键协方差这几个小统计量：驱逐时用它们挑出已被摘要充分覆盖的 token 以保持几何规整，推理时又用它们给出被丢注意力输出的闭式一阶近似。
评分依据：KV 缓存驱逐是端侧长上下文推理的关键内存手段，方法轻量可迁移，但实验未涉及设备（相关性 5）。指出「方向错配」这一被忽视的误差来源并给出闭式补偿，角度新颖（贡献 6）。
