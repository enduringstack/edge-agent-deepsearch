SideQuest: Model-Driven KV Cache Management for Long-Horizon Agentic Reasoning

13 公司项目 2026-02-26 · Sanjay Kariyappa; G. Edward Suh / arXiv
NVIDIA方向:KV cache方向:记忆方向:工具调用方向:规划推理模型:GPT
这是什么深度研究这类长时间运行的 Agent 任务里，检索回来的网页 token 把上下文和 KV 缓存撑爆。SideQuest 让推理模型自己判断哪些上下文已经没用，从而压缩 KV 缓存。
有什么结果只用 215 条样本训练模型，在 Agent 任务上峰值 token 用量最多减少 65%，准确率下降很小，优于基于启发式的 KV 缓存压缩方法。
怎么做到把“清理无用上下文”作为与主推理并行的辅助任务交给模型自己完成，避免管理过程产生的 token 污染主推理的记忆。
评分依据：直接针对 Agent 长程推理的 KV 缓存内存瓶颈，思路可迁移到内存紧张的端侧 Agent，但实验基于 GPU 上的 gpt-oss-20b。机构依据：PDF 首页两位作者均署名 NVIDIA。 作者机构依据：arXiv PDF 首页署名 NVIDIA（PDF 首页两位作者均署名 NVIDIA，邮箱为 nvidia.com）。
