Accelerating CPU Speculative Decoding via Unified Graph Execution and Transactional KV Isolation

11 学校预印本 2026-10-17 · Zhangdie Yuan / arXiv
方向:投机解码方向:KV cache方向:推理框架硬件:CPU模型:Llama
这是什么在 CPU 上跑投机解码时，草稿模型和目标模型来回切换、KV 缓存回滚时反复分配内存，开销很大。SubTernary 是专门消除这些开销的 CPU 执行框架。
有什么结果比 llama.cpp 的投机解码快 1.35 倍、比普通自回归解码快 3.99 倍，回滚延迟保持常数级；消融显示系统运行时贡献了 35.0% 的吞吐提升，三值 SIMD 内核再贡献 6.0%。
怎么做到把两个模型编译进同一块内存区并共用常驻线程池，投机 token 写到固定暂存区，回滚时只需重置指针、不重新分配内存；另外加了一个 AVX2 三值低比特计算内核作为示例。
评分依据：CPU 上的投机解码与 KV 回滚优化可直接迁移到 PC 和端侧 CPU 推理，但实验在服务器级 Xeon 虚拟机上完成。属于扎实的工程优化，方法新意中等。
