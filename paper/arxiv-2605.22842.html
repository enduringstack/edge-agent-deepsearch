The Misattribution Gap: When Memory Poisoning Looks Like Model Failure in Agentic AI Systems

9 学校预印本 开源 2026-05-12 · Tanzim Ahad; Ismail Hossain; Md Jahangir Alam; Sai Puppala; Syed Bahauddin Alam; Sajedul Talukder / arXiv
方向:记忆方向:安全隐私应用:RAG
这是什么多 Agent 系统出问题时，人们通常怪模型没对齐。这篇指出记忆层投毒造成的异常行为看起来和模型故障一模一样，防御者会用错补救手段，并提出检测和防御方法。
有什么结果64 个记录在案的失效案例中，归因系统都把锅甩给了模型；4 个安全分类器在 510 个检查点上零检出；65 个有效案例中有 59 个 Agent 明确引用了被注入的文档。反事实组合测试能以 87.5% 准确率、零误报定位到注入条目，跨会话信息流控制可拦截 97% 的攻击。
怎么做到攻击者把伪装成制度文件的文档正常上传到共享向量库，来源信息在流转中丢失后，它被当成可信系统上下文召回；防御端用反事实组合测试找出肇事记忆条目，并在跨会话边界做信息流控制。
评分依据：研究 Agent 长期记忆的安全问题，对任何带持久记忆的 Agent（包括端侧）都有参考，但实验场景是云端多 Agent 流水线。提出新的失效路径并给出可量化的检测与防御，有一定新意。
