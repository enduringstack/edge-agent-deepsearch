这是什么PyTorch 官方端侧推理框架 ExecuTorch 发布 v1.2.0，把实时语音模型、单片机和更多手机/嵌入式加速器纳入端侧部署范围。
有什么结果未报告
怎么做到新增 Voxtral Realtime 流式语音、Qwen3.5（0.8B/2B/4B）、Parakeet、Silero VAD 等模型导出；Cortex-M 成为一等目标并接入 CMSIS-NN；Metal 后端支持 4 位量化，Vulkan 支持 int8；高通 QNN 新增面向硬件的量化器、CDSP 直连模式和长上下文 attention sink；Arm Ethos-U 支持大模型；编译期优化缩小二进制，并支持 LoRA 端侧个性化。
评分依据：版本内容几乎全部服务端侧部署：覆盖单片机、手机 NPU/DSP、Apple GPU 和嵌入式 NPU，是端侧推理主力框架的一次大版本；主要是工程整合，没有单点算法创新。
