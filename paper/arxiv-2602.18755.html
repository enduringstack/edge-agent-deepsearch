DualScale: Energy-Efficient Disaggregated LLM Serving via Phase-Aware Placement and DVFS

8 学校预印本 2026-02-21 · Omar Basit; Yunzhao Liu; Z. Jonny Kong; Y. Charlie Hu / arXiv
方向:云端serving方向:能耗功耗方向:调度服务硬件:H100模型:Llama
这是什么预填充与解码分离部署的大模型服务很耗电，DualScale 同时调度两类 GPU 的放置和频率，在满足时延指标的前提下省电。
有什么结果在 16 张 H100 上用生产风格流量服务 Llama 3.3 70B，满足首 token 和逐 token 时延目标，同时相比 DistServe 预填充阶段节能最多 39%、解码阶段最多 48%。
怎么做到粗时间尺度上按阶段决定 GPU 放置和基准频率；细时间尺度上预填充用模型预测控制、解码用基于时延余量的轻量调节，逐迭代调整 GPU 频率。
评分依据：纯数据中心的分离式大模型服务能耗优化，与端侧只有宽泛关联；把放置和动态调频按两个时间尺度联合优化有一定工程新意。
