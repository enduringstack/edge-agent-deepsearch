RhinoVLA Technical Report

17 学校预印本 开源 2026-06-05 · Huixi Technology; :; Chen Zhang; Chenyang Zhou; Guanglei Ding; Guanghui He; Haibin Gao; Jiajia Chen / arXiv
应用:机器人方向:编译部署方向:高效推理方向:多模态模型:Qwen
这是什么一个面向部署的机器人视觉语言动作模型，和一颗端侧芯片协同设计，目标是在机上跑到实时闭环控制所需的帧率。
有什么结果下游表现与同参数量级的对照模型相当，同时在该端侧芯片上达到每秒 11.69 次的端到端推理，满足 10 Hz 的实时闭环控制目标；项目计划开源。
怎么做到作者先定位出视觉和上下文 token 是部署时延的主要来源——在模型维度固定时，投影算子的计算量随输入 token 数线性增长；据此采用 token 高效的 Qwen3-VL 底座和连续动作专家来压低视觉侧的 token 与计算负担。为支持跨机器人学习，还设计了视角注册表、72 维物理状态动作槽位空间和按机器人实例的低秩适配组成的统一接口。部署侧则通过硬件感知编译、混合精度执行和并行视觉编码来优化。
评分依据：模型与端侧芯片协同设计，并在该芯片上实测达到实时闭环控制所需帧率，端侧契合度最高；作者机构未在论文元数据中给出可核验的一手署名证据，因此暂按预印本档收录。从 token 预算出发反推架构选择，再配硬件感知编译，是完整的软硬协同路径。
