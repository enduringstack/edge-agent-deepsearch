Run AI Models for Edge Application Development with Just a Few Commands

13 官方动态 开源 2026-10-30 · NVIDIA / NVIDIA
NVIDIA方向:推理框架方向:投机解码方向:编译部署硬件:Jetson硬件:GPU
这是什么英伟达的教程：用 TensorRT Edge-LLM 这套轻量 C++ 推理运行时，在 DGX Spark 64GB 上几条命令就能把模型下载、编译成引擎并跑起来，开发完的同一套推理框架可直接部署到 Jetson Thor、DRIVE AGX Thor、IGX Thor 等嵌入式平台。
有什么结果在 DGX Spark 64GB 上跑 Nemotron-3.5 Lightning（NVFP4、批大小 1）：开启 DSpark 投机解码（3 个草稿词元）后，HumanEval 提示的平均生成速度从每秒 73.4 个词元提升到 126.9 个，SpeedBench 1K/2K 从约 73 提升到 108.5/105.3，首词元时延基本不变，推理峰值内存 27.9GB（含系统）。
怎么做到trtedge 命令行工具自动下载模型并构建 TensorRT 引擎，可本地对话或起一个 OpenAI 兼容的本地 API 服务；再挂上 DSpark 草稿模型，让它一次猜几个词元交给主模型一次性验证，从而加速生成。
评分依据：这是面向车载、机器人和边缘设备的端侧大模型推理运行时，开发机与 Jetson Thor 等目标设备共用同一套框架，端侧相关度高；方法本身是工程化封装加投机解码，创新度中等，但给出了可复现的实测数字。
