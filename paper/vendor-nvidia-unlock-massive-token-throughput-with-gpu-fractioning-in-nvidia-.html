Unlock Massive Token Throughput with GPU Fractioning in NVIDIA Run:ai

5 官方动态 2026-02-18 · NVIDIA / NVIDIA
NVIDIA方向:云端serving方向:调度服务硬件:GPU模型:Phi
这是什么英伟达与 Nebius 联合测试 Run:ai 的 GPU 切分调度：把一块 GPU 分给多个大模型推理实例共用，看能多服务多少用户、时延会不会变差。
有什么结果用 0.5 块 GPU 即可拿到整卡 77% 的吞吐和 86% 的并发用户数，首 token 时延保持在 1 秒内；Phi-4-Mini 这类小模型用 0.25 块 GPU 时并发用户最多翻倍；聊天、推理、嵌入模型混部后系统总用户数接近 3 倍。
怎么做到Run:ai 调度器按用户声明的显存需求动态切分 GPU，运行时隔离显存、公平分配算力，并按并发和 token 时延自动扩缩容；测试在 64 块 H100 NVL 和 32 块 HGX B200 集群上进行。
评分依据：属于云端多模型推理调度，与端侧无直接关系；小模型共享加速器、混部互不干扰的结论对边缘服务器部署有一点参考价值。
