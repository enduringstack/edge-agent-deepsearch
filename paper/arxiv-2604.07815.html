AsyncTLS: Efficient Generative LLM Inference with Asynchronous Two-level Sparse Attention

10 公司项目 2026-04-09 · Yuxuan Hu; Jianchao Tan; Jiaqi Zhang; Wen Zan; Pingwei Sun; Yifan Lu; Yerui Sun; Yuchen Xie / arXiv
Meituan方向:稀疏注意力方向:KV cache应用:长上下文推理模型:Qwen
这是什么长上下文推理既有注意力平方复杂度，又有 KV cache 占满显存的问题。AsyncTLS 用两级稀疏注意力加异步卸载，在精度和速度之间取平衡。
有什么结果在 Qwen3 和 GLM-4.7-Flash（覆盖 GQA 与 MLA 结构）上精度与全注意力相当，算子加速 1.2-10 倍，在 48k-96k 上下文下端到端吞吐提升 1.3-4.7 倍。
怎么做到先按块粗筛、再在块内按 token 细选，兼顾精度和索引开销；同时利用时间局部性，把 KV cache 的搬运与计算异步重叠。
评分依据：稀疏注意力加 KV cache 卸载是端侧长上下文推理的关键技术，可直接迁移，但实验在服务器 GPU 上进行。方法是块级与 token 级稀疏的组合，工程整合为主。 作者机构依据：arXiv PDF 首页署名 Meituan（PDF 首页多位作者（含第二作者 Jianchao Tan）署名 Meituan, Beijing）。
