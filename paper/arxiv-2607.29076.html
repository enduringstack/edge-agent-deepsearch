Selective KV Cache Protection for Noise-Resilient LLM Inference on Analog Compute-In-Memory Systems

15 学校预印本 2026-07-31 · Yuannuo Feng; Wenyong Zhou; Yuang Ma; Yizhe Chen; Wenshuai Yao; Yuxin Xie; Ngai Wong; Wang Kang / arXiv
方向:KV cache方向:能耗功耗硬件:CIM
这是什么模拟存内计算芯片很适合低功耗跑大模型，但 KV cache 要反复写入，噪声会把注意力计算搞坏。这篇首次系统研究了这个问题，并只对最怕噪声的少量 token 做数字化保护。
有什么结果在九个大模型上，模拟噪声下的平均困惑度从 33.91 降到 11.95，接近无噪声的 11.06；动态 KV 的编程行利用率从 23.1% 提升到 91.2%。
怎么做到发现开头的 sink token 和最近的 token 对噪声最敏感，就把它们放在高精度数字通路，其余大部分 KV 留在模拟阵列上；再用协同调度器安排模拟写入、所有权切换和批量矩阵乘，压住数字通路开销。
评分依据：面向低功耗模拟存内计算的大模型推理，是端侧硬件路线的直接问题，但结果基于噪声建模评测而非流片实测；按 token 分级保护加软硬协同调度的思路新颖、收益明显。
