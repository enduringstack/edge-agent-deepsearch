How Many Visual Tokens Do Multimodal Language Models Need? Scaling Visual Token Pruning with F^3A

10 学校预印本 开源 2026-05-09 · YiJie Huang; Yiqun Zhang; Zhuoyue Jia; Xiaocui Yang; Junzhao Huang; Zihan Wang; Shi Feng; Daling Wang / arXiv
方向:剪枝稀疏方向:多模态方向:高效推理
这是什么多模态大模型把大量图像 token 喂给语言模型，推理成本很高。这篇研究到底需要多少视觉 token，并提出免训练的视觉 token 剪枝方法 F^3A。
有什么结果未报告
怎么做到在图像 token 进入语言模型之前，先根据问题生成轻量线索，用冻结的稀疏感知头把线索对应到图像网格，再按粗定位、局部细化、保覆盖竞争和补回漏掉区域的顺序分配固定的 token 预算，不需要训练也不多跑一次大模型。
评分依据：视觉 token 剪枝能直接降低多模态模型推理开销，对端侧 VLM 有迁移价值，但论文没有端侧设备实验，摘要也未给出具体数字。把剪枝看成按问题搜证据的思路有一定新意，但仍属常见的免训练剪枝方向。
