How Many Visual Tokens Do Multimodal Language Models Need? Scaling Visual Token Pruning with F^3A

10 学校预印本 开源 2026-05-09 · YiJie Huang; Yiqun Zhang; Zhuoyue Jia; Xiaocui Yang; Junzhao Huang; Zihan Wang; Shi Feng; Daling Wang / arXiv
方向:剪枝稀疏方向:多模态方向:高效推理模型:Qwen
这是什么多模态大模型要把大量图像 token 喂给语言模型，推理成本很高。这篇研究到底需要保留多少视觉 token，并提出一种免训练的视觉 token 剪枝方法 F³A。
有什么结果在 Qwen3-VL 2B 到 235B 共 10 个模型、11 个多模态基准上，只保留 20% 视觉 token 时平均保住全量 token 93.86% 的性能，所有模型和保留比例下都优于 FastV、VisionZip、DivPrune、CDPruner；要达到全量 97% 的性能平均只需 39.9% 的 token，最强基线需要 50.1%。在 Qwen3-VL-8B 单卡上，20% 保留率时端到端时延从 354.7 ms 降到 274.3 ms，提速 1.29 倍。
怎么做到在图像 token 进入语言模型之前，先根据问题生成轻量线索，用冻结的稀疏感知头把线索对应到图像网格，再按粗定位、局部细化、保覆盖竞争和补回漏掉区域的顺序分配固定的 token 预算，不需要训练也不多跑一次大模型。
评分依据：视觉 token 剪枝能直接降低多模态模型的预填充和 KV cache 开销，对端侧 VLM 有迁移价值，但实验都在服务器 GPU（H200）上进行，没有端侧设备测试，相关度 5。把剪枝看成按问题搜证据的思路有一定新意、跨规模评测扎实，但仍属常见的免训练剪枝方向，贡献 5。代码已开源。
