Tencent/ncnn: riscv: unified elempack optimization for im2col gemm and winograd convolution (#6740)

12 开源大项目 开源 2026-05-25 · Tencent / GitHub
方向:推理框架方向:高效推理方向:编译部署硬件:CPU
这是什么ncnn 合入 RISC-V 平台卷积计算的统一打包优化。
有什么结果未报告。该提交只公开了代码规模：涉及 32 个文件、新增 15384 行。
怎么做到把 im2col 加矩阵乘和 Winograd 两条卷积实现路径上的数据打包方式统一起来，让 RISC-V 向量指令可以用同一套排布处理，减少重复的排布转换代码。
评分依据：RISC-V 是嵌入式与物联网设备的重要指令集，卷积算子打包优化直接服务于这类端侧硬件，契合度高。贡献上是引擎内部的算子工程重构。
