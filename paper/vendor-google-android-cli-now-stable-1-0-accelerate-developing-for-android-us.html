Android CLI Now Stable 1.0: Accelerate developing for Android using any agent

7 官方动态 2026-05-19 · Google / Google
Google应用:代码方向:工具调用
这是什么安卓命令行工具发布 1.0 稳定版，目的是让任意 AI 智能体都能顺手做安卓开发。
有什么结果未报告量化数值。官方强调的是能力范围，比如新增的 android studio 子命令可以让智能体调用 Android Studio 积累十余年的静态分析、重构和界面渲染能力。
怎么做到命令行提供文件分析、查找符号声明与引用、渲染 Compose 预览、查依赖版本等子命令，并通过新的子命令把智能体接到 Android Studio 的工具能力上；官方明确做成与智能体无关，Gemini、Antigravity 2.0、Claude 和 Codex 都能用。
评分依据：工具跑在开发者本机，但驱动它的智能体通常是云端模型，不涉及端侧推理，端侧相关性低。把 IDE 能力以命令行方式暴露给任意智能体，是比较实用的接口设计。
