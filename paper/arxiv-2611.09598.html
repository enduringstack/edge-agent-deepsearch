Transformer-FSQ: Discrete Latents for Extreme KV-Cache Compression

14 学校预印本 开源 2026-11-06 · Andras Szecsenyi; Thomas L. Lee; Vaisakh Shaj; Elliot J. Crowley; Amos Storkey / arXiv
方向:KV cache方向:量化应用:长上下文推理模型:Qwen硬件:GPU
这是什么想在本地消费级设备上跑私有长上下文模型，KV cache 往往比模型本身还大。这篇论文把 KV 投影换成有限标量量化瓶颈，让缓存直接存整数码，把 KV cache 压缩到几十倍甚至近百倍。
有什么结果在 0.6B–8B 模型上与五类基线比较，压缩率 12 倍到 97.5 倍区间内 RULER 长上下文检索精度均为最高；融合 Triton 内核在 Qwen3-8B-Base 上 32 倍压缩时解码吞吐为原生 SDPA 的 1.01 倍、97.5 倍压缩时为 1.54 倍；按论文测算，16 GiB 显卡放下 Qwen3-8B 后可存的 token 从约 5.4k 增至 139 万。
怎么做到用有限标量量化（FSQ）替换原来的 K/V 投影，每个 token 只存一组打包整数码、不需要额外量化元数据；改造预训练模型时只训练这些投影（训练 token 数约为原参数量的 0.25 倍），解码时内核直接读整数码计算注意力。
评分依据：明确以本地消费设备上的长上下文为目标，极限 KV 压缩可直接迁移到端侧大模型，但实测在桌面 GPU 上完成、没有手机或 NPU 数据，因此相关度中等偏上；把 KV 压到近百倍且精度领先、内核不掉速，贡献突出，代码已开源。
