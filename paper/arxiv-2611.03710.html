te-comp: A Complete MLIR Compiler Generating Self-Contained C Inference Engines for MCUs

16 学校预印本 2026-10-31 · Van Chan Ngo / arXiv
方向:编译部署方向:推理框架方向:量化方向:KV cache硬件:MCU
这是什么想在只有几百 KB 内存的单片机上跑神经网络，现有方案要么带解释器和内核库，要么依赖 Python 代码生成加手写内核。te-comp 是一个基于 MLIR 的完整编译器，直接把模型编译成不依赖任何运行库的纯 C 推理引擎。
有什么结果在 10 个 MCUNet 卷积网络基准上，比 MCUNet TinyEngine 平均少用 38% SRAM（最多 5.9 倍）和 15% Flash；把 830 万参数的 GPT-Neo（TinyStories-v2）部署到 160MHz 单核 Cortex-M7 上，固件占 512KB SRAM 中的 249KB、4MB Flash 中的 3.62MB，可交互生成约每秒 1 个词元。
怎么做到输入 .tflite 或 .safetensors 模型，经 MLIR 多层方言做权重常驻 Flash、原地深度卷积、算子特化和内存规划等优化，再生成内核、权重数组、内存布局和 RTOS 集成层全部 C 源码；针对语言模型还加了 Q4_0 权重量化、有状态 int4 KV 缓存和词表裁剪。
评分依据：直接面向 MCU 级端侧部署，并在 Cortex-M7 真机上跑通了小型语言模型，端侧契合度很高（相关度 9）。从标准模型格式一步生成零依赖 C 推理引擎、并覆盖语言模型专用优化，是 MCU 编译栈上少见的完整方案（贡献 7）。作者署名 TeComp AI，属个人或小型初创公司，不在公司名单内，未标注公司归属。
