Turn your REST APIs into MCP tools with Google Cloud API Gateway

6 官方动态 2026-09-24 · Google / Google
Google方向:工具调用方向:云端serving
这是什么Google Cloud API Gateway 开始支持 MCP 协议，已有的 REST 接口加上注解就能变成智能体可以调用的工具。
有什么结果官方说明单个网关最多支持 1000 个工具，要求 OpenAPI 3.0.x 或 3.1.x，不支持 2.0。
怎么做到网关在 /mcp 端点上提供 MCP 的 JSON-RPC 服务，把 tools/call 转成对应的 REST 调用，沿用既有的 JWT 或 API key 鉴权、配额和日志策略，再把响应翻译回 MCP 格式。
评分依据：云端网关的工具接入能力，与端侧部署没有直接关系；对了解 MCP 工具生态的服务端一侧有参考价值。
