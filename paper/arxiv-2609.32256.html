LAM: Efficient Lossy Agent Memory Framework With A Retrieval-Score Error Bound

11 公司项目 2026-09-26 · Baixi Sun; Le Chen; Anjir Ahmed Chowdhury; Xiaolong Ma; Chih-Hsuan Yang; Mingze Xia; Syed Zawad; Sheng Di / arXiv
IBM方向:记忆方向:KV cache应用:长上下文推理应用:代码模型:Qwen模型:Llama
这是什么智能体在读输入、推理、调工具的过程中记忆越积越多，推理成本不断上升，最终超出上下文窗口；用大模型做摘要又会增加时延，而且说不清丢了多少信息。LAM 是一个有损的智能体记忆系统，删掉冗余记录的同时给出检索分数误差的上界。
有什么结果在 600 条智能体轨迹上去掉 22.47% 的观测 token，同时保留 99.984% 的标准补丁证据；在删除集固定时，性能模型预测“在预填充前删除记录”比“从已预填充的上下文里删除”端到端快 71.4–91.6 倍，这一收益来自调度方式而不是去重规则本身。
怎么做到由三部分组成：一条带检索分数替换误差上界的确定性去重规则；一个保留已缓存前缀、并让压缩与推理重叠执行的记忆管理器；一个在部署前估算压缩开销的性能模型。
