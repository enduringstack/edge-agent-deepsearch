NVIDIA Nemotron 3 Nano Omni Powers Multimodal Agent Reasoning in a Single Efficient Open Model

11 官方动态 开源 2026-04-28 · NVIDIA / NVIDIA
NVIDIA方向:多模态方向:MoE方向:量化方向:高效推理应用:OCR应用:视频应用:语音硬件:GPU
这是什么NVIDIA 开源 Nemotron 3 Nano Omni，一个能同时看图、看视频、听音频、读文档的推理模型，用来替代智能体系统里各自独立的视觉、语音、文本模型，充当“眼睛和耳朵”。
有什么结果在 MMlongbench-Doc、OCRBenchV2 等文档理解榜和 WorldSense、DailyOmni、VoiceBench 等音视频榜领先；在固定交互速度下，视频推理有效系统容量最高为其他开放全模态模型的 9.2 倍，多文档推理为 7.4 倍。
怎么做到采用 30B 总参数、每次只激活约 3B 的混合专家架构，把视觉和音频编码器并入同一模型，支持 FP8 和 NVFP4 量化及高效视频采样，并给出 vLLM、SGLang、TensorRT-LLM 部署配方。
评分依据：3B 激活参数加低比特量化让它具备在本地工作站或边缘服务器部署的潜力，对端侧多模态感知有迁移价值；但官方评测和部署场景以数据中心 GPU 为主。
