When KV Cache Reuse Fails in Multi-Agent Systems: Cross-Candidate Interaction is Crucial for LLM Judges

11 公司项目 2026-01-13 · Sichu Liang; Zhenglin Wang; Jiajia Chu; Pengfei Xia; Hui Zang; Deyu Zhou / arXiv
Huawei方向:KV cache方向:高效推理方向:评测基准
这是什么多智能体系统常让一个大模型当裁判，从多个候选答案里挑最好的；为了省预填充开销，大家开始复用各候选的 KV cache。这篇指出这种复用对“裁判”场景并不安全。
有什么结果在 GSM8K、MMLU、HumanEval 上，复用策略下最终准确率看似稳定，但裁判的选择与完整预填充时高度不一致（用新提出的裁判一致率 JCR 衡量），越靠后的候选块受影响越大。
怎么做到把复用 KV cache 与完整预填充的裁判决策逐一比对，再分析注意力分布，发现复用削弱了候选之间的交叉注意力；消融实验表明显式保留候选间交互才能保住原决策。
评分依据：KV cache 复用是端侧和云端都在用的推理加速手段，本文揭示其在多智能体裁判场景下的隐性失效，可迁移到资源受限的多智能体推理设计，但未涉及端侧部署（相关度 5）。属于有价值的问题发现而非新系统（贡献 6）。 作者机构依据：arXiv PDF 首页署名 Huawei（arXiv HTML 首页作者 3、4、5（含通讯作者 Hui Zang）署名 Huawei Technologies Ltd）。
