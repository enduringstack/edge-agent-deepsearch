Pallas: A Proactive KV Cache Migration Framework for LLM Inference in AI-RAN

10 学校预印本 2026-08-17 · Tianhang Ding; Jianchun Liu; Hongli Xu / arXiv
方向:KV cache方向:调度服务方向:端云协同硬件:GPU模型:Qwen模型:Llama
这是什么AI-RAN 把大模型推理放到基站旁的边缘服务器上服务手机用户，但用户切换基站时，正在生成的请求的 KV cache 还留在原基站。Pallas 在切换发生之前就把推理状态提前准备到预测的目标基站，减少服务中断。
有什么结果基于 vLLM 的原型部署在两台各配一块 RTX A6000 的服务器上，在 3 个模型和 100–500 Mbps 基站间链路下测试：平均服务中断时间比目标侧恢复方案缩短 2.28–89.68 倍，平均逐 token 时延比源侧转发方案降低 16.0%–50.0%。
怎么做到开始准备时把已生成的序列切成稳定的历史前缀和仍在增长的后缀：目标基站自己对前缀做预填充重建，源基站把后缀的 KV 块边生成边发过去；切换时两部分拼成最新 KV cache 后在目标基站继续解码，提前多久开始准备由在线调度器按移动性预测和运行时遥测决定。
评分依据：服务对象是移动用户，但推理跑在基站侧 GPU 服务器上，属于边缘 serving 与 KV cache 管理技术，可迁移但不是终端部署（相关度 4）。把 KV 迁移提前到切换之前、前缀重算与后缀传输并行，是针对移动网络场景的新思路（贡献 6）。
