ONNX Runtime v1.25.0

11 开源大项目 开源 2026-04-20 · microsoft / GitHub
方向:推理框架方向:量化方向:编译部署硬件:CPU硬件:GPU
这是什么微软 ONNX Runtime 发布 1.25.0 版，这个跨平台推理引擎在 CPU、GPU、浏览器和移动端执行后端上都有更新，并修了一批安全漏洞。
有什么结果未报告
怎么做到引入可动态加载的 CUDA 插件执行后端和模型包预览（按设备自动挑选已编译模型）；WebGPU 后端加入子组矩阵乘、2 比特权重和 Flash Attention 改进；ARM64 上加入 KleidiAI SME2 内核和非对称 4 比特矩阵乘；Android 加入 16KB 页对齐；同时移除 ArmNN 后端。
评分依据：ONNX Runtime 是手机和 PC 上常用的推理引擎，本版的 ARM 4 比特内核、WebGPU 量化矩阵乘和 Android 适配都直接服务资源受限设备；不过属于常规版本迭代，发布说明只列改动、没有给性能数字，所以效果写未报告。
