What Makes Agent Memory Useful for Reliable Unanswerable Question Handling?

10 学校预印本 2026-08-28 · Chuanyuan Tan; Junjie Yu; Yuxin Wang; Yining Zheng; Xipeng Qiu; Wenliang Chen / arXiv
方向:记忆方向:评测基准应用:RAG
这是什么这项研究系统比较智能体在处理不可回答问题时的四种记忆方法，分析什么样的记忆能稳定帮助智能体拒答或作出可靠判断。
有什么结果未报告
怎么做到研究在统一的智能体 RAG 框架下，对三个数据集和两个基础模型测试不同记忆表示、决策指导、轨迹塑形及记忆组合方式。
评分依据：可靠且紧凑的过程式记忆可迁移到端侧 Agent 和 RAG，但论文重点是行为可靠性与迁移规律，没有设备端部署或资源收益证据。
