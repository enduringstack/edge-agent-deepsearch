Selective Forgetting: A Graph-Based Memory Framework for Long-Term LLM Agents

10 学校预印本 开源 2026-08-29 · Theo Rusu; Sourena Khanzadeh; Manar Alalfi / arXiv
方向:剪枝稀疏方向:记忆方向:评测基准应用:RAG
这是什么这项工作检验图结构是否真的能改善对话记忆，并提出选择性遗忘策略，在尽量不损伤回答质量的前提下缩小长期记忆。
有什么结果图记忆的 token F1 为 0.417，低于扁平向量记忆的 0.468；在定位指定助手轮次时分别为 0.607 和 0.911。选择性遗忘删除了 9.8% 的节点、减少 9.5% 的存储字节，token F1 变化仅为 0.001，评审正确率下降 1.6 个百分点。
怎么做到系统把记忆表示成带类型的节点和边，进行两跳检索，并依据新近度、访问频率、中心性和年龄的加权分数周期性裁剪节点。
评分依据：受控遗忘能帮助资源受限 Agent 管理长期内存，但研究没有设备端部署，相关性中等；论文给出了图记忆的负面证据及可量化裁剪方案，贡献度中等。
