When Quantization Breaks Memory: Recurrent-State Write-Back

9 学校预印本 2026-09-03 · Ismail Erbas, Xavier Intes, Vikas Pandey / arXiv
方向:量化方向:编译部署
这是什么发现量化后的循环状态写回模型会导致精度崩塌（0.94降到0.39），对所有带持久状态的量化部署都是关键警示。
有什么结果量化隐状态写回后在后续步骤被读取，误差逐步累积，精度从0.94崩塌到0.39。
怎么做到每一步把量化后的隐状态写回循环记忆，下一步读取的是已经带量化误差的值，误差在多步推理中指数放大，导致灾难性精度下降。
